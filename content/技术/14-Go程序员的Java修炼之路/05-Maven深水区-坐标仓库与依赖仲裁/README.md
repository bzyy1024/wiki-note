## 原章开头引子

> 那个订单服务你终于跑起来了。`mvn spring-boot:run` 打出 `Started OrderApplication in 4.2 seconds` 的那一瞬间，你松了口气。
>
> 但你心里还挂着三个结。第一个：你在 `order-web/pom.xml` 里只写了 9 个依赖，`mvn dependency:tree` 却吐了 87 行 —— 多出来的 78 个是哪来的？第二个：你在 `order-core` 里写了个 `mybatis` 依赖，**没写版本号**，它居然编译通过了，版本是谁给它的？第三个最邪门 —— 周三下午同事往 `order-web` 里加了个报表 SDK，周四早上一个跑了三个月没出过事的订单详情接口开始报 `NoSuchMethodError`。
>
> 这三件事是同一件事。这一章把它们一起解决。
