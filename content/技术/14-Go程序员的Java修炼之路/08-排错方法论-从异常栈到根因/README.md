## 原章开头引子

> 凌晨两点，告警响了。你打开日志，看到一个 200 行的异常栈，最上面是你从没见过的类，中间全是框架的包名（`org.apache.catalina`、`org.springframework`、`sun.reflect`），最下面一行 `Caused by: java.lang.NullPointerException` 后面跟着你自己代码的某一行 —— 但那行代码看起来不可能 NPE。
>
> 这一章不教你读异常栈（那个你半天就会）。这一章教你**在没有源码、没有文档、前任已离职的情况下，用一套固定的动作，在 30 分钟内把"不知道哪错了"收敛到"知道是哪个类的哪一行"**。
