# Rust 程序员硬核修炼手册

> 墨叔陪你从零把 Rust 啃透。不假设你是 Go 程序员，不写对照表；读者默认是有几年经验的程序员，但 Rust 从第一性原理讲起、讲到深。
> 叙事风格：导师 vs 读者对谈，多反问、生活化比喻、讲设计意图。每章章末都有【思考题】+【参考答案】——答案当学习材料看，不是测验。

## 这本书在讲什么

Rust 选了内存安全的第三条路：**编译期保证、零运行时开销**。它的严格不是找茬，是把你从内存 bug 的提心吊胆里解放出来。全书的因果链只有一条：

**无 GC 又要安全 → 必须有明确的所有权 → 唯一主人催生 move → move 带来"只想借"的需求催生借用 → 借用需要"借多久"的约束催生生命周期 → 这一整套在并发下升级成"消灭数据竞争" → unsafe / 宏 / 零成本抽象是给硬核场景留的口子。**

顺着这条链读，规则不是背下来的，是自己长出来的。

## 怎么读

- **必啃**：第二、三、四章（所有权 / 借用 / 生命周期）。这三章是地基，慢一点没关系，后面全靠它。
- **可跳**：第十二章（模块化与 crate）如果你已熟悉 Cargo，可只扫一遍；第十八章（实战）建议跟着敲一遍。
- **别跳**：第十三章（并发）是前面所有知识的"兑现时刻"——你会发现严格原来是为了这个。
- 每章章末的【思考题】先自己推，再看【参考答案】。参考答案写的是推导过程，不是结论。

Rust 的严格不是限制你的自由，是把你从内存安全的担惊受怕里解放出来。带着"清醒地正确"这个心态上路，那个苛刻的编译器，其实是你请到的最靠谱的搭档。
