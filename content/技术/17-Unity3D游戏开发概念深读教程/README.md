# 《Unity3D 游戏开发概念深读教程》总览

一份用**溯源学习法**写给"懂编程、但不懂游戏/图形/音频底层"的你的概念地图。

核心主张：不要背参数，要理解"为什么需要它"。每一章固定走：

```
自然现象  →  现实中遇到的问题  →  工程师拿出的方案  →  方案落进引擎成了哪些参数
```

读完任意一章，你应能回答三句话：它对应现实里的什么？没有它会出什么岔子？引擎给了哪几个旋钮对付它？

## 怎么开始
1. 先读 **[00-导读.md](00-导读.md)** —— 学习方法、目录、以及"100 万字够不够"的实话。
2. 按目录顺序读各章；每章末尾的【思考题】先自己想，再看【参考答案】。
