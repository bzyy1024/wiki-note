## 贯穿全章的核心问题

### 问题 1：架构师做什么？

**不是画架构图。** 架构图只是决策的记录。

**架构师的核心工作是：在约束条件下做决策，并为决策的后果负责。**

```
约束:
  · 业务需求（功能、性能、成本）
  · 团队能力（几个人？什么水平？）
  · 时间（什么时候上线？）
  · 技术现状（已有什么？能用什么？）

决策:
  · 用什么技术？
  · 怎么拆分模块？
  · 数据怎么存？
  · 服务怎么通信？
  · 出错了怎么办？

★ 每一个决策都会在未来产生后果
★ 架构师的价值 = 决策质量 × 决策的影响范围
```

### 问题 2：为什么音视频值得学

**因为它是最"吃基础设施"的系统。**

```
一条直播链路涉及：
  采集 → 前处理 → 编码 → 封装 → 传输 → 解封装 → 解码 → 后处理 → 渲染

★ 涉及 8 个环节，每个都有专门的算法和标准
★ 涉及 CPU、GPU、网络、存储的极限
★ 涉及延迟与质量的艰难权衡

★ 学完音视频，你对"系统设计"的理解会上升一个层次
  因为它逼着你同时考虑：计算密集、IO 密集、实时性、带宽限制
```
