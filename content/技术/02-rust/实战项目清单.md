## 项目 1: 命令行 grep 工具

**对应章节:** 01, 02, 03  
**预估时间:** 3-5 天  
**难度:** ⭐⭐

### 功能需求

```
minigrep [选项] <pattern> <文件...>

选项:
  -i, --ignore-case     忽略大小写
  -n, --line-number     显示行号
  -c, --count           只显示匹配行数
  -r, --recursive       递归搜索目录
  -v, --invert          反向匹配
  --color               彩色输出

示例:
  minigrep "fn main" src/main.rs
  minigrep -r -i "todo" src/
  minigrep -n "error" logs/app.log
```

### 技术架构

```
src/
├── main.rs         # CLI 解析 + 入口
├── lib.rs          # 库接口
├── search.rs       # 搜索逻辑
├── output.rs       # 输出格式化
└── error.rs        # 错误类型
```

### 关键实现

```rust

    pattern: &str,
```

2. **正则支持:** 集成 `regex` crate
3. **流式输出:** 文件边读边输出,不全部加载到内存
4. **性能对比:** 和系统 grep 进行基准测试

### 评估标准

## 项目 2: 并发文件下载器

**对应章节:** 05, 09  
**预估时间:** 4-6 天  
**难度:** ⭐⭐⭐

### 功能需求

```
downloader [选项] <URL...>

选项:
  -c, --concurrent <N>   并发数 (默认 4)
  -o, --output <dir>     输出目录 (默认当前目录)
  --retry <N>            失败重试次数
  --timeout <secs>       超时时间

特性:
  - 显示下载进度条
  - 支持断点续传
  - 多线程分片下载大文件
```

### 技术架构

```rust
// 核心数据流
URL列表
  ↓ (解析)
DownloadTask { url, output_path, range? }
  ↓ (并发执行)
HTTP请求 (reqwest)
  ↓ (流式写入)
临时文件
  ↓ (合并)
最终文件
```

### 关键代码结构

```rust
use tokio::sync::Semaphore;
use tokio_stream::StreamExt;
use reqwest::Client;
use indicatif::{MultiProgress, ProgressBar};

pub struct Downloader {
    client: Client,
    semaphore: Arc<Semaphore>,
    progress: MultiProgress,
    options: DownloadOptions,
}

#[derive(Debug, Clone)]
pub struct DownloadOptions {
    pub concurrent: usize,
    pub retry: usize,
    pub timeout: Duration,
    pub output_dir: PathBuf,
}

impl Downloader {
    pub async fn download_all(&self, urls: Vec<String>) -> Vec<DownloadResult> {
        let futures: Vec<_> = urls.into_iter()
            .map(|url| self.download_one(url))
            .collect();
        
        futures::future::join_all(futures).await
    }
    
    async fn download_one(&self, url: String) -> DownloadResult {
        let _permit = self.semaphore.acquire().await.unwrap();
        
        // 实现重试逻辑
        for attempt in 0..=self.options.retry {
            match self.do_download(&url).await {
                Ok(path) => return DownloadResult::Success(path),
                Err(e) if attempt < self.options.retry => {
                    eprintln!("Retry {}/{}: {}", attempt + 1, self.options.retry, e);
                    tokio::time::sleep(Duration::from_secs(1)).await;
                }
                Err(e) => return DownloadResult::Failed(e.to_string()),
            }
        }
        unreachable!()
    }
}
```

### 进阶功能

1. **分片下载:** 对支持 Range 请求的服务器使用多线程分片
2. **进度持久化:** 保存下载进度到文件,支持中断恢复
3. **速度限制:** 实现令牌桶算法限制下载速度
4. **哈希校验:** 下载完成后验证 MD5/SHA256

### 评估标准

- [ ] 并发下载多个文件正确
- [ ] 进度条显示准确
- [ ] 网络错误能正确重试
- [ ] 磁盘写入使用 Buffer (避免频繁 syscall)
- [ ] 取消下载时清理临时文件

## 项目 3: 结构化日志解析器

**对应章节:** 04, 06, 08  
**预估时间:** 5-7 天  
**难度:** ⭐⭐⭐

### 功能需求

```
logparser [选项] <log文件>

支持格式:
  - Nginx access log
  - JSON Lines
  - 用户自定义正则

分析功能:
  - Top N 请求路径
  - 请求状态码分布
  - 响应时间分位数 (p50, p95, p99)

  - IP 访问频次统计

输出格式:
  - 终端表格
  - JSON
  - CSV
```

### 关键实现

```rust
// 使用 Trait 抽象解析器
trait LogParser: Send + Sync {
    fn parse_line(&self, line: &str) -> Option<LogEntry>;
    fn name(&self) -> &str;
}

#[derive(Debug, Clone)]
struct LogEntry {
    timestamp: chrono::DateTime<chrono::Utc>,
    level: Option<LogLevel>,
    message: String,
    fields: std::collections::HashMap<String, serde_json::Value>,
}

// 流式处理 + 聚合
struct LogAnalyzer {
    parsers: Vec<Box<dyn LogParser>>,
    aggregators: Vec<Box<dyn Aggregator>>,
}

trait Aggregator: Send + Sync {
    fn feed(&mut self, entry: &LogEntry);
    fn report(&self) -> serde_json::Value;
    fn name(&self) -> &str;
}

// 示例聚合器: 响应时间统计
struct LatencyStats {
    samples: Vec<f64>,
}

impl Aggregator for LatencyStats {
    fn feed(&mut self, entry: &LogEntry) {
        if let Some(latency) = entry.fields.get("duration") {
            if let Some(v) = latency.as_f64() {
                self.samples.push(v);
            }
        }
    }
    
    fn report(&self) -> serde_json::Value {
        let mut sorted = self.samples.clone();
        sorted.sort_by(|a, b| a.partial_cmp(b).unwrap());
        
        let percentile = |p: f64| -> f64 {
            let idx = ((sorted.len() as f64 * p) as usize).min(sorted.len() - 1);
            sorted[idx]
        };
        
        serde_json::json!({
            "count": sorted.len(),
            "p50": percentile(0.5),
            "p95": percentile(0.95),
            "p99": percentile(0.99),
            "max": sorted.last().copied().unwrap_or(0.0),
        })
    }
    
    fn name(&self) -> &str { "latency_stats" }
}
```

### 进阶功能

1. **并行解析:** 使用 Rayon 并行处理多个文件
2. **内存效率:** 使用流式处理, 处理 GB 级日志文件
3. **实时监控:** tail -f 功能, 实时输出统计

### 评估标准

- [ ] 处理 1GB 日志文件内存 < 100MB
- [ ] 统计结果的准确性

## 项目 4: 迷你 Key-Value 存储

**对应章节:** 06, 07, 09  
**预估时间:** 7-10 天  
**难度:** ⭐⭐⭐⭐

### 功能需求

```
类 Redis 的 K-V 存储服务

支持命令:
  SET key value [EX seconds]
  GET key
  DEL key [key ...]
  KEYS pattern
  EXPIRE key seconds
  TTL key
  INCR key
  LPUSH/LPOP key value
  HSET/HGET key field value

特性:
  - 基于 TCP 的文本协议 (RESP 简化版)
  - 数据持久化 (AOF 日志)
  - LRU 淘汰策略
  - 异步 IO
```

### 技术架构

```
客户端 TCP 连接
    ↓
协议解析 (自定义 RESP 解析器)
    ↓
命令分发器
    ↓
存储引擎 (HashMap + LRU + TTL)
    ↓
持久化 (AOF 文件)
```

### 关键代码

```rust
use tokio::net::TcpListener;
use std::sync::Arc;
use tokio::sync::RwLock;

// 存储引擎
type Db = Arc<RwLock<Storage>>;

pub struct Storage {
    data: std::collections::HashMap<String, Value>,
    expiry: std::collections::BTreeMap<std::time::Instant, String>,
}

#[derive(Debug, Clone)]
pub enum Value {
    String(String),
    Integer(i64),
    List(std::collections::VecDeque<String>),
    Hash(std::collections::HashMap<String, String>),
}

// 命令
#[derive(Debug)]
pub enum Command {
    Get { key: String },
    Set { key: String, value: String, expiry: Option<Duration> },
    Del { keys: Vec<String> },
    // ...
}

// 主循环
#[tokio::main]
async fn main() {
    let db: Db = Arc::new(RwLock::new(Storage::new()));
    let listener = TcpListener::bind("127.0.0.1:6379").await.unwrap();
    
    loop {
        let (socket, _) = listener.accept().await.unwrap();
        let db = Arc::clone(&db);
        
        tokio::spawn(async move {
            handle_client(socket, db).await;
        });
    }
}
```
