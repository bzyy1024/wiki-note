## 这套教程在解决什么

你不是不会做 agent，你是被"LLM 没法逻辑"这个错觉困住了。真相是：**逻辑不在模型里，在模型外面那层循环里。** 这套教程要把那层循环补全，再把 Claude Code / Codex 这类你已经用得挺爽的工具拆开，让你看懂里面的齿轮——等你看懂了，自己造一个就只是"想造多大"的问题。

全套 15 个文件，约 **15 万字**（案例实战篇已拆为上 / 中 / 下三篇，每篇 30 分钟以内），对话讨论式（墨叔 vs 老哥），每个子章节 30 分钟以内，章末都配【思考题】+【参考答案】（答案当学习材料看，不是测验）。代码以 Python 示意为主，**不交付可运行工程**——定位是"理论 + 真实架构剖析"。

## 怎么读效率最高

1. **顺序读**，前面是后面的词汇表。
2. 每个子章节**先自己答章末思考题，再看参考答案**——"看懂"和"能讲给别人听"中间差着十万八千里，思考题就是逼你跨那道沟。
3. 所有 Python 片段是**示意**，不是让你抄去跑的，作用是把机制钉死。真要动手，读完 Part 8 蓝图你自然知道该补什么工程细节。
4. 本教程**不教具体 SDK 写法**（会过期），只教**十年不过时的心智模型与系统设计取舍**。抓住这些，换任何框架都只是换个螺丝刀。
5. 想回看全局，就回这一页。

## 一句话总纲

**Agent = 大厨（模型）+ 递纸条的人（你写的循环）。你焦虑的"逻辑缺失"，只看到了大厨；补全循环这层心智模型，后面所有机制才有落脚点。**

## 配套实战手册（可运行代码）

理论看累了吧？`实战/` 目录下有一套完整的**可运行配套**——从 lab00 跑通第一个循环，到 lab06 造出能改 bug 的迷你 Claude Code，再到 lab07 学会评测它。**每个 lab 默认零依赖、零 API key、离线可跑**（内置 mock LLM 适配器，没 key 也能看完整流程）。

先读 [实战/00-README.md](实战/00-README.md) 这个总入口，按 lab00→lab07 顺序动手。每个 lab 都标注了对应的理论 Part：理论卡壳时回去翻对应章节，代码跑起来时回来对照机制。难度阶梯：

```
lab00 最简循环（Part1） → lab01 工具（Part2） → lab02 规划（Part3） → lab03 记忆（Part4）
   → lab04 工程化（Part5） → lab05 多智能体（Part7） → lab06 迷你 Claude Code（Part8） → lab07 评测（Part9）
```
