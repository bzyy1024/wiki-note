# Python 高级工程师实战教程

> 面向 **5 年经验 Go 后端工程师** 的 Python 进阶教程。目标不是「能跑 AI 生成的脚本」，而是能在真实项目里像高级工程师一样用 Python——理解每个特性的设计意图、适用场景、收益与代价。
>
> **总字数：约 10.7 万字（106,664 中文字）｜ 30 篇（1 篇导读 + 28 篇技术章 + 1 篇收尾）｜ 每篇独立成文件，技术阅读带思考约 30 分钟。**

---

## 这份教程怎么用

- **对话式**：正文用「墨叔」（导师）和「老哥」（你，Go 工程师）对谈推进，多反问。看到反问先自己答，再往下看。
- **Go 对照镜**：你熟的东西当锚点，几乎每章都拿 Go 类比，比从零讲快十倍。
- **三锚点**：每章都回答——「怎么用 / 什么场景用 / 收益与代价」。
- **章末【思考题】+【参考答案】**：思考题先自己想，参考答案当教材看（详实、有代码），不是测验。
- **建议顺序读**：后面章频繁引用前面概念。挑读也行，但第 1 章（思维对撞）和第 2 章（类型系统）建议先读。
