# 任务调度 - 练习题

## 练习 1：调度统计

记录每个进程的调度统计信息：
```c
typedef struct {
    uint32_t context_switches;  // 被调度次数
    uint32_t total_ticks;       // 获得的总tick数
    uint32_t cpu_percent;       // CPU占用百分比
} sched_stats_t;
```

实现 `scheduler_dump_stats()` 打印所有进程的调度统计。

## 练习 2：优先级调度

修改轮转调度器支持优先级：
- 高优先级进程获得更大的时间片
- 实现多级就绪队列（每个优先级一个队列）

```c
#define NUM_PRIORITIES 4
static process_t *ready_queues[NUM_PRIORITIES];

void schedule(void) {
    // 从最高优先级队列开始查找就绪进程
    for (int p = 0; p < NUM_PRIORITIES; p++) {
        if (ready_queues[p]) {
            // 调度这个进程
        }
    }
}
```

## 练习 3：sleep系统调用

实现进程休眠功能：
```c
void process_sleep(uint32_t milliseconds) {
    current->wake_tick = ticks + ms_to_ticks(milliseconds);
    current->state = PROCESS_BLOCKED;
    schedule();
}
```

在定时器中断中检查是否有进程需要唤醒。

## 练习 4：yield系统调用

实现主动让出CPU：
```c
void task_cooperative(void) {
    while (1) {
        do_work();
        scheduler_yield();  // 主动让出
    }
}
```
