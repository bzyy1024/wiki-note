# 汇编练习

## 🟢 基础练习

### 练习1：修改Hello World

修改汇编速成中的 Hello World 程序，让它显示你自己的名字。

**要求：**
- 修改 `message` 字符串
- 编译运行，确认能正确显示

### 练习2：多行输出

修改程序，按以下格式打印多行信息：

```
Line 1: Hello
Line 2: World
```

**提示：** 使用 `0x0D, 0x0A` 换行。

### 练习3：理解寄存器

阅读以下代码，写出执行后各寄存器的值：

```asm
mov eax, 10
mov ebx, 20
add eax, ebx      ; eax = ?
sub ebx, 5        ; ebx = ?
xor ecx, ecx      ; ecx = ?
inc ecx            ; ecx = ?
```

## 🟡 进阶练习

### 练习4：字符循环打印

编写引导扇区程序，打印字母 A 到 Z：

```
ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

**提示：** 'A' 的 ASCII 码是 65，使用循环和 `inc` 指令。

### 练习5：十六进制打印

编写一个函数，将 AL 寄存器中的值以十六进制形式打印（如 `0x4F`）。

**提示：** 需要分别处理高4位和低4位，转换为 ASCII 字符。

## 🔴 挑战练习

### 练习6：简单计算器

编写一个引导扇区程序，计算 `123 + 456` 并将结果以十进制打印在屏幕上。

**提示：** 需要实现数字到ASCII的转换。
