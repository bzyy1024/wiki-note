# 第2章：基础知识速成

> 补充操作系统开发所需的最小前置知识集

## 学习目标

1. 了解CPU的基本工作原理和寄存器
2. 理解内存地址和寻址方式
3. 掌握NASM汇编语言基础语法
4. 掌握C语言底层编程要点

## 预计时间

⏱️ 3-4小时

## 前置要求

- 完成 [01-环境准备](../01-环境准备/README.md)
- 有基本的编程经验（任何语言均可）

## 本章内容

### 📖 核心知识

1. [CPU和内存基础](CPU和内存基础.md) - CPU寄存器、指令周期、内存寻址
2. [汇编语言速成](汇编语言速成.md) - NASM语法、常用指令、Hello World
3. [C语言要点](C语言要点.md) - 指针、内联汇编、结构体、编译过程

### ✏️ 练习

4. [汇编练习](练习题/汇编练习.md) - 汇编语言动手练习
5. [C语言练习](练习题/C语言练习.md) - C语言底层编程练习

## 学习建议

- 不需要精通汇编，能**看懂**基本代码即可
- 重点理解**寄存器**和**内存地址**的概念
- C语言部分重点关注**指针**和**内联汇编**
- 遇到不懂的先跳过，后面用到时会再详细讲解

## 成果检查

- ✅ 能识别常见的x86汇编指令
- ✅ 理解寄存器的作用
- ✅ 能用C语言直接操作内存地址
- ✅ 了解编译和链接的过程
