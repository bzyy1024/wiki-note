# 第5章：进入保护模式

> 从16位实模式切换到32位保护模式

## 学习目标

1. 理解实模式的限制和保护模式的优势
2. 掌握GDT（全局描述符表）的结构
3. 实现从实模式到保护模式的切换
4. 在32位模式下直接操作VGA显存

## 预计时间

⏱️ 4-5小时

## 前置要求

- 完成 [04-编写Bootloader](../04-编写Bootloader/README.md)

## 本章成果预览

切换到32位保护模式后，在VGA显存中直接写入字符：

```
Booting MyOS...
Kernel loaded!
P                    ← 32位模式下写入的字符
```
