## 练习 2：实现简单命令行

在回显基础上实现行编辑功能：

```c
#define LINE_BUFFER_SIZE 128
static char line[LINE_BUFFER_SIZE];
static uint32_t line_pos = 0;

void process_input(void) {
    char c = keyboard_getchar();
    if (c == '\n') {
        line[line_pos] = '\0';
        process_command(line);  // 处理命令
        line_pos = 0;
    } else if (c == '\b' && line_pos > 0) {
        line_pos--;
    } else if (line_pos < LINE_BUFFER_SIZE - 1) {
        line[line_pos++] = c;
    }
}
```

实现一个能识别 "help"、"clear"、"version" 命令的简单shell。

## 练习 3：LED控制

PS/2键盘有3个LED灯（Num Lock、Caps Lock、Scroll Lock）。
通过端口0x60发送命令控制它们：

```c
void keyboard_set_leds(bool scroll, bool num, bool caps) {
    uint8_t leds = (scroll) | (num << 1) | (caps << 2);

    // 等待键盘准备好
    while (inb(0x64) & 0x02);
    outb(0x60, 0xED);  // LED控制命令

    while (inb(0x64) & 0x02);
    outb(0x60, leds);  // LED状态
}
```

实现并测试：按Caps Lock时切换Caps Lock LED。
