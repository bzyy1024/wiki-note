# 英语与人文素养课：从学不好英语，到提升人文底蕴

> 这是一套帮你从「英语读不进、人文底子薄」成长为「会学英语、有人文素养」的通识课程。
> 课程提炼自英语名著阅读、外刊精读、人文通识、数学启蒙、历史故事的核心理念。
> 每一课都是一个爱读书的老师，带着一个"觉得英语难、读书少"的小白，学会方法、提升素养。

## 怎么学？三句真心话

1. **语言是"用"出来的，不是"背"出来的。** 多读、多听、多用，比死记硬背有效。
2. **人文素养，是"慢功夫"。** 别急，一本书、一篇文章地积累。
3. **把学到的，讲给孩子或朋友听。** 教是最好的学，也能带动身边的人一起成长。
