# 05 词根篇一：动作与力量

> 本课目标：**攻克最核心的动作类词族**——说、拿、放、走、拉、写、做、跑、投、切、站、坐、抓、打、建…… 这些是英语动词词汇的"心脏"，覆盖了阅读里出现频率最高的一大批单词。

---

## 一、进入核心区：词根是心脏

> 👩‍🏫 **老师**：前面我们学了前缀（路牌）和后缀（身份证）。现在终于到了最刺激的部分——词根。**词根是单词的心脏，决定一个词"干什么"。**
>
> 👨‍🎓 **小白**：那我要从哪个词根开始学？
>
> 👩‍🏫 **老师**：从"**动**"开始。因为英语里最常用、最核心的，永远是"动作"——说、拿、走、做。这些词根最高产，也最好记。

---

## 二、重点词族精讲

### 词族 1：「说」—— dict / log / loqu

**核心词根**：`dict`（说）、`log`（说/话/道理）、`loqu/locut`（说）

| 单词 | 拆解 | 意思 |
|------|------|------|
| dictionary | dict + ionary（名词） | 字典（收集"说法"的书） |
| predict | pre（提前）+ dict | 预测 |
| contradict | contra（反对）+ dict | 反驳、顶嘴 |
| verdict | ver（真）+ dict | 真实的说法 → 裁决、判决 |
| dictate | dict + ate（动词） | 口述、命令、支配 |
| dialogue | dia（之间）+ logue（说） | 对话 |
| monologue | mono（单一）+ logue | 独白 |
| eloquent | e（向外）+ loqu + ent | 说得流利的 → 雄辩的 |

> 🤔 **想一想**：`dictator`（独裁者）和 `dictate`（命令）有什么联系？为什么一个"说"的词根会变出"独裁"？——因为独裁者就是**只许自己说话、别人都闭嘴**的人。

### 词族 2：「拿、取」—— cap / cept / ceive

**核心词根**：`cap/cept/ceive`（拿、取、抓）

| 单词 | 拆解 | 意思 |
|------|------|------|
| capture | cap + ture | 捕获 |
| accept | ac（向里）+ cept | 接受（拿进来） |
| receive | re（回）+ ceive | 收到（拿回来） |
| concept | con（一起）+ cept | 一起抓住 → 概念 |
| except | ex（向外）+ cept | 拿出来 → 除外 |
| perceive | per（彻底）+ ceive | 完全抓住 → 察觉、感知 |

> 🤔 **想一想**：`accept`（接受）和 `except`（除外）只差两个字母，为什么意思几乎相反？关键在**前缀**：`ac-` 是"向里"，`ex-` 是"向外"。往里拿 vs 往外拿，方向一换，天壤之别。

### 词族 3：「走、离开」—— ced / cess / gress

**核心词根**：`ced/cess`（走）、`grad/gress`（步、走）

| 单词 | 拆解 | 意思 |
|------|------|------|
| proceed | pro（向前）+ ceed | 前进、继续 |
| succeed | suc（向上/靠近）+ ceed | 走上去 → 成功 |
| exceed | ex（超出）+ ceed | 走出、超过 |
| access | ac（向里）+ cess | 走进去 → 进入、通道 |
| process | pro（向前）+ cess | 向前走 → 过程 |
| progress | pro（向前）+ gress | 进步 |
| graduate | grad + uate | 一步步走完 → 毕业 |

> 🤔 **想一想**：`success`（成功）、`succession`（连续）、`succeed` 这三个词，为什么都带"走"的意思？——因为"成功"的本义就是"**一步步走上去**"。想通了这一点，这一族词你就全通了。

### 词族 4：「放、落」—— pos / pon / cad

**核心词根**：`pos/pon`（放）、`cad/cas/cid`（落下）

| 单词 | 拆解 | 意思 |
|------|------|------|
| position | pos + ition | 位置（放的地方） |
| compose | com（一起）+ pose | 放到一起 → 组成、作曲 |
| deposit | de（向下）+ posit | 往下放 → 存款、存放 |
| expose | ex（向外）+ pose | 放出来 → 暴露 |
| accident | ac（向）+ cid + ent | 突然落下来 → 事故 |
| incident | in + cid + ent | 落进来的事 → 事件 |
| coincide | co（一起）+ in + cide | 一起落下 → 巧合、同时发生 |

> 🤔 **想一想**：`compose` 既是"组成"又是"作曲"。这两层意思怎么统一？——"作曲"就是把一个个音符"**放到一起**"。英语单词的多义，几乎都源于这个字面逻辑。

### 词族 5：「拉、写、画」—— tract / scrib / graph

**核心词根**：`tract`（拉）、`scrib/script`（写）、`graph`（写/画）

| 单词 | 拆解 | 意思 |
|------|------|------|
| attract | at（向）+ tract | 拉过来 → 吸引 |
| contract | con（一起）+ tract | 拉在一起 → 合同、收缩 |
| extract | ex（向外）+ tract | 拉出来 → 提取、拔出 |
| describe | de（向下）+ scribe | 写下来 → 描述 |
| prescribe | pre（提前）+ scribe | 提前写 → 开药方、规定 |
| photograph | photo（光）+ graph | 光写下的 → 照片 |
| autograph | auto（自己）+ graph | 自己写的 → 亲笔签名 |

> 🤔 **想一想**：`contract` 为什么既是"合同"又是"收缩"？——"合同"是双方"**拉在一起**"的约定；"收缩"是肌肉"**拉在一起**"。同一个字面意思，用在不同场景，就成了两个中文词。

### 词族 6：「做、动、工作」—— ag / act / oper / fac / mov

**核心词根**：`ag/act`（做、动）、`oper`（工作）、`fac/fic/fect`（做）、`mov/mot`（动）

| 单词 | 拆解 | 意思 |
|------|------|------|
| action | act + ion | 行动 |
| agent | ag + ent（人） | 做事的人 → 代理人、特工 |
| operate | oper + ate | 操作、运转、动手术 |
| factory | fact + ory（场所） | 做东西的地方 → 工厂 |
| efficient | ef（向外）+ fic + ient | 做得出来的 → 高效的 |
| perfect | per（彻底）+ fect | 彻底做完 → 完美的 |
| motion | mot + ion | 运动 |
| promote | pro（向前）+ mote | 向前推 → 促进、升职 |

> 🤔 **想一想**：`factory`（工厂）、`manufacture`（制造）、`fact`（事实）这三个词，都藏着 `fac`（做）。你能看出"事实"为什么也是"做"出来的吗？——事实就是"**已经做出来了、摆在那里**"的东西。

### 词族 7：「跑、投」—— cur / curs / ject

**核心词根**：`cur/curs`（跑）、`ject`（投、扔）

| 单词 | 拆解 | 意思 |
|------|------|------|
| current | curr + ent | 正在跑的 → 当前的、水流 |
| occur | oc（向）+ cur | 跑过来 → 发生 |
| course | course | 跑的过程 → 课程、路线 |
| project | pro（向前）+ ject | 往前投 → 项目、投射 |
| inject | in（向里）+ ject | 投进去 → 注射 |
| reject | re（回）+ ject | 扔回去 → 拒绝 |
| object | ob（对面）+ ject | 扔到对面 → 反对；物体 |

> 🤔 **想一想**：`subject`（科目、主题、主语）和 `object`（物体、宾语、反对）为什么是"主"和"客"？——`sub` 是"在下面"，`ob` 是"对面"。"被扔到下面（被统治）的是主语"，"扔到对面的是宾语"。语法书里的主语、宾语，原来都是"投掷"来的！

### 词族 8：「切、刻、写」—— sect / cis / cid

**核心词根**：`sect/seg`（切）、`cis/cid`（切）

| 单词 | 拆解 | 意思 |
|------|------|------|
| section | sect + ion | 切开的一部分 → 部分、章节 |
| insect | in + sect | 切成节的小虫 → 昆虫 |
| decide | de（向下）+ cide | 一刀切下去 → 决定 |
| precise | pre（提前）+ cise | 提前切好 → 精确的 |
| scissors | sciss + ors | 剪子 |

> 🤔 **想一想**：`decide`（决定）为什么是"切"？——因为"做决定"就像**一刀切下去**，斩钉截铁，不再犹豫。想通这个画面，`decide` 你一辈子忘不掉。

### 词族 9：「站、坐」—— st / stat / sist / sed

**核心词根**：`st/stat/sist`（站）、`sed/sess/sid`（坐）

| 单词 | 拆解 | 意思 |
|------|------|------|
| stand | st + and | 站立 |
| state | stat + e | 站着的状态 → 状态、国家 |
| station | stat + ion | 站的地方 → 车站、站点 |
| exist | ex（向外）+ sist | 站到外面 → 存在 |
| insist | in（在）+ sist | 站在原地不动 → 坚持 |
| president | pre（前）+ sid + ent | 坐在前面的人 → 总统、主席 |
| session | sess + ion | 坐在一起 → 会议、会期 |

> 🤔 **想一想**：`president`（总统）的字面意思是"**坐在最前面的人**"。你还知道哪个"领导人"的英文也是"坐"出来的吗？（提示：`chairman` 主席——`chair` 是椅子！）

### 词族 10：「抓、拿、坚持」—— tain / ten / tent / hab

**核心词根**：`tain/ten/tent`（拿、握、坚持）、`hab/hib`（拥有、握住）

| 单词 | 拆解 | 意思 |
|------|------|------|
| contain | con（一起）+ tain | 握在一起 → 包含、容纳 |
| maintain | main（手）+ tain | 用手握住 → 维持、保养 |
| obtain | ob + tain | 拿到手 → 获得 |
| retain | re（回）+ tain | 拿回来 → 保留 |
| habit | hab + it | 握住不放的东西 → 习惯 |
| exhibit | ex（向外）+ hibit | 拿出去给人看 → 展览 |

> 🤔 **想一想**：`maintain` 和 `contain` 都带 `tain`（拿）。为什么一个"维持"、一个"包含"？——`main` 是"手"，用手握住=维持；`con` 是"一起"，握在一起=包含。**前缀再次决定了方向。**

## 三、其余动作类词族速查表

以下词族同样重要，用表格快速过一遍（重点记词根 + 一个代表词）：

| 词族 | 核心词根 | 代表词 | 字面逻辑 |
|------|---------|--------|---------|
| 打、战 | bat, bell | battle（战役）、rebel（re+bell 反着战→造反） | 打 |
| 盖、覆、折 | cover/tect, plic/ply | protect（pro 前+tect 盖→保护）、reply（re 回+ply 折→回折→答复） | 盖住、折叠 |
| 绑、连 | lig, junct, nect | religion（re+lig 绑回→宗教）、connect（con+nect 绑一起→连接） | 绑 |
| 手 | man/manu | manual（手的→手册）、manufacture（手+做→制造） | 手 |
| 压、拉紧 | press, strict/string | express（ex 外+press 压→挤出→表达）、restrict（re+strict 拉紧→限制） | 压、拉 |
| 建、伸 | struct, tend/tens/tent | construct（con+struct 建→建造）、extend（ex+tend 伸→延伸） | 建、伸 |
| 跟、标、交 | sequ/secut, sign, trad | sequence（顺序）、sign（标记）、tradition（trad 交给→传统） | 跟随、交给 |
| 送 | mit/miss | transmit（trans+mit 跨着送→传送）、dismiss（dis+miss 送走→解散） | 送 |
| 吸 | sorb/sorpt, haust | absorb（ab+sorb 吸→吸收）、exhaust（ex+haust 抽干→耗尽） | 吸 |
| 根、辐射 | rad/radic, radi | radical（根+al→根本的、激进的）、radiation（辐射） | 根、放射 |

> 🤔 **想一想**：`religion`（宗教）的字面意思是"**绑回去**"——把人重新绑回（神的身边）。这个画面感，比死记"宗教"两个字强一百倍。你还觉得单词是随机排列吗？
