# 苏楠楠万词班 · 词根词缀系统培训课

> **一句话说清这门课**：不用死记硬背，靠"词根 + 前缀 + 后缀"这三把钥匙，把 1 万个英文单词串成一张网。学完之后，你再看到一个陌生单词，第一反应不是"查字典背它"，而是"拆开它、猜出它、记住它"。

## 这门课的核心秘密（三句话）

英语单词，尤其是高级词汇，**不是一个个孤立的符号，而是一块块拼出来的积木**。

```
    单词 = 前缀（方向/否定/程度） + 词根（核心意思） + 后缀（词性）
```

举个例子，`transmit` 这个单词：

| 拆解 | 部分 | 意思 |
|------|------|------|
| trans | 前缀 | 跨越、穿过（from one place to another） |
| mit | 词根 | 送、发送（send） |
| —— | 后缀 | （动词，无具体意思） |

所以 `transmit` = "跨越着送过去" = **传送、发射、传播**。

你再看 `transmit` 的同族兄弟：

- `mission`（送出去的任务）→ 使命、任务
- `admit`（ad=向里 + mit=送）→ 送进来 → 准许进入、承认
- `dismiss`（dis=分开 + miss=送）→ 送走 → 解散、解雇、不予理会
- `emit`（e=向外 + mit=送）→ 送出去 → 发出、发射

**背一个 `mit`，你就解锁了一整个家族。** 这就是"万词班"的底气：不是让你背一万个词，而是让你认识几百个"造词零件"，自己拼出一万个词。

## 课程的三大原则（学习前先记住）

1. **词根为王**：词根是单词的"心脏"，决定单词的**核心意思**，永远优先学。
2. **前缀定方向**：前缀像"路牌"，告诉你这个词往哪个方向走（往里/往外/反对/加强……）。
3. **后缀定身份**：后缀像"身份证"，告诉你这个词是名词、动词、形容词还是副词。

> 一句话记法：**词根是"干什么"，前缀是"往哪干"，后缀是"什么身份"。**

## 三个"千万别"

1. **千万别从头背单词表**。先把零件（词根词缀）装进脑子，单词自然就长出来了。
2. **千万别只看不拆**。每遇到一个生词，强迫自己用 `前缀+词根+后缀` 拆一遍，拆三遍就成肌肉记忆。
3. **千万别一次吃太多**。一个词族学完，立刻用自测题巩固，再学下一个，贪多嚼不烂。
