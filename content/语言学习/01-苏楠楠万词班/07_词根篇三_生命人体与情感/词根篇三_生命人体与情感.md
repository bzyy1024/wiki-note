# 07 词根篇三：生命 · 人体 · 情感

> 本课目标：**攻克"生命、人体、情感"词族**——生、死、身、心、命、父、母、人民、情感、苦难、笑、恩…… 这些词根是医学、心理学、社会学词汇的地基。

---

## 一、开场：从"活着"开始

> 👩‍🏫 **老师**：英语里有一个词根，长得像"生命"本身，它造出了 `vivid`、`vital`、`survive`、`vitamin` 一大家子。你能猜出是哪个吗？
>
> 👨‍🎓 **小白**：……`viv` 或者 `vit`？
>
> 👩‍🏫 **老师**：聪明！就是 `viv/vit`（生命）。记住它，下面一整族词你都不用死背。

---

## 二、重点词族精讲

### 词族 1：「生」—— viv / vit / gen / nat

**核心词根**：`viv/vit`（生命、活）、`gen`（出生、产生）、`nat`（出生）

| 单词 | 拆解 | 意思 |
|------|------|------|
| vivid | viv + id | 活生生的 → 生动的 |
| vital | vit + al | 生命的 → 至关重要的 |
| survive | sur（在上）+ vive | 活下来 → 幸存 |
| vitamin | vit + amin | 维持生命的物质 → 维生素 |
| generate | gen + erate | 使产生 → 产生、发电 |
| gene | gene | 基因（生命的基本单位） |
| native | nat + ive | 出生的 → 本地的、土生土长的 |
| nation | nat + ion | 出生在一起的人 → 民族、国家 |

> 🤔 **想一想**：`native`（本地人）和 `nation`（国家）居然同根，都源于 `nat`（出生）。为什么"出生"能变成"国家"？——因为国家就是"**出生在同一片土地的人**"组成的共同体。

### 词族 2：「死」—— mort

**核心词根**：`mort`（死）

| 单词 | 拆解 | 意思 |
|------|------|------|
| mortal | mort + al | 会死的 → 凡人、致命的 |
| immortal | im（不）+ mortal | 不朽的、长生不老的 |
| mortuary | mort + uary（场所） | 停尸房 |

> 🤔 **想一想**：`mortal` 既是"凡人"又是"致命的"，这两个意思怎么统一？——凡人"**会死**"，致命的（伤）"**导致死亡**"。核心都是"死"。

### 词族 3：「命、活、心、神」—— anim / psych / cord

**核心词根**：`anim`（生命、灵魂、气息）、`psych`（心智、灵魂）、`cord`（心）

| 单词 | 拆解 | 意思 |
|------|------|------|
| animal | anim + al | 有生命的东西 → 动物 |
| animate | anim + ate | 使有生命 → 使生动、动画的 |
| unanimous | un（一）+ anim + ous | 一条心 → 一致同意的 |
| psychology | psych + o + logy（学） | 研究心智的学科 → 心理学 |
| record | re（再）+ cord | 再次放在心上 → 记录 |
| cordial | cord + ial | 发自内心的 → 热诚的 |

> 🤔 **想一想**：`unanimous`（一致同意的）字面意思是"**一个灵魂**"。当一群人"一个灵魂"，不就是"意见完全一致"吗？还有 `record`（记录），本义是"**再次放在心上**"——记下来，才不忘。

### 词族 4：「身体」—— corp / corpor

**核心词根**：`corp/corpor`（身体）

| 单词 | 拆解 | 意思 |
|------|------|------|
| corpse | corpse | 尸体 |
| corporation | corpor + ation | 一群人组成"一个身体" → 公司、法人 |
| incorporate | in（使）+ corpor + ate | 使成为一体 → 合并、纳入 |

> 🤔 **想一想**：`corporation`（公司）为什么和"身体"有关？——因为公司是**一群人凝聚成一个"整体"**，像一个有生命、有组织的"身体"。想通这一点，`corporate`（公司的）、`incorporate`（合并）就都通了。

### 词族 5：「神经」—— neur

**核心词根**：`neur`（神经）

| 单词 | 拆解 | 意思 |
|------|------|------|
| neuron | neur + on | 神经元 |
| neurology | neur + o + logy（学） | 神经学 |
| neurotic | neur + otic | 神经过敏的 |

### 词族 6：「父、母」—— patr / matr

**核心词根**：`patr/pater`（父）、`matr/mater`（母）

| 单词 | 拆解 | 意思 |
|------|------|------|
| patron | patr + on | 像父亲一样庇护你的人 → 赞助人、老主顾 |
| patriot | patr + iot | 爱"祖国（父邦）"的人 → 爱国者 |
| pattern | patr + ern | 像"父"一样的模板 → 模式、图案 |
| maternal | matr + al | 母亲的 |
| matriarch | matr + i + arch（首领） | 女家长 |

> 🤔 **想一想**：`patriot`（爱国者）的字面意思是"**爱父邦的人**"——祖国在英语里被称作 `fatherland`（父之国）。而 `pattern`（模式）为什么是"父"？——因为"父"是家庭的"**模板和样板**"，就像图案是复制的模板。

### 词族 7：「人、城、整体」—— popul / civ / integr

**核心词根**：`popul/publ`（人民）、`civ`（城市、公民）、`integr`（整体）

| 单词 | 拆解 | 意思 |
|------|------|------|
| population | popul + ation | 人口 |
| public | publ + ic | 公众的 |
| republic | re（事务）+ public | 公共事务 → 共和国 |
| civil | civ + il | 公民的、文明的 |
| civilization | civil + ization | 文明 |
| integrity | integr + ity | 完整 → 正直、诚信 |

> 🤔 **想一想**：`republic`（共和国）字面是"**公共的事务**"——权力属于公众，这就是共和的本义。而 `integrity`（正直）为什么源于"整体"？——因为一个正直的人，是**表里如一、完整不分裂**的人。

### 词族 8：「情感、苦难」—— sens / sent / path / pass

**核心词根**：`sens/sent`（感觉）、`path/pass`（感受、受苦）

| 单词 | 拆解 | 意思 |
|------|------|------|
| sense | sens + e | 感觉、意义 |
| sentiment | sent + iment | 情感、情绪 |
| consent | con（共同）+ sent | 同样的感受 → 同意 |
| sympathy | sym（共同）+ pathy | 同样的感受 → 同情 |
| pathetic | path + etic | 令人同情的 → 可怜的 |
| passion | pass + ion | 强烈的情感 → 激情 |
| patient | pat + ient | 忍受（病痛）的人 → 病人；有耐心的 |

> 🤔 **想一想**：`sympathy`（同情）和 `consent`（同意）都源于"**同样的感受**"。为什么"同样感受"既能变成"同情"又能变成"同意"？——同情是"我感受到你的痛苦"，同意是"我与你感受一致"。**核心都是"共情"。**

### 词族 9：「笑、惊、恩」—— rid / grat

**核心词根**：`rid`（笑）、`grat`（愉悦、恩惠）

| 单词 | 拆解 | 意思 |
|------|------|------|
| ridicule | rid + icule | 使发笑 → 嘲笑 |
| ridiculous | rid + iculous | 荒唐可笑的 |
| grateful | grat + eful | 充满感激的 |
| gratitude | grat + itude | 感激 |
| congratulate | con + grat + ulate | 一起高兴 → 祝贺 |

> 🤔 **想一想**：`congratulate`（祝贺）的字面意思是"**一起高兴**"。所以"祝贺"的英文里藏着一个"高兴"（`grat`）。你还能想起哪个带 `grat` 的词？

### 词族 10：「心、中心、勇」—— centr / cord / cour

**核心词根**：`centr`（中心）、`cord/cour/cor`（心）

| 单词 | 拆解 | 意思 |
|------|------|------|
| center | centr | 中心 |
| concentrate | con + centr + ate | 聚到中心 → 集中 |
| courage | cour + age | 心里的力量 → 勇气 |
| encourage | en（使）+ courage | 使有勇气 → 鼓励 |

> 🤔 **想一想**：`courage`（勇气）源于 `cour`（心）。为什么"勇气"和"心"有关？——因为在古人看来，勇气是"**从心底升起的力量**"。所以"鼓励"就是"**把勇气放进别人心里**"。

## 三、其余生命情感类词族速查表

| 词族 | 核心词根 | 代表词 | 字面逻辑 |
|------|---------|--------|---------|
| 存在 | sist/sta, ess/est | exist（站到外→存在）、essence（本质） | 站、是 |
| 关心、放心 | cur, cour/cor | cure（治愈）、secure（se 无+cur 忧→安全） | 关心 |
| 头、首要 | capit, prim | capital（头→首都、资本）、primary（首要的） | 头、第一 |
| 自己 | auto, ego, sui | automatic（自动）、ego（自我）、suicide（自杀） | 自己 |
| 保护、服务 | serv | preserve（pre 前+serve 保→保存）、reserve（储备） | 保持、服务 |
| 客、敌 | host | host（主人/宿主）、hostile（敌对的） | 客人/敌人 |
| 美、力、权、安 | pot, pac, fort | potential（潜能）、peace（和平）、force（力量） | 有力、和平 |
| 恩、仁慈、商 | grat, merc | mercy（仁慈）、merchant（商人） | 恩惠、交易 |

> 🤔 **想一想**：`host` 既是"主人"又是"敌人"（hostile 敌对的），是不是很分裂？其实"主人"和"陌生人/敌人"在词源上是相通的——**外来的人，既可能是客人，也可能是敌人**。而 `secure`（安全）字面是"**没有忧虑**"（se 无 + cur 忧）。
