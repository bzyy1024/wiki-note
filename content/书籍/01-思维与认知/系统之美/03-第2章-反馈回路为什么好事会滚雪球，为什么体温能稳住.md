## 第2章 反馈回路：为什么好事会滚雪球，为什么体温能稳住

**小林**：上一章我回去填了那三张表，有点扎心，但很清楚。今天讲什么？

**老陈**：讲一个我认为是全书最值钱的概念。上一章你已经自己发现两个了，你还记得吗？

**小林**：钱少压力大熬夜生病更花钱那个，还有没时间不学习干活慢更没时间那个。

**老陈**：对，那两个都是环。今天我们给它们起名字，看清它们的构造，然后学会一眼认出来。

先问你一个特别简单的问题：**为什么你的体温是 36.5 度左右，而不是今天 40 度明天 30 度？**

**小林**：因为身体会调节？

**老陈**：怎么调节？说细一点。

**小林**：热了就出汗，冷了就抖。

**老陈**：好。这个过程里有几个关键动作，我拆给你：

一，有一个存量：体温。

二，有一个目标：36.5 左右。

三，有一个测量：身体知道现在多少度。

四，有一个比较：现在比目标高还是低。

五，有一个动作：高了就散热(出汗、血管扩张)，低了就产热(发抖、血管收缩)。

六，动作改变了存量，于是又回到第三步。

**小林**：转起来了。

**老陈**：对，这就叫**回路**。而这一个，因为它总是把存量往目标拉回去，我们叫它**调节回路**(也叫平衡回路、负反馈回路)。

它的性质是：**追求稳定，抵抗变化，趋向某个目标值。**

**小林**：所以它是好东西？

**老陈**：这里我要给你一个重要提醒：**回路本身没有好坏，只有形状。** 一个把你拉回 36.5 度的调节回路，救你的命；一个把你的收入拉回原来水平的调节回路，可能让你穷一辈子。

**小林**：等等，收入也有调节回路？

**老陈**：太有了，而且很多人被它锁住了一生。我讲两个。

第一个：你涨薪 30%，三个月内你的生活水平就升到新水平(换更好的房、换更好的手机、吃更好的饭)，于是你的月度结余回到涨薪前。你的存量目标值没变，所以系统把它拉回去了。

**小林**：这个我朋友就是。他涨了很多，还是月光。

**老陈**：第二个更隐蔽：你干得好，公司给你更多活，你更忙，你没时间提升和找更好的机会，于是你的市场价值涨得慢。这里的调节回路把你锁在了"好用的执行者"这个位置上。

**小林**：这个我怀疑我自己就在里面。

**老陈**：先记住这个感觉，第7章和第9章我们会回来处理它。

### 一、增强回路：滚雪球，两个方向都滚

**老陈**：现在讲第二种。你猜猜和"往回拉"相反的是什么？

**小林**：往外推？越走越远？

**老陈**：对。**增强回路**(也叫正反馈回路)。它的性质是：**当前状态越强，它就越强；越弱，就越弱。它放大变化，产生指数式的增长或崩塌。**

最经典的例子：**利息**。

你有一万块，年化 5%，一年后一万零五百。第二年的利息是按一万零五算的，所以更多。存量越大，入流越大，存量就更大。

**小林**：这个我懂。但说实话，我这点存款，利息几乎感觉不到。

**老陈**：这就是增强回路最骗人的地方，我一定要给你讲透。

**增强回路的早期，几乎看不见；一旦看得见，往往已经追不上了。**

我给你个数字感受一下。一个东西每天涨 1%，一年后是多少倍？

**小林**：1% 而已……一年三百多天，三倍多？

**老陈**：37 倍多。

**小林**：什么？

**老陈**：这就是为什么增强回路是普通人最该敬畏的东西。它不符合我们的直觉。我们的大脑天生是线性的：走一步一米，走十步十米。但增强回路是"走一步，你的步幅也变大"。

**小林**：那反过来呢？往下滚也这么快？

**老陈**：这是我更想让你警惕的。往下滚的时候更快，因为往下滚常常伴随着能力的丧失。

我给你讲三个"往下滚"的例子，你看看眼熟不。

**例一，债务。** 你欠了一笔钱，利息在滚。为了还利息，你不敢换工作(怕断收入)，所以你留在低薪的地方；因为收入不涨，你还得慢；因为还得慢，利息更多。这是一个很紧的下滑环，很多人一辈子出不来。

**例二，信誉。** 你有一次没交付，别人开始不太敢给你重要的事；你只做零碎的事，没机会证明；没机会证明，别人更不敢给。你越来越边缘。

**小林**：这个……我真的经历过一次。我犯了一个错，之后半年我明显被绕过去了。

**老陈**：那你当时怎么出来的？

**小林**：我后来主动去接了一个所有人都不想干的破活，做成了。

**老陈**：记住你自己这个动作，它非常正确，我们回头会讲为什么。这叫**给下滑环插一根杠**。

**例三，情绪和关系。** 你心情差，所以不太想跟人打交道；不打交道，你的支持系统变弱；支持系统弱，你心情更差。这个环在抑郁的形成里非常典型，而且它有个特别坏的性质：**它会让你失去打破它的意愿。**

**小林**：说到这个，我上半年有一段时间就是这样。周末谁叫我我都不去，然后越来越不想去。

**老陈**：所以这里有一个非常实用的判断：**当你发现"越怎样就越怎样"的时候，你就在一个增强回路里。** 这时候不要问"我该更努力吗"，要问"这个环的哪一环最容易被我掐断"。

**小林**：怎么找那个最容易掐断的？

**老陈**：一般来说，找**最不需要别人配合、最不需要状态好、最小的那个动作**。

比如情绪那个环，你不需要"心情变好才出门"，你可以"不管心情，先出门走二十分钟"。你把"心情差→不出门"这一段掐断了，环就转不动了。

比如信誉那个环，你不需要等一个大机会，你可以像你当初那样，接一个别人都不要的、小的、但一定能做成的事。这是掐断"没机会证明"那一段。

比如债务那个环，你不需要一下还完，你需要先停止新增(掐断"入流")，再从利息最高的那笔开始。因为最高利息那笔是环转得最快的地方。

### 二、两种回路怎么打架：这才是真实世界

**老陈**：现在讲重点。真实系统里，从来不是单一回路。永远是**一堆回路在同时转，互相打架，此起彼伏。**

我用你最关心的减肥来讲，因为这个例子能一次讲透。

先看你的期望：我少吃多动，体重下降。听起来是个简单的因果。

但真实情况是至少四个回路在转。

**回路 A(你以为的那个)**：少吃 → 能量赤字 → 体重下降。这不是回路，这是一条线，是你的行动路径。

**回路 B(调节回路，来自身体)**：体重下降 → 身体感知到"资源不足" → 基础代谢下调、食欲激素上升 → 你更容易饿、消耗更少 → 体重下降变慢，甚至回升。

**小林**：这个我体验过。前两周掉得快，后来纹丝不动，而且特别想吃东西。

**老陈**：这不是你不行，这是一个救过你祖先命的调节回路在正常工作。它的目标值是"维持现有体重"，你越努力，它越用力拉。

**回路 C(增强回路，来自意志)**：饿 → 意志力消耗 → 意志力低 → 更容易破功 → 破功后自责 → 情绪差 → 用吃来安慰 → 更破功。

**小林**：这个也是我。而且破功之后我会想"算了都这样了，索性吃个够"。

**老陈**：这叫"破窗"，是增强回路的典型加速方式。

**回路 D(调节回路，来自社会)**：你变瘦 → 别人夸你 → 你满足 → 警惕性下降 → 恢复旧习惯 → 反弹。

**小林**：我天，最后这个太真实了。我瘦了以后被夸了几次，然后我就觉得"我可以吃一点了"。

**老陈**：现在你回头看你去年的失败。你以为你在跟"我的懒"打架，实际上你在同时跟三个回路打架，而且你只用了一个动作(少吃多动)去对抗它们。

**小林**：那怎么办？我听着有点绝望。

**老陈**：反过来想。**既然回路这么强，那就别硬扛回路，去改回路。** 一个一个来。

对 B(代谢调节)：不要造成极端赤字。极端赤字会把这个回路激活到最大。缓慢的赤字让它反应弱。同时，保持力量训练和蛋白摄入，让身体不觉得需要拆肌肉，这是降低这个回路的"增益"。

**小林**：所以慢一点其实是在跟回路合作。

**老陈**：对，这是系统思维里非常重要的一个转变：**从"战胜系统"到"顺着系统"。**

对 C(意志力环)：核心不是练意志力，是**减少需要意志力的场合**。你家里没有零食，你就不需要意志力。你的午饭是固定的，你就不需要每天做十次选择。这是把环的一个节点直接删掉。

**小林**：这个便宜多了。

**老陈**：而且更狠一点：你还要**预设破功**。你规定"每周有一顿是随便吃的"，那么"破功→自责→报复性吃"这个链条就断了，因为那不叫破功，那叫计划的一部分。

**小林**：我从来没想过要主动给失败留位置。

**老陈**：这是个很深的道理：**一个不允许失败的计划，会因为第一次失败而全盘崩塌。这不是执行问题，是设计问题。**

对 D(被夸奖后松懈)：把目标从"瘦到多少斤"改成"某种生活方式的维持"。因为前者是一个终点，到了就该结束了；后者没有终点。

**小林**：等一下。这个我要停一下。我以前所有的计划都是"三个月瘦十斤"这种。你说这个设定本身有问题？

**老陈**：我问你，你去年"三个月瘦十斤"达成之后，第四个月你的计划是什么？

**小林**：……没有。我就正常吃了。

**老陈**：所以那个计划是精确设计来让你反弹的。**当目标是一个数字终点，达成的那一刻，所有支撑行为都失去了理由。** 这一条不止用在减肥上，你想想公司里那些"专项攻坚三个月"之后一切照旧的项目。

**小林**：全是。我们每年都有几个。

### 三、认回路的实操：三句话，随时能用

**老陈**：我给你三句可以在任何场合直接套用的话。

**第一句："这里有什么在自我强化？"**

用来找增强回路。信号词是"越……就越……"。

看到"越有钱的人越容易赚钱"、"越忙的人越没时间提升"、"越受欢迎的餐厅越排队"、"越吵的会议越没人说真话"，这些全是。

**第二句："这里有什么在把它拉回去？"**

用来找调节回路。信号词是"总是回到"、"怎么都保持在"、"过一段时间又".

看到"每次涨薪后还是月光"、"每次大扫除后一个月又乱了"、"每次整改后半年又反弹"、"团队每次培训后热情三周"，这些全是。

**第三句："这个回路的目标值是多少？谁定的？"**

这是最厉害的一句，我要多说两句。

调节回路一定有一个目标值。你的体温回路目标是 36.5，你的钱包回路目标是"我习惯的生活水平"，你们公司的质量回路目标是"不被投诉到老板那里"，而不是"做得好"。

**小林**：等一下，这个说法有点意思。你是说很多组织的质量目标其实是"不被投诉"？

**老陈**：你自己判断。如果一个问题很严重但从来没有客户投诉到高层，它会被修吗？

**小林**：不会。我们就是这样。

**老陈**：那么这个系统的真实目标值就是"投诉不上去"，而不是"质量好"。这解释了为什么你们会花很多力气在"安抚"而不是"修复"上——在真实目标下，安抚更划算。

**小林**：所以要改的不是员工的态度，是那个目标值。

**老陈**：对，你已经提前摸到第10章了。

### 四、一个完整的案例：为什么"团队目标越喊越歪"

**老陈**：我们用回路来解剖一个你亲身经历的事——你们的日活项目。你把过程再说一遍，我们一起画。

**小林**：老板说要提升日活，我们做了签到、打卡、每日抽奖。数据涨了。今年投诉翻倍，老板让降低打扰。

**老陈**：好。我们数一数这里有几个回路。

**回路 1(增强，好的那面)**：做活动 → 日活涨 → 老板满意 → 给更多资源 → 做更多活动 → 日活涨。这是你们去年爽的原因。

**回路 2(增强，坏的那面)**：做活动 → 打扰用户 → 一部分用户烦 → 但他们不会立刻卸载，只是变冷淡 → 你们看到"数据还行" → 继续加活动 → 更烦。

注意这里有个关键：**用户变冷淡这个信号，在你们的数据里看不见**，因为你们看的是日活，而"被烦到但还没走"的用户，在日活里是正常的，甚至因为签到还是活跃的。

**小林**：对！我们的看板上根本没有"烦不烦"这个东西。

**老陈**：这就是第8章要讲的信息流缺失。你的回路缺了一个必要的反馈线，于是它变成了一个没有刹车的增强回路。

**回路 3(调节，迟到的那个)**：用户烦 → 累积到一定程度 → 投诉/卸载/口碑变差 → 老板终于感受到 → 要求降低打扰。

这个调节回路是存在的，但它**延迟很长**。等它起作用，已经过了一年，伤害已经沉淀成存量了。

**小林**：所以我们不是没有反馈，是反馈太晚。

**老陈**：而且更糟的是，**因为太晚，你们会做过度反应**。老板现在说"降低打扰"，你们会怎么做？

**小林**：可能会一刀砍掉所有推送。

**老陈**：然后日活掉，老板又急，又让加回来。你们就开始在两个极端之间振荡。这是延迟系统的典型症状，下一次我们讲韧性和延迟的时候会细讲。

**小林**：我现在有点想吐槽：这么明显的事，为什么当时没人发现？

**老陈**：因为在当时的结构下，没有人有动力发现。这句话很重要，我拆给你：

发现问题需要有人去看"用户烦不烦"，但没有一个指标衡量它，所以看它的人得不到任何好处；

提出问题的人会被视为"给大家泼冷水"，因为当时数据正好、老板正满意；

而继续加活动的人，能立刻拿到看得见的功劳。

**小林**：所以不是大家笨，是说真话的人要自己承担成本，而闭嘴的人有奖励。

**老陈**：你这句话说得比我好。记下来，这是你以后看任何组织问题的一把钥匙。

**小林**：我总结一下这一章。

第一，系统会自己动，因为它有回路。

第二，两种基本回路：增强回路放大变化(越……越……)，调节回路追求稳定(总是回到)。

第三，回路无好坏，看它把你推向哪。

第四，真实世界永远是多回路打架，所以简单因果几乎总是错的。

第五，对付回路不是硬扛，而是改回路：删节点、降增益、补反馈、改目标值。

第六，增强回路早期看不见，所以对下滑环要早，对上升环要有耐心。

**老陈**：非常好。我再给你加一条，也是我做了这么多年最深的感受：

**大多数人的痛苦，来自于用线性的努力，去对抗回路型的结构。** 你每天多走一步，而结构每天把你的步幅缩小一点。看清回路，你才知道该往哪使那一点点力。

下一章我们讲一个更实际的问题：为什么有的人、有的公司、有的家庭特别扛造，出了事还能起来；有的一个小意外就崩了。这个东西叫韧性，而它跟你想象的完全不一样。

### 【思考题】

**第1题**
请在你自己的生活里，找出一个正在往下滚的增强回路(越……就越……)。要求写清楚这个环上的每一个节点，至少三个节点。然后回答：这个环上哪一个节点，是"只需要你自己动、不需要别人配合、不需要你状态好"就能掐断的？给出你本周就能做的一个具体动作。

**第2题**
找出你身上一个"总是回到原点"的现象(比如房间总是乱回去、钱总是存不下、每次立志学习都持续三周)。请指出这个调节回路的目标值是什么，以及这个目标值是被什么定义的。注意：不要回答"我懒"，"懒"不是目标值。

**第3题**
回想一个你亲历过的、组织里"数据变好但事情变糟"的例子。请画出至少两个回路：一个是让大家继续做下去的增强回路，一个是迟到的调节回路。然后回答：当时缺少的那条反馈线是什么？如果你有权加一个指标，你会加什么？

### 【参考答案】

**第1题参考答案**

先给你一个完整示范，再给你判断标准。

示范环(职场里极常见的"忙碌陷阱")：

节点一：我手上活多，时间紧。
节点二：因为时间紧，我用最熟的方式做，不学新方法、不做复盘。
节点三：因为不学新方法，我的效率停留在原地，甚至因为业务变复杂而相对下降。
节点四：因为效率不涨，同样的活占我更多时间。
回到节点一，且更紧。

这个环还有一条支线让它更快：因为我总是"能干完"，所以别人放心继续给我派活，于是我的活更多。这条支线很重要，因为它说明**这个环的一部分动力来自你的可靠**，这也是为什么老实人容易被困住。

现在找可掐断的节点。

节点一(活多)：不容易，需要别人配合，需要你有议价权。
节点三(效率)：这是结果，不是可操作的地方。
节点四：同上。
节点二：这是唯一你能单方面动的。

具体到"本周能做的一个动作"，好的答案长这样：**每天下班前用五分钟写三行——今天最耗时间的一件事是什么、它为什么耗、下次可以少做哪一步。** 注意这个动作的三个特征：不需要别人同意、不需要你状态好、小到没有理由不做。这三条是选动作的标准。

坏的答案长这样："我要开始学习，每天两小时。"为什么坏？因为它恰恰需要你现在最缺的东西(时间和状态)，它会在第一个加班日死掉，然后你会得到一次自责，让环转得更快。

再给两个常见环的答案，供你对照：

情绪下滑环：越难受越不想见人，越不见人越难受。可掐断点是"不需要心情好就能做的、有身体参与的、不需要社交的事"——出门走路、晒太阳、做一顿饭。注意不要选"约朋友出来聊聊"作为第一步，因为它需要状态和别人配合，成功率低。

拖延环：越拖越焦虑，越焦虑越不敢开始，越不敢开始越拖。可掐断点是"把开始的门槛降到荒谬"——不是"今天写完报告"，而是"打开文件，写一个标题"。这个环的燃料是"开始的心理成本"，所以要打的就是那个成本。

判断你答案质量的标准：**你的动作是否在环的最上游、最小、且不依赖你当前最缺的资源。** 如果三条都满足，你写对了。

**第2题参考答案**

这道题的核心在于理解"目标值"这个概念，而且这道题最容易答错的地方，就是把答案写成对自己的道德评价("我懒""我自控力差")。道德评价没有任何操作价值，因为它不指向任何可以改的东西。

先说清什么是目标值：调节回路总是把存量拉向某个水平，这个水平就是目标值。它通常不是你嘴上的目标，而是你的系统实际默认的那个"舒服位置"。

案例一：房间总是乱回去。

目标值不是"整洁"，而是"我能忍受的最低整洁度"。这个目标值由什么定义？由三件事：一是你的物品数量除以收纳空间的比值——东西比位置多，那乱就是唯一的稳态；二是"归位的动作成本"，如果放回去要开柜门、挪箱子、找位置，那么它一定不会被放回去；三是"你什么时候会被触发去收拾"，通常是有人要来、或者乱到影响功能。

所以要改的是目标值本身：减少物品总量、把常用物品的归位动作降到一步、以及把触发条件提前(比如固定每周有人来，或者固定周五晚上十分钟)。注意第三条是给这个回路装一个新的、更早的触发器，让它在低水位就动作，这样它维持的位置就变了。

案例二：钱总是存不下。

目标值是"你习惯的生活水位"，它由你的日常消费惯性、你的社交环境的消费标准、以及"钱在你账上有多容易被花掉"共同定义。最后一条很实在：如果所有钱都在同一个随时能刷的账户里，那么这个回路的目标值就等于"月底剩下的零头"。

改法是改结构，而不是改决心：把入流分叉(到账即自动转出固定比例)、把出流加摩擦(大额消费设二十四小时冷静期)、把参照系换掉(减少和消费水平远高于你的人的高频比较)。这三个动作分别改的是流量路径、动作成本、目标值的社会来源。

案例三：立志学习总是持续三周。

目标值是"你在没有外部压力时会自然做的事的量"，接近于零。三周是意志力储备的典型耗尽周期。它由什么定义？由"这件事是否被嵌进你已有的固定流程"。凡是需要你每天重新决定一次的事，都会在三周内回到目标值。

改法是把它挂在一个已经稳定的行为后面(通勤、午饭后、睡前刷牙后)，把它变成那个行为的尾巴，而不是一个独立的新事项。同时把量降到你觉得"这也太少了"的程度——因为你要建立的是回路，不是成绩。

统一的判断标准：**你的答案里必须出现"结构性的定义者"(空间、动作成本、账户设置、触发条件、参照人群、既有流程)，而不能只出现"我的性格"。** 如果你写出了结构性定义者，你就找到了可以动手的地方。

**第3题参考答案**

以一个非常常见的场景为例：客服团队的"首次响应时长"考核。

增强回路(让大家继续做下去的)：
压缩响应时长 → 首响指标变好 → 上级表扬、团队拿奖 → 更加追求首响 → 客服养成"先回一句再说"的习惯 → 首响指标更好。

迟到的调节回路：
"先回一句再说"意味着问题实际没解决 → 客户二次、三次来问 → 总工单量上升、客户不满累积 → 若干个月后表现为满意度下降、投诉上升、退订增加 → 高层察觉 → 要求整改。

现在回答"缺少的反馈线"。这是这道题最有价值的部分。

缺少的不是"客户满意度"，很多公司都有满意度调查，但它通常在每次会话后单独打分，而且回收率低、被客服话术引导("麻烦给个五星")。真正缺的是**把同一个问题的完整生命周期串起来的那条线**，也就是"一次解决率"或者"同一客户同一问题的重复咨询次数"。

为什么这条线最关键？因为它是唯一能同时看见"快"和"真的解决了"的指标。首响时长只能看见快；工单量只能看见忙；满意度容易被操作。而"同一问题重复咨询次数"这个指标，会让"先回一句再说"这个行为直接暴露——你回得再快，客户再来问，这个数字就上去了。

如果我有权加一个指标，我会加这个。并且我会加一个配套动作(这是超出题目但更重要的部分)：**把这个指标的统计单位从"个人"上升到"团队"**。因为如果按个人算，客服会开始互相推工单，好让重复咨询算到别人头上——这就是我们第9章要讲的"规则一定会被优化"的现象。

最后给你这道题的通用结论，值得记住：**当一个组织出现"数据好但事情糟"，几乎总是因为它测量了"过程的速度"，却没有测量"结果的完成"。** 速度好测、及时、客观；完成难测、滞后、需要判断。系统会自动往好测的那个方向长。所以设计指标的时候，第一个要问的问题不是"这个指标准不准"，而是"如果有人只优化这个指标，他会干出什么事"。
