## 练习 2：注册自定义中断处理器

在 `kernel.c` 中注册一个断点（INT 3）处理器：

```c
void breakpoint_handler(registers_t *regs) {
    screen_set_color(VGA_COLOR_YELLOW, VGA_COLOR_BLACK);
    screen_printf("[BREAKPOINT] at EIP: 0x%x\n", regs->eip);
    screen_set_color(VGA_COLOR_LIGHT_GREY, VGA_COLOR_BLACK);
}

// 在kernel_main中注册并测试
register_interrupt_handler(3, breakpoint_handler);
__asm__ volatile("int $3");  // 触发断点
```

验证处理器被正确调用并打印了EIP。

## 练习 3：实现定时器中断

时钟中断（IRQ0）是向量32。实现一个简单的计时器：

```c
static uint32_t tick = 0;

void timer_handler(registers_t *regs) {
    tick++;
    if (tick % 100 == 0) {  // 约每秒一次
        screen_printf("[TIMER] %d seconds\n", tick / 100);
    }
}

// 注册
register_interrupt_handler(32, timer_handler);
```

## 练习 4：PIC中断掩码

学习使用中断掩码控制IRQ：

```c
// 禁用某个IRQ
void irq_set_mask(uint8_t irq) {
    uint16_t port;
    if (irq < 8) {
        port = 0x21;
    } else {
        port = 0xA1;
        irq -= 8;
    }
    uint8_t value = inb(port) | (1 << irq);
    outb(port, value);
}

// 启用某个IRQ
void irq_clear_mask(uint8_t irq) {
    // 提示：与上面相反，使用 & ~(1 << irq)
}
```

实现 `irq_clear_mask`，并测试只启用键盘中断（IRQ1）。
