# 手动配置指南

## Ubuntu/Debian

### 1. 更新系统

```bash
sudo apt update && sudo apt upgrade -y
```

### 2. 安装编译工具链

```bash
# GCC 和基本编译工具
sudo apt install -y build-essential

# 32位支持（编译32位内核需要）
sudo apt install -y gcc-multilib

# NASM 汇编器
sudo apt install -y nasm
```

### 3. 安装 QEMU

```bash
sudo apt install -y qemu-system-x86
```

### 4. 安装调试器

```bash
sudo apt install -y gdb
```

### 5. 安装辅助工具

```bash
# 二进制文件查看
sudo apt install -y hexdump xxd

# 磁盘映像工具
sudo apt install -y mtools
```

### 6. 验证

```bash
gcc --version        # 应显示 gcc 版本
nasm --version       # 应显示 NASM 版本
qemu-system-x86_64 --version  # 应显示 QEMU 版本
gdb --version        # 应显示 GDB 版本
make --version       # 应显示 Make 版本
```

## macOS

### 1. 安装 Homebrew（如未安装）

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### 2. 安装工具

```bash
# 交叉编译工具链（macOS 原生 GCC 是 Clang，需要交叉编译器）
brew install i686-elf-gcc
brew install i686-elf-binutils

# NASM
brew install nasm

# QEMU
brew install qemu

# GDB（macOS 自带 lldb，但 GDB 对 OS 调试更方便）
brew install gdb
```

### 3. 验证

```bash
i686-elf-gcc --version
nasm --version
qemu-system-x86_64 --version
```

> ⚠️ macOS 上使用 `i686-elf-gcc` 替代 `gcc`，后续 Makefile 需要相应调整。

## Windows（WSL2）

### 1. 安装 WSL2

以管理员身份打开 PowerShell：

```powershell
wsl --install -d Ubuntu
```

重启后设置用户名和密码。

### 2. 进入 WSL

```powershell
wsl
```

### 3. 按 Ubuntu 步骤安装

进入 WSL 后，按照上面 Ubuntu/Debian 的步骤安装所有工具。

### 4. 图形界面支持

Windows 11 的 WSL2 自带图形支持（WSLg），QEMU 窗口可以直接显示。

Windows 10 需要安装 X Server（如 VcXsrv）：

```bash
# 设置 DISPLAY 环境变量
export DISPLAY=$(cat /etc/resolv.conf | grep nameserver | awk '{print $2}'):0
```

## 编辑器配置

### VSCode（推荐）

安装以下扩展：
- **C/C++** - C语言语法支持
- **x86 and x86_64 Assembly** - 汇编语法高亮
- **Makefile Tools** - Makefile 支持
- **Hex Editor** - 查看二进制文件

### Vim

在 `.vimrc` 中添加：
```vim
" 汇编文件类型识别
au BufRead,BufNewFile *.asm set filetype=nasm
" Tab设置
set tabstop=4
set shiftwidth=4
set expandtab
```
