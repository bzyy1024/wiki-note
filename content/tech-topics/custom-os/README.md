# 从零开始的操作系统教程

> 让计算机初级程序员能够从零开始，逐步学习并实现一个64位操作系统

## 快速开始

**5分钟看到效果：**
```bash
cd 00-快速体验/
./run.sh
```

**从头学起：**
1. 先完成 [01-环境准备](01-环境准备/README.md) 配置开发环境
2. 阅读 [02-基础知识](02-基础知识/README.md) 补充前置知识
3. 从 [03-BIOS与启动](03-BIOS与启动/README.md) 开始动手

## 学习建议

1. **按顺序学习** - 每章建立在前章基础上，不要跳章
2. **动手实践** - 亲自敲代码、编译、运行，不要只看
3. **善用调试** - 遇到问题先查"常见错误.md"，再用GDB调试
4. **做练习题** - 至少完成🟢基础练习，巩固核心概念
5. **对比检查点** - 卡住时对比检查点代码找出差异
