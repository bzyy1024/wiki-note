# 虚拟内存 - 练习题

## 练习 1：高半内核映射

修改vmm_init，将内核映射到虚拟地址0xC0000000（3GB处）：

```c
// 物理地址 0x0-0x400000 映射到虚拟地址 0xC0000000-0xC0400000
for (uint32_t i = 0; i < 1024; i++) {
    vmm_map_page(dir, 0xC0000000 + i * PAGE_SIZE, i * PAGE_SIZE, PAGE_WRITABLE);
}
```

注意：这需要同时保持恒等映射，直到跳转到高地址代码。

## 练习 3：需求分页

实现延迟分配（lazy allocation）：
1. vmm_map_page时只在页表中标记"待分配"（不分配物理帧）
2. 第一次访问时触发缺页异常
3. 在缺页处理器中分配物理帧并建立真正的映射

## 练习 4：写时复制（COW）

实现简单的Copy-on-Write：
1. 两个页目录共享同一个物理页（标记为只读）
2. 写入时触发缺页异常
3. 在异常处理器中复制物理页并重新映射为可写
