# 练习题

## 🟢 基础练习

### 练习1：颜色测试

编写一个函数，在屏幕上显示所有16种颜色及其名称。

### 练习2：画分隔线

实现 `screen_draw_line()` 函数，在屏幕上画一行 `═` 字符（80个）。

### 练习3：定位输出

实现 `screen_print_at(int row, int col, const char *str)` 在指定位置输出。

## 🟡 进阶练习

### 练习4：完善printf

为 `screen_printf` 添加以下格式支持：
- `%u` — 无符号整数
- `%08x` — 带前导零的十六进制
- `%p` — 指针地址

### 练习5：滚屏测试

编写测试代码，连续输出30行文本，验证滚屏功能正确。

## 🔴 挑战练习

### 练习6：状态栏

在屏幕最后一行实现一个固定的状态栏（不随内容滚动），显示系统信息。
