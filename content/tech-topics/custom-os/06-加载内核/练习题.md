# 练习题

## 🟢 基础练习

### 练习1：修改内核消息

修改 `kernel.c`，在屏幕上显示不同的消息。

### 练习2：彩色输出

修改内核代码，用不同颜色显示消息。在屏幕第二行显示绿色的 "Kernel OK"。

### 练习3：理解编译过程

手动执行 Makefile 中的每条命令，观察每步产生的文件大小和内容。

## 🟡 进阶练习

### 练习4：实现 memset

在 `kernel.c` 中实现 `memset` 函数，用它来清屏：

```c
void memset(void *ptr, int value, int size);
```

### 练习5：多行输出

实现一个简单的 `print_at` 函数：

```c
void print_at(const char *msg, int row, int col, char color);
```
