## 练习 2：连续帧分配

有时需要分配多个连续的物理页帧（例如DMA缓冲区）。实现：

```c
uint32_t pmm_alloc_frames(uint32_t count);
void pmm_free_frames(uint32_t phys_addr, uint32_t count);
```

提示：需要在位图中查找连续count个空闲位。

## 练习 3：BIOS内存检测

修改bootloader，在实模式下使用INT 0x15, AX=0xE820获取内存映射，然后传递给内核。

```nasm
; 在boot.asm中，进入保护模式前调用
detect_memory:
    mov di, 0x8000      ; 结果存放位置
    xor ebx, ebx        ; 续传标记
    mov edx, 0x534D4150  ; "SMAP"签名
.loop:
    mov eax, 0xE820
    mov ecx, 24          ; 每条记录大小
    int 0x15
    ; ...处理结果...
```

## 练习 4：实现简单的kfree

为bump allocator添加一个简单的释放机制（使用空闲链表）：

```c
struct free_block {
    uint32_t size;
    struct free_block *next;
};

void kfree(void *ptr);
```
