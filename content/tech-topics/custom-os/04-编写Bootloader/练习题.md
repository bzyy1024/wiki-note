### 练习4：磁盘读取重试

修改 `disk_read` 函数，当读取失败时自动重试3次（而不是立即停止）。

**提示：**
```asm
mov cx, 3       ; 重试次数
.retry:
    ; ... 尝试读取 ...
    jnc .success  ; 成功则跳过重试
    dec cx
    jnz .retry
    ; 3次都失败，报错
```

## 🔴 挑战练习

### 练习6：实现LBA到CHS的转换

编写函数将LBA（逻辑块地址）转换为CHS（柱面-磁头-扇区），支持读取更大范围的磁盘。

公式：
```
Sector   = (LBA % sectors_per_track) + 1
Head     = (LBA / sectors_per_track) % heads
Cylinder = (LBA / sectors_per_track) / heads
```
