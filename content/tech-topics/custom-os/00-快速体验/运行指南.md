# 运行指南

## 前提条件

你需要安装 QEMU 虚拟机。如果还没安装：

**Ubuntu/Debian:**
```bash
sudo apt install qemu-system-x86
```

**macOS:**
```bash
brew install qemu
```

**Windows WSL:**
```bash
sudo apt install qemu-system-x86
```

## 运行方式

### 自动运行

```bash
./run.sh
```

### 手动运行

```bash
qemu-system-x86_64 -drive format=raw,file=预编译镜像/os.img
```

### 使用额外选项

```bash
# 带串口输出（可以在终端看到调试信息）
qemu-system-x86_64 -drive format=raw,file=预编译镜像/os.img -serial stdio

# 指定内存大小
qemu-system-x86_64 -drive format=raw,file=预编译镜像/os.img -m 128M
```

## 退出QEMU

- 按 `Ctrl+Alt+Q` 退出
- 或关闭QEMU窗口

## 常见问题

### Q: 提示找不到 qemu-system-x86_64

安装QEMU后重试，参考上面的安装命令。

### Q: 窗口一闪而过

尝试在终端中运行，查看错误信息。

### Q: 显示 "No bootable device"

确认 `预编译镜像/os.img` 文件存在且完整。
