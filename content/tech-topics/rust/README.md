# Rust 高级开发学习教程

> 为 Go 程序员打造的 Rust 进阶之路
> 
> 通过 8-12 周的系统学习,从 Rust 新手成长为高级开发者

## 📚 课程特色

- ✅ **为 Go 程序员定制** - 大量 Go vs Rust 对比
- ✅ **深入底层原理** - 不仅教怎么用,更解释为什么
- ✅ **完整参考答案** - 所有练习和面试题都有详细答案
- ✅ **求职导向** - 项目作品集 + 面试题库
- ✅ **螺旋式学习** - 知识点多次迭代,加深理解

## 🚀 快速开始

1. **环境搭建**
   ```bash
   # 安装 Rust
   curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
   
   # 配置 VS Code
   # 安装 rust-analyzer 插件
   ```

2. **开始学习**
   - 阅读 [学习路线图](00-学习路线图.md)
   - 从 [01-从Go到Rust-思维转换](01-从Go到Rust-思维转换.md) 开始

3. **实践项目**
   - 完成每章练习题
   - 按阶段完成实战项目

## 💡 学习建议

1. **按顺序学习** - 章节之间有依赖关系
2. **动手实践** - 每个示例都要运行
3. **完成练习** - 先自己做,再看答案
4. **坚持到底** - 第 6-7 周最难,挺过去会有质的飞跃
