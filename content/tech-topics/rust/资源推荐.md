## 六、工具链

### 必备工具

```bash
# 安装 Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 常用命令
rustup update          # 更新工具链
rustup component add clippy rustfmt rust-analyzer

cargo new my_project   # 创建项目
cargo build --release  # 构建
cargo test             # 测试
cargo clippy           # Lint
cargo fmt              # 格式化
cargo doc --open       # 生成文档
cargo bench            # 基准测试
```

## 八、速查表 (Cheat Sheet)

### 所有权速查

```
值绑定: let x = value;       → x 拥有 value
移动:   let y = x;           → y 拥有, x 不可用 (非Copy)
复制:   let y = x;           → y 是副本, x 仍可用 (Copy类型)
借用:   let r = &x;          → r 借用 x, x 仍可用
可变借:  let r = &mut x;      → r 可变借用 x (独占)
克隆:   let y = x.clone();   → 深复制, 两者独立
```

### 生命周期速查

```rust
// 函数
fn foo<'a>(x: &'a str, y: &'a str) -> &'a str { ... }

// 结构体
struct Foo<'a> {
    x: &'a str,
}

// 方法
impl<'a> Foo<'a> {
    fn method(&'a self) -> &'a str { ... }
}

// 'static
fn static_ref() -> &'static str { "hello" }  // 字符串字面量
```

### 错误处理速查

```rust
// 返回类型
fn foo() -> Result<T, E>
fn bar() -> Option<T>

// 传播错误
let x = foo()?;  // 失败时提前返回

// 转换
result.unwrap()           // panic on err
result.expect("msg")      // panic with msg
result.unwrap_or(default) // 默认值
result.map(|v| ...)       // 转换 Ok 值
result.and_then(|v| ...)  // 链式 Result
```

### Trait 速查

```rust
// 定义
trait Greet {
    fn greet(&self) -> String;
    fn hello(&self) { println!("{}", self.greet()); }  // 默认实现
}

// 泛型约束
fn print<T: Display + Debug>(val: T) { ... }
fn print<T>(val: T) where T: Display + Debug { ... }

// Trait 对象
fn do_stuff(val: &dyn Trait) { ... }      // 借用
fn do_stuff(val: Box<dyn Trait>) { ... }  // 拥有
```
