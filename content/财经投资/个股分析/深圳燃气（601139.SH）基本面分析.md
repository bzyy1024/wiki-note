# 深圳燃气（601139.SH）基本面分析

> 说明：以下内容用于基本面研究与学习，不构成投资建议。涉及最新财报、估值和实时经营数据的部分，如未能确认，统一标注为“数据待核实”。

## 1. 公司基础信息

- 公司名称：深圳市燃气集团股份有限公司
- 股票代码：601139.SH
- 所属行业：城市燃气 / 公用事业
- 主营业务：城市燃气销售、燃气工程、综合能源、LNG相关业务
- 主要收入来源：管道燃气销售、工程安装、LNG贸易和综合能源服务
- 主要利润来源：城市燃气经营权、气量增长、安装业务和部分综合能源服务

通俗理解：
- 深圳燃气就是典型的“城市燃气基础设施 + 贸易 + 综合服务”公司。
- 它赚的钱，既来自卖气的稳定现金流，也来自工程安装和上下游价差管理。

### 商业模式简述
- 模式：公用事业 + 贸易型业务结合
- 收入渠道：居民、工商用户售气，燃气工程安装，LNG采购和转售，综合能源服务
- 成本结构：气源采购成本占比高，管网和安全投入稳定，工程业务会影响利润弹性

### 主打产品/服务
Top 3 可理解为：
1. 城市管道燃气销售
2. 燃气工程安装与接驳
3. LNG贸易与综合能源业务

近3年产品线变化：
- 从单一城市燃气向综合能源和LNG业务延展
- 工商业用户和综合服务比重提升
- 更强调气源优化、毛差管理和跨业务协同

## 2. 行业分析

- 所处阶段：成熟公用事业 + 低速成长行业
- 市场空间：城市燃气渗透率较高，增长来自工商业用气、城市扩张和能源替代
- 3到5年增长逻辑：
  - 城市人口和产业活动带来的气量增长
  - 工商业用能替代和清洁能源政策
  - 综合能源、分布式和LNG业务延伸
- 成长空间判断：
  - 总量空间不算大，但在工业气量、综合能源和服务化上仍有延展
  - 天花板受城市边界、气源成本和管网覆盖限制
- 竞争格局：区域经营特征较强，竞争主要体现在气源、用户结构和服务效率
- 周期位置：弱周期，但盈利会受气价、采购成本和冬季需求影响
- 关键驱动因素：气价政策、气源采购、城市人口、工商业活动、天气和安全监管
- 观察指标：售气量、毛差、工商业客户增长、工程业务收入、应收账款、库存和安全事故
- 最大风险：气源成本波动、价差收窄、安全风险、政策调价滞后

## 3. 商业模式与核心竞争力

- 商业模式完整链条：上游气源采购 -> 管网输配 -> 居民和工商业售气 -> 工程安装 -> 综合能源与LNG业务延伸
- 可复制性：区域特许经营和管网网络有壁垒，但贸易和综合能源竞争更激烈
- 护城河：城市特许经营权、管网网络、用户基础、服务和安全管理能力
- 护城河性质：长期有效，但不如水电那样绝对稀缺
- 相较同行优势：深圳市场优质、工商业客户基础强、管理和服务能力较好
- 相较同行劣势：燃气贸易受气价波动影响，利润率通常不高
- 定价权：有限，终端价格受监管和传导机制约束
- 资产模式：重资产型，管网和终端基础设施占用明显

## 4. 财务报表深度分析

以下结论偏趋势判断，具体年度数据待核实。

- 营业收入：总体稳步增长，但受气量和工程业务影响
- 归母净利润：相对稳定，但毛差和工程业务会带来波动
- 毛利率：不算高，主要看气源成本和终端传导
- 净利率：通常较薄，公用事业特征明显
- ROE：中等偏稳，不属于高利润行业
- 资产负债率：基础设施企业通常不低，需要看现金流覆盖
- 经营现金流：总体可用，但气价和应收会影响节奏
- 自由现金流：受管网投资和安全投入影响
- 存货/应收：LNG贸易、工程结算和终端回款都值得盯
- 资本开支：持续存在，管网扩建和安全改造是重点
- 分红：具备一定稳定分红基础，但弹性不如高利润行业

### 杜邦分析（方向性）
- 净利率：偏薄
- 总资产周转率：中等，取决于气量和工程业务
- 权益乘数：可能对ROE贡献较大，但并非主要看点

结论：
- 盈利驱动更偏“高周转 + 适度杠杆 + 稳定服务”，不是高利润驱动

## 5. 多年经营质量分析

- 业绩特征：稳定中带有能源贸易波动
- 历史增长来源：城市扩张、工商业客户增加、LNG业务和综合能源
- 可持续性：较好，但利润率受气源成本制约
- 周期贡献 vs 公司能力贡献：
  - 周期贡献：中等，天气和气价会带来波动
  - 公司能力贡献：较强，尤其是客户结构和气源管理

## 6. 管理层与资本配置

- 管理层：总体稳健，强调安全、效率和综合能源转型
- 资本配置：以管网、安全和业务延伸为主
- 需要警惕：LNG贸易波动、工程业务回款和安全事故
- 大股东减持、商誉和关联交易：以公告为准，关注区域经营稳定性

## 7. 风险分析

- 行业风险：气价和毛差波动
- 政策风险：终端调价机制、环保政策和安全监管
- 周期风险：冬季需求、工业景气和气源供需
- 技术替代风险：电气化和分布式能源替代部分需求
- 原材料成本波动风险：气源采购成本是核心风险
- 竞争加剧风险：综合能源与LNG贸易竞争加剧
- 财务风险：工程回款、贸易库存和负债
- 公司治理风险：安全生产、合规和项目投资

压力测试（方向性，数据待核实）：
- 温和压力：毛差收窄，利润小幅承压
- 中度压力：气源成本上升且传导滞后，净利润可能下降5%到15%
- 重度压力：安全事故或气源大幅波动，现金流和估值同步承压

## 8. 估值分析

适合的方法：
- PE估值：看稳定利润
- PB估值：看公用事业资产和安全边际
- 股息率：适合防御型观察
- DCF：适合长期管网和现金流资产

估值逻辑：
- 深圳燃气更适合看“气量增长 + 毛差 + 现金流稳定性”
- 如果工商业客户增长和毛差改善，估值可以维持；反之要回到防御性定价

三情景（数据待核实）：
- 保守：毛差一般，业务平稳
- 中性：气量稳增，综合能源逐步贡献
- 乐观：工商业用气和综合能源加速

当前价格判断：数据待核实，建议结合PE、PB和股息率综合判断。

## 9. 投资价值总结

- 值不值得长期跟踪：值得，偏稳定配置和公用事业研究视角
- 最核心投资逻辑：区域燃气基础设施 + 气量增长 + 综合能源延伸
- 最大护城河：特许经营、管网和用户基础
- 最容易高估的点：把气量增长当成高成长
- 最容易低估的点：城市资源价值和服务延展能力
- 当前最大风险点：气源成本、毛差和安全
- 买入条件：估值合理、毛差稳定、工商业气量增长
- 放弃关注条件：毛差持续收窄、安全和回款恶化
