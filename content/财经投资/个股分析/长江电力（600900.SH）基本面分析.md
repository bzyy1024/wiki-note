# 长江电力（600900.SH）基本面分析

> 说明：以下内容用于基本面研究与学习，不构成投资建议。涉及最新财报、估值和实时经营数据的部分，如未能确认，统一标注为“数据待核实”。

## 1. 公司基础信息

- 公司名称：中国长江电力股份有限公司
- 股票代码：600900.SH
- 所属行业：水电 / 公用事业
- 主营业务：大型水电站发电与售电
- 主要收入来源：发电量销售、电价收入
- 主要利润来源：稳定发电能力、低运维成本和长期资产运营

通俗理解：
- 长江电力本质上是“把水资源变成长期稳定现金流”的公司。
- 它不像制造业那样靠不断卖更多产品，而是靠少数超大型水电站长期收租金式地发电。

### 商业模式简述
- 模式：典型公用事业，B2B/B2G色彩强
- 收入渠道：上网电价、发电量结算、部分资产运营和投资收益（数据待核实）
- 成本结构：前期资本开支极大，后期运维成本低，典型长久期资产

### 主打产品/服务
Top 3 可以理解为：
1. 三峡及梯级水电发电业务
2. 电力销售与调峰能力
3. 相关水电资产运营

近3年产品线变化：
- 主体仍是水电主业，变化不在产品，而在机组效率、调度和资产整合
- 如有外延并购或抽蓄布局，更多是资产配置延展（数据待核实）

## 2. 行业分析

- 所处阶段：成熟且极度稳定的公用事业行业
- 市场空间：水电总量空间有限，增长主要来自发电效率、来水条件和资产整合
- 3到5年增长逻辑：
  - 来水情况改善带动发电量上升
  - 机组效率和调度优化
  - 资产整合与新项目并表
  - 抽水蓄能、调峰和电力系统价值提升
- 成长空间判断：
  - 行业总量天花板很明确，但现金流质量和分红能力持续增强仍有价值
- 竞争格局：天然区域垄断和资源垄断，行业竞争远低于制造业
- 周期位置：弱周期甚至准逆周期，受来水和电价政策影响但不受商品周期主导
- 关键驱动因素：来水、调度、电价政策、电力需求、电网消纳能力
- 观察指标：发电量、来水、利用小时数、上网电价、分红率、资本开支
- 最大风险：来水偏枯、政策调整、电价机制变化、超预期资本开支

## 3. 商业模式与核心竞争力

- 商业模式完整链条：水资源与电站建设 -> 长期运营 -> 发电售电 -> 现金流回收 -> 持续分红和资产扩张
- 可复制性：极低，核心资源和大型水电站难以复制
- 护城河：稀缺水资源、特许经营、超长寿命资产、调度能力和规模优势
- 护城河性质：非常长期，甚至接近“准永久”级别，但受政策和来水约束
- 相较同行优势：资产质量高、现金流稳定、分红能力强、负债可控
- 相较同行劣势：成长性有限，受自然来水和政策制约
- 定价权：一般不强，但在稳定收益属性上有很高吸引力
- 资产模式：重资产型，但属于“高质量长久期重资产”

## 4. 财务报表深度分析

以下结论偏趋势判断，具体年度数据待核实。

- 营业收入：总体稳定，受发电量和电价影响
- 归母净利润：稳定性强，波动显著低于周期行业
- 毛利率：较高且稳定，体现低运维成本
- 净利率：稳定，盈利质量好
- ROE：通常较稳，部分年份受杠杆和来水波动影响
- 资产负债率：前期投资形成的债务较高，但现金流支撑能力强
- 经营现金流：非常强，是公司最核心的财务优点
- 自由现金流：随着大额投资周期结束，长期趋势有望改善
- 存货/应收：相对可控，重点看电费结算和政策回款
- 资本开支：前期极大，后期趋于平稳，决定FCF弹性
- 分红：高分红和长期分红属性突出，是核心卖点之一

### 杜邦分析（方向性）
- 净利率：高且稳定
- 总资产周转率：不高，但水电资产就是长久期低周转型
- 权益乘数：会影响ROE，但核心不是高杠杆投机

结论：
- 盈利驱动主要靠“高利润 + 长周期稳定现金流”，不是高杠杆

## 5. 多年经营质量分析

- 业绩特征：极稳健，周期波动小
- 历史增长来源：新增机组、资产注入、来水改善、电价调整
- 可持续性：长期仍然优质，但增速不会高
- 周期贡献 vs 公司能力贡献：
  - 周期贡献：来水波动带来一定影响
  - 公司能力贡献：资产运营和调度能力是核心

## 6. 管理层与资本配置

- 管理层：战略清晰，围绕“稳定发电 + 长期分红”展开
- 资本配置：偏稳健，重视长期资产质量和分红回报
- 需要警惕：若继续大规模扩张且回报不及预期，会压制自由现金流
- 大股东减持、商誉和关联交易：需以公告为准，重点关注资本开支节奏

## 7. 风险分析

- 行业风险：水电总量增长有限
- 政策风险：电价机制、生态环保和水资源调度
- 周期风险：来水丰枯导致发电量波动
- 技术替代风险：新能源与储能对电力系统结构的影响
- 原材料成本波动风险：相对较低
- 竞争加剧风险：较低，主要是政策和资源约束
- 财务风险：前期投资与杠杆水平
- 公司治理风险：资产整合、资本开支和回报效率

压力测试（方向性，数据待核实）：
- 温和压力：来水偏弱，发电量下降，利润小幅波动
- 中度压力：持续偏枯年份，净利润可能下降10%到20%
- 重度压力：电价机制变化或超大资本开支，估值和现金流承压

## 8. 估值分析

适合的方法：
- 股息率估值：最重要，适合高分红稳定资产
- DCF：适合长久期现金流资产
- PB估值：适合看资产质量和安全边际
- PE估值：可作为辅助

估值逻辑：
- 长江电力更适合看“稳定现金流折现 + 股息率 + 分红可持续性”
- 如果股息率回到历史相对高位，研究价值通常更好；如果估值过高，则回报会被压缩

三情景（数据待核实）：
- 保守：来水一般，分红维持稳定
- 中性：发电量平稳，分红继续增长
- 乐观：来水改善、资产运营效率提升

当前价格判断：数据待核实，建议结合股息率和DCF综合判断。

## 9. 投资价值总结

- 值不值得长期跟踪：值得，是公用事业里最典型的核心资产之一
- 最核心投资逻辑：稳定现金流 + 长期分红 + 稀缺水电资产
- 最大护城河：资源、资产寿命和经营稳定性
- 最容易高估的点：把低波动等同于绝对低风险
- 最容易低估的点：分红稳定性和资产稀缺性
- 当前最大风险点：来水波动和政策变化
- 买入条件：股息率具备吸引力，估值回到历史合理区间
- 放弃关注条件：政策机制明显转弱、分红不及预期、资本开支失控
