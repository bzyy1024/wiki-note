# 财富与投资课：从不懂投资，到看懂财富的游戏

> 这是一套帮你从「不懂投资、只会存钱」成长为「看懂财富、会投资」的理财课程。
> 课程提炼自天使投资、股市实战、巴菲特等财富智慧，案例丰富、层层设问。
> 每一课都是一个投资老手，带着一个"想理财又怕亏"的小白，看懂财富的游戏规则。

---


## 怎么学？三句真心话

1. **投资第一课，是"别亏钱"。** 先学会"守住本金"，再谈"赚钱"。
2. **认知决定收益。** 你赚不到"认知之外"的钱，所以先提升认知，再谈操作。
3. **用"亏得起的钱"练手。** 别一开始就重仓，先小成本试错、积累经验。

## 结业标准（成为"大佬"的标志）

学完 9 课，你应该能做到：

- [ ] 分清"财富思维"和"资本思维"
- [ ] 理解"长期主义"和"复利"的力量
- [ ] 能区分"投资"和"投机"
- [ ] 掌握股市、天使投资的基本逻辑
- [ ] 有投资纪律，不被情绪和"常识"左右

**当你能理性地分析一个投资机会，而不是靠"消息、感觉、跟风"，并守住本金——你就已经是投资的大佬了。**
