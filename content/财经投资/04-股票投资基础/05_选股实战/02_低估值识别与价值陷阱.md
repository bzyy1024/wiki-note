## 第一节：三维度低估判断框架

老陈在白板上画了三个圆，彼此有交叉区域：

「低估值判断，不能只看一个维度。要从三个角度同时确认，三维度同时满足，才是高置信度的低估信号。」

### 维度一：绝对低估（与自身历史比较）

#### 判断规则1：PE < 历史均值 - 1个标准差

$$\text{PE低估线} = \overline{PE} - \sigma_{PE}$$

- $\overline{PE}$：该股过去5年（或10年）PE均值
- $\sigma_{PE}$：PE的标准差

**示例**（某消费品公司，示意性数字）：

| 统计项 | 数值 |
|-------|------|
| 过去10年PE均值 | 28倍 |
| PE标准差 | 8倍 |
| 低估线 | 28 - 8 = **20倍** |
| 当前PE | 18倍 |
| 结论 | 低于低估线，**绝对低估** ✓ |

#### 判断规则2：PB < 1（且ROE > 10%）

$$\text{PB} = \frac{\text{每股市价}}{\text{每股净资产}}$$

**逻辑**：PB < 1意味着市场对这家公司的定价低于其账面净资产，相当于"一元钱不到能买一元的资产"。但这个规则必须附加条件：**ROE > 10%**，否则净资产本身就是在缩水的烂摊子。

> PB < 1 + ROE > 10% = 股权极度低估的强信号

**反例**：某公司PB = 0.6，但ROE只有3%，说明公司每年只能靠净资产赚3%，相当于活期存款收益率还不如，PB低不代表便宜。

#### 判断规则3：股息率 > 10年国债收益率 × 2

**当前基准**：10年期国债收益率约2.5%（2024年水平），因此阈值约为5%

$$\text{股息率} = \frac{\text{每股股息}}{\text{每股市价}} \times 100\% > 5\%$$

**逻辑**：股息率高于国债收益率两倍，说明持有这只股票获得的股息本身就已超越无风险收益，即使股价不涨也有较好回报。

---

### 维度二：相对低估（同行横向比较）

「只跟自己历史比还不够。」老陈说，「一家公司PE=20倍，如果全行业平均PE=30倍，那20倍就是相对便宜；但如果全行业PE=10倍，20倍反而偏贵。」

#### 判断规则1：个股PE / 行业平均PE < 0.8

$$\text{相对估值比} = \frac{\text{个股 PE}}{\text{行业平均 PE}} < 0.8$$

**示例**：
- 某银行股PE = 5倍，银行行业平均PE = 7倍
- 相对估值比 = 5/7 = 0.71 < 0.8 → **相对低估** ✓

#### 判断规则2：PEG < 1（成长股适用）

$$\text{PEG} = \frac{\text{PE}}{\text{净利润增速（\%）}}$$

- PEG < 1：用低于增速的价格买入成长，**性价比高**
- PEG > 2：为成长支付了过高溢价，**危险**

**示例**：
- A公司PE = 30倍，净利润增速 = 35%/年 → PEG = 0.86 < 1 ✓
- B公司PE = 30倍，净利润增速 = 10%/年 → PEG = 3.0，贵了 ✗

> **注意**：PEG仅适合业绩持续高增长的成长股，对周期股、困境股无效。

---

### 维度三：历史分位低估（本股的长期位置）

「第三个维度，是把当前估值放进历史长河里看——它现在处于历史上的哪个位置？」

$$\text{PE历史分位} = \frac{\text{历史上PE低于当前值的交易日数量}}{\text{总交易日数量}}$$

**判断标准**：
| PE历史分位 | 估值信号 |
|-----------|---------|
| < 20%     | 极度低估（罕见机会） |
| 20%~30%   | 低估区间（积极关注） |
| 30%~70%   | 合理区间 |
| > 70%     | 偏贵 |
| > 90%     | 极度高估（谨慎持仓） |

**同理，PB历史分位**：
- < 20% → 极度低估

> **三维度同时满足规则**：
> - 绝对低估：PE < 历史均值 - 1σ，且股息率 > 5%
> - 相对低估：个股PE / 行业PE < 0.8
> - 历史分位低估：PE历史分位 < 30%
>
> **三者同时满足 = 高置信度低估信号**，建议重点研究

## 第二节：七大价值陷阱详解

「好，三维度框架是正面进攻的武器。接下来，我带你认识价值投资最危险的敌人——**价值陷阱**。」

老陈的语气变得严肃：「这些公司看起来便宜，实际上是财富绞肉机。」

### 陷阱一：周期陷阱（最常见、最迷惑人）

老陈问：「你知道为什么钢铁股在景气高峰时PE最低吗？」

「……因为利润高，所以PE低？」

「对。但你有没有想过，那个利润是不是可持续的？」

**运作机制**：
- 周期行业（钢铁、煤炭、化工、航运）的利润随经济周期大幅波动
- 景气顶部：吨钢利润300元，全年净利润100亿，股价50亿，PE=0.5倍（看起来极度低估）
- 景气底部：吨钢亏损50元，全年净利润-10亿，PE无意义（或负值）

**判断规则**：
- 看`P/中周期平均利润`而非即期PE
- 钢铁/煤炭/化工：用过去10年的平均利润计算"标准化PE"
- 如果`标准化PE > 15倍`，当前高利润是周期顶部的幻觉

**案例（示意性数字）**：某钢铁公司2021年景气期：
- 当年利润80亿，股价400亿，即期PE = 5倍（"超低估"）
- 但2017-2021年平均利润仅20亿，标准化PE = 400/20 = 20倍（并不便宜）
- 2022年行业下行，利润降至5亿，PE=80倍，股价开始下跌

---

### 陷阱二：困境陷阱（基本面持续恶化）

「PE低，但低的原因是市场预期利润会继续下滑。」

**识别特征**：
- 收入连续2年以上同比下降
- 毛利率持续收窄（竞争加剧或成本上升）
- 管理层开始抛售股权
- 客户流失，主要订单减少

**案例（示意性）**：某传统零售公司：
- 2020年净利润5亿，市值40亿，PE=8倍（"便宜"）
- 但电商冲击下，同店销售连续3年-15%/年
- 2023年净利润只剩2亿，市值还是35亿，PE=17.5倍
- "PE低"买入，越跌越亏，PE反而更高了

**判断规则**：看连续2年以上的营收增速。连续负增长的公司，当期低PE往往是未来高PE的前兆。

---

### 陷阱三：杠杆陷阱（ROE虚高）

「这个陷阱专门针对我们上一篇讲的ROE筛选。」

**运作机制**：
- 通过大量借款，用财务杠杆人为拉高ROE
- 表面上：净资产50亿，总资产500亿（负债率90%），净利润10亿，ROE=20%（看起来很好）
- 实质上：这10亿净利润是靠450亿负债撬出来的，ROIC=10/(50+450×有息占比)，可能很低

**公式验证**：

$$\text{去杠杆ROE} = \text{净利率} \times \text{资产周转率}$$

如果去杠杆ROE只有3%，说明这门生意不加杠杆本身只能赚3%，高ROE完全是杠杆的幻觉。

**一旦去杠杆**（被迫或主动）：
- 资产出售→资产周转率下降
- 还债→净资产减少
- 利息增加→净利润减少
- 三重打击下，ROE可能从20%崩至3%，股价雪崩

**案例（示意性）**：某地产开发商：
- 表面ROE 18%，PE 6倍，PB 0.8倍，看起来很便宜
- 资产负债率92%，有息负债/EBITDA = 8倍
- 2021年政策收紧后，去杠杆，净资产减半，利润转负，股价跌去80%

---

### 陷阱四：商誉陷阱（利润黑洞随时引爆）

「商誉是A股最危险的报表科目之一。」老陈说。

**商誉的形成**：

$$\text{商誉} = \text{收购支付对价} - \text{被收购方净资产公允价值}$$

**商誉减值的触发**：被收购公司当年利润未达到收购时承诺的业绩目标，需进行减值测试，减值金额直接计入当期亏损。

**危险阈值**：
- 商誉/净资产 > 30%：需要关注
- 商誉/净资产 > 50%：**高危**，一旦集中减值，净资产可能蒸发大半

**案例（示意性）**：某传媒公司2018年：
- 净资产100亿，商誉75亿（占比75%）
- 多个收购标的业绩承诺期满后暴雷
- 当年计提商誉减值65亿，当年亏损55亿（业绩变脸）
- 股价从20元跌至3元

---

### 陷阱五：政策依赖陷阱（补贴一退，利润归零）

老陈问：「你有没有算过，有些公司的净利润和政府补贴金额……差不多？」

小林皱眉：「那意思是如果补贴停了，公司其实亏损？」

「正是。」

**识别方法**：

$$\text{政策依赖度} = \frac{\text{政府补贴（营业外收入）}}{\text{净利润}} \times 100\%$$

如果政策依赖度 > 50%，该公司的盈利能力存在重大不确定性。

**常见领域**：新能源（补贴退坡时期）、光伏早期、部分军工、特定农业

**判断规则**：
1. 查利润表附注中"政府补贴"明细
2. 用`扣非净利润`代替`净利润`（扣非后PE更真实）
3. 查看近3年补贴金额趋势是否在递减

---

### 陷阱六：竞争恶化陷阱（护城河正在消失）

「这种陷阱最隐蔽。」老陈皱起眉头，「你看到的是历史高峰期的漂亮利润，却没看到这个护城河正在被挖穿。」

**信号识别**：
- 毛利率连续3年下降（定价权减弱）
- 市场份额下滑（新竞争者入侵）
- 客单价下降（被迫以价换量）
- 研发/广告投入占比下降（防守意愿减弱）

**案例（示意性）**：某手机配件公司：
- 2018年毛利率45%，市场份额35%，PE=12倍，看起来便宜
- 但竞争对手不断进入，2019-2021年毛利率连年下降：42%→38%→31%
- 利润不断压缩，尽管PE始终"便宜"，股价实际跌了60%

**护城河评估四问**：
1. 产品有无真实差异化？
2. 客户切换成本高不高？
3. 新竞争者进入门槛高不高？
4. 成本端是否具备规模优势？

---

### 陷阱七：流动性陷阱（便宜但买不进卖不出）

「最后一个陷阱不是基本面问题，而是市场结构问题。」

**定义**：A股部分小市值股票（市值 < 30亿），估值确实低，但日均成交额只有几百万元，大资金根本无法建仓或退出，流动性溢价极低。

**危害**：
- 大资金买入即拉升，但卖出时同样会大幅压价
- 股权质押比例高时，大股东强制平仓导致流动性瞬间枯竭
- 退市风险与信息不对称风险更高

**判断规则**：
- 日均成交额 < 5000万元：流动性陷阱警戒线
- 市值 < 20亿：流动性不足，排除

## 第三节：好公司 vs 好股票终极辨析

老陈重新画出那个2×2矩阵，这次加了具体的案例：

```
                低估值                    高估值
         ┌─────────────────────┬──────────────────────────┐
 好公司  │  ★★★ 理想买入        │  可持有，不宜新建重仓      │
         │  示例：茅台2018低谷  │  示例：茅台2021年 PE=60倍  │
```

老陈说：「我给你三个现实案例，你来判断落在哪个格子：」

**案例1**：某白酒龙头，ROE=28%，ROIC=25%，毛利率92%，PE当前18倍，历史PE分位15%。

「对。」

「差公司+低估值……价值陷阱？」

「答对了。ROE高是靠杠杆，ROIC已经低于WACC，典型的差公司。」

**案例3**：某互联网平台，ROE=18%，自由现金流充沛，但当前PE=55倍，历史PE分位82%。

「好公司，但高估……可以持有，但不要重仓加仓？」

「非常好。这就是2021年很多白马股的状态——公司本身没问题，但价格太贵，持有者的未来回报会被高估值拖累。」

## 第四节：安全边际计算

「找到了好公司，判断了低估，还差最后一步——算安全边际。」

**巴菲特的原则**：内在价值折价30%以上才买入。

$$\text{安全边际} = \frac{\text{内在价值} - \text{当前市价}}{\text{内在价值}} \times 100\% \geq 30\%$$

**内在价值估算（DCF简化版）**：

$$\text{简化内在价值} \approx \frac{\text{自由现金流} \times (1+g)}{r - g}$$

其中：
- $g$：预期长期增长率（保守估算，通常取5%~10%）
- $r$：折现率（通常取WACC，约8%~10%）

**示例**（某消费品公司，示意性数字）：
```
当年自由现金流 = 50亿
保守增长率 g  = 7%
折现率 r      = 10%
→ 内在价值    = 50 × 1.07 / (0.10 - 0.07) = 53.5 / 0.03 ≈ 1783亿

当前市值      = 1200亿
安全边际      = (1783 - 1200) / 1783 = 32.7%  > 30% ✓
→ 具备安全边际，满足买入条件
```

老陈说：「安全边际不是精确计算，是一种保守主义哲学。你故意把增长率估低一点，折现率估高一点，如果在这么保守的假设下还有30%折价，说明这个价格真的便宜，即使你的预测有误差，也有容错空间。」

## 第五节：Tushare历史PE分位计算

```python
import tushare as ts
import pandas as pd
import numpy as np

pro = ts.pro_api('你的TOKEN')

# 获取茅台过去5年日度估值数据
df = pro.daily_basic(
    ts_code='600519.SH',
    start_date='20190101',
    end_date='20231231',
    fields='trade_date,pe_ttm,pb,dv_ratio'
)

df = df.dropna(subset=['pe_ttm'])
df = df.sort_values('trade_date')

# 计算当前PE历史分位
current_pe   = df['pe_ttm'].iloc[-1]
pe_percentile = (df['pe_ttm'] < current_pe).mean()

print(f"当前PE: {current_pe:.1f} 倍")
print(f"PE历史分位: {pe_percentile:.1%}")

if pe_percentile < 0.20:
    print("→ 极度低估区间，重点关注")
elif pe_percentile < 0.30:
    print("→ 低估区间，可以介入")
elif pe_percentile < 0.70:
    print("→ 合理区间，持有")
else:
    print("→ 估值偏高，谨慎新建仓位")
```

## 追问思考题

### 题目一
一家煤炭公司，2022年煤炭景气期净利润80亿，市值400亿，PE=5倍，历史PE分位只有8%（历史上从没这么便宜过），股息率达到12%。请问：这符合本篇讲的三维度低估标准吗？你会买入吗？请从"周期陷阱"角度分析。

> **答案方向**：表面看，PE=5倍、历史分位8%、股息率12%，三维度似乎全满足。但这是典型的**周期陷阱**：PE低是因为当期利润处于超高景气峰值（煤价历史高位），而历史分位低也是因为历史上从未有过如此高的利润，这是"分母异常膨胀"导致的虚假低估。正确做法：计算过去10年标准化PE（用平均利润而非当期利润），若标准化PE>15倍，说明当前价格并不便宜。股息率同理，基于峰值利润的高股息不可持续。

### 题目二
你发现一家公司PB=0.7，ROE=15%，PE历史分位25%，似乎是好的买入机会。但进一步调查发现商誉占净资产的55%，且大股东在过去6个月股权质押比例从40%上升至75%。你会如何综合判断？

> **答案方向**：表面估值数据不错，但有两个高危信号：①**商誉陷阱**：55%商誉占比超过30%警戒线，若被收购标的业绩不达预期，将引发大规模减值，净资产可能大幅缩水，导致PB反弹至正常水平甚至更高；②**大股东质押风险**：质押比例从40%升至75%，说明大股东资金链可能存在压力，一旦股价下跌触及平仓线，将引发强制卖出，流动性危机可能爆发。综合评估：这是一个看起来便宜、实则处于"地雷区"的价值陷阱，应回避。

### 题目三
"好公司+高估值=可以持有但不宜重仓买入"，这句话在实践中如何操作？如果你已经重仓持有一只好公司的股票，估值从历史分位30%上升到80%，你应该怎么做？

> **答案方向**：这道题没有标准答案，体现投资哲学的差异。方向一（偏价值）：分批减仓，把仓位从重仓降至标配，锁定部分收益，静待价格回落至合理区间再加回来；方向二（偏成长）：如果公司基本面在持续改善（ROE提升、FCF增加、竞争地位强化），高估值可能是市场重估的过程，选择持有但不再加仓。关键判断依据：**估值上升是否伴随基本面同步改善**——若PE从20升至40，但同期净利润也翻倍，则PEG并未恶化；若PE从20升至40但利润原地踏步，则需要降仓。
