# 附录｜财务报表分析速查手册

> 这是一本「随手翻」的工具手册，把整套课的核心术语、公式、框架浓缩成几页。
> 学习过程中随时查阅，学完后也能当「字典」用。

---

## 一、核心术语速查表

| 术语 | 一句话解释 |
|------|-----------|
| 资产负债表 | 某一时点的「家底快照」，资产 = 负债 + 所有者权益 |
| 利润表 | 一段时期的「赚钱流水」，收入 − 成本 − 费用 = 利润 |
| 现金流量表 | 一段时期的「现金进出」，分经营、投资、筹资三块 |
| 权责发生制 | 收入/费用在「发生时」确认，不管钱收没收 |
| 收付实现制 | 只在「真收/真付钱」时确认 |
| 流动资产 | 一年内能变现的资产（现金、应收、存货等）|
| 非流动资产 | 变现慢、长期用的资产（固定资产、无形资产、商誉等）|
| 经营性负债 | 欠供应商/员工/客户的钱（应付、预收等），「两头吃」的结果 |
| 金融性负债 | 银行借款、发债，要付利息、有还本压力 |
| 核心利润 | 主业经营赚的钱，剔除了投资收益、营业外等杂项 |
| 扣非净利润 | 扣除非经常性损益后的净利润，更接近真实主业赚钱能力 |
| 商誉 | 并购时买价超过净资产公允价值的溢价，业绩不达标就减值 |
| 合并报表 | 母公司 + 全部子公司的整体报表 |
| 母公司报表 | 只看母公司自身法人的报表 |

## 二、核心公式速查

### 1. 基础公式
```
资产 = 负债 + 所有者权益
毛利 = 营业收入 − 营业成本
毛利率 = 毛利 ÷ 营业收入
净利润率 = 净利润 ÷ 营业收入
```

### 2. 张新民核心指标
```
核心利润 ≈ 营业收入 − 营业成本 − 税金及附加
          − 销售费用 − 管理费用 − 研发费用 − 财务费用(经营部分)

核心利润获现率 = 经营活动现金流量净额 ÷ 核心利润
   （≥ 1 优秀；0.5~1 关注；< 0.5 警惕）

销售收现率 = 销售商品、提供劳务收到的现金 ÷ 营业收入
   （≈ 1 说明收入都收回了现金）
```

### 3. 传统比率（记住它们的局限）
```
流动比率 = 流动资产 ÷ 流动负债（传统标准 >2，但会失灵）
速动比率 = (流动资产 − 存货) ÷ 流动负债（传统标准 >1，会失灵）
资产负债率 = 负债 ÷ 资产（不是越低越好，要看负债性质）
```

### 4. 效率与回报
```
资产周转率 = 营业收入 ÷ 平均总资产
自由现金流 = 经营活动现金流量净额 − 资本开支
```

## 三、张新民分析框架「一页纸」

### 战略关系资产负债表（核心工具）

```
┌──────────────────┬──────────────────┐
│   经营性资产      │   经营性负债      │  ← 「两头吃」的体现
│  (自己干活的家当)  │  (欠供应商/客户)  │
├──────────────────┼──────────────────┤
│   投资性资产      │   金融性负债      │  ← 加杠杆、有代价
│  (投出去的钱)     │  (银行借款/发债)  │
│                  ├──────────────────┤
│                  │   股东权益        │  ← 自己攒的本钱
└──────────────────┴──────────────────┘
```

### 三个战略问题
1. 靠什么赚钱？（商业模式）
2. 在干什么、给谁干？（经营 vs 投资；谁在支持）
3. 靠谁支持发展？（上下游 / 银行 / 股东）

### 三「子」口诀
> **底子（资产质量）× 面子（利润质量）× 里子（现金质量）** —— 三者一致则健康，三者打架必有鬼。

---

## 四、六步拆解法（案例通用）

```
第1步 定性   —— 干什么的？经营/投资型？重/轻资产？
第2步 资产   —— 底子：应收、存货、商誉有没有雷？
第3步 利润   —— 面子：核心利润、扣非、毛利率趋势？
第4步 现金   —— 里子：经营现金流、获现率、自由现金流？
第5步 风险   —— 十大信号中了几条？附注/审计/关联交易？
第6步 结论   —— 好/普通/危险？买入/回避？理由？
```

## 五、十大爆雷预警信号（避雷清单）

1. 经营现金流长期为负
2. 应收账款、存货增速远超收入
3. 存贷双高（假现金警报）
4. 大股东高比例质押、频繁减持
5. 频繁更换会计师事务所
6. 审计报告非标意见
7. 商誉占比过高、并购标的不达标
8. 关联交易异常、其他应收款巨大
9. 毛利率、净利率异常地好
10. 核心利润与净利润背离（靠杂项凑）

> 中 3 条以上，建议直接回避。

## 六、三块现金流的组合画像

| 经营 | 投资 | 筹资 | 画像 |
|:----:|:----:|:----:|------|
| + | − | + | 成长期：造血 + 扩张 + 融资 |
| + | − | − | 成熟期：造血 + 扩张 + 还债分红（优质）|
| + | + | − | 收缩/去杠杆 |
| − | + | + | 危险：失血 + 卖资产 + 借钱续命 |
| − | − | + | 激进烧钱（高风险）|

---

## 七、五步体检流程

```
造血（经营现金流）→ 家底（资产质量）→ 面子（利润质量）
→ 结构（重/轻资产、两头吃）→ 趋势（改善 or 恶化）
```

---

## 八、五类审计意见（从好到坏）

```
标准无保留意见  →  带强调事项段  →  保留意见
→  无法表示意见  →  否定意见
（非标 = 警报，基本可拉黑）
```

---

## 九、投资「九问清单」（买入前必过）

```
□ 搞懂商业模式了吗？
□ 核心利润为正且可持续吗？
□ 核心利润获现率 ≥ 1 吗？
□ 经营现金流长期为正吗？
□ 负债以经营性为主吗？（两头吃）
□ 踩中「十大预警信号」了吗？
□ 审计意见是标准无保留吗？
□ 价格贵吗？（安全边际）
□ 愿意持有 3~5 年吗？
```
