# 第10章 现金流：赚钱的公司为什么会猝死

## 引子：一个真实的下午

一月十四号，腊月二十四。

小林在工资表上签完字，抬头问了老周一句："周哥，这个月的工资，钱够吗？"

老周正在看电脑，头也没抬："够。"

"我是说，账上的现金。"

老周这才转过身来，看了她两秒。

"你问这个干什么？"

"我算了一下，一月要付的原料款三千二百万，年终奖一千八百万，还有上个月那笔设备尾款六百万。我们账上……"小林翻了翻手机上的银行余额截图，"两千一百万。"

老周的脸色变了。

"你从哪儿看的两千一百万？"

"资金日报啊，我每天早上都能收到。"

"那你怎么现在才说？"

"我上个月就觉得不对劲……"小林的声音小下去，"但我以为年底回款会到。"

老周站起来，在办公室里转了两圈，然后拿起电话。

那天下午，小林第一次知道原来公司还有"过桥"这种事。老周跟银行谈了三天，把一笔二月底到期的授信提前支出来，才把工资和年终奖发出去。利息多付了十几万。

周一，老周把她叫过去，说了一句让她整个人凉透的话：

"小林，这事你别往外说。王总要是知道我们是最后一刻才搞定的，会换人。"

"那……我当时问您的时候……"

"我问你，"老周打断她，"你觉得这事该谁管？"

小林张了张嘴，没说出话。

她心里有个声音在喊：三个月前我就能看出来。三个月前的资金日报上，那个数字就在往下掉。可是她每天收到那份日报，看一眼余额，然后关掉。她一直以为，钱不够是老周的事，是公司的事，是银行的事——反正不是"做报表的人"的事。

那天晚上，她给墨叔发了一条消息。

"墨叔，我差点让我们公司发不出工资。"

墨叔回得很快："明天中午，老地方。带上你们最近六个月的资金日报。"

## 对谈

"我给你讲个故事。"墨叔把茶杯推到一边。

"是您那家公司倒闭的事吗？"

"你知道？"

"您上次提过一嘴。年利润八百万，发不出工资。"

"对。"墨叔说，"那家公司叫恒昌调味品，在河北。我在那儿做财务负责人，那年我三十五岁。"

### 一、那年我们赚了八百一十万

"我先问你一个问题。"墨叔说，"一家公司，一年净利润八百一十万，创历史最好水平，会在三个月后发不出工资吗？"

"不会吧。"

"你再想想。"

"……除非钱没到账。"

"钱没到账，这是第一层。"墨叔竖起一根手指，"我给你讲三层。"

"第一层，那八百一十万利润里，有六百二十万是应收账款。"

"年底集中发货？"

"你怎么知道？"

"我们去年也是这么干的。"小林苦笑，"十二月二十八号还在开票。"

"对。我们跟一个大超市系统谈了个'年度合作'，条件是账期九十天。销售的老大跟我说，这一单做完，全年任务就完成了。我说账期太长，他说'你不懂，这是战略客户'。"

"然后呢？"

"然后我们十二月发了两千三百万的货，成本一千六百八十万，报表上多了六百二十万的利润。钱一分没到。"

"第二层。"墨叔竖起第二根手指，"我们那年上了一条新线。"

"这条新线，跟利润有关系吗？"

"一点关系都没有。"墨叔说，"花了一千一百六十万，钱是实打实付出去的——设备款分三期，第一期十二月付的。这一千一百六十万，在现金流量表上记在'购建固定资产支付的现金'里，在利润表上一个字都没有。"

"第三层，贷款。"

"三月份到期一千万本金。"

"对，一千万。前年借的，三年期，到期一次性还本。"

"所以——"

"所以我把那年的现金流算给你听。"墨叔在纸上写了四行。

```
经营活动现金流净额     + 460 万元
投资活动现金流净额    −1,160 万元（新线）
筹资活动现金流净额     − 500 万元（还贷 1,000 万，新借 500 万）
                       ─────────
现金净变动            −1,200 万元
期初现金                +900 万元
                       ─────────
期末现金                −300 万元
```

"所以我们那年赚了八百一十万，现金净流出了一千二百万。"墨叔说，"三月的工资是二百一十万。账上连三百万元的窟窿都堵不上。"

"后来呢？"

"工人堵在厂门口三天。"墨叔说，"我赔了公司一百二十万——赔偿金、停产损失、还有两个客户听说我们出问题之后抽走的订单。"

"那您当时为什么不早说？"

"你以为我没说吗？"墨叔苦笑，"我在年会上说过。我说'我们今年的利润质量不太高'。"

"他们没听懂？"

"他们听懂了，但没当回事。"墨叔说，"**这就是那次事故给我上的第一课：财务讲'利润质量不高'，在老板耳朵里等于什么都没说。**你得说'三月的工资发不出来'。"

"那您后来怎么说的？"

"后来我学会了一种说法。"墨叔说，"我不说'利润质量'，我说：'王总，我们今年赚了八百一十万，但这些钱现在在三个地方——六百二十万在超市的账上，九十天才回来；一千一百六十万变成了车间里那台新机器；还有一千万三月份要还给银行。账上现在剩九百万。'"

"这样说就懂了？"

"这样说，他当场就把电话打给银行了。"

### 二、三组混淆，讲成一种本能

"墨叔，我承认我以前没把现金当回事。"小林说，"但我不是不会算间接法，我每年编现金流量表编得可顺了。"

"你会编表，不代表你有现金流的感觉。"墨叔说，"我问你三组东西的区别，你用一句话说清楚。"

"第一组：收入和现金流入。"

"收入是发货开票就确认，现金流入是钱到账才算。赊销有收入没现金，预收款有现金没收入。"

"第二组：成本和现金流出。"

"成本是……"小林卡住了，"成本里有折旧，折旧不付现。还有，采购付钱的时间和耗用的时间不一样。"

"我给你补一句更狠的。"墨叔说，"**你买原料付的钱，在那一刻是现金流出，但不是成本；它得等到这批原料被投产、被卖出去，才变成成本。**中间这段时间，它叫什么？"

"存货。"

"对。所以：**成本是现金流出穿过存货这道门之后，才变成的样子。**"

"第三组：利润和现金结余。"

小林想了很久。

"利润是……一段时间里，收入减成本的结果，但它不管钱有没有动。现金结余是……钱真的多了还是少了。"

"我给你一个更好记的说法。"墨叔说，"**利润是一个'观点'，现金余额是一个'事实'。**观点可以讨论，事实不能。"

"我拿你们公司举个例子。"他翻出小林带过来的资金日报。

"你看看这个月，收入多少？"

"六千八百万。"

"卖出去的货，收回来的现金呢？"

"……五千九百万？"

"差九百万。这九百万去哪儿了？"

"变成应收账款了。"

"再看，这个月营业成本四千九百万，采购付出去多少钱？"

"五千四百万。"

"多付了五百万，去哪儿了？"

"……存货。"

"你看。"墨叔说，"**收入六千八百万，进来五千九百万；成本四千九百万，出去五千四百万。**收入比成本多一千九百万，现金却只多了五百万。"

小林盯着这几个数，忽然明白了什么。

"所以……利润和现金的差别，就藏在这两个'错位数'里。"

"你再说一遍，我没听清。"

"**卖出去的没收回来，是应收；买进来的没用完，是存货。**利润表不管这两个，现金流量表管。"

"好。"墨叔点点头，"这句话，就是你以后判断任何一家公司现金状况的第一反应。"

### 三、营运资金三要素与现金转换周期

"那我该怎么系统地看这件事？"

"三个要素，一个周期。"墨叔说，"先说三个要素：应收、应付、存货。"

"应收是我们替客户垫的钱。"

"对。客户拿走货，没给钱，等于你借给他一笔无息贷款。"

"应付是供应商替我们垫的钱。"

"对。你拿了货没付钱，等于供应商借给你一笔无息贷款。这两笔，方向相反。"

"存货是我们垫给自己的钱。"

"这个说法有意思，你展开说说。"

"就是……我们花钱买了原料，加工成产品，放在冷库里。这笔钱已经出去了，但在卖掉之前，它回不来。所以是我们自己占着自己的钱。"

"很好。"墨叔说，"现在把这三个串起来，就是一个周期——**现金转换周期**，英文缩写 CCC。"

他在纸上画了一条时间线。

```
付钱给供应商 ──────────► 收客户的钱
    │                          │
    │◄── 存货天数 ──►│◄─ 应收天数 ─►│
    │                               │
    │◄────── 应付天数 ──────►│
    │                               │
    └────── 现金转换周期 CCC ──────┘
```

"公式就一句话："

```
CCC = 存货周转天数 + 应收账款周转天数 − 应付账款周转天数
```

"我给你讲讲这个公式的物理意义。"墨叔说，"你从掏钱买原料那天开始算，到你把货卖掉、把钱收回来那天为止，中间隔了多少天，这中间的资金全是你自己垫的。这叫什么？这叫'钱躺在生意里的时间'。"

"优鲜是多少天？"

"你自己算。应收六十三天，存货七十五天，应付四十五天。"

"六十三加七十五减四十五……九十三天。"

"九十三个日日夜夜。"墨叔说，"**我们公司每做一块钱的生意，就有一块钱被锁在生意里九十三天。**"

"那……这九十天，占用多少钱？"

"你说呢？"

"八亿除以三百六十五，乘九十三……两亿零四百万。"

"两亿零三百八十四万。"墨叔说，"我给你补一个更准的口径。"

```
简化口径（管理层沟通用，全按收入）：
80,000 ÷ 365 × 93 = 20,384 万元 ≈ 2.04 亿元

账面精确口径（存货和应付按成本算）：
应收账款占用 = 80,000 × 63 ÷ 365 = 13,808 万元
存货占用     = 57,600 × 75 ÷ 365 = 11,836 万元
应付占用     = 57,600 × 45 ÷ 365 =  7,101 万元（抵减项）
净营运资金   = 13,808 + 11,836 − 7,101 = 18,543 万元 ≈ 1.85 亿元
```

"两个口径差了一千八百万。为什么？"

"因为……存货和应付是按成本算的，不是按售价。简化口径把它们都按收入算了，高估了。"

"对。**跟老板沟通用 2.04 亿，自己心里有数用 1.85 亿。**两个都要会算，而且你要能说清楚为什么不一样——这个'为什么'，就是你比别人专业的那一点点。"

### 四、增长吃现金：卖得越好，死得越快

"墨叔，我一直有个地方想不通。"

"说。"

"我们今年卖得挺好，收入涨了百分之十一。为什么现金反而更紧了？"

"你这个问题问得好，但问反了。"墨叔说，"**不是'为什么增长让现金变紧了'，是'增长本来就要吃现金'。**"

"啊？"

"我问你：你要多做一块钱的生意，得先垫什么？"

"先买原料……"

"然后呢？"

"生产，变成存货。"

"然后呢？"

"卖出去，变成应收。"

"然后呢？"

"然后……等客户付钱。"

"从你掏第一分钱，到客户把钱给你，中间多少天？"

"九十三天。"

"所以你每增加一块钱的年销售额，就要预先垫多少钱？"

"九十三除以三百六十五……两毛五？"

"两毛五分五厘。"墨叔说，"**每多做一块钱的年收入，你要先掏两毛五分五厘的现金，而且这钱一年只能周转 3.92 次。**"

小林忽然坐直了。

"我给你算个大的。"墨叔说，"假设明年我们收入增长 30%。"

```
新收入 = 80,000 × 1.30 = 104,000 万元
新营业成本 = 104,000 × (1 − 28%) = 104,000 × 0.72 = 74,880 万元

新应收账款 = 104,000 × 63 ÷ 365 = 17,951 万元
新存货      = 74,880 × 75 ÷ 365 = 15,386 万元
新应付账款  = 74,880 × 45 ÷ 365 =  9,232 万元
新净营运资金 = 17,951 + 15,386 − 9,232 = 24,105 万元

原净营运资金 = 18,543 万元
需额外垫资   = 24,105 − 18,543 = 5,562 万元
```

"五千五百多万。"

"五千五百六十二万。那明年多赚多少利润？"

"十万四千万乘百分之五，是五千二百万。减掉今年的四千万……多赚一千二百万。"

"所以——"

"所以多赚一千二百万，要先垫五千五百六十二万。"小林的声音有点发抖，"净现金是负的四千三百六十二万。"

"对。"墨叔说，"**这就是'卖得越好，死得越快'。**"

"那……增长岂不是坏事？"

"不是坏事，是要配钱。"墨叔说，"我给你三种情况，你自己判断。"

"第一种：用利润撑增长。每年多赚的利润，能不能覆盖多垫的营运资金？优鲜的情况是：多赚 1,200 万，多垫 5,562 万，覆盖不了，差 4,362 万。"

"那差的怎么办？"

"要么借钱，要么拖供应商，要么老股东掏钱。"

"第二种：用借款撑增长。借 4,362 万，一年利息按 6%，二百六十二万。多赚的一千二百万减掉利息，还剩九百三十八万。看起来还行，但你的资产负债率上去了，而且银行不会无限借给你。"

"第三种：先把 CCC 压下来再增长。这才是正解。"

### 五、压 CCC：四个抓手，各管一段

"怎么压？"

"四个抓手，我一个一个说。"墨叔伸出四根手指。

**抓手一：应收——账期谈判**

"我们应收六十三天，能压到多少？"

"你先回答我：六十三天是怎么来的？"

"……合同账期？"

"你去查一下。"墨叔说，"我猜你们的情况是这样：合同上写的是 45 天，但实际上客户平均 63 天才付。中间那 18 天是什么？"

"是……逾期？"

"对，还有开票延迟、对账延迟、付款流程慢。"墨叔说，"所以我给你三个动作，按难度排序："

"第一个动作，**把'开票到回款'的天数单独统计出来**。很多公司只统计'发货到回款'，但真正的黑洞在'货到了，发票没开'或者'发票开了，客户没收到'。"

"第二个动作，**把逾期客户分级，交给不同的人去催**。超过 30 天的，销售跟；超过 60 天的，销售总监跟；超过 90 天的，财务发正式函件，并停止发货。"

"第三个动作，**用价格换账期**。你跟客户说：账期从 60 天缩到 30 天，我给你 1.5 个点折扣。这笔账要这么算："

```
原：账期 60 天，边际贡献率 28.5%（B 端）
    年化占用回报 = 28.5% × (365 ÷ 60) = 173.4%

新：账期 30 天，边际贡献率 28.5% − 1.5% = 27.0%
    年化占用回报 = 27.0% × (365 ÷ 30) = 328.5%
```

"看起来丢了 1.5 个点的毛利，实际上占用回报翻了将近一倍。"

"而且还有一个隐性好处：账期短的客户，往往更健康。"

**抓手二：应收——预收款设计**

"第四个动作是预收款。"墨叔说，"这是最狠的一招，因为它能把 CCC 变成负数。"

"负数？那不是客户先给钱吗？"

"对。**你如果能收到预收款，你的应收天数是零，你的现金转换周期可能变成负数——不是你垫钱给客户，是客户垫钱给你。**"

"我们这种行业能收预收款吗？"

"能，但要设计。四种常见做法："

```
一、年框 + 预付：签年度框架协议，客户预付全年货款的 10%-20%，
    换来"淡旺季优先保供"和"价格锁定"。

二、新品首发：新品上市，经销商要先打款才能拿到首发配额。
    你们 180 个 SKU，每年推新品的时候都能用。

三、旺季产能预约：十一月前，让客户预约定产能，付定金锁定。
    这既收了钱，又提前锁定了排产计划——一箭双雕。

四、充值返点：给经销商做"预存货款返 2%"。
    表面看是让利 2%，实际是拿 2% 换来了无息资金。
```

"最后一个我算给你看。"墨叔说，"假设一个经销商一年做 500 万，预存 100 万，返 2%。"

```
让利 = 500 × 2% = 10 万元
提前收到的资金 = 100 万元，平均占用期按 6 个月算
资金成本节约 = 100 × 6% × (6 ÷ 12) = 3 万元

看起来亏 7 万。但如果这 100 万让他把账期从 60 天缩到 30 天：
全年应收占用减少 = 500 × (60 − 30) ÷ 365 = 41 万元
资金成本节约 = 41 × 6% = 2.5 万元
```

"还是亏。"

"对，单看财务是亏的。"墨叔说，"但你漏了一样东西——**锁定**。预存货款的经销商，不会临时跳到别家去。这一条值多少钱？"

"这个……算不出来。"

"算不出来不等于不存在。"墨叔说，"**BP 的本事，就是能把算不出来的东西，也摆到桌面上让老板自己权衡。**你要做的是把'算得出来的部分'算清楚，然后说一句：'另外还有一块是锁定客户，这个我没法算，您觉得值多少？'"

**抓手三：存货——库存周转**

"存货七十五天，怎么压？"

"你先回答我一个问题：七十五天，是'平均'还是'结构'？"

"什么意思？"

"我打个比方。你家附近有两个人，一个人一顿饭吃三碗，一个人三天不吃饭。平均下来一人一天一碗半，看着挺正常。但你不能按'平均'给他们备饭。"

"所以要看结构。"

"对。存货一定要拆成三类看："

```
第一类：能卖的、好卖的（A 类）
        这些是"活"的库存，75 天里可能只有 30 天是它们。

第二类：能卖的、但卖得慢的（B 类）
        周转正常，但占了地方。

第三类：卖不掉的（C 类）
        滞销、临期、规格淘汰、客户退回的。
        这些货在账上是资产，在冷库里是负债——每天都要付电费。
```

"我猜你们的存货里，第三类占了多少？"

"我……没统计过。"

"这就是你要做的第一件事：做一张**库龄表**。按 0-30 天、31-60 天、61-90 天、91-180 天、180 天以上五档，把存货金额和占比列出来。"

"然后呢？"

"然后你会看到一个让你震惊的数。"墨叔说，"我做过十几家公司的库龄表，几乎没有一家 180 天以上库龄的占比低于 5%。"

"那怎么办？"

"三个动作："

```
一、设一条红线：库龄超过 180 天的，必须每月上报，由销售、生产、财务三方会签处理方案
   （打折、转渠道、改包装、报废）。

二、把"库龄"写进销售的考核里。谁卖出去的货，最后变成了滞销，算谁的。
   这一条最难推，但最有效。

三、算清楚"最小起订量"。小批量订单带来的换线成本和库存碎片，
   是不是超过了它的贡献毛利？第 8 章那个预制菜就是活例子。
```

**抓手四：应付——付款节奏**

"应付四十五天。这个……是不是越长越好？"

"你先回答我：我们延长账期，代价是什么？"

"供应商会不高兴。"

"具体一点。"

"可能会涨价，或者断供。"

"对。**应付账款是你向供应商借的一笔无息贷款，但它有两个隐藏利率：一个是涨价，一个是断供风险。**"

"那怎么办？"

"三条原则。"

"第一，**不要一刀切地拖**。把所有供应商按'可替代性'分成三类：完全可替代的（标准包装、通用辅料）、可替代但切换有成本的（主要原料）、不可替代的（独家配方原料）。对第一类可以谈长账期；对第三类，反而要考虑提前付款换更好的价格。"

"第二，**用现金折扣换账期，要算清楚**。供应商说'10 天内付款给 2% 折扣'，值不值？"

```
放弃折扣，多占用 45 − 10 = 35 天
这 35 天的成本 = 2% ÷ 98% = 2.041%
年化 = 2.041% × (365 ÷ 35) = 21.3%
```

"年化百分之二十一！"小林叫出来。

"所以原则上，能拿的现金折扣一定要拿。"墨叔说，"除非你的资金成本高于 21%，或者你手上的钱有更高回报的去处。"

"第三，**付款节奏要平滑**。很多公司是月底集中付款，于是月初账上有钱、月末紧张。你可以跟供应商谈'每月两次付款窗口'，把现金流摊平。这件事不省钱，但它让你每个礼拜都睡得着。"

### 六、13 周滚动现金流预测：BP 的真家伙

"墨叔，那我具体该做什么表？"

"直接法，滚动 13 周。"

"为什么要 13 周？"

"你猜呢？"

"一个季度？"

"一个季度，正好是一个季度。"墨叔说，"为什么是一个季度？因为**一个季度是你能'看见'的最长距离，也是你还有时间反应的最短距离。**超过一个季度，你的预测全是假的；短于一个季度，等你发现问题已经来不及改了。"

"为什么用直接法？"

"因为间接法是用来对外报的，直接法是用来管钱的。"墨叔说，"我要知道的是'下周三有多少钱进来、多少钱出去'，不是'净利润加回折旧'。"

"那这张表长什么样？"

墨叔拿过一张 A3 纸，横过来画了一张表。

| 行 | 项目 | 数据来源 | 谁提供 |
|---|---|---|---|
| 1 | 期初现金余额 | 资金日报 | 资金岗 |
| 2 | 现金流入：现款现货销售 | 按历史日均 × 季节系数 | 销售运营（小陈） |
| 3 | 现金流入：应收账款回款 | 分客户的回款计划表 | 销售运营 + 应收会计 |
| 4 | 现金流入：其他（退税、补贴、处置） | 专项台账 | 税务会计、总账 |
| 5 | 现金流出：原料采购付款 | 采购付款计划 | 采购部（赵经理） |
| 6 | 现金流出：职工薪酬 | 工资表 + 社保公积金 | 人力资源部 |
| 7 | 现金流出：税费 | 申报表 | 税务会计 |
| 8 | 现金流出：费用报销与付款 | 报销系统 + 历史平均 | 各部门 + 应付会计 |
| 9 | 现金流出：资本性支出 | 在建工程与设备付款计划 | 设备部、工程部 |
| 10 | 现金流出：还本付息 | 贷款合同还款计划 | 资金岗 |
| 11 | 净现金流 | 4 − 10 | 财务 |
| 12 | 期末现金余额 | 1 + 11 | 财务 |
| 13 | 最低安全现金余额 | 固定值或按周测算 | 财务 + 老板 |
| 14 | 缺口 / 盈余 | 12 − 13 | 财务 |

"表头是横着排的，第一列是周次，从本周开始往后推 13 周。"墨叔说，"每周一更新一次，把刚过去的那周换成实际数，把第 13 周补上。"

"为什么每周都要更新？"

"因为**预测的价值不在于准，在于你每周都在重新看一遍。**"墨叔说，"你每周看一遍，第三周就会发现有个数不对，第四周就会去问，第五周问题就暴露了。你要是做一次管三个月，那这张表做不如不做。"

"那数据从哪儿来？"

"这是最关键的。"墨叔说，"我给你一条经验：**这张表 80% 的工作量在'要数据'，20% 在'算'。**你要提前跟每个人约定好："

```
给销售运营（小陈）的话：
"每周五下班前，把下周预计回款按客户列给我，不用精确，
 但你要标出来哪几笔'有把握'、哪几笔'可能拖'。
 这个表你本来就有，我只是想让你多列一列。"

给采购（赵经理）的话：
"每周五把下周要付的款列给我，按供应商和金额。
 我知道有些还没最后定，你估一个就行，我不要精确，
 我要的是'有没有一笔大额的会在下周冒出来'。"

给人力资源的话：
"每月的工资、社保、年终奖计提，给我一张全年的日历表，
 标出来哪几个月是大月（年终奖、季度奖）。"

给设备部的话：
"所有在建和已批的设备，付款节点给我一张表，
 我按周摊进去。"
```

"他们要是不给呢？"

"这是你真正的第一个坎。"墨叔说，"我给你三句话。"

"第一句，不要以'财务需要'的名义要。要以'我们能一起提前看到问题'的名义要。"

"第二句，先给后要。你先给他们一样东西——比如你先给销售运营一份'分客户的账龄与逾期表'，他下次就不好意思不给你回款计划。"

"第三句，如果实在要不来，就用历史数据推一个，然后把'假设'写在表上，每周开会的时候当着所有人的面念出来：'应收回款这一行，是我按过去 13 周的平均回款率推的，如果有偏差，请销售这边纠正。'**你把假设摊在桌面上，纠正它的责任就转移了。**"

"这就不一样了？"

## 演算台

### 演算一：优鲜食品现金转换周期完整计算

**已知条件**

```
营业收入       80,000 万元
营业成本       57,600 万元（毛利率 28%）
应收账款       13,800 万元
存货           11,800 万元
应付账款        7,100 万元
资金成本率      6%
```

**第一步：算三个周转天数**

```
应收账款周转天数 = 应收账款 ÷ 营业收入 × 365
                 = 13,800 ÷ 80,000 × 365 = 62.96 天 ≈ 63 天

存货周转天数     = 存货 ÷ 营业成本 × 365
                 = 11,800 ÷ 57,600 × 365 = 74.77 天 ≈ 75 天

应付账款周转天数 = 应付账款 ÷ 营业成本 × 365
                 = 7,100 ÷ 57,600 × 365 = 45.00 天
```

**第二步：算现金转换周期**

```
CCC = 存货天数 + 应收天数 − 应付天数
    = 75 + 63 − 45 = 93 天
```

**第三步：算占用的资金量**

```
简化口径（全部按收入，适合跟老板沟通）：
占用资金 = 80,000 ÷ 365 × 93 = 20,384 万元 ≈ 2.04 亿元

账面精确口径（存货与应付按成本）：
应收账款占用 = 80,000 × 63 ÷ 365  = 13,808 万元
存货占用     = 57,600 × 75 ÷ 365  = 11,836 万元
应付账款占用 = 57,600 × 45 ÷ 365  =  7,101 万元
净营运资金占用 = 13,808 + 11,836 − 7,101 = 18,543 万元 ≈ 1.85 亿元

两口径差异 = 20,384 − 18,543 = 1,841 万元
差异原因：存货与应付发生在成本口径，简化法按收入口径计算，高估了 1,841 万元。
```

**第四步：这笔钱的年成本**

```
18,543 × 6% = 1,112.6 万元
```

营运资金一年的资金成本 1,112.6 万元，相当于全年净利润 4,000 万元的 27.8%。

**换个条件会怎样**：如果 CCC 是 60 天（行业优秀水平），能省多少？

```
60 天占用（精确口径）：
应收 = 80,000 × 63 ÷ 365 = 13,808（不变，假设只压存货和应付）
存货（假设压到 55 天）= 57,600 × 55 ÷ 365 = 8,678 万元
应付（假设延到 58 天）= 57,600 × 58 ÷ 365 = 9,153 万元
净营运资金 = 13,808 + 8,678 − 9,153 = 13,333 万元

释放资金 = 18,543 − 13,333 = 5,210 万元
节约利息 = 5,210 × 6% = 312.6 万元
```

相当于净利润增加 312.6 万元，增幅 7.8%。**一分钱的销售都没多做，利润涨了近 8%。**

### 演算二：增长 30%，要额外垫多少钱

**题目**：优鲜食品明年收入增长 30%，周转天数维持不变，需要额外垫付多少营运资金？

**第一步：新一年的规模**

```
新营业收入 = 80,000 × 1.30 = 104,000 万元
新营业成本 = 104,000 × 0.72 = 74,880 万元
新净利润   = 104,000 × 5% = 5,200 万元
```

**第二步：新一年的营运资金占用**

```
新应收账款 = 104,000 × 63 ÷ 365 = 17,950.7 万元
新存货     = 74,880 × 75 ÷ 365 = 15,386.3 万元
新应付账款 = 74,880 × 45 ÷ 365 =  9,231.8 万元
新净营运资金 = 17,950.7 + 15,386.3 − 9,231.8 = 24,105.2 万元
```

**第三步：额外垫资**

```
额外垫资 = 24,105.2 − 18,543 = 5,562.2 万元
```

简化口径验证：

```
24,000 ÷ 365 × 93 = 6,115.1 万元
```

两个口径的差异同样是存货与应付按成本还是按收入计算造成的。跟老板沟通时可以说"大约五千五百万到六千一百万"。

**第四步：增长的净现金结果**

```
增量净利润 = 5,200 − 4,000 = 1,200 万元
增量营运资金占用 = 5,562 万元
净现金结果 = 1,200 − 5,562 = −4,362 万元
```

**结论：收入增长 30%，利润增加 1,200 万，现金反而净流出 4,362 万。**

**第五步：这 4,362 万从哪儿来？**

| 来源 | 金额 | 代价 |
|---|---|---|
| 银行借款 | 4,362 万元 | 年息 6%，262 万/年；资产负债率上升 |
| 延长供应商账期 | 需要应付天数从 45 天延到多少？ | 涨价、断供风险 |
| 压缩现有 CCC | 见演算三 | 需要销售、生产配合 |

如果选择延长供应商账期：

```
需要新增占用 = 4,362 万元
需延长应付天数 = 4,362 ÷ 74,880 × 365 = 21.3 天
新应付天数 = 45 + 21.3 = 66.3 天
```

**应付账款从 45 天拖到 66 天**——这是一个非常激进的动作，代价几乎肯定是采购涨价。假设涨价 2%：

```
采购涨价成本 = 74,880 × 2% = 1,497.6 万元
```

1,497.6 万 > 262 万（借款利息）。**所以拖供应商远不如去借钱。**这一条，值得你拿着算给赵经理和老板看。

### 演算三：把 CCC 压缩 15 天，能释放多少现金

**题目**：三项各优化 5 天——应收从 63 天压到 58 天，存货从 75 天压到 70 天，应付从 45 天延到 50 天。

**第一步：新的 CCC**

```
新 CCC = 58 + 70 − 50 = 78 天
压缩 = 93 − 78 = 15 天
```

**第二步：逐项计算释放的现金**

```
应收账款释放 = 13,808 − (80,000 × 58 ÷ 365)
             = 13,808 − 12,712.3 = 1,095.7 万元

存货释放     = 11,836 − (57,600 × 70 ÷ 365)
             = 11,836 − 11,046.6 = 789.4 万元

应付账款释放 = (57,600 × 50 ÷ 365) − 7,101
             = 7,890.4 − 7,101 = 789.4 万元

合计释放 = 1,095.7 + 789.4 + 789.4 = 2,674.5 万元
```

**验算（简化口径）**：

```
80,000 ÷ 365 × 15 = 3,287.7 万元
```

简化口径 3,287.7 万，精确口径 2,674.5 万。**跟老板说"压缩 15 天能释放约 2,700 万到 3,300 万现金"。**

**第三步：这笔钱的价值**

```
节约利息 = 2,674.5 × 6% = 160.5 万元/年

相当于净利润提升 = 160.5 ÷ 4,000 = 4.0%
```

**第四步：三个动作分别怎么做，谁负责**

| 要素 | 目标 | 具体动作 | 责任人 | 难度 |
|---|---|---|---|---|
| 应收 63 → 58 天 | 释放 1,096 万 | 开票时效从 5 天压到 2 天；超 30 天逾期由销售总监跟；对 3 个大客户推"账期 60 天换 1.5% 折扣" | 张总监 + 应收会计 | 中 |
| 存货 75 → 70 天 | 释放 789 万 | 库龄 180 天以上每月上报三方会签；砍掉 8 个长尾 SKU；对 A 类 SKU 设安全库存上限 | 李厂长 + 销售运营 | 高 |
| 应付 45 → 50 天 | 释放 789 万 | 只针对可替代供应商（包装、通用辅料）谈；不可替代原料不动 | 赵经理 | 低 |

**第五步：难度排序与推进节奏**

应付最容易（打个电话的事），应收中等（要跟客户谈），存货最难（要动生产计划和 SKU 结构，动了就有人不高兴）。

**所以推进顺序是：先做应付（两周见效），再做应收（一到两个月），存货放最后（一个季度起步，而且要老板亲自站台）。**

**换个条件会怎样**：如果只能做存货这一项，把存货从 75 天压到 60 天呢？

```
存货释放 = 11,836 − (57,600 × 60 ÷ 365) = 11,836 − 9,468.5 = 2,367.5 万元
新 CCC = 63 + 60 − 45 = 78 天（同样是压 15 天）
```

跟三项各压 5 天的效果（2,674.5 万）差不多。**这说明：压存货一项，抵得上三项平均用力。**但难度也最大。

### 演算四：现金折扣到底该不该拿

**题目**：供应商给出条件"10 天内付款，享 2% 折扣"，否则 45 天付款。

**计算放弃折扣的年化成本**

```
放弃折扣，可多占用天数 = 45 − 10 = 35 天
放弃折扣的成本 = 2% ÷ (1 − 2%) = 2% ÷ 98% = 2.041%
年化成本 = 2.041% × (365 ÷ 35) = 21.29%
```

**判断规则**：

```
若公司资金成本 < 21.29%  → 应该拿折扣（提前付款）
若公司资金成本 > 21.29%  → 可以放弃折扣（占用资金）
```

优鲜的资金成本约 6%，远低于 21.29%，**应该拿折扣**。

**演算**：某供应商年供货额 3,000 万元，全部享受 2% 折扣：

```
年节约 = 3,000 × 2% = 60 万元
提前付款占用的额外资金 = 3,000 × (45 − 10) ÷ 365 = 287.7 万元
这笔资金的年成本 = 287.7 × 6% = 17.3 万元
净收益 = 60 − 17.3 = 42.7 万元
```

**换个条件会怎样**：如果供应商给的是"30 天内付款享 1% 折扣，否则 60 天"呢？

```
多占用天数 = 60 − 30 = 30 天
放弃折扣成本 = 1% ÷ 99% = 1.010%
年化 = 1.010% × (365 ÷ 30) = 12.29%
```

仍高于 6%，**还是应该拿**。

**临界点**：折扣率多少时，拿与不拿无所谓（公司资金成本 6%，账期差 35 天）？

```
设折扣率为 d：
d ÷ (1 − d) × (365 ÷ 35) = 6%
d ÷ (1 − d) = 6% × 35 ÷ 365 = 0.5753%
d = 0.5753% × (1 − d)
d = 0.5753% − 0.5753%d
1.005753d = 0.5753%
d = 0.572%
```

**折扣率只要超过 0.57%，在 35 天账期差下就该拿。**这个结论很反直觉——大部分人觉得"1% 的折扣有什么好拿的"。

**这一题的真正价值**：下次采购部说"这个供应商的现金折扣我们一直没拿，才 1 个点，不值得折腾"，你可以当场算出这个数给他看。

## 墨叔的三条提炼

**一、把三组混淆变成一种本能：收入不等于现金流入、成本不等于现金流出、利润不等于现金结余**
赊销有收入没现金，预收款有现金没收入；买原料付钱那一刻是现金流出但不是成本，它得穿过存货这道门才变成成本；利润是一个观点，现金余额是一个事实。判断一家公司的现金状况，第一反应就是找那两个"错位数"：卖出去没收回来的是应收，买进来没用完的是存货。利润表不管这两个，现金流量表管。

**二、CCC 是"钱躺在生意里的时间"，增长会按比例放大它**
现金转换周期 = 存货天数 + 应收天数 − 应付天数。优鲜是 93 天，意味着每增加 1 元年收入，要先垫 0.255 元现金，一年只能周转 3.92 次。收入增长 30%，利润多 1,200 万，营运资金要多垫 5,562 万，净现金流出 4,362 万——这就是"卖得越好死得越快"的全部机理。所以增长的决策从来不是一个销售决策，它是一个融资决策加一个效率决策。

**三、BP 在现金流上的四件事，都是可以直接上手的**
一是账期谈判（把"发货到回款"拆成"发货到开票""开票到送达""送达到期""到期到付款"四段，分别找责任人和压降空间）；二是预收款设计（年框预付、新品首发、旺季产能预约、充值返点）；三是库存周转（做库龄表、设 180 天红线、把库龄写进销售考核）；四是付款节奏（按可替代性分三类、拿到能拿的现金折扣、把付款窗口摊平）。再加一件更基础的事：做一张滚动 13 周的直接法现金流预测表，每周一更新，数据来源分工到人。

【参考答案】

**第 1 题**

现金转换周期示意（文字版）：

```
时间轴：从"掏钱"到"收钱"

第 0 天   付款给供应商（买原料）        → 现金开始流出
第 0~D 天  原料在仓库 / 在产线 / 在成品库 → 这是"存货天数"
第 D 天   货发给客户，开票，记应收账款
第 D~D+R 天 等客户付款                   → 这是"应收天数"
第 D+R 天 收到客户的钱                   → 现金终于回来

同时，在第 0 天之后的第 P 天，你才真正把钱付给供应商 → 这是"应付天数"

净占用 = 存货天数 + 应收天数 − 应付天数 = CCC
```

增长在三个环节上放大占用：

**环节一，存货。**收入增长，你要先备货。而且备货往往要比收入增长得更快——因为你要应付不确定性，安全库存会跟着上台阶。这就是为什么很多公司收入涨 30%、存货涨 50%。

**环节二，应收。**收入增长，应收账款按同比例增长（如果账期不变）。更糟的是，为了冲收入，销售往往会给新客户更长的账期、给老客户更宽松的信用政策，于是应收涨得比收入快。优鲜就是活例子：收入涨 11.1%，应收涨 40.8%。

**环节三，应付。**理论上应付也应该同比例增长，能抵消一部分。但现实中，供应商给你的账期是有上限的，而且你的采购集中度越高、议价能力越强，应付才涨得动。很多公司在增长期反而被迫给供应商缩短账期（因为要抢货），这是雪上加霜。

**一句话总结**：增长的现金代价 = 增量收入 ÷ 365 × CCC。这个式子里，CCC 是乘数。所以压 CCC 和增长一样重要——甚至更重要，因为压 CCC 不花钱，增长要花钱。

**第 2 题**

可以，负 CCC 在零售业和部分互联网零售公司里很常见。

**典型的例子**：大型连锁超市。假设它的存货周转天数是 40 天（生鲜快、干货慢，平均下来 40 天），应收账款几乎为零（顾客当场付钱，或者刷银行卡第二天到账，算 2 天），应付账款是 70 天（对供应商账期长）。

```
CCC = 40 + 2 − 70 = −28 天
```

**这意味着什么？**意味着它在卖掉一件商品之后的 28 天前，就已经收到了顾客的钱；而它要付给供应商的钱，还要再等 28 天。也就是说，**它的供应商和顾客在替它垫整盘生意的钱。**

**这带来三个巨大优势：**

第一，增长不吃现金，反而产出现金。多开一家店，三个月后这家店就开始往总部输血。这就是为什么这类公司可以靠自有现金流快速扩张，不用融资。

第二，规模越大越有钱。因为采购量越大，对供应商的账期谈判能力越强，CCC 越负。这是个正反馈。

第三，它可以用供应商的钱去做别的事（开新店、做地产、做金融）。零售业的"类金融"模式，本质就是这个。

**但负 CCC 的公司，增长也不是完全不吃现金。有两个例外：**

例外一，**开新店的资本开支**。装修、设备、租金押金，这些是实打实要先付的，不在 CCC 里。所以这类公司的现金流压力主要在投资活动，不在营运资金。

例外二，**进入新市场或新业态的初期**。新店有爬坡期，前几个月销量上不去，存货周转慢，供应商账期也还没谈下来，这时候 CCC 可能是正的。等它成熟了才转负。

补充一个反例提醒你注意：**负 CCC 不是"好公司"的充分条件。**有些公司靠恶意拖欠供应商做出来的负 CCC，是在透支自己的供应链。判断方法是看它的应付天数是不是显著高于行业平均——如果高出一大截，那不是议价能力，是风险。

**第 3 题**

我给你一套五步评估法。

**第一步：给供应商分三类，先分再谈。**

```
A 类（完全可替代）：标准包装、通用辅料、办公用品、通用配件
   供应商数量多，切换成本几乎为零。
   这一类可以激进谈账期。

B 类（可替代，但切换有成本）：主要原料（面粉、油脂）、通用包装定制件
   有 3-5 家可选，但要重新打样、试产、验厂，切换周期 1-3 个月。
   这一类可以谈，但要给交换条件。

C 类（不可替代）：独家配方原料、专利包材、独家代理设备备件
   只有一家或两家。
   这一类原则上不动账期，反而可以考虑提前付款换价格或换保供。
```

**第二步：看四个数据。**

```
数据一：该供应商的年采购额（A）
数据二：当前账期（P₀）和目标账期（P₁）
数据三：该供应商所在市场的平均账期（P̄）——这是你的谈判基准线
数据四：该供应商对你的依赖度 = 你的采购额 ÷ 该供应商的年销售额（D）
```

**第三步：算依存度，这是谈判筹码的核心。**

```
若 D > 30%：你是他的大客户，你有很强的话语权，账期可以谈到 P̄ 以上 15-30 天。
若 D 在 10%~30%：你是重要客户，可以谈到 P̄ 以上 0-15 天。
若 D < 10%：你只是小客户，能谈到 P̄ 就不错了，超过就要付代价。
```

**第四步：算这笔账值不值。**

```
延长账期释放的资金 = A × (P₁ − P₀) ÷ 365
资金收益 = 释放资金 × 资金成本率

代价估计：
  A 类：几乎无代价，可能只损失一点点价格优惠（0.3%-0.5%）
  B 类：需要交换条件（承诺年度采购量、独家、或接受 0.5%-1.5% 的涨价）
  C 类：代价高（涨价 2%-5%，或断供风险）
```

举例：某 B 类供应商年采购额 3,000 万，账期从 45 天谈到 60 天：

```
释放资金 = 3,000 × 15 ÷ 365 = 123.3 万元
资金收益 = 123.3 × 6% = 7.4 万元/年

若代价是涨价 1%：3,000 × 1% = 30 万元/年
30 万 > 7.4 万 → 不划算
```

**这个演算要记住：延长账期的收益通常很小，代价可能很大。**很多时候，延长账期是财务的一厢情愿，真正的解法是提高效率而不是揍供应商。

**第五步：给交换条件，别空手去谈。**

可以给的交换条件，按代价从小到大排：

```
一、付款节奏可预期化（承诺每月固定两个付款日，从不拖欠）
    ——这对供应商很有价值，因为他也缺现金流确定性，代价几乎为零。

二、年度采购量承诺（我保证一年从你这儿买够 X 万，你给我 Y 天账期）

三、独家或优先（你这个品类我只从你这儿买）

四、接受小幅涨价（最贵，放在最后）
```

**判断规则的总结一句话**：账期不是越长越好，**账期的合理长度 = 行业平均账期 + 你的议价能力溢价 − 供应商的替代难度折扣**。超过这个数，你是在用供应链安全换现金流，短期好看，长期要还。

**第 4 题**

**（1）三项周转天数与 CCC**

```
营业成本 = 60,000 × (1 − 30%) = 42,000 万元

应收账款周转天数 = 9,600 ÷ 60,000 × 365 = 58.4 天
存货周转天数     = 10,500 ÷ 42,000 × 365 = 91.25 天
应付账款周转天数 = 6,300 ÷ 42,000 × 365 = 54.75 天

CCC = 91.25 + 58.4 − 54.75 = 94.9 天 ≈ 95 天
```

**（2）两种口径的占用额**

```
精确口径：
应收账款占用 = 9,600 万元（账面数）
存货占用     = 10,500 万元（账面数）
应付账款占用 = 6,300 万元（账面数）
净营运资金   = 9,600 + 10,500 − 6,300 = 13,800 万元

简化口径：
60,000 ÷ 365 × 94.9 = 15,600 万元

差异 = 15,600 − 13,800 = 1,800 万元
```

差异原因：简化口径把存货和应付都按收入口径计算，但这两项实际发生在成本口径。营业成本只有收入的 70%，所以简化口径高估了。

**注意**：这道题的存货天数 91.25 天明显偏高（食品行业通常在 45-75 天）。如果你在实践中遇到这种数，第一反应应该是"存货里可能有一大块卖不动的"，要去做库龄表。

**（4）增长 25%**

```
新收入 = 60,000 × 1.25 = 75,000 万元
新营业成本 = 75,000 × 0.70 = 52,500 万元

新应收账款 = 75,000 × 58.4 ÷ 365 = 12,000.0 万元
新存货     = 52,500 × 91.25 ÷ 365 = 13,125.0 万元
新应付账款 = 52,500 × 54.75 ÷ 365 =  7,875.0 万元
新净营运资金 = 12,000 + 13,125 − 7,875 = 17,250 万元

额外垫资 = 17,250 − 13,800 = 3,450 万元
```

（验算：按同比例，13,800 × 25% = 3,450 万元。一致，因为周转天数不变时，营运资金与收入同比例增长。）

```
原净利润 = 60,000 × 4% = 2,400 万元
新净利润 = 75,000 × 4% = 3,000 万元
增量净利润 = 600 万元

净现金结果 = 600 − 3,450 = −2,850 万元
```

**增量利润远远覆盖不了增量营运资金，缺口 2,850 万元。**

**（5）压缩 CCC**

```
新 CCC = (91.25 − 4) + (58.4 − 4) − (54.75 + 4)
       = 87.25 + 54.4 − 58.75 = 82.9 天
压缩 = 94.9 − 82.9 = 12 天
```

```
释放现金：
应收账款 = 9,600 − (75,000 还是 60,000？用当前收入 60,000)
         当前收入下：新应收 = 60,000 × 54.4 ÷ 365 = 8,942.5 万元
```

**这一题的关键提示**：注意第（4）问和第（5）问的对比——增长 25% 要垫 3,450 万，压缩 12 天只释放 1,580 万。**光靠压 CCC 撑不起 25% 的增长。**真正的解法是组合：压 CCC 一部分、借款一部分、或者把增长速度降到现金能承受的水平。这就是你要拿去跟老板说的话。

**第 5 题**

这是一道必须真的去做的题。我不给答案，给四条判卷标准，和一个可能让你不舒服的提醒。

**判卷标准：**

第一条，你必须拿到一个真实的余额数字，而且要是"今天的"，不是"上月末的"。很多公司的资金日报是 T+1 的，你要问清楚这个余额是哪个时点的。

第二条，你的"未来四周要付的五笔最大的钱"里，至少要有三笔是能说出具体日期和金额的（工资几号发、多少；哪笔货款几号到期、多少；哪笔贷款几号还本、多少）。说不出日期的，说明你还没摸到门。

第三条，你要能算出一个"四周后的预计余额"。不用精确，±20% 都可以。**有这个数，你就已经比公司里 90% 的人更接近真相了。**

第四条，你要能说出"这个数有几个人知道"。如果答案是"只有资金岗和老板"，那你有两个选择：要么继续当不知道的人，要么成为第三个人。

**那个可能让你不舒服的提醒：**

小林在引子里遇到的情况，不是一个特例，是一个普遍现象——**大部分公司的现金流，是靠"最后一刻有人搞定"来维持的，不是靠"提前有人看管"来维持的。**

搞定它的人（老周）不会感谢你指出问题，因为他知道自己是侥幸过关的；而老板（王总）一旦知道真相，第一反应往往是换人。所以你做这件事，要注意三件事：

```
一、先做，别先说。把表做出来，自己跑四周，验证一下准确度，
    再去跟老周说。第一次就拿着不准的数去，你会失去第二次机会。

二、先给老周看，再给老板看。让他成为第二个人，不是最后一个人。
    给他一个"我们一起把这事管起来"的位置，而不是一个"你被抓到了"的位置。

三、永远带着方案去，永远说"我们"不说"你们"。
    "我看了一下未来四周，第 3 周有点紧，我想了三个办法……"
    这句话的主语是"我"和"我们"，不是"你"。
```

最后一句：**现金流这件事，是财务人最容易建立专业信用、也最容易得罪人的地方。**你唯一的护身符是"提前"——提前三周说，你是功臣；提前三天说，你是马后炮；事后说，你是事后诸葛亮。
