# 第09章 本量利：一把刀，切开八成的经营决策

## 引子：一个真实的下午

周二上午十点，张总监推门进来，把一张 A4 纸拍在小林桌上。

"小林，帮我们算个数。"

纸上写着：端午档，商超渠道，主推三款水饺，降价百分之八，走量。销量能涨两成五。

"多少钱的单子？"小林问。

"预计八千万的盘。"

"那降百分之八，少收六百四十万啊。"

张总监笑了："所以说要你们财务算嘛。销量涨两成五，多卖两千万，总不能还亏吧？"

"可是……"

"你就告诉我，这笔生意做下来，公司赚了还是亏了。下午三点经营会我要用。"

小林盯着那张纸。她脑子里过了一遍：少收 640 万，多卖 2000 万的货，毛利率 28%……多卖的 2000 万带来 560 万毛利，抵不上 640 万。

"应该是亏的。"她说。

张总监的脸沉下来："你算的是死的。多卖两千万，产能利用率上去了，单位成本下来了，你怎么不算？而且我们占了货架，对手就少一格，这个你怎么算？"

"我……"

"你们财务就是只会算账不会算生意。"张总监把纸抽回去，"我自己跟王总说。"

那天下午小林没去开会。她坐在工位上，把那个"多卖两千万到底赚不赚"的问题在纸上画了三遍，画出来的东西让她自己都不敢相信——

她发现自己算的"560万对640万"是错的，而张总监说的"单位成本会下来"也是错的。两个人都错，但错的地方不一样。

更可怕的是，她发现自己根本不知道正确答案长什么样。

周五中午，她把这事儿讲给墨叔听。

"墨叔，我算不出来。"

"你知道你为什么算不出来吗？"

"因为我不会？"

"因为你手里没有一把刀。"墨叔说，"我给你一把。"

## 对谈

### 一、从老马便利店讲起

"你们小区门口有个便利店，老板姓马。"

"知道，老马便利店。"

"你先回答我一个问题：老马这个月，卖多少钱才不亏？"

"这我哪知道，我又不知道他的成本。"

"我告诉你。"墨叔说，"房租一个月六千，雇了一个店员八千，水电杂费一千五，冰柜和货架折旧摊销五百。加起来多少？"

"一万六。"

"还有一个数：便利店的毛利率，大概二十二个点。"

"那……"小林算了算，"一万六除以零点二二……七万二。"

"七万二千七百二十七块。"墨叔说，"平均到每天，两千四百二十四块。"

"这个有什么用？"

"你再回答我一个问题：老马一天卖三千块，和一天卖两千块，差别有多大？"

"差一千块。"

"错。"墨叔说，"一天卖三千，一个月卖九万，比盈亏平衡点多了一万七千多，这一万七千多全部是利润——按毛利算，一万七千二百七十三块。"

"哦对，因为固定成本已经平掉了。"

"那天卖两千呢？"

"两千乘三十是六万，比七万二千七百二十七少了一万二千七百二十七……所以亏一万二千七百二十七？"

"对。"

"所以……"小林愣住了，"营业额差三分之一，利润从赚一万七变成亏一万二。"

"营业额差 33%，利润差了 290%。"墨叔说，"这就是我说的那把刀的锋利之处。"

"那这个……叫什么？"

"经营杠杆。后面细讲。你先把这几个词记住。"

他在纸上写了五行。

```
贡献毛利     = 收入 − 变动成本
边际贡献率   = 贡献毛利 ÷ 收入
盈亏平衡点   = 固定成本 ÷ 边际贡献率
安全边际     = 实际销售额 − 盈亏平衡销售额
经营杠杆系数 = 贡献毛利 ÷ 营业利润
```

"这五个词，加起来就够你用一辈子了。"墨叔说，"八成的经营决策，拿这五样东西一量，答案自己就跳出来。"

### 二、先把"混合成本"这关过了

"墨叔，那我先问一个问题。这些词里最难的是什么？"

"不是算，是拆。"墨叔说，"**把成本拆成变动和固定，是这把刀唯一的准备工作。**"

"第八章不是拆过了吗？"

"第八章拆的是产品成本，这一章你要拆的是**整个公司的成本结构**。我问你，优鲜八亿的收入，变动成本占多少？"

"营业成本五亿七千六。"

"那是毛利率口径，里面混着固定制造费用。"墨叔说，"我要的是：这八亿里，有多少是'卖得越多花得越多'的，有多少是'不管卖多少都要花'的。"

小林想了想："变动的是……直接材料、直接人工、还有运费、销售提成、平台佣金。"

"固定的是？"

"折旧、管理人员工资、研发、厂房冷库租金、还有……"

"等等。"墨叔打断她，"你觉得'销售提成'是变动的？"

"按回款额算，当然是变动的。"

"那'销售员底薪'呢？"

"固定。"

"那'销售部经理的年终奖'，是按团队总业绩算的，是变动还是固定？"

"……"

"你看，又模糊了。"墨叔笑了，"我教你一条最实用的处理办法，叫**按'决策周期'拆**。"

"什么意思？"

"你要做的这个决策，影响的时间跨度是多长？如果是一个月内的促销决策，那几乎一切都是固定的——连原材料都是，因为你这个月该进的货已经进了。如果是一年的预算决策，那直接材料、计件工资、提成、运费都是变动的。如果是三年的战略规划，连管理人员编制都是变动的。"

"所以……"

"所以**在做本量利分析之前，先写明：我这个决策的周期是一年。**然后按一年的口径去拆。"

"那拆完了呢？"

"拆完你会得到一张表。我给你把优鲜的拆好了，你看看。"

| 项目 | 金额（万元） | 占收入比 | 性质 |
|---|---|---|---|
| 营业收入 | 80,000 | 100.0% | — |
| 变动制造成本（材料、计件工资、变动制造费用） | 49,600 | 62.0% | 变动 |
| 固定制造费用（折旧、固定人工、厂房冷库） | 8,000 | 10.0% | 固定 |
| **毛利** | **22,400** | **28.0%** | — |
| 变动销售费用（运费、佣金、促销员、平台佣金） | 3,600 | 4.5% | 变动 |
| 固定销售费用 | 6,500 | 8.1% | 固定 |
| 管理费用 | 7,000 | 8.8% | 固定 |
| 研发费用 | 800 | 1.0% | 固定 |
| 财务费用 | 500 | 0.6% | 固定 |
| **净利润** | **4,000** | **5.0%** | — |

"所以变动成本一共是多少？"

"四万九千六加三千六……五亿三千二百万。"

"变动成本率？"

"百分之六十六点五。"

"边际贡献率？"

"百分之三十三点五。"

"贡献毛利？"

"两亿六千八百万。"

"固定成本一共？"

"八千加六千五加七千加八百加五百……两亿两千八百万。"

"验算一下。"

"两亿六千八减两亿两千八……四千万。对上了！"

"你看，你自己把它算通了。"墨叔说，"现在回答我第一个问题：优鲜一年卖多少钱才不亏？"

"两亿两千八百万，除以零点三三五……六亿八千万？"

"六亿八千零六十万。"墨叔说，"我们去年卖了多少？"

"八亿。"

"那安全边际呢？"

"八亿减六亿八千万……一亿两千万。"

"安全边际率呢？"

"一亿两千万除以八亿……百分之十五。"

"记住这个数。"墨叔说，"**优鲜的安全边际只有 15%。**也就是说，销售额只要掉 15%，公司就一分钱不赚。"

小林有点发愣："那……这算健康吗？"

"你说呢？"

"百分之十五，感觉挺薄的。"

"薄，但不是最糟。"墨叔说，"真正吓人的是下面这个数。"

### 三、经营杠杆：那把刀最锋利的地方

"再算一个。贡献毛利两亿六千八百万，营业利润四千万。"

"经营杠杆系数等于……两亿六千八除以四千万，六点七？"

"六点七。"墨叔说，"这个数是什么意思？"

"意思是……"

"它的意思是：**收入每变动 1%，利润变动 6.7%。**"

小林的手停住了。

"八亿的收入，掉一成，变成七亿二。"

"那……利润掉百分之六十七？"

"你自己算。"

```
收入 72,000 万元
变动成本 = 72,000 × 66.5% = 47,880 万元
贡献毛利 = 72,000 − 47,880 = 24,120 万元
固定成本 = 22,800 万元（不变）
营业利润 = 24,120 − 22,800 = 1,320 万元
利润降幅 = (4,000 − 1,320) ÷ 4,000 = 67.0%
```

小林看着自己算出来的数，半天没说话。

"收入掉一成，利润掉三分之二。"她喃喃地说。

"反过来呢？"

"反过来……收入涨一成，利润涨三分之二？"

"涨到六千六百八十万。"墨叔说，"**同一家公司，同样的产品，收入上下摆动 10%，利润上下摆动 67%。**这就是为什么王总只看两个数——他本能地知道，收入那头的一点点风吹草动，到利润这头就是台风。"

"那……为什么会这样？"

"因为固定成本的占比太高了。"墨叔说，"八亿收入里，两亿两千八百万是不管卖多少都要花的钱。这些钱像个秤砣，杠杆越长，撬动得越猛。"

"那是不是固定成本越低越好？"

"你先回答我：外包生产，把固定成本变成变动成本，好不好？"

"好啊，轻资产。"

"那我问你，行业景气、订单爆满的时候，外包的报价会怎么样？"

"会涨。"

"涨到什么程度？"

"……可能会吃掉我的毛利。"

"所以呢？"

"所以……固定成本不是越低越好。"小林慢慢地说，"固定成本高，意味着你赌未来会好，赌对了赚得多；固定成本低，意味着你放弃了赚大钱的可能，换来下行时的安全。"

"这句话值一万块。"墨叔说，"经营杠杆不是好坏问题，是**赌注大小**的问题。你要做的是让老板知道他在赌多大，而不是劝他别赌。"

"那我该怎么跟王总说？"

"给他三个数：安全边际 15%，经营杠杆 6.7，以及'收入掉 15% 公司归零'。然后加一句：如果我们能把固定成本压掉两千万，经营杠杆就降到多少？"

"压掉两千万……固定成本变成两亿零八百万，贡献毛利两亿六千八百万，利润六千万。杠杆系数……四点四七。"

"你看，从 6.7 降到 4.5。"墨叔说，"这就是降本这件事在老板心里真正的分量——它不是省了两千万，它是把公司从'收入掉 15% 就死'变成'收入掉 22% 才死'。"

### 四、六个问题，一把刀

"墨叔，那我把这五个词学会了，能用在哪儿？"

"我给你六个问题，都是你们公司明年一定会遇到的。"

**问题一：要不要降价促销**

"就是张总监那个端午方案。"

"对。你现在会算了吗？"

"会一点。但这回我得先问一句：这八千万是 B 端的还是 C 端的？"

"好问题。"墨叔点头，"为什么这么问？"

"因为 B 端和 C 端的边际贡献率不一样。"

"多少？"

"B 端毛利率 22%，C 端 37%。但那是毛利，不是贡献毛利……"

"我已经帮你拆好了。"墨叔在纸上写，"B 端边际贡献率 28.5%，C 端 41.0%。加权平均 33.5%。"

"那如果这八千万是 C 端的呢？"

"你自己算。降价 8%，销量涨 25%。"

小林在纸上算：

```
原收入 8,000 万元，C 端边际贡献率 41.0%
原贡献毛利 = 8,000 × 41.0% = 3,280 万元
原变动成本 = 8,000 − 3,280 = 4,720 万元

新收入 = 8,000 × 1.25 × 0.92 = 9,200 万元
新变动成本 = 4,720 × 1.25 = 5,900 万元
新贡献毛利 = 9,200 − 5,900 = 3,300 万元

变化 = 3,300 − 3,280 = +20 万元
```

"赚了二十万。"

"赚了二十万。"墨叔重复了一遍，"八千万的大盘子，折腾一场促销，赚二十万。"

"那……这不划算。"

"是不划算。但我现在改一个字：这八千万不是 C 端的，是 B 端的。"

```
原收入 8,000 万元，B 端边际贡献率 28.5%
原贡献毛利 = 8,000 × 28.5% = 2,280 万元
原变动成本 = 8,000 − 2,280 = 5,720 万元

新收入 = 8,000 × 1.25 × 0.92 = 9,200 万元
新变动成本 = 5,720 × 1.25 = 7,150 万元
新贡献毛利 = 9,200 − 7,150 = 2,050 万元

变化 = 2,050 − 2,280 = −230 万元
```

小林倒吸一口气。

"同样一句'降价 8%、销量涨 25%'，放在 C 端上赚二十万，放在 B 端上亏两百三十万。"

"为什么会差这么多？"

"因为边际贡献率越低，降价对你伤害越大。"墨叔说，"我给你一个公式，你记下来，这辈子都用得上。"

```
保本销量增长率 = 降价幅度 ÷ (边际贡献率 − 降价幅度)
```

"验算一下。C 端：8% ÷ (41% − 8%) = 8 ÷ 33 = 24.2%。张总监说能涨 25%，刚好过了线，所以赚二十万。"

"B 端：8% ÷ (28.5% − 8%) = 8 ÷ 20.5 = 39.0%。要涨 39% 才保本，涨 25% 远远不够。"

"我明白了……"小林说，"所以张总监那句话，不能笼统地说'值不值'，得先问是 B 端还是 C 端。"

"你现在知道下午那会儿你错在哪儿了吗？"

"我错在……我用毛利率算，没有用贡献毛利。而且我没问 B 端 C 端。"

"还有一条更重要的。"墨叔说，"**你当时应该反问张总监一句：这 25% 的销量增长，是怎么估出来的？**"

"啊？"

"这才是关键。"墨叔说，"本量利算得再准，输入是假的，输出就是垃圾。这个 25%，是市场调研做出来的，还是销售拍脑袋拍出来的，还是'去年这么干涨了这么多'？你得问。"

**问题二：要不要加一个销售人员**

"第二个问题。"墨叔说，"华东区申请加一个业务员。"

"一年多少钱？"

"底薪十五万，社保公积金四万，差旅四万，办公两万。二十五万。"

"那他一年得卖多少才回本？"

"你说呢？"

"用那个公式的思路……二十五万除以边际贡献率。"

"华东区的边际贡献率是多少？华东区 B 端一亿九、C 端一亿三。"

```
B 端贡献 = 19,000 × 28.5% = 5,415 万元
C 端贡献 = 13,000 × 41.0% = 5,330 万元
合计贡献 = 10,745 万元
华东区加权边际贡献率 = 10,745 ÷ 32,000 = 33.6%
```

"二十五万除以零点三三六……七十四万四。"

"七十四万四。这就是这个业务员的**保本销售额**。"

"才七十四万？感觉不多啊。"

"是不多。但你要接着问三件事。"墨叔竖起三根指头。

"第一，这七十四万是'毛利'还是'现金'？新客户带来的应收款，账期 63 天，你得垫钱。垫多少？"

"七十四万乘六十三分之三百六十五……十二万八。"

"一年资金成本按 6%，是七千七百块。所以保本线是七十五万二。"

"第二，第一年能不能做到七十四万？新人有爬坡期，华东区一个新业务员，第一年做到多少，你们有数据吗？"

"这个……我们没统计过。"

"那就去要。找小陈，销售运营那边一定有人均产出的数据。"

"第三，第二年和第三年呢？如果第一年只做到五十万，亏多少？"

"五十万乘零点三三六是十六万八，减二十五万……亏八万二。"

"如果第二年做到一百五十万呢？"

"一百五十万乘零点三三六是五十万四，减二十五万……赚二十五万四。"

"所以两年的账是：第一年亏八万二，第二年赚二十五万四，两年净赚十七万二。"墨叔说，"**这个决策不能只看一年。**"

"那……结论是什么？"

"结论是：加人这件事的关键不在'成本多少'，在'这个人一年能带来多少新客户、新客户的复购率是多少'。"墨叔说，"你要去问的不是'要不要加人'，而是'我们上一个新业务员，第一年做了多少、第二年做了多少、第三年呢'。"

**问题三：要不要投一笔广告费**

"第三个。华东区要在电商平台投三百万推新品。"

"三百万除以零点四一……七百三十二万。"小林已经会算了，"要带来七百三十二万的增量收入才保本。"

"对。但我再问你一层：这七百三十二万，是'第一年'的，还是'永远'的？"

"……什么意思？"

"广告是有后劲的。今年投了三百万，带来九百万增量收入。明年不投了，这些新客户里会有一部分留下来，继续买。"

"那……得算两年。"

"假设留存率 40%。第一年带来 900 万，第二年留下 360 万。"

```
第一年增量贡献毛利 = 900 × 41.0% = 369 万元
第二年增量贡献毛利 = 360 × 41.0% = 147.6 万元
两年合计 = 516.6 万元
减广告费 300 万元
净赚 = 216.6 万元
```

"那如果只带来六百万呢？"

```
第一年 = 600 × 41.0% = 246 万元
第二年 = 240 × 41.0% = 98.4 万元
两年合计 = 344.4 万元
净赚 = 44.4 万元
```

"还是赚。"

"那如果只带来四百万呢？"

```
第一年 = 400 × 41.0% = 164 万元
第二年 = 160 × 41.0% = 65.6 万元
两年合计 = 229.6 万元
净亏 = 70.4 万元
```

"所以临界点在哪儿？"

"我教你反着算。"墨叔说，"设第一年增量收入为 X，留存率 40%，边际贡献率 41%。"

```
X × (1 + 40%) × 41.0% = 300
X × 1.4 × 0.41 = 300
X × 0.574 = 300
X = 522.6 万元
```

"**第一年只要能做到 522.6 万，这笔广告在两年周期内就不亏。**"墨叔说，"这个数，比单看一年的 731.7 万低了 28%。"

"所以……"

"所以你要跟市场部说的一句话是：**给我一个你们对'留存率'的估计，我就能把保本线降下来。**这个对话一开口，你在他们眼里就不一样了。"

**问题四：要不要开新厂（或新线）**

"第四个。李厂长申请在华南厂加一条水饺线。"

"华南厂现在产能利用率多少？"

"百分之四十八。"

"那还加线？"小林脱口而出。

"你先别急。"墨叔说，"你先算：这条线要花多少钱？"

"我算不出来，我不知道设备多少钱。"

"我告诉你：设备投资两千六百万，八年折旧，一年三百二十五万。加上新增人员四百万、厂房冷库改造分摊两百七十五万、其他两百万。一年新增固定成本多少？"

"三百二十五加四百加两百七十五加两百……一千二百万。"

"对。那这条线一年要产多少才保本？"

"得知道一袋贡献毛利多少。"

"华南厂要是做水饺，平均一袋贡献毛利四块八。"

"一千二百万除以四点八……两百五十万袋。"

"两百五十万袋。"墨叔说，"现在问你第三个问题：**华南厂现有的闲置产能，够不够？**"

"华南厂设计产能三万五千吨，现在是百分之四十八，也就是一万六千八百吨。按百分之九十的上限算，能到三万一千五百吨。闲置可用……一万四千七百吨。"

"那新增需求是多少？"

"这个……我不知道。"

"这就是关键。"墨叔说，"**在决定'要不要加线'之前，先回答'闲置产能能不能覆盖新增需求'。**如果新增需求只有三千吨，华南厂现有闲置一万四千七百吨，绰绰有余，一分钱都不用投，最多加个班次。"

"加班次也要钱啊。"

"对，但那是**阶梯**，不是斜坡。"墨叔说，"这个问题我们待会儿单讲。"

"那什么时候才该加线？"

"当新增需求超过三万一千五百吨的时候。"墨叔说，"而一旦超过，你还得算一件事：新线投产之后，全公司的固定成本上了一个台阶，盈亏平衡点也跟着上移。"

```
新线投产后：
新增固定成本 1,200 万元
新盈亏平衡营收 = (22,800 + 1,200) ÷ 33.5% = 24,000 ÷ 0.335 = 71,642 万元
原盈亏平衡营收 = 68,060 万元
上移 = 3,582 万元
```

"也就是说，加了这条线，公司每年要多卖三千五百八十二万才能回到原来的利润水平。"

"这个数，李厂长知道吗？"

"他不知道。"墨叔说，"**这就是你要告诉他的。**"

**问题五：淡旺季怎么定价**

"第五个问题，跟你们太相关了。"

"淡旺季？"

"你们水饺的旺季是十一月到一月，淡季是三月四月、七月八月。淡季产能利用率多少？"

"华东厂……淡季大概四成五。"

"旺季呢？"

"九成五以上，有时候要加班。"

"好。我问你：**淡季的时候，有一张订单，单价低于单位成本，接不接？**"

"不接吧，接了亏。"

"你上次是怎么说的？"墨叔笑了，"'低于成本的单不能接'——这是全中国财务人说得最多的一句错话。"

"难道能接？"

"你先回答我：淡季的时候，那四成五的产能里，闲置的那五成五，它的折旧在不在赚？"

"在啊，不管开不开，折旧都提。"

"那闲置产能的边际成本是多少？"

"只有变动成本……"

"所以呢？"

小林眼睛亮了："所以淡季只要单价高于单位变动成本，就有贡献毛利，就能接。"

"接多少都行吗？"

"……不是。要高于单位变动成本，而且不能扰乱价格体系。"

"再加一条。"墨叔说，"**也不能让客户养成习惯。**你淡季卖七块，旺季你卖多少？客户会说你涨价。"

"那淡季的下限是多少？"

"三条线：一是不低于单位变动成本；二是不低于'旺季客户会拿来做参照的那个价'的某个比例；三是不能让渠道窜货。"

"那旺季呢？"

"旺季是另一个问题，因为旺季有产能瓶颈。"墨叔说，"旺季你不能按'单位贡献毛利'排单，得按'**单位瓶颈资源的贡献毛利**'排。"

"瓶颈资源？"

"就是那个最紧的、卡住你的东西。你们是什么？"

"……包饺子的机器？还是速冻隧道？"

"对，速冻隧道。我给你举个例子。"

"某个月，速冻隧道还剩 4 万小时。手里有两张订单："

| 订单 | 单价 | 单位变动成本 | 单位贡献毛利 | 单袋耗隧道小时 | 每小时贡献 |
|---|---|---|---|---|---|
| 甲（大客户 A） | 10.50 | 6.20 | 4.30 | 0.008 | 537.5 元 |
| 乙（大客户 B） | 9.20 | 5.60 | 3.60 | 0.005 | 720.0 元 |

"甲的单位贡献毛利更高（4.30 对 3.60），所以按常识先接甲？"

"对啊。"

"你算一算，4 万小时全给甲，能赚多少；全给乙，能赚多少。"

```
全给甲：4 万小时 ÷ 0.008 = 500 万袋
        贡献毛利 = 500 万 × 4.30 = 2,150 万元

全给乙：4 万小时 ÷ 0.005 = 800 万袋
        贡献毛利 = 800 万 × 3.60 = 2,880 万元
```

小林看着这两个数，说不出话。

"单位贡献毛利低的那张单，反而多赚七百三十万。"

"为什么？"

"因为它吃得少。"墨叔说，"乙虽然每袋贡献少七毛，但它每袋只吃 0.005 小时，同样一小时能做更多袋。"

"所以旺季排单的规矩是？"

"**按'单位瓶颈资源贡献'从高到低排，排到产能用完为止。**"墨叔说，"你要是不知道瓶颈在哪儿，就去车间待三天。"

**问题六：亏损产品要不要停**

"最后一个。"墨叔说，"有个 SKU，一年卖一千二百万，报表上亏八十万。停不停？"

"停啊。"

"你先告诉我它的数据。"

"收入一千二百万，变动成本一千万，专属固定成本二百八十万。所以亏八十万。"

"贡献毛利多少？"

"二百万。"

"那停了之后，公司利润会怎么变？"

"省下八十万的亏损……利润增加八十万？"

"错。"墨叔说，"你先回答我：那二百八十万的专属固定成本，停了这个 SKU 之后，全都省得下来吗？"

"……不一定。"

"对。你去拆一下。"

```
专属固定成本 280 万元拆分：
专属设备租赁      100 万元  → 停产可退租，可避免
专属促销员（2 人）  80 万元  → 可转岗或解约，可避免
共用设备折旧分摊   100 万元  → 停了照样提，不可避免
                            ─────────────
可避免合计         180 万元
不可避免           100 万元
```

"现在你再算：停掉它，公司利润怎么变？"

```
失去的贡献毛利      −200 万元
省下的可避免固定成本 +180 万元
                    ─────────
净影响               −20 万元
```

"所以停了反而少赚二十万。"

"对。"墨叔说，"**报表上亏八十万的产品，停掉之后公司反而少赚二十万。**这个反直觉的结论，就是你拿去开经营分析会的杀手锏。"

"那什么时候才该停？"

"两种情况下该停。"

"第一种：腾出来的产能，能用来生产贡献毛利更高的东西。比如腾出来的产线做别的，能带来二百六十万贡献毛利，那净影响就是 +60 万，值得停。"

"第二种：可避免的固定成本，比你想的多。比如那个专属促销员其实是劳务派遣，随时退；设备租赁下个月就到期不再续。"

"所以这个决策的正确提问不是'它亏多少'，而是——"

"**停了之后，哪些钱真的不用再花了？**"小林接了上去。

"对了。"墨叔说，"我再给你一个大例子。你们 B 端，一年四亿八，按固定成本分摊后，是亏的。"

"亏多少？"

```
B 端收入 48,000 万元，边际贡献率 28.5%
B 端贡献毛利 = 48,000 × 28.5% = 13,680 万元
若按收入分摊全部固定成本 22,800 万元：
B 端分摊 = 22,800 × (48,000 ÷ 80,000) = 13,680 万元
B 端"利润" = 13,680 − 13,680 = 0 万元
```

"刚好打平。"小林说。

"那如果 B 端的固定制造费用分摊多一点点，它就是亏的。"墨叔说，"现在我问你：如果砍掉整个 B 端，公司会怎么样？"

```
砍掉 B 端后：
收入 = 32,000 万元（只剩 C 端）
贡献毛利 = 32,000 × 41.0% = 13,120 万元
固定成本 = 22,800 万元（绝大部分省不下来）
营业利润 = 13,120 − 22,800 = −9,680 万元
```

"从赚四千万变成亏九千六百八十万。"

"这就是'亏损业务该不该砍'这道题的最优答案。"墨叔说，"**先看贡献毛利是不是正的，再看固定成本能不能真的省下来。两条都满足才砍。**"

### 五、两个必须点破的错误

"墨叔，我还有两个地方一直别扭。"

"你说。"

**错误一：用"单位成本 + 目标毛利率"倒推定价**

"我们定价一直是这么干的啊。算出单位成本，加百分之三十的毛利，就是售价。"

"我问你：单位成本是怎么算出来的？"

"固定制造费用除以产量……"小林的声音慢下来。

"产量怎么定的？"

"排产计划。"

"排产计划根据什么定？"

"销售预测。"

"销售预测根据什么定？"

"根据……价格？"

"你看。"墨叔说，"**成本取决于产量，产量取决于销量，销量取决于价格，价格取决于成本。**这是个圈。"

"那不就是……死循环？"

"我给你演示一遍。"墨叔拿过纸，"假设市场调研出来的需求关系是：销量（万袋）= 240 − 15 × 单价（元）。"

"第一步，假设产量 200 万袋，单位成本 = 5.60 + 260 ÷ 200 = 6.90 元，目标毛利率 30%，定价 = 6.90 ÷ 0.70 = 9.86 元。"

"第二步，按 9.86 元，销量 = 240 − 15 × 9.86 = 92.1 万袋。单位成本变成 5.60 + 260 ÷ 92.1 = 8.42 元。重新定价 = 8.42 ÷ 0.70 = 12.03 元。"

"第三步，按 12.03 元，销量 = 240 − 15 × 12.03 = 59.6 万袋。单位成本 = 5.60 + 260 ÷ 59.6 = 9.96 元。定价 = 14.23 元。"

"第四步，销量 = 240 − 15 × 14.23 = 26.6 万袋。单位成本 = 5.60 + 260 ÷ 26.6 = 15.37 元。定价 = 21.96 元。"

"第五步，销量 = 240 − 15 × 21.96 = 负的。"

小林看着这张表，笑不出来了。

"价格越算越高，销量越算越少，最后这个产品消失了。"

"那正确的做法是什么？"

"**先用市场调研把'价格—销量'这条线画出来，再用贡献毛利最大化去找最优价格。**"墨叔说，"你算一下，Q = 240 − 15P，单位变动成本 5.60，固定制造费用 260 万。"

```
贡献毛利 = Q × (P − 5.60) = (240 − 15P) × (P − 5.60)
         = 240P − 1,344 − 15P² + 84P
         = −15P² + 324P − 1,344

求最大值：对 P 求导，−30P + 324 = 0，得 P = 10.80 元
此时 Q = 240 − 15 × 10.80 = 240 − 162 = 78 万袋
贡献毛利 = 78 × (10.80 − 5.60) = 78 × 5.20 = 405.6 万元
```

"验算一下周围的价格。"墨叔说。

```
P = 10.00 元：Q = 90.0 万袋，贡献毛利 = 90.0 × 4.40 = 396.0 万元
P = 10.80 元：Q = 78.0 万袋，贡献毛利 = 78.0 × 5.20 = 405.6 万元  ← 最大
P = 11.00 元：Q = 75.0 万袋，贡献毛利 = 75.0 × 5.40 = 405.0 万元
P = 12.00 元：Q = 60.0 万袋，贡献毛利 = 60.0 × 6.40 = 384.0 万元
```

"最优价是 10.80 元。"小林说，"而成本加成法算出来是 9.86 元起步，还一路发散。"

"所以定价的正解是：**以市场为起点，以贡献毛利最大为目标，以变动成本为止损线。**"墨叔说，"单位成本在这件事里，只有一个用处——告诉你长期来看这个价能不能活，不能用来定这个价。"

**错误二：忽略"阶梯固定成本"**

"第二个错误。"墨叔说，"我们在算'要不要开第二班'的时候，经常假设成本是连续的。"

"什么意思？"

"你们那条水饺线，单班产能 150 万袋，年固定制造费用 260 万。现在预测销量 155 万袋。多出来的 5 万袋，要不要开第二班？"

"开第二班要多花钱吧。"

"加 90 万。夜班补贴、增加的班组长、设备加速折旧。"

"那……先算算单位成本。"

"你先按连续假设算。"

```
连续假设：单位固定制造费用 = 260 ÷ 155 = 1.68 元/袋
          单位成本 = 5.60 + 1.68 = 7.28 元/袋
```

"再按实际算。"

```
实际情况：单位固定制造费用 = (260 + 90) ÷ 155 = 2.26 元/袋
          单位成本 = 5.60 + 2.26 = 7.86 元/袋
```

"差多少？"

"零点五八元一袋，乘一百五十五万袋……九十万。"

"正好等于那九十万的阶梯增量。"墨叔说，"这就是为什么'连续性假设'骗人——**它把一次性的台阶，抹成了平滑的斜坡。**"

"那决策怎么做？"

"用增量思维，不用平均思维。"墨叔说，"开第二班，是为了多产 5 万袋。这 5 万袋能带来多少贡献毛利？"

```
假设售价 10.80 元，单位变动成本 5.60 元
增量贡献毛利 = 5 万袋 × 5.20 元 = 26 万元
```

"26 万，够不够付那 90 万？"

"不够。"

"所以不该开。那要多少才够？"

"九十万除以五点二……十七万三千袋。"

"也就是总销量要到 167.3 万袋，才值得开第二班。"

"记住这个句式。"墨叔说，"**不要问'单位成本变成多少'，要问'多出来的这部分，贡献毛利够不够付跳上去的那个台阶'。**"

### 六、小林的第二次不服

"墨叔。"小林忽然放下笔，"我有个问题，憋了半天了。"

"说。"

"您今天讲这些——盈亏平衡点、经营杠杆、最优价格——这些东西，我们公司没有一个人这么算。老周不会，王总不会，张总监更不会。我学会了，跟谁说去？"

"你觉得呢？"

"我觉得……我算出来也没人听。"

"我给你讲个事。"墨叔说，"我刚做 BP 那会儿，第一次在经营会上说'我们的安全边际只有百分之九'。"

"没人理？"

"有人理了，但是被怼了。销售的老大说了一句话，我记到现在。他说：'你说的这个数，跟我下个月要卖多少货，有什么关系？'"

"那您怎么答的？"

"我当时没答上来。"墨叔笑了，"散会以后我回去想了一整晚。第二天我拿着一张表去找他。"

"什么表？"

"我把他那三个大客户，每个客户算了一个'保本销售额'——这个客户一年得卖多少钱，才够覆盖为他专门配的两个业务员、一台车、一个冷库隔间。"

"然后呢？"

"然后他当天下午就把我叫过去了，说：'你这个表能不能按片区做一份？'"

"所以……"小林慢慢地说，"不是他们不要这个数，是这个数得落到他们自己的事儿上。"

"对了。"墨叔说，"**没有人会为了'公司的盈亏平衡点'激动，但每个人都会为了'我这摊生意到底要卖多少才不亏'激动。**你要做的不是把本量利讲给他们听，是把本量利翻译成他们的语言。"

"那张总监那个促销方案呢？"

"你打算怎么跟他谈？"

小林想了想："我会先问他：这八千万是 B 端还是 C 端？如果是 B 端，降价 8% 需要销量涨 39% 才保本，你估的 25% 不够。如果是 C 端，需要涨 24.2%，25% 刚好过线，能赚二十万——但八千万的盘子赚二十万，值得吗？还有可能要搭进去促销员和堆头费。"

"还有呢？"

"还要问他那 25% 是怎么估出来的。"

"好。"墨叔点点头，"你再加最后一句：'张总，我不是反对这个方案。我是想跟你一起把这笔账算清楚，让你去跟王总说的时候，能说得更硬气。'"

"为什么要加这句？"

"因为你是在卖判断，不是在卡费用。"墨叔说，"这两件事的语气，差一个字都不行。"

## 演算台

### 演算一：优鲜食品整体盈亏平衡与安全边际

**已知条件**

```
营业收入            80,000 万元
变动制造成本        49,600 万元（62.0%）
固定制造费用         8,000 万元（10.0%）
变动销售费用         3,600 万元（4.5%）
固定销售费用         6,500 万元（8.1%）
管理费用             7,000 万元（8.8%）
研发费用               800 万元（1.0%）
财务费用               500 万元（0.6%）
```

**第一步：拆变动与固定**

```
变动成本合计 = 49,600 + 3,600 = 53,200 万元
变动成本率   = 53,200 ÷ 80,000 = 66.5%

固定成本合计 = 8,000 + 6,500 + 7,000 + 800 + 500 = 22,800 万元
```

**第二步：贡献毛利与边际贡献率**

```
贡献毛利   = 80,000 − 53,200 = 26,800 万元
边际贡献率 = 26,800 ÷ 80,000 = 33.5%

验算：营业利润 = 26,800 − 22,800 = 4,000 万元
      净利率 = 4,000 ÷ 80,000 = 5.0%。与已知一致。
```

**第三步：盈亏平衡点**

```
盈亏平衡销售额 = 22,800 ÷ 33.5% = 68,059.7 万元 ≈ 6.81 亿元
```

**第四步：安全边际**

```
安全边际额   = 80,000 − 68,059.7 = 11,940.3 万元
安全边际率   = 11,940.3 ÷ 80,000 = 14.93%
```

含义：销售额下降 14.93%，公司归零。

**第五步：经营杠杆系数**

```
经营杠杆系数 DOL = 贡献毛利 ÷ 营业利润 = 26,800 ÷ 4,000 = 6.7
验算：安全边际率 = 1 ÷ 6.7 = 14.93%。与上一步一致。
```

**第六步：敏感性**

| 情景 | 销售额 | 贡献毛利 | 固定成本 | 营业利润 | 利润变动 |
|---|---|---|---|---|---|
| 下滑 20% | 64,000 | 21,440 | 22,800 | −1,360 | −134% |
| 下滑 15% | 68,000 | 22,780 | 22,800 | −20 | −100.5% |
| 下滑 10% | 72,000 | 24,120 | 22,800 | 1,320 | −67.0% |
| 现状 | 80,000 | 26,800 | 22,800 | 4,000 | — |
| 增长 10% | 88,000 | 29,480 | 22,800 | 6,680 | +67.0% |
| 增长 20% | 96,000 | 32,160 | 22,800 | 9,360 | +134.0% |

**换个条件会怎样**：如果通过降本把固定成本压掉 2,000 万（降到 20,800 万），其他不变：

```
盈亏平衡销售额 = 20,800 ÷ 33.5% = 62,089.6 万元
安全边际率 = (80,000 − 62,089.6) ÷ 80,000 = 22.39%
经营杠杆系数 = 26,800 ÷ (26,800 − 20,800) = 26,800 ÷ 6,000 = 4.47
```

固定成本降 8.8%，经营杠杆降 33%，安全边际率从 14.9% 涨到 22.4%。**这才是降本真正的价值——它不是省钱，是买保险。**

### 演算二：C 端促销方案的完整盈亏测算

**题目**：端午档 C 端促销，原价基础上降价 8%，预计销量增长 25%。涉及产品线原年销售额 8,000 万元。

**已知**：C 端边际贡献率 41.0%。

**第一步：算保本销量增长率**

```
保本销量增长率 = 降价幅度 ÷ (边际贡献率 − 降价幅度)
               = 8% ÷ (41.0% − 8%)
               = 8 ÷ 33 = 24.24%
```

预计增长 25% > 24.24%，勉强通过。

**第二步：算实际盈亏**

```
原收入 = 8,000 万元
原贡献毛利 = 8,000 × 41.0% = 3,280 万元
原变动成本 = 8,000 − 3,280 = 4,720 万元

新销量系数 = 1.25
新价格系数 = 0.92
新收入 = 8,000 × 1.25 × 0.92 = 9,200 万元
新变动成本 = 4,720 × 1.25 = 5,900 万元
新贡献毛利 = 9,200 − 5,900 = 3,300 万元

贡献毛利变化 = 3,300 − 3,280 = +20 万元
```

**第三步：扣掉促销的执行成本**

```
促销员临时工（40 人 × 12 天 × 180 元）= 8.64 万元
堆头费、海报、试吃物料 = 25.00 万元
平台资源位 = 18.00 万元
合计 = 51.64 万元

净结果 = 20 − 51.64 = −31.64 万元
```

**结论**：算上执行成本，这笔促销实际净亏 31.64 万元。

**第四步：反推需要多少销量增长才保本（含执行成本）**

```
设销量增长率为 x：
(1 + x) × (8,000 × 0.92 − 4,720) = 3,280 + 51.64
(1 + x) × (7,360 − 4,720) = 3,331.64
(1 + x) × 2,640 = 3,331.64
1 + x = 1.2620
x = 26.20%
```

**需要销量增长 26.2%，而不是 25%。**缺口 1.2 个百分点，对应收入约：

```
8,000 × 1.2% = 96 万元
```

**换个条件会怎样**：同样方案放在 B 端（边际贡献率 28.5%）

```
保本销量增长率 = 8% ÷ (28.5% − 8%) = 8 ÷ 20.5 = 39.02%

新贡献毛利 = (1.25) × (8,000 × 0.92 − 5,720) = 1.25 × (7,360 − 5,720)
           = 1.25 × 1,640 = 2,050 万元
原贡献毛利 = 8,000 × 28.5% = 2,280 万元
变化 = 2,050 − 2,280 = −230 万元
```

**一句话结论**：同样的"降价 8% 换 25% 销量"，在 C 端算上执行成本后净亏 32 万，在 B 端净亏 282 万（230 + 52）。**边际贡献率每低 12.5 个百分点，同一个促销方案的代价就多出 250 万。**

### 演算三：经营杠杆与"销量下滑一成"的完整推演

**已知**：销售额 80,000 万元，边际贡献率 33.5%，固定成本 22,800 万元。

**情景：销量下滑 10%**

```
新销售额 = 80,000 × 0.90 = 72,000 万元
新变动成本 = 72,000 × 66.5% = 47,880 万元
新贡献毛利 = 72,000 − 47,880 = 24,120 万元
固定成本 = 22,800 万元（假设一年之内不变）
新营业利润 = 24,120 − 22,800 = 1,320 万元

利润变动额 = 1,320 − 4,000 = −2,680 万元
利润变动率 = −2,680 ÷ 4,000 = −67.0%
```

**用经营杠杆直接验证**：

```
利润变动率 = 销售变动率 × DOL = (−10%) × 6.7 = −67.0%
```

**分板块看（B 端 / C 端）**

```
B 端：收入 48,000 万元，边际贡献率 28.5%，贡献毛利 13,680 万元
C 端：收入 32,000 万元，边际贡献率 41.0%，贡献毛利 13,120 万元
合计贡献毛利 = 26,800 万元
```

若只有 B 端下滑 10%（收入掉 4,800 万）：

```
B 端贡献毛利减少 = 4,800 × 28.5% = 1,368 万元
公司营业利润 = 4,000 − 1,368 = 2,632 万元（−34.2%）
```

若只有 C 端下滑 10%（收入掉 3,200 万）：

```
C 端贡献毛利减少 = 3,200 × 41.0% = 1,312 万元
公司营业利润 = 4,000 − 1,312 = 2,688 万元（−32.8%）
```

**有意思的结论**：C 端收入只有 B 端的三分之二，但同样下滑 10%，对利润的伤害几乎一样（1,312 万 vs 1,368 万）。因为 C 端的边际贡献率更高，**每一块钱的 C 端收入更"沉"。**

**给老板的一句话**："如果一定要保一边，收入同样掉 10% 的情况下，保 C 端比保 B 端少损失 56 万；但如果 C 端掉的是高毛利新品，损失会更大。所以我需要先拿到两个板块的 SKU 级数据才能给准确答案。"

### 演算四：阶梯固定成本的决策陷阱

**已知**：水饺线单班产能 150 万袋，年固定制造费用 260 万元；开第二班需增加固定成本 90 万元。单位变动成本 5.60 元，售价 10.80 元，预测销量 155 万袋。

**错误做法：按连续性假设算**

```
单位固定制造费用 = 260 ÷ 155 = 1.677 元/袋
单位成本 = 5.60 + 1.677 = 7.277 元/袋
单位利润 = 10.80 − 7.277 = 3.523 元/袋
报表利润 = 155 万 × 3.523 = 546 万元
```

**正确做法：算上那级台阶**

```
单位固定制造费用 = (260 + 90) ÷ 155 = 2.258 元/袋
单位成本 = 5.60 + 2.258 = 7.858 元/袋
单位利润 = 10.80 − 7.858 = 2.942 元/袋
报表利润 = 155 万 × 2.942 = 456 万元

差异 = 546 − 456 = 90 万元（正好等于那级台阶）
```

**增量决策法（推荐）**

```
不开第二班：产量 150 万袋，卖 150 万袋（多出的 5 万袋需求放弃）
  贡献毛利 = 150 万 × (10.80 − 5.60) = 150 万 × 5.20 = 780 万元
  固定成本 = 260 万元
  利润 = 780 − 260 = 520 万元

开第二班：产量 155 万袋，卖 155 万袋
  贡献毛利 = 155 万 × 5.20 = 806 万元
  固定成本 = 260 + 90 = 350 万元
  利润 = 806 − 350 = 456 万元

差额 = 456 − 520 = −64 万元
```

**结论：不该开第二班，开了反而少赚 64 万元。**

**临界点**

```
设增量销量为 Q 万袋：
Q × 5.20 = 90
Q = 17.31 万袋

即总销量需达到 150 + 17.31 = 167.31 万袋，才值得开第二班。
```

**敏感性追问**：如果那 5 万袋不是"多出来的需求"，而是"一个大客户的年度框架协议，丢了明年就没了"呢？

这时候要算的是**客户生命周期价值**，不是这一单的贡献毛利：

```
若该客户年采购 8 万袋，预计合作 5 年，年贡献毛利 = 8 万 × 5.20 = 41.6 万元
5 年合计 = 208 万元 > 90 万元的台阶
```

这时候开第二班就值得了。**决策的变量从来不是成本，是那个"如果我不做，会发生什么"。**

## 墨叔的三条提炼

**一、本量利的五个词，是经营决策的最小充分工具集**
贡献毛利（收入减变动成本）、边际贡献率（贡献毛利除以收入）、盈亏平衡点（固定成本除以边际贡献率）、安全边际（实际减盈亏平衡）、经营杠杆系数（贡献毛利除以营业利润）。这五个词加上一把"变动/固定"的拆分尺，能回答八成的经营问题。真正的难点从来不是公式，是把成本拆干净——拆的时候先声明决策周期是多久，同一个成本在一年口径和三年口径下的归类可能完全不同。

**二、所有"要不要多做一件事"的问题，都等价于"增量贡献毛利够不够付增量成本"**
不要算平均，要算增量。降价促销，算"多卖的这些带来的贡献毛利，够不够付降价的代价"；加一个人，算"他带来的增量收入乘边际贡献率，够不够付他的年成本"（再乘上资金占用和爬坡期）；投一笔广告，算"两年累计的增量贡献毛利够不够付这笔钱"（记得把留存率算进去）；开一条新线，先问"现有闲置产能够不够"，不够再算"新增固定成本需要多少增量贡献毛利才填得上"。公式是同一个：**保本增量 = 增量固定成本 ÷ 边际贡献率**。

**三、两个错误会让你把刀砍向自己**
第一个是"单位成本加目标毛利率倒推定价"——成本取决于产量，产量取决于销量，销量取决于价格，价格取决于成本，这是个死循环，迭代下去价格会一路发散到卖不出去。正解是：以市场调研出来的"价格—销量"关系为起点，以贡献毛利最大化为目标求最优价，以单位变动成本为止损线。第二个是把固定成本当成连续变量——固定成本是台阶不是斜坡，问"单位成本变成多少"会骗你，问"多出来的这部分贡献毛利够不够付跳上去的那个台阶"才不会。

## 一页纸工具

**本量利速算卡（贴在显示器边上）**

```
五个词：
  贡献毛利     = 收入 − 变动成本
  边际贡献率   = 贡献毛利 ÷ 收入
  盈亏平衡点   = 固定成本 ÷ 边际贡献率
  安全边际率   = (实际销售额 − 盈亏平衡销售额) ÷ 实际销售额
  经营杠杆系数 = 贡献毛利 ÷ 营业利润 = 1 ÷ 安全边际率

三个万能公式（背下来）：
  保本销量增长率（降价场景）= 降价幅度 ÷ (边际贡献率 − 降价幅度)
  保本增量收入（花钱场景） = 增量固定成本 ÷ 边际贡献率
  利润变动率               = 销售变动率 × 经营杠杆系数

三个必问（每次用之前先问自己）：
  1. 我这个决策的周期是多长？变动/固定按这个周期拆对了吗？
  2. 输入的关键假设（销量增长、留存率、爬坡期）是谁给的？怎么验证？
  3. 有没有"阶梯"？产能、班次、人数、仓租，哪些是跳的不是滑的？
```

**六个问题的判断清单**

| 问题 | 核心指标 | 判断规则 | 别忘了问 |
|---|---|---|---|
| 要不要降价促销 | 保本销量增长率 | 预计增长率 > 保本增长率才值 | 边际贡献率是 B 端还是 C 端口径？执行成本多少？ |
| 要不要加一个人 | 保本增量收入 | 增量收入 × 边际贡献率 > 年成本 | 爬坡期多久？第二年能做到多少？ |
| 要不要投广告费 | 两年累计增量贡献 | 累计 > 投放额 | 留存率多少？怎么估的？ |

**跟业务谈本量利的三句台词**

- 对销售总监："张总，降价 8% 不是不行，但我得先跟您确认：这盘货是 B 端还是 C 端？B 端要涨 39% 才保本，C 端要涨 24%。您估的 25%，在 C 端刚好过线，在 B 端差得远。另外，这 25% 是怎么估出来的？我想跟您对一下口径，好让您去跟王总说的时候更硬气。"

【参考答案】

**第 1 题**

推导：

```
设销售额为 S，边际贡献率为 r，固定成本为 F。
贡献毛利 = S × r
营业利润 = S × r − F
盈亏平衡销售额 S₀ = F ÷ r

安全边际率 = (S − S₀) ÷ S = (S − F/r) ÷ S = 1 − F ÷ (S × r)
           = 1 − F ÷ 贡献毛利

经营杠杆系数 DOL = 贡献毛利 ÷ 营业利润 = (S × r) ÷ (S × r − F)

1 ÷ DOL = (S × r − F) ÷ (S × r) = 1 − F ÷ (S × r)

所以：安全边际率 = 1 ÷ DOL
```

管理含义：这两个数不是两个数，是同一个数的两种说法。安全边际率回答"还能跌多少"，经营杠杆系数回答"跌 1% 会怎样"。它们互为倒数，意味着**你不可能只改一个**。

降本和降风险的关系，就藏在这个等式里。降本（尤其是降固定成本 F）会同时产生三个效果：

```
原：S = 80,000，r = 33.5%，F = 22,800
安全边际率 = 1 − 22,800 ÷ 26,800 = 14.93%
DOL = 6.7

降固定成本 2,000 万后：F = 20,800
安全边际率 = 1 − 20,800 ÷ 26,800 = 22.39%
DOL = 26,800 ÷ 6,000 = 4.47
```

固定成本降 8.8%（2,000 ÷ 22,800），安全边际率涨 50%（14.93% → 22.39%），经营杠杆降 33%（6.7 → 4.47）。

**这就是降本和降风险的关系：降固定成本不是线性地省钱，它是杠杆式地买保险。**省下来的每一块钱固定成本，都会同时抬高盈亏平衡的缓冲垫、并压低下行的放大倍数。这也是为什么在经济下行期，砍固定成本比砍变动成本重要得多——砍变动成本只省一分，砍固定成本既省一分又降一倍杠杆。

反过来也成立：**加固定成本（扩产、开店、招人）是在加杠杆。**加之前必须算清楚：新的盈亏平衡点是多少？安全边际还剩多少？一旦加完，收入要是没跟上，亏损会放大多少倍？

**第 2 题**

这句话对不对，取决于"成本"指的是哪个成本。

**如果是"单位变动成本"，这句话是对的。**单价低于单位变动成本，卖一单亏一单的现金，做得越多死得越快。这一条没有例外。

**如果是"完全成本"或"单位成本"，这句话通常是错的。**因为单位成本里含着分摊的固定制造费用，而那部分钱不管你接不接这一单都要花。只要单价高于单位变动成本，这一单就贡献正的贡献毛利，就能帮你分担一部分固定成本。

**判断流程，五步：**

第一步，问清楚"成本"是哪个口径。把单位成本拆成"单位变动成本 + 单位固定制造费用分摊"。

第二步，看单价是否高于单位变动成本。低于，直接拒；高于，进入第三步。

第三步，看有没有产能瓶颈。
- 产能闲着：只要单价 > 单位变动成本，且有正的贡献毛利，原则上可以接。
- 产能紧张：进入第四步。

第四步，算"单位瓶颈资源的贡献毛利"。找出最卡的那道环节（设备小时、人工小时、冷库位、资金），算每个候选订单在这个环节上每小时（或每单位资源）能创造多少贡献毛利，从高到低排，排到资源用完为止。单价低但耗资源少的订单，可能比单价高但吃资源的订单更划算。

第五步，加三个附加条件审查：
- 会不会扰乱价格体系（老客户知道了要不要补偿）？
- 会不会带来不成比例的营运资金占用（账期 120 天 vs 30 天）？
- 会不会触发阶梯固定成本（需不需要加一个班次、加一台设备）？

**"要附加条件才能接"的典型情况**，就是这三种。遇到它们，你要谈的不是"接不接"，而是"怎么接"：

```
扰乱价盘 → 改成"专供规格"或"限量特供批次"，包装、规格、条码与主流产品区隔
账期太长 → 用价格换账期：单价降 3%，账期从 120 天缩到 45 天
          验算：贡献毛利 20%、账期 120 天 vs 贡献毛利 17%、账期 45 天
                前者年化 = 20% × (365 ÷ 120) = 60.8%
                后者年化 = 17% × (365 ÷ 45)  = 137.9%
                看似降价，实则更划算
触发阶梯 → 要求客户承诺一个最低年度采购量，把台阶填平
```

**第 3 题**

至少这三个维度：

**维度一：需求的可预测性。**需求越稳定、越可预测，越适合高固定成本结构（自建产能、长期用工）。因为你能把产能填满，摊薄的效果是确定的。需求波动大、季节性强的（比如冷冻食品的淡旺季），高固定成本就很危险——淡季那半年，产能闲着，折旧照提。中间的解决办法是"产能弹性"：核心产能自建，峰值部分外包或用临时工。

**维度二：规模效应与议价能力。**如果规模能显著降低成本（比如一条线开满比开半负荷的单位成本低 30%），而且你有信心拿到足够的量，那自建是对的。反之，如果外包的规模效应比你强（专业代工厂服务几十个客户），那就别自建。判断标准：**算一算"达到多少量，自建的单位成本才低于外包"**，这个量你有没有把握拿到。

**维度三：这个环节是不是你的护城河。**如果是核心工艺、配方、品质控制点，自建，哪怕贵一点；如果是标准化、可替代的环节（包装、运输、基础加工），外包。因为高固定成本换来的不只是成本，还有控制力——控制力在核心环节是资产，在非核心环节是包袱。

补充两个实务维度：

**维度四：资金成本与融资能力。**高固定成本要占压大量资金。如果你的资金成本是 8%，而行业平均是 4%，那你自建的门槛就比同行高。

**维度五：周期位置。**行业景气上行期，适度加固定成本（因为产能会紧缺、外包会涨价）；下行期，反过来实现轻资产。但这话说起来容易做起来难，因为设备投资有建设周期，等你建好可能周期已经过去了——所以老手会问"这个行业的产能建设周期是多长"。

**第 4 题**

**（1）边际贡献率、贡献毛利、营业利润**

```
边际贡献率 = 1 − 62% = 38.0%
变动成本 = 30,000 × 62% = 18,600 万元
贡献毛利 = 30,000 − 18,600 = 11,400 万元
营业利润 = 11,400 − 9,120 = 2,280 万元
```

**（2）盈亏平衡点、安全边际、经营杠杆**

```
盈亏平衡销售额 = 9,120 ÷ 38.0% = 24,000 万元
安全边际额 = 30,000 − 24,000 = 6,000 万元
安全边际率 = 6,000 ÷ 30,000 = 20.0%
经营杠杆系数 = 11,400 ÷ 2,280 = 5.0
验算：1 ÷ 5.0 = 20.0%。与安全边际率一致。
```

**（3）销售额增长 15%**

```
新销售额 = 30,000 × 1.15 = 34,500 万元
新贡献毛利 = 34,500 × 38.0% = 13,110 万元
新营业利润 = 13,110 − 9,120 = 3,990 万元
利润增长率 = (3,990 − 2,280) ÷ 2,280 = 75.0%
验算：15% × 5.0（经营杠杆）= 75.0%。一致。
```

**（4）降价促销判断**

```
保本销量增长率 = 降价幅度 ÷ (边际贡献率 − 降价幅度)
               = 6% ÷ (38% − 6%) = 6 ÷ 32 = 18.75%
```

预计增长 20% > 18.75%，**划算**。

```
原贡献毛利 = 6,000 × 38% = 2,280 万元
原变动成本 = 6,000 − 2,280 = 3,720 万元
新收入 = 6,000 × 1.20 × 0.94 = 6,768 万元
新变动成本 = 3,720 × 1.20 = 4,464 万元
新贡献毛利 = 6,768 − 4,464 = 2,304 万元
变化 = 2,304 − 2,280 = +24 万元
```

验算保本点：(1 + x) × (6,000 × 0.94 − 3,720) = (1 + x) × (5,640 − 3,720) = (1 + x) × 1,920 ≥ 2,280 → 1 + x ≥ 1.1875 → x ≥ 18.75%。一致。

注意：只多赚 24 万元。如果这个促销还要花执行费用（堆头、促销员、物料），大概率会变成净亏。**所以"划算"和"值得做"是两件事。**

**（5）设备购置决策**

```
新增固定成本 = 180 + 120 = 300 万元
单位贡献毛利 = 45 元
保本产量 = 3,000,000 ÷ 45 = 66,667 件 ≈ 6.67 万件
产能利用率 = 66,667 ÷ 100,000 = 66.7%
```

需要达到设计产能的 66.7% 才保本。

```
若预计年销量 5 万件：
贡献毛利 = 50,000 × 45 = 225 万元
固定成本 = 300 万元
净结果 = 225 − 300 = −75 万元
```

**不该买。**每年亏 75 万元。

**但要先问一个问题：不买这台设备，这 5 万件能不能用现有产能做？**

- 如果现有产能够（比如现有设备利用率只有 60%），那完全不该买——用现有设备做，贡献毛利 225 万全是净赚（不考虑其他增量成本）。
- 如果现有产能不够，那要比较几种方案：买新设备（亏 75 万）、加班（算加班费的增量）、外包（算外购价与自制变动成本之差 × 数量 + 增量固定成本）。

假设外包单价 130 元，自制变动成本 95 元（单位贡献毛利 45 元意味着售价 140 元，变动成本 95 元）：

```
外包 5 万件：增量成本 = 50,000 × 130 = 650 万元
             收入 = 50,000 × 140 = 700 万元
             贡献 = 50 万元
自制（买设备）：贡献毛利 225 万元 − 固定成本 300 万元 = −75 万元
自制（加班，假设加班增加变动成本 10 元/件）：
             单位贡献 = 45 − 10 = 35 元
             贡献 = 50,000 × 35 = 175 万元，无新增固定成本
             净结果 = +175 万元
```

**结论：加班（175 万）> 外包（50 万）> 买设备（−75 万）。**

这一小题的重点在最后一步：**"该不该买设备"从来不是一个是非题，它是一个三选一甚至四选一的题。**你把所有选项的贡献毛利摆在一张纸上，答案自己就出来了。而很多人的错误是，只算了"买"这一种方案，就开始讨论"买多少钱的设备合适"。

**第 5 题**

这是一道必须回到你自己工作现场的题。我给判卷标准和一个示范。

**判卷标准三条：**

第一条，你选的这个决策必须真实发生过，而且**当时是怎么算的，你能复述出来**（包括"当时根本没算"——那也是一种处理方式，而且是最需要改的那种）。

第二条，你重算的结果必须落到"增量贡献毛利 vs 增量成本"这个式子上。如果你重算完还是在算"毛利率变了几个点"，说明这一章没吃透。

第三条，你必须能指出**假设差在哪儿**。本量利算错的案例里，九成不是公式错，是输入错——尤其是那个"销量能涨多少"的数字，往往来自某个人的直觉。

**一个示范：**

"我们去年双十一在电商平台做了一次满减，力度是满 199 减 40，相当于打八折。当时销售部是这么算的：去年同期做过一次类似的，销量涨了 60%，这次力度更大，估计能涨 70%。财务这边只做了一件事——核了一下毛利，说'打折后综合毛利率还有 12%，还有得赚'，就放行了。

事后复盘：那次活动销售额 820 万，同比涨 68%，但算上平台佣金、赠品、退货（退货率比平时高了 8 个百分点），实际是亏的。

用本量利重算：我们的边际贡献率（扣掉平台佣金和变动促销费用后）是 26%，不是 38%。降价 20% 意味着保本销量增长率 = 20% ÷ (26% − 20%) = 333%。也就是说，销量要涨三倍多才保本。而涨 68% 远远不够。

差在哪个假设？两个：一是把毛利率当成了边际贡献率，漏掉了平台佣金和赠品这些变动销售费用；二是没算退货率上升——退货不只是少了收入，还有来回运费和报废。

如果再给我一次机会，我会在会上说一句：'这次活动的边际贡献率是 26%，不是 38%。打八折需要销量涨 3.3 倍才不亏，我们估的是涨 70%。我不反对做，但我建议要么把力度降到九折，要么把这个活动限定在清仓的老品上——老品卖不动也是沉没，能收回一点变动成本加一点贡献就是赚。'"

请注意最后那句话的结构：**不给否定结论，给两个可选项。**这是 BP 说话的标准姿势——你不是来说"不行"的，你是来说"这么干不行，那么干行"的。
