# 第 3 章 · 嗔：愤怒与报复性交易

## 本章核心

**"嗔"在佛家是对逆境的愤怒抗拒，在股市是"亏损后骂市场、报复性加仓"。**

## 嗔的典型表现

1. **骂庄家、骂市场**——亏损后把责任推给"庄家割韭菜""市场不公"，而不是反思自己；
2. **报复性交易**——"我就不信了，再买！"——用情绪对抗市场，越亏越加仓；
3. **赌徒心态**——亏损后想"一把回本"，反而越陷越深。

## 嗔的深层机制

作者点破：**嗔的本质，是"不愿承认错误"**。亏损让人产生"被羞辱感"，而人的本能反应不是"认错止损"，而是"愤怒 + 反击"。**愤怒，是对"我错了"这个事实的逃避。**

## 为什么"嗔"是亏损的加速器

- 骂市场 → 不反思 → 不改进 → 重复犯错；
- 报复性加仓 → 情绪化决策 → 越陷越深；
- "一把回本" → 加大杠杆 → 可能爆仓。

**嗔，是把"小亏"变成"巨亏"的关键一步。**

## 现代理论对接

| 作者观点 | 对应理论 |
|---|---|
| 亏损后愤怒 | 损失厌恶 + 自我防卫 |
| 不愿认错 | 认知失调（费斯汀格） |
| 报复性交易 | 情绪化决策（hot-state） |

**关键机制**：费斯汀格的"认知失调"——当"我亏了"和"我没错"冲突时，人会感到痛苦，于是要么"认错"（止损），要么"合理化"（怪市场）。**大多数人选择了后者，因为前者更痛。**
