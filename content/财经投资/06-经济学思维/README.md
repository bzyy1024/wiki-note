# 经济学思维课：从被事实蒙骗，到看穿世界的运行

> 这是一套帮你从「被表象蒙骗」成长为「用经济学看世界」的思维课程。
> 课程提炼自经济学课的核心思想，用大量反直觉案例，层层设问、启发思考。
> 每一课都是一个经济学老师，带着一个"眼见为实"的小白，学会"从约束看世界"。

---


## 怎么学？三句真心话

1. **放空你的"常识"。** 经济学里很多结论，和你"想当然"的想法相反。先接受"反直觉"，才能真正看懂。
2. **每一课都有一堆"颠覆认知"的案例。** 先自己想，再听分析，收获翻倍。
3. **学完一课的当周，用它重新审视一个你"习以为常"的现象。**

---

## 结业标准（成为"大佬"的标志）

学完 11 课，你应该能做到：

- [ ] 不轻易被"表面的现象"和"道德化的判断"蒙骗
- [ ] 会用"约束条件"看人的行为，而不是贴"好人/坏人"标签
- [ ] 理解"成本、价格、供需"这些核心概念的真实含义
- [ ] 能看穿"价格管制""打击高利贷"等政策的后果
- [ ] 拥有"经济学的思维方式"——看结果，而非看动机

**当你能用"约束"和"成本"的视角，解释一个社会现象，并且让人信服——你就已经是经济学的高手了。**
