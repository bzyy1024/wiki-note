# 金融通识课：从勤劳不富，到看懂金钱的运转

> 这是一套帮你从「金融小白」成长为「看懂金钱世界」的通识课程。
> 课程提炼自耶鲁金融课的核心思想，用大量历史与现实案例，层层设问、启发思考。
> 每一课都是一个金融学老师，带着一个"勤劳却不富有"的小白，看懂金融的底层逻辑。

## 怎么学？三句真心话

1. **别把金融当"炒股"**。金融的本质是"跨期价值交换"，它关乎你的养老、婚姻、教育、甚至文化。
2. **每一课都用"历史 + 生活"的案例。** 金融不是抽象的公式，它藏在你能看到、能体会到的现实里。
3. **学完一课的当周，用它审视一次你真实面对的"钱"的问题。**
