## 学习顺序

1. 先看总览，理解为什么不同行业不能用同一套指标。
2. 再结合自己感兴趣的行业，按“商业模式 → 核心指标 → 估值方法 → 风险点”去看。
3. 每一篇都带了 2-3 个 A 股代表性股票示例，方便你把抽象概念和真实公司对应起来。

## 使用说明

- 这些股票例子是为了帮助理解行业逻辑，不构成投资建议。
- 如果你想深入某个行业，可以继续把该行业拆成更细的子行业版本。
- 最好的学习顺序是：先通读总览，再选一个最熟悉的行业读深一点。
