# 第 7 课：价格三大构成——为什么管价格越管越糟

## 本课要解决的问题

上一课知道了价格由工资+利润+地租构成。但这三大块在市场上是怎么自动变成一个"数"的？斯密用了一个很漂亮的"水面和波浪"的类比——自然价格是水平面，每天的你看到的价格是波浪。本课结束后，你会理解为什么价格不是被谁"定"的，以及为什么控制价格通常适得其反。

---

## 核心内容

### 一、自然价格 vs 市场价格——水位和波浪的关系

斯密做了这样一个区分：

**自然价格**——在充分竞争下，这个商品的价格刚好覆盖工资、利润、地租。这是它长期的"重心"。

**市场价格**——你今天在菜市场、超市、网上看到的价格。每天在变——今天三块、明天三块五。

斯密用了一个非常形象的比喻：自然价格就像**水位线**——水平面是固定的。市场价格就像水面上的**波浪**——风一吹，波浪翻起来；风停了，波浪平回去。浪再高，时间一拉长，水面还在那。

为什么市场价格不会长期远离自然价格？斯密给了两个互斥的力：

**向上推**：市场价格高于自然价格 → 利润高 → 新人往里冲 → 供给增加 → 价格被拽下去。  
**向下拽**：市场价格低于自然价格 → 亏钱 → 老玩家退场 → 供给减少 → 价格弹回来。

利润和亏损，像两根弹簧，把价格永远拉向"自然水平"。

### 二、价格是稀缺性的信号系统——别关收音机

斯密最被低估的洞见：**价格不是一个任意的数字——它是市场在向全世界广播。**

一个东西突然贵了 → 广播频道在说："这缺了！谁有谁快点来，现在利润高！"  
一个东西突然便宜了 → 广播频道在说："这太多了！别再来生产了，再干要亏钱。"

把你放到这个隐喻里——

疫情期间你发现口罩突然贵了五倍十倍。你的第一反应可能是骂奸商。但价格信号说的是另一句话："这里急缺口罩。不管是谁——有口罩的、能造口罩的、能运口罩的——现在利润是以往的几十倍，快来生产。"

然后呢？三个月后，全球口罩产能暴增，价格落回去了。不是被骂回去的——**是价格信号把生产者"喊"过来的。**

斯密给的关键提醒：**面对一个价格现象，你的第一步永远是"读懂它在说什么信号"，而不是"关了收音机"。**

### 三、价格管制的经典翻车——你要菜便宜，结果没菜了

斯密在《国富论》里花了很大篇幅反对行政限价。他用了一个逻辑链来解释为什么"好心"的价格管制几乎必然翻车——

假设某城市觉得菜太贵了，颁布"蔬菜零售价不得高于每斤五块"。

- 第一天：全市菜价牌全改成五块，市长上了新闻。
- 第一周：菜贩子会计一算账——种子、化肥、运输、摊位租金全加上，卖五块钱一斤只剩一点点利润，有时候还亏。而隔壁在工地搬砖的朋友一天能赚二百——我为什么要卖菜？
- 第二周：一部分菜贩子不干了。市场上的菜少了。老百姓发现早上买菜要排队，去晚了就没了。
- 第四周：菜市场一半摊位空着。剩余菜贩子抬价到九块——你问为什么，他说"就这么多菜，你不买别人买。"
- 第六周：菜市场基本没人卖菜了。老百姓在微信群里找"私人菜源"，十二块一斤。

发生了什么？**城市关掉了价格收音机，但没解决收音机里说的那个问题——"菜不够多"。**

价格高的本质是菜不够多（供给不足）。你不去解决"为什么菜不够多"，你只关收音机——供给问题没消失，最终在黑市里以更高的价格重新冒了出来。

## 实际运用：把你的工资当成价格信号来读

你的月薪，本质上是你个人劳动力的"市场价格"。

它长期不变 → 一个信号：你提供的这种劳动，目前市场上供给充分或者过剩。和你差不多的人太多了。

它突然涨了 → 一个信号：你这类型的人突然稀缺了。可能是因为你新学了一个技能、转了一个领域、或者行业需求爆发了。

**你的工资不涨不是老板的问题——是市场在告诉你：你提供的东西不够稀缺。**

怎么办？斯密的价格理论给出的答案一点都不温暖："你想涨价，就想办法从一个'同质化产品'变成'稀缺品'——学别人不会的、进别人不敢进的、积累别人没有的。"

这就是把你自己当成一个商品、用价格信号的逻辑来管理自己的职业。

## 常见误区

> "斯密说不要管价格，所以疫情期间口罩任由它涨到天价？"

斯密反对的是不理解信号本质的粗暴干预。他从未讨论过战争、疫情、自然灾害这些极端状态下的紧急管制——那是另一个范畴的事。他的核心逻辑是：**在正常运转的市场里，管理价格不如管理竞争的公平性和信息透明度。** 别把"一般经济学原理"和"极端紧急状态下的公共决策"混为一谈。

## 动手练习

**任务一：追踪一个价格。**

找一个你经常买的东西——任何东西都行（奶茶、共享单车、充电宝、你那个牌子牙膏）。记下它今天的价格。下周、下下周再看，记下来变化。如果有变化，试着回答：

- 是供应链出了问题（少了）还是需求端爆了（需要的人多了）？
- 这个变化是一时的（短期波动），还是趋势性的（长期方向）？

**任务二：读你的"个人价格信号"。**

如果你最近两年换了工作或者涨过薪——这一次变化背后的原因是什么？是因为你供不应求了（学了新东西、去了新赛道），还是行业整体水涨船高？

如果你最近两年工资没动过——你提供的技能，在市场上的"稀缺度"最近有变化吗？没有的话，你打算做什么？
