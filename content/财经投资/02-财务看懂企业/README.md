# 财务看懂企业课：从看不懂报表，到一眼看穿企业

> 这是一套帮你从「财务小白」成长为「能看懂企业」的财务启蒙课程。
> 课程提炼自清华名师肖星的财务课，用"财"眼看世界，案例丰富、层层设问。
> 每一课都是一个耐心的老师，带着一个完全不懂财务的小白，从一张报表里读出企业的真相。

---

## 学习路线图

```
阶段一：财务之眼（先学会用"财"的视角看世界）
├── 第1课  "财"眼看世界 —— 为什么你要懂点财务？
├── 第2课  日常业务背后的财务实质 —— 每笔生意都是一笔账
└── 第3课  客户是"唯利是图"的 —— 应收账款里的秘密

阶段二：看懂企业（三张表，企业的"体检报告"）
├── 第4课  资产负债表：企业的"家底清单"
├── 第5课  利润表：企业到底赚不赚钱？
└── 第6课  现金流量表：企业有没有"真金白银"？

阶段三：关键指标（一眼看穿企业健康度）
├── 第7课  赚钱重要还是有钱重要？—— 利润 vs 现金流
└── 第8课  读懂企业的关键财务指标

阶段四：看懂大动作（企业的"生老病死"）
├── 第9课  投资与固定资产 —— 生命中无法承受之"重"
├── 第10课 并购与融资 —— 企业怎么"长大"？
└── 第11课 成本与存货 —— 小项目里的大乾坤

阶段五：结课复盘
└── 第12课 如何解读财务报表 —— 结课复盘，成为"财务大佬"
```

---

## 怎么学？三句真心话

1. **别怕，财务没有想象中难。** 你不是要当会计，你只要学会"用财务的眼睛看企业"，看穿三张表就够用了。
2. **每一课都有一堆"灵魂拷问"，先自己想 30 秒。** 财务最怕死记硬背，理解逻辑才记得住。
3. **学完一课的当周，找一家你熟悉公司的年报看一眼。** 看真实的报表，比看一百个抽象概念都管用。

## 结业标准（成为"大佬"的标志）

学完 12 课，你应该能做到：

- [ ] 拿到一份财报，知道先看哪三张表、各看什么
- [ ] 能判断一家企业"家底厚不厚"（资产负债表）
- [ ] 能判断一家企业"赚不赚钱、有没有真钱"（利润表 + 现金流量表）
- [ ] 会用 ROE、毛利率、周转率等指标给企业"体检"
- [ ] 能解释"为什么有的公司赚钱却缺钱"

**当你能把"这家公司靠什么赚钱、健不健康"讲给一个完全不懂的人听，而且对方听懂了——你就已经是财务大佬了。**
