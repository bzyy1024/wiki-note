# 第10课：绝对与相对剩余价值——加班和996的本质

## 本课要解决的问题

资本家想让剩余价值更多，无非两条路：

- **路一**：延长工作时间——原本干8小时，现在干12小时
- **路二**：提高生产效率——8小时内干出更多东西

在马克思的框架里，这分别叫**绝对剩余价值的生产**和**相对剩余价值的生产**。今天你经历的996、OKR、KPI、效率工具、打卡考勤——所有这些让你更累的东西，全部可以归到这两类。

理解了这个，你就看懂了"为什么加班和不加班你都是输家"。

## 核心内容

### 一、绝对剩余价值——在时间的轴向上挖

**定义**：在必要劳动时间不变的前提下，通过延长总工作日来增加剩余劳动时间。

原始版：本来8小时工作日，必要劳动4小时，剩余劳动4小时。资本家延长到12小时——必要劳动还是4小时，剩余劳动变成了8小时。剩余价值率从100%变成了200%。

这就是最原始、最赤裸的剥削方式。19世纪的工人每天干14-16小时，甚至童工也干同样的时长——这就是绝对剩余价值的生产。

**在现代的变形**：
- 996（早9到晚9，每周6天）
- "自愿加班"文化
- 把工作"带到家里"（微信随时在线、随时处理工作）
- "弹性工作制"——弹的是你的下限，不是上限

**类比**：你在健身房跑步。绝对剩余价值就是——教练不断把跑步机的时间往上加。本来跑30分钟，现在跑60分钟。跑的强度没变，但总里程翻倍了。

### 二、相对剩余价值——在时间的深度上挖

**定义**：工作日长度不变，通过提高劳动生产率来缩短必要劳动时间，从而相对延长剩余劳动时间。

原始版：8小时工作日，必要劳动4小时，剩余劳动4小时。技术升级后，工人的必要劳动缩短到2小时（因为维持生活所需商品的社会必要劳动时间下降了）——剩余劳动变成了6小时。工作日还是8小时，但剩余价值率从100%变成了300%。

**在现代的变形**：
- ERP系统、自动化工具（减少不必要的时间浪费）
- OKR/KPI考核（逼你在同样时间内做更多）
- "敏捷开发"（缩短交付周期 = 提升单位时间产出）
- AI辅助（一个人能干三个人的活）
- 扁平化管理、减少会议（一切"降本增效"的本质）

**类比**：还是在健身房跑步。相对剩余价值就是——教练不给你加时间，但把坡度调大了、速度加快了。还是跑30分钟，但你消耗的热量变成了两倍。

### 三、两种剩余价值的关系

| | 绝对剩余价值 | 相对剩余价值 |
|---|---|---|
| **怎么增加** | 延长时间 | 提高效率 |
| **手段** | 加班、996、随时在线 | 技术升级、流程优化、管理改进 |
| **工人感受** | 直接的累（时间被占了） | 间接的累（强度提高了） |
| **有没有上限** | 有——一天就24小时，人得睡觉 | 理论上没有——效率可以无限提高 |
| **在哪更常见** | 低端制造业、服务业 | 高科技行业、白领工作 |

马克思指出：绝对剩余价值是资本主义早期的典型手段。但工人会反抗（一天24小时你不能全占了），国家会立法（8小时工作制）。于是资本转向了相对剩余价值——同样是8小时，让你"更高效"地产出更多。

**但请注意**：现实中两者并行。996是绝对（时间延长）+ 相对（高强度工作）的双重压榨。

### 四、工人的"反抗"和资本的"应对"

马克思在《资本论》第8章用了大量篇幅描述英国工人争取正常工作日的历史。这不是一个经济分析——而是一部**阶级斗争的史诗**：

- 14-15世纪：英国颁布法律强制延长工作日（资本需要劳动力）
- 19世纪初：工作日普遍在14-16小时
- 1833年：工厂法限制童工工作时间为每天9小时
- 1847年：十小时工作日法案通过
- 资本的反击：分散化生产、计件工资、加速机器转速

**马克思的伟大洞见**：工人争取缩短工作日的斗争，不仅仅是"想多休息"——这是**工人阶级作为一个阶级在反抗自己被彻底消耗殆尽**的斗争。资本的本性是24小时不间断地消耗劳动力——如果工人不联合起来反抗，就会被榨干。

### 五、为什么你的效率提高了，你却没变轻松

这是相对剩余价值最反直觉的地方。

按照常识：技术提高了效率 → 一个人干两个人的活 → 那是不是可以少干点时间？

在资本主义的逻辑下：技术提高了效率 → 社会必要劳动时间降低了 → 你的必要劳动时间缩短了 → 等价于你在更短的时间内就"挣够了"自己的工资 → 剩下的时间全变成了剩余劳动。但工作日长度没变——所以**你干的活更多、压力更大，但感觉上"还是8小时"**。

**为什么？因为技术进步的果实被资本拿走了。**

在非资本主义的社会里：技术提高效率 → 大家用更少的时间满足基本需求 → 剩下的时间归自己支配。但在资本主义下：那些"节省下来的时间"一秒钟都不会变成你的自由时间——它会立刻被转化为剩余劳动时间。

## 实际运用

### 场景一：你上了新系统，工作量翻倍了

公司引入了新的管理系统，号称"提高效率"。原来你一天录入50条数据，现在系统帮你自动填了大部分，你觉得"快多了"。

结果：你的KPI从50条变成了150条。系统帮了你的忙，但你反而更累了。

分析：效率提升 → 社会必要劳动时间降低 → 剩余劳动时间相对延长。系统省下来的时间，一秒钟都没归你，全归了公司。

### 场景二：从996到"大小周"再到"正常双休"

中国的互联网公司经历了：疯狂996 → 舆论压力 → 取消大小周 → 但立刻转向"OKR更紧 + 裁员更狠"。

这是从"绝对剩余价值"转向"相对剩余价值"的典型案例。工作时间不能延长了，就在单位时间的产出上下功夫：OKR定得更高、团队裁得更小、每个人都得干更多活。

### 场景三：远程办公——是自由还是更深的控制

疫情期间远程办公被吹捧为"灵活工作"——不用通勤了。但对很多人来说，结果是：工作时间模糊了界限。早上起床就开始回消息，晚上11点还在开会。

这是**绝对剩余价值生产的新形式**：不是"强制延长工时"，而是"让你的整个生活都变成潜在的工作时间"。你失去了工作时间的"边界"，资本获得了对你所有时间的潜在支配权。

## 常见误区

> **"马克思反对技术进步、反对效率提升。"**

大错特错。马克思最崇拜的就是生产力发展。他对资本主义最尖锐的批判恰恰是：资本主义**妨碍**了技术进步对人类解放的促进作用。技术进步应该让所有人工作更少、生活更好——但在资本主义下，它变成了让一部分人剥削更多人的工具。

> **"既然提高效率就是加强剥削，那我不提高效率行不行？"**

个人层面，你不提高效率 → 你的个别劳动时间高于社会平均 → 你的产品没有竞争力 → 你被淘汰。这是"囚徒困境"——所有工人都想不卷，但谁先不卷谁先死。这不是某个人的选择问题，是整个体系的强制力。

## 动手练习

1. **区分你的加班**：回忆你最近一个月的工作——
   - 哪些工作属于"绝对剩余价值"产出（单纯延长了时间但效率没变）？
   - 哪些属于"相对剩余价值"产出（效率/强度提高了，同样时间干更多）？
   - 哪个让你更累？为什么？

2. **技术进步对你的影响测试**：你工作中最近一次"效率提升"（新工具、新流程、新系统）——省下来的时间去了哪里？是变成了你的休息时间，还是变成了新的工作任务？
