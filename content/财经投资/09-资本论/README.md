# 《资本论》系列课程：从商品到资本主义的终极秘密

## 课程定位

《资本论》常被称为"最难读懂的经典"之一。很多人翻开第一卷第一篇，就被"商品""价值形式""抽象劳动"这些概念劝退。但《资本论》真正要回答的问题其实极其朴素：**为什么创造财富的人反而最贫穷？为什么技术进步了，人反而更累了？为什么资本家越赚越多，普通人越来越忙？**

这套课程的目标不是让你成为马克思主义学者，而是帮你用马克思的思维框架，重新理解工作、金钱、技术、不平等——这些你每天都在打交道的东西。学完之后，你能做到的不是"背诵剩余价值公式"，而是**看穿日常生活背后那些看不见的关系**。

## 为什么是12课

马克思的《资本论》第一卷遵循一条极其严密的逻辑链，12课正好对应这条链上的12个关键节点：

- **第 1 课**：破冰，建立背景认知——为什么这本书值得读
- **第 2-5 课**：从商品出发，层层剥开到货币和拜物教——这是马克思分析资本主义的"出发点"，也是最抽象、最需要耐心但最重要的部分
- **第 6-8 课**：揭示货币如何变成资本、劳动力如何变成商品、剩余价值如何产生——这是全书的理论核心，也是马克思对资本主义批判的"心脏"
- **第 9-11 课**：深化剩余价值理论，分析不变资本与可变资本、绝对与相对剩余价值、技术的影响——将核心理论延伸到具体经济运行层面
- **第 12 课**：资本积累的趋势分析 + 全书框架回顾——收束整合，形成可迁移的思维工具

## 怎么用这套课程

### 自学用
- 每天学一课，12天完成
- 每课后有"动手练习"，一定要做——不做等于白看
- 建议边看边记笔记，用自己的话重写关键概念

### 带领别人学（共读/训练营）
- 每周2-3课为宜，太快了消化不了
- 每课后组织群内讨论：用马克思的框架分析一个你身边的例子
- 第6-8课是核心，可以放慢节奏，每课一周

### 做音频/视频内容
- 每课控制20-30分钟讲解
- 优先用人话翻译术语，概念先给类比再给定义

## 每课统一结构

每课包含四个板块：

- **核心内容**：知识点拆解，大白话 + 类比 + 原书引述
- **实际运用**：1-3个生活/工作场景分析
- **常见误区**：预判最容易理解偏的地方
- **动手练习**：可操作的练习，有具体步骤和完成标准
