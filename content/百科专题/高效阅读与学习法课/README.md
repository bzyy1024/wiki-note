# 高效阅读与学习法课：从读不完一本书，到一年读透 100 本

> 这是一套帮你从「读书慢、记不住、读了白读」的小白，成长为「高效阅读、知识管理」大佬的学习法课程。
> 课程提炼自"十倍速读书法"和"知识管理"的核心理念，案例丰富、层层设问。
> 每一课都是一个爱读书的老师，带着一个"买书如山倒、读书如抽丝"的小白，学会真正的"会读书"。

## 怎么学？三句真心话

1. **阅读不是"比谁读得多"，是"比谁用得上"。** 读 100 本不如用透 1 本。
2. **每一课都有练习，别只"看"。** 拿一本手边的书，边学边练。
3. **从今天开始，每天读 30 分钟。** 方法再好，不读也是空谈。

## 结业标准（成为"大佬"的标志）

学完 10 课，你应该能做到：

- [ ] 快速抓住一本书的核心，而不是"从头读到尾"
- [ ] 读书时主动提问，而不是被动接收
- [ ] 能把一本厚书，提炼成一页纸的精华
- [ ] 会做"内化式"的读书笔记，而不是抄书
- [ ] 能把读到的知识，讲给别人听、用在自己身上
- [ ] 有一套属于自己的"阅读系统"

**当你能把一本书的精华，讲给一个没读过的人听，并且对方觉得"值了"——你就已经是阅读的大佬了。**
