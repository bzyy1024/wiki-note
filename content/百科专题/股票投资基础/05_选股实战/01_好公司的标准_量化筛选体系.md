## 开篇：PE低为什么总亏钱？

小林盯着自选股列表，皱着眉头走进老陈的办公室。

「老陈，我每次选股都是看PE低的买，但总亏钱。好公司到底有什么标准？」

老陈没有立刻回答，而是反问道：「你买的那些PE低的股票，后来发生什么了？」

「要么利润下滑，PE反而越来越高；要么股价继续跌，跌了一半还觉得很便宜……」

「好。」老陈点点头，「那我问你，茅台2020年PE是40倍，格力电器同年PE是10倍，你应该买哪个？」

小林不假思索：「当然是PE低的格力，更便宜啊。」

「那你去查一下，2020年到2023年，这两只股票的股价走势有什么差别。」

小林翻了翻手机，沉默了片刻。

「……茅台涨了，格力……基本没动。」

「所以，你的问题不在于PE高低，而在于——你根本不知道什么是好公司。PE只是个价格标签，而价格标签便宜，不代表商品值得买。」老陈端起茶杯，「今天我们先解决一个根本性的认知问题：**好公司和好股票，是两件不同的事情。**」

## 第一节：好公司 ≠ 好股票

老陈在白板上写下一个2×2的矩阵：

```
              低估值          高估值
好公司   │  ★ 理想买入  │  可持有，不重仓  │
差公司   │  价值陷阱    │    坚决不碰      │
```

「小林，你一直在左下角这个格子里打转——拿着低估值的差公司，以为捡到了便宜。」

「那好公司是怎么定义的？」小林问。

「不是我来定义，是数据来定义。」老陈拿出一张纸，「我有一套四关量化筛选体系，每一关都有具体的指标和阈值。过了四关的公司，才有资格被称为候选好公司。」

「然后呢？」

「然后再看估值，决定是不是好股票。但今天，我们先只谈第一步——把好公司找出来。」

> **核心认知**：
> - 好公司：持续创造经济价值，护城河深厚，财务健康
> - 好股票：好公司 + 合理或低估的价格
> - PE低的股票，可能是：①真正低估的好公司（少数）②利润见顶的周期股③基本面持续恶化的烂公司（多数）

## 第二节：四关量化筛选体系

### 第一关：盈利质量——排除"纸面富贵"

老陈说：「我先问你，一家公司说它净利润10亿，你相信吗？」

「财务报告上写的，为什么不信？」

「因为净利润是可以'设计'的。」老陈意味深长地笑，「但现金不会说谎。第一关，我们要验证利润是不是真实的。」

#### 指标1：经营现金流 / 净利润 > 0.8（连续3年）

**核心逻辑**：一家真正赚钱的公司，利润最终应当流回现金。如果净利润高但经营现金流持续偏低，说明利润停留在应收账款、存货等"资产"中，没有真正变成钱。

$$\text{现金含量} = \frac{\text{经营活动现金流净额}}{\text{净利润}}$$

**阈值**：> 0.8，且连续3年不低于此水平

**示例数据**（某消费品公司，示意性数字）：

| 年份 | 净利润（亿） | 经营现金流（亿） | 现金含量 |
|------|------------|----------------|---------|
| 2019 | 50         | 48             | 0.96 ✓  |
| 2020 | 58         | 52             | 0.90 ✓  |
| 2021 | 65         | 60             | 0.92 ✓  |
| 2022 | 70         | 63             | 0.90 ✓  |
| 2023 | 80         | 75             | 0.94 ✓  |

→ 五年现金含量均>0.8，利润质量极高，通过第一关指标1。

**反例**（某工程类公司，示意性数字）：

| 年份 | 净利润（亿） | 经营现金流（亿） | 现金含量 |
|------|------------|----------------|---------|
| 2019 | 30         | 8              | 0.27 ✗  |
| 2020 | 35         | -2             | -0.06 ✗ |
| 2021 | 38         | 5              | 0.13 ✗  |

→ 利润全部积压在应收账款里，典型"账面利润"。

#### 指标2：应收账款增速 < 收入增速

**核心逻辑**：如果收入增长，但应收账款增速远超收入增速，说明公司靠赊账堆出来的销售额，未来可能大量坏账。

$$\text{应收增速} = \frac{应收账款_t - 应收账款_{t-1}}{应收账款_{t-1}}$$

**判断规则**：`应收账款增速 < 收入增速` 为正常；若`应收增速 > 收入增速×1.5`，属于预警信号。

**示例**：
- 某公司收入增速20%，应收账款增速15%→ 正常 ✓
- 某公司收入增速20%，应收账款增速45%→ 警惕 ✗（增速是收入的2倍以上）

#### 指标3：毛利率连续5年稳定或提升（波动 < 5个百分点）

**核心逻辑**：毛利率代表产品定价权。优秀公司的毛利率应当稳固——竞争对手无法通过降价抢走客户。

$$\text{毛利率} = \frac{\text{营业收入} - \text{营业成本}}{\text{营业收入}} \times 100\%$$

**阈值**：5年内毛利率最大波动幅度 < 5个百分点，且不呈下降趋势。

| 毛利率水平 | 含义 |
|-----------|------|
| > 40%     | 强定价权（白酒、软件、医药） |
| 20%~40%   | 中等护城河（消费品、医疗器械） |
| < 20%     | 同质化竞争激烈（钢铁、化工、代工） |

---

老陈问：「第一关你明白了吗？三个指标，核心是什么？」

小林想了想：「验证利润是不是真钱？」

「对。利润表可以修饰，但现金流更难造假，毛利率更能反映竞争地位。过了第一关，至少说明这家公司赚的是真钱。」

### 第二关：资本效率——找真正会赚钱的生意

「好，利润是真钱了。」老陈继续，「但光有真钱还不够，我问你，同样赚100元，一家公司用了1000元资本，另一家用了100元资本，哪个更厉害？」

「用100元资本的那个，效率更高。」

「这就是第二关要衡量的东西——这门生意，资本效率高不高？」

#### 指标1：ROE > 15%（连续5年，且非高杠杆驱动）

$$\text{ROE} = \frac{\text{净利润}}{\text{股东权益（净资产）}} \times 100\%$$

**阈值**：连续5年ROE均 > 15%

> **重要限定**：高ROE必须结合杜邦分析来验证。
>
> **杜邦三因子拆解**：
> $$\text{ROE} = \underbrace{\frac{\text{净利润}}{\text{收入}}}_{\text{净利率}} \times \underbrace{\frac{\text{收入}}{\text{总资产}}}_{\text{资产周转率}} \times \underbrace{\frac{\text{总资产}}{\text{净资产}}}_{\text{权益乘数（杠杆）}}$$

老陈说：「你觉得哪种ROE > 15%是真本事？」

小林思考片刻：「……靠利润率高，或者资产周转快？」

「对。如果ROE高但主要是权益乘数（杠杆）贡献的，那是借钱堆出来的，一旦去杠杆就崩。所以我的判断规则是：**净利率必须 > 10% 才算真实ROE**。」

**示例对比**（示意性数字）：

| 公司 | 净利率 | 资产周转率 | 权益乘数 | ROE  | 质量评级 |
|------|--------|-----------|---------|------|---------|
| A（白酒）| 35%  | 0.65      | 1.3     | 29.6% | ★★★ 高质量 |
| B（零售）| 2%   | 3.5       | 2.5     | 17.5% | ★★ 中等（靠周转）|
| C（地产）| 12%  | 0.8       | 5.2     | 49.9% | ★ 危险（靠杠杆）|

#### 指标2：ROIC > WACC

这是整个四关体系中最重要的一个指标，也是最容易被散户忽视的。

$$\text{ROIC} = \frac{\text{EBIT} \times (1 - \text{税率})}{\text{净债务} + \text{净资产}}$$

其中：
- **EBIT**（息税前利润）= 净利润 + 所得税 + 利息支出
- **净债务** = 有息负债 - 货币资金
- **投入资本** = 净债务 + 净资产（股东权益）

$$\text{WACC} \approx 8\% \sim 10\%（A股通用估算）$$

WACC（加权平均资本成本）代表投资者要求的最低回报率。

> **关键判断原则**：
> - `ROIC > WACC`：每投入1元资本，创造超过资本成本的价值，**扩张越多越好**
> - `ROIC < WACC`：每投入1元资本，反而在毁灭价值，**扩张越多亏越多**（帝国建造者陷阱）

**示例计算**（某制造业公司，示意性数字）：

```
净利润      = 20亿
所得税      = 5亿
利息支出    = 3亿
→ EBIT     = 20 + 5 + 3 = 28亿
税率        = 20%
→ NOPAT    = 28 × (1 - 20%) = 22.4亿

有息负债    = 50亿
货币资金    = 10亿
净债务      = 40亿
净资产      = 100亿
投入资本    = 140亿

→ ROIC     = 22.4 / 140 = 16%
   WACC    ≈ 9%
   ROIC - WACC = +7%  →  每年每元投入创造0.07元超额价值 ✓
```

老陈问：「现在你理解为什么有些公司越扩张越不值钱了吗？」

小林恍然大悟：「因为它的ROIC比WACC低，扩张本身就在毁灭价值！」

「对。这就是巴菲特为什么说'平庸的管理层会把好公司管烂'——他们只会投资ROIC < WACC的项目，表面上利润在增长，实则是在慢慢吞噬股东价值。」

#### ROE vs ROIC 的完整区别（CFA级别辨析）

```
ROE（股东权益回报率）：
  分母 = 股东权益（净资产）
  视角 = 股东视角，只看股东投入的钱赚了多少
  缺陷 = 负债越高，净资产越小，ROE自然越高（杠杆美化效果）

ROIC（投入资本回报率）：
  分母 = 净资产 + 有息负债（全部投入资本）
  视角 = 企业整体经营视角，评估这门生意本身的效率
  优势 = 剔除杠杆影响，更真实地反映业务质量
```

> **实操规则**：
> 1. 先看ROE，排除 < 15% 的公司
> 2. 再用杜邦分析验证驱动因子，净利率是否 > 10%
> 3. 最后计算ROIC，验证 > WACC（约8-10%）

#### 指标3：自由现金流 / 净利润 > 0.7

$$\text{FCF（自由现金流）} = \text{经营活动现金流} - \text{资本支出（购买固定资产）}$$

$$\text{FCF质量比} = \frac{\text{FCF}}{\text{净利润}} > 0.7$$

**含义**：利润中有多少是真正可以"拿走"的钱。FCF质量高的公司，利润可以用来分红、回购或再投资，股东实际获益更多。

### 第三关：财务健康——排除暴雷风险

「找到好生意后，还要确保它不会突然暴雷。」老陈拿出一张风险清单，「第三关专门排查财务地雷。」

#### 指标1：资产负债率 < 60%（金融股除外）

$$\text{资产负债率} = \frac{\text{总负债}}{\text{总资产}} \times 100\%$$

金融股（银行、保险）天然高负债，这条规则不适用；其余行业超过60%需谨慎，超过75%属于高危。

#### 指标2：有息负债 / EBITDA < 3倍

$$\text{有息负债} = \text{短期借款} + \text{长期借款} + \text{应付债券}$$

$$\text{EBITDA} = \text{净利润} + \text{所得税} + \text{利息} + \text{折旧摊销}$$

**阈值含义**：
- < 2倍：偿债能力极强
- 2~3倍：健康范围
- 3~5倍：需关注
- > 5倍：极度危险，一旦经营波动可能资金链断裂

#### 指标3：货币资金 > 短期有息负债

$$\text{货币资金} > \text{短期借款} + \text{一年内到期的长期借款}$$

**逻辑**：确保公司不会因为还不上短期债而爆雷。这是最基础的流动性安全垫。

老陈问：「为什么这条很重要？」

「……因为就算公司长期赚钱，但如果短期现金不够还债，也会倒闭？」

「对！A股上好几家公司，长期盈利能力没问题，但某一年集中到期的债务还不上，直接ST，股价腰斩。短期流动性是生存问题，不能忽视。」

#### 指标4：商誉 / 净资产 < 30%

$$\text{商誉占比} = \frac{\text{商誉}}{\text{净资产}} \times 100\%$$

**商誉的本质**：公司收购时，溢价支付的部分。收购价=100亿，目标公司净资产=60亿，则商誉=40亿。

**风险**：如果被收购公司业绩不达预期，商誉需要减值，直接冲击利润表。商誉越大，潜在的利润黑洞越深。

**示例**（示意性数字）：
- 某传媒公司商誉80亿，净资产100亿，商誉占比80%
- 某年被收购子公司业绩大幅下滑，计提商誉减值50亿
- 当年净利润从10亿变为亏损40亿，股价直接腰斩

### 第四关：成长质量——排除昙花一现

「过了前三关，说明公司现在很好。但投资是买未来，还要看它能不能持续成长。」

#### 指标1：收入5年CAGR > 10%

$$\text{CAGR} = \left(\frac{\text{期末收入}}{\text{期初收入}}\right)^{\frac{1}{n}} - 1$$

**示例**：
- 某公司2018年收入50亿，2023年收入80亿（5年）
- CAGR = (80/50)^(1/5) - 1 = 1.6^0.2 - 1 ≈ 9.9%

老陈：「你觉得9.9%能过关吗？」

小林：「差一点，不够10%……」

「那好，你再想想，如果这家公司行业整体增速是5%，它9.9%说明什么？」

「说明它在跑赢行业，市场份额在扩大……」

「所以CAGR阈值不是绝对的，要结合行业背景看。成熟行业5%以上可接受，成长行业要求20%以上。」

#### 指标2：净利润增速与收入增速匹配

**判断规则**：
- 利润增速略快于收入增速（1.0~1.5倍）→ 规模效益，正常 ✓
- 利润增速长期大幅超过收入增速（>2倍）→ 需验证原因：是否来自一次性收益？是否来自降本到极限（不可持续）？
- 利润增速长期低于收入增速 → 利润率在下降，竞争恶化，注意 ✗

#### 指标3：研发投入 / 收入趋势（科技类专用）

对于科技、医药、半导体类公司，研发投入是未来成长的种子：

$$\text{研发强度} = \frac{\text{研发费用}}{\text{营业收入}} \times 100\%$$

**参考基准**：
- 软件/互联网：通常 > 10%
- 医药：创新药 > 15%，仿制药 > 5%
- 半导体：> 15%
- 研发强度持续下降的科技公司，成长动力堪忧

## 第三节：Tushare批量筛选示例

老陈说：「四关理论讲完了，手工算太慢，教你用代码批量筛。」

```python
import tushare as ts
import pandas as pd

pro = ts.pro_api('你的TOKEN')  # 替换为实际token

# 获取单只股票三年财务数据（以贵州茅台为例）
ts_code = '600519.SH'

# 取利润表关键字段
df_income = pro.income(
    ts_code=ts_code,
    start_date='20190101',
    end_date='20231231',
    fields='end_date,revenue,n_income_attr_p,grossprofit_margin'
)

# 取资产负债表关键字段
df_bal = pro.balancesheet(
    ts_code=ts_code,
    start_date='20190101',
    end_date='20231231',
    fields='end_date,total_assets,total_liab,total_hldr_eqy_exc_min_int,'
           'accounts_receiv,goodwill,money_cap,lt_borr,st_borr'
)

# 取现金流量表关键字段
df_cash = pro.cashflow(
    ts_code=ts_code,
    start_date='20190101',
    end_date='20231231',
    fields='end_date,n_cashflow_act,free_cashflow'
)

# 合并三表（以年报为主，period_type='4'）
df = df_income.merge(df_bal, on='end_date').merge(df_cash, on='end_date')

# 计算第一关指标：现金含量
df['cash_quality'] = df['n_cashflow_act'] / df['n_income_attr_p']
print("现金含量（应>0.8）：")
print(df[['end_date', 'cash_quality']])
```

> **注意**：Tushare数据字段单位通常为"万元"，批量对比时注意统一量纲。

## 第四节：四关体系总结

老陈把四关指标写在白板上，递给小林一支笔：

「现在你来告诉我，一家公司要通过四关，最核心的三个字是什么？」

小林想了很久，写下：**真、效、稳、续**

- **真**：利润是真钱（第一关：现金含量 > 0.8）
- **效**：资本效率高（第二关：ROIC > WACC）
- **稳**：财务不暴雷（第三关：负债率 < 60%，商誉可控）
- **续**：成长可持续（第四关：CAGR > 10%，利润增速匹配）

老陈点点头：「你悟了。下次再有人给你推荐股票，先把这四关走一遍，能过的留下，过不了的直接扔。」

「但是……」小林迟疑，「过了四关就可以买了吗？」

老陈摇摇头，笑着说：「那才走了一半。好公司找到了，还要判断价格是不是合理。那是下一篇的内容——**低估值识别与价值陷阱**。」

## 追问思考题

### 题目一
一家A股公司，ROE连续5年都在20%以上，但你发现它的杜邦分解中，权益乘数从3倍升到了5倍，而净利率从15%降到了12%。请判断：这家公司的ROE质量是否在提升？应当如何进一步验证？

> **答案方向**：ROE质量在**下降**。权益乘数（杠杆）不断增加说明公司在靠加杠杆维持ROE水平，而净利率下降说明核心业务盈利能力在弱化。进一步验证方向：①计算ROIC看是否仍高于WACC；②检查有息负债/EBITDA是否已超过3倍警戒线；③查看经营现金流质量是否下降。

---

### 题目二
某科技公司，收入5年CAGR = 25%，但自由现金流连续5年为负（FCF < 0）。该公司是否能通过第四关？你认为这种情况可能代表什么含义？

> **答案方向**：**未能通过**第二关的FCF质量指标。自由现金流持续为负，需区分两种情况：①公司处于高速扩张期，大量资本支出用于建厂/研发（如早期的亚马逊），若经营现金流为正但资本支出高，可能是主动投资未来；②经营现金流本身为负，说明业务模式本身不产生现金，危险。判断关键：**经营活动现金流**是正是负，是区分主动投资与业务造血不足的分水岭。

### 题目三
某医药公司商誉占净资产的45%，超过了30%的预警线。但管理层解释称："被收购的子公司业绩超预期，商誉不存在减值风险。"你应该如何独立验证这个说法？

> **答案方向**：不能仅凭管理层说法。验证路径：①查看子公司（若已在A股单独上市）的独立财务数据，对比与收购时承诺业绩的差距；②关注审计师是否对商誉减值测试发表保留意见；③计算收购时支付的PE/PB倍数是否合理，溢价越高减值空间越大；④查看被收购公司所在行业景气度变化，若行业整体下行，管理层乐观预期需打折扣。
