# 《国富论》系列课程：从读懂到活用

## 课程定位

这系列课程的目标不是一个"读书会"——不是把《国富论》讲一遍给你听就完事。目标是两件事：

1. **吃透全书**：国富论的核心逻辑、关键概念、论证链条，一个不落
2. **用到生活**：每一课都有具体的、可操作的练习，让你当天就能用

所以它不是"一周速读班"，而是"读懂 + 会用"的完整训练。

## 为什么是12课

《国富论》原著五大板块：财富定义、分工、交换与货币、价值与价格、资本、政府的角色。每块内容足够深，拆得太少吃不透，拆得太多就散了。12 课的节奏是：

- **第 1-3 课**：打基础——重新理解财富、吃透分工
- **第 4-5 课**：理解交换系统——市场是怎么长出来的
- **第 6-8 课**：攻克价格——全书最绕但最重要的三连讲
- **第 9-10 课**：资本双讲——国家怎么富 + 你自己怎么富
- **第 11-12 课**：边界与实战——政府角色 + 把全书变成肌肉记忆

## 怎么用这套课程

**如果你是自学**：按顺序一天一课，每课约 20-30 分钟阅读 + 15 分钟做练习。不要跳，因为每课讲的内容是下一课的前提。

**如果你是带别人学**：把每课的"讨论题"和"行动练习"拿出来就可以做成小组分享、训练营任务。

## 每课统一结构

每课包含四个板块：

- **核心内容**：把这一课的知识点讲透，有案例、有类比
- **实际运用**：这个知识点在你的工作、生活、决策里怎么用
- **常见误区**：最容易理解偏的地方，帮你踩刹车
- **动手练习**：读完就能做的具体任务，有模板有指引
