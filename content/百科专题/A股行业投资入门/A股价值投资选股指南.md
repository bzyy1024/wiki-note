# A股价值投资选股指南

> 目标：找出**基本面优质 + 当前价格低估**的股票，长期持有获取复利回报。

---

## 一、A股的特殊性（先建立正确认知）

A股与港股、美股有本质不同，入场前需了解：

- **散户主导**：情绪驱动短期价格，低估可以持续很久，需要耐心
- **财报可信度**：造假风险高于成熟市场，需交叉验证（现金流 vs 利润）
- **政策影响大**：行业受政策影响显著，部分赛道说没就没
- **分红不稳定**：很多公司分红靠心情，需看历史分红连续性
- **估值失真**：PE/PB 绝对值参考价值有限，**历史分位更重要**

---

## 二、先选赛道，再选公司

不要一上来就筛个股，先确认行业是否值得长期投入：

| 推荐赛道 | 逻辑 |
|----------|------|
| 消费品（食品饮料、医药） | 周期性低，现金流稳定，品牌壁垒强 |
| 公用事业（电力、水务、燃气） | 垄断经营，股息稳定，防御性强 |
| 银行 / 保险 | 低PB策略有效，关注资产质量和不良率 |
| 优质制造业龙头 | 规模效应明显，出口竞争力强 |

**规避方向：**
- 重资产、高负债、强政策依赖行业
- 景气度依赖单一大客户的公司
- 商誉占净资产比例过高的公司

## 三、核心筛选指标

### 3.1 盈利能力（最重要）

| 指标 | 建议标准 | 说明 |
|------|---------|------|
| ROE（净资产收益率） | 连续5年 > 15% | 最核心指标，剔除高杠杆拉升的ROE |
| 毛利率 | > 30% 且逐年稳定 | 反映竞争壁垒与定价权 |
| 净利率 | 与行业对比，持续稳定 | 排除一次性利润暴增 |
| 经营现金流 / 净利润 | > 80% | 利润是否真实，识别"纸面盈利" |

### 3.2 估值水平

| 指标 | 建议标准 | 说明 |
|------|---------|------|
| PE历史分位 | < 30%（近5~10年） | 比PE绝对值更有参考价值 |
| PB历史分位 | < 30% | 银行/地产重点参考 |
| PE绝对值 | < 行业平均，消费类 < 25 | 辅助参考 |

### 3.3 分红质量

> **关键区分：每股分红 ≠ 股息率**

- **每股分红金额**：反映公司盈利健康度与回报意愿，看是否逐年稳定/增长
- **股息率**（= 每股分红 / 股价）：反映当前买入价格的性价比，股价低时股息率自然高
- **派息率**（= 分红 / 净利润）：健康区间 30%~70%，过高说明留存利润不足

**实操建议：**
- 看"每股分红"历史趋势 → 判断公司质地
- 看"当前股息率"是否处于历史高位 → 判断买入时机

### 3.4 财务健康度

| 指标 | 建议标准 | 说明 |
|------|---------|------|
| 资产负债率 | < 50%（金融股除外） | 过高则财务风险大 |
| 流动比率 | > 1.5 | 短期偿债能力 |
| 速动比率 | > 1 | 剔除存货后的偿债能力 |
| 商誉 / 净资产 | < 20% | 过高则有减值暴雷风险 |
| 应收账款增速 | 不应远超营收增速 | 警惕虚假收入 |

## 四、历史数据回溯

拉取近 **5~10年** 数据，观察以下趋势：

1. **营收 & 净利润**：是否持续稳定增长，排除大起大落
2. **ROE / 毛利率 / 净利率**：是否保持稳定或持续改善
3. **资产负债率**：是否逐年可控，没有大幅扩张负债
4. **经济下行周期表现**：2018年、2020年、2022年公司业绩是否抗跌
5. **PE/PB历史分位**：当前估值在历史中处于什么位置

## 六、综合评分表

分析完一只股票后，用以下表格打分（每项 1~5 分）：

| 评估维度 | 得分 | 简要说明 |
|----------|------|----------|
| 盈利能力（ROE / 毛利率） | /5 | |
| 业绩稳定性（近5~10年趋势） | /5 | |
| 财务健康度（负债 / 现金流） | /5 | |
| 估值水平（PE/PB历史分位） | /5 | |
| 分红质量（每股分红稳定性） | /5 | |
| **总分** | **/25** | |

**参考结论：**
- 20分以上：值得重点研究，可考虑建仓
- 15~19分：有亮点但有瑕疵，小仓位关注
- 15分以下：暂不考虑，继续观察

## 七、买入 & 持有原则

1. **分批建仓**：估值进入历史低分位（< 30%）时，分 2~3 次建仓，避免一次满仓
2. **分散持仓**：持有 5~10 只，单只仓位不超过 30%
3. **持有周期**：以 3 年为最低基准，A股短期波动剧烈，不要被噪音带走
4. **卖出条件**（二选一）：
   - 估值回归合理甚至高估（PE历史分位 > 70%）
   - 基本面发生重大变化（主业崩塌、财务造假、行业逻辑颠覆）
5. **止损红线**：基本面恶化立即卖出，**不是跌了就卖，是逻辑破了就卖**

## 八、AI 辅助分析提示词模板

将以下内容发给 AI，附上股票名称/代码即可获得结构化分析：

```
你是一位专业的A股价值投资分析师。请对【股票名称/代码】按以下框架进行分析：

1. 盈利能力：近5年ROE、毛利率、净利率趋势，经营现金流/净利润比值
2. 估值水平：当前PE、PB 及其近5~10年历史分位数
3. 分红质量：近5年每股分红金额趋势、派息率是否稳定
4. 财务健康：资产负债率、流动比率、商誉风险、应收账款异常
5. 历史抗压：在2018、2020、2022年下行周期中的业绩表现
6. 综合结论：是否值得买入，合理买入价格区间，主要风险点

请用表格和结构化方式呈现分析结果。
```
