# 从账本到全局——月月的财务经理觉醒之路

> 一个做了10年财务的女生，如何突破"执行者"的天花板，成为真正的财务经理？

---

## 关于这个系列

**主角：** 月月，33岁，华鑫五金制造厂财务专员，从业10年，认真负责，但感觉思维一直没有"打开"。

**引路人：** 陈姐，45岁，从小公司财务做起，现任上市公司财务总监，月月的大学同学。

**背景：** 月月想晋升财务经理，但她意识到，拦住她的不是技术能力，而是**思维方式**。

这个系列记录了月月六个关键时刻的顿悟——每一次，都是从一个职场困境出发，在和陈姐的对话中，完成一次思维的跃升。

## 思维跃升全景图

```
执行者思维                          经营者思维
─────────────────────────────────────────────────────
"我做对了就行"          →          "我的工作创造了什么价值？"
"数字准确就好"          →          "数字说明公司发生了什么？"
"报表发出去了"          →          "报表能帮老板做什么决定？"
"能省则省"              →          "这笔钱花得值不值？"
"预算是各部门的事"      →          "预算是公司战略的数字翻译"
"财务管财务的"          →          "财务能看见整个公司的命运"
```

---

## 怎么读这个系列

**推荐方式：线性阅读**
从第一篇读到第六篇，跟着月月一起经历每一次成长。思维转变是递进的，前面的基础支撑后面的跃升。

**遇到困境时：按需查阅**
如果你正好遇到某个具体问题（比如"不知道怎么做预算"），可以直接翻到对应篇章，每篇都是独立完整的。

**每篇读完后，做一件事：**
对照"实操建议"，选一条本周就能用上的，立刻去做。
思维改变靠的不是"看懂了"，而是"做了"。
