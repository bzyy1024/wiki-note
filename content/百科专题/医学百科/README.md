# 医学常识知识库

## 📖 关于本知识库

这是一个通过对话形式深入讲解医学常识的知识库。每个话题都以医学生和教授的对话展开，从日常现象出发，逐步深入到生理机制，澄清常见误区，指导正确应对。

**适合谁：** 没有医学背景，但想真正理解身体如何工作、疾病为何发生、药物怎样起效的普通读者。

**核心理念：** 不只告诉你"怎么做"，更要让你理解"为什么这样做"。

---

## 🚀 如何使用

### 三种阅读方式

**1. 系统学习**  
从基础概念开始，建立完整的知识体系  
推荐顺序：免疫系统 → 炎症反应 → 发烧的真相 → 其他基础概念 → 具体主题

**2. 问题导向**  
遇到具体健康问题，直接查找相关主题  
使用下方的快速查找索引

**3. 随机探索**  
浏览目录，选择感兴趣的话题阅读

### 阅读建议

- ⏰ 每篇对话阅读时间：15-25分钟
- 📝 建议做笔记，特别是关键要点部分
- 🔗 看到延伸阅读时，可以跳转深入了解
- ⚠️ 本知识库仅供科普，不能替代医疗建议
