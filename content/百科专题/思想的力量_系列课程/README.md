# 《思想的力量》系列课程：用哲学思维重新看世界

## 课程定位

这系列课程不是一本"哲学名词手册"——不是把苏格拉底、康德、尼采挨个介绍一遍就完事。目标是两件事：

1. **吃透西方哲学的主线**：从古希腊到当代，哲学思考的核心问题、关键转折、思想脉络，一条线串下来
2. **用到生活**：每一课都有具体的场景迁移和可操作的练习，让你当天就能用哲学框架分析自己的问题

哲学不是"高深"的学术奢侈品。它是每个人在面临选择、面对困惑、理解世界时，最底层的操作系统。这门课要做的，就是帮你装上这套系统。

## 为什么是12课

《思想的力量》原著五大板块：形而上学与认识论、道德与政治哲学、宗教哲学、女性主义哲学、东方与后殖民思想。全书跨越2500年西方哲学史，内容极其庞大。12课的节奏是：

- **第 1 课**：入门——哲学到底是什么、为什么"思想"本身有力量
- **第 2-4 课**：古希腊三大支柱——前苏格拉底、苏格拉底/柏拉图、亚里士多德，这是整个西方哲学的"源代码"
- **第 5 课**：过渡时代——希腊哲学如何融入基督教、信仰与理性怎么开始对话
- **第 6-7 课**：现代哲学的两大高峰——笛卡尔到休谟的知识论革命、康德的哥白尼式翻转
- **第 8-9 课**：19-20世纪两条分叉路——大陆哲学（存在、意义、历史）和分析哲学（语言、逻辑、验证）
- **第 10-11 课**：哲学的应用——道德哲学和政治哲学直接回答"我该怎么活""社会该怎么建"
- **第 12 课**：收束——把所有哲学工具整合成一套可以随时调用的思维框架

## 怎么用这套课程

**如果你是自学**：按顺序一天一课，每课约 20-30 分钟阅读 + 15 分钟做练习。不要跳，因为每课的核心概念是下一课理解的基础。如果某一课觉得太难，可以先读"实际运用"部分——把概念拉回生活，再回头读"核心内容"。

**如果你是带别人学**：每课的"讨论题"和"动手练习"可以直接拿出来做小组分享、读书会讨论或训练营任务。哲学最适合对话——一个人读容易困，两个人聊就活了。

## 每课统一结构

每课包含四个板块：

- **核心内容**：把这一课的知识点讲透，有类比、有思想脉络、有哲学家的核心主张
- **实际运用**：这个哲学框架在你的工作、生活、决策里怎么用
- **常见误区**：最容易理解偏的地方，帮你踩刹车
- **动手练习**：读完就能做的具体思维训练，有步骤有指引
