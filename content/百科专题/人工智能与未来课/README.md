# 人工智能与未来课：从AI小白，到看懂未来

> 这是一套帮你从「不懂AI、害怕未来」成长为「看懂AI、拥抱未来」的科技通识课程。
> 课程提炼自人工智能课、未来科技对话、科幻思辨，案例丰富、层层设问。
> 每一课都是一个懂技术的老师，带着一个"担心被AI取代"的小白，看懂AI和未来。

---

## 学习路线图

```
阶段一：认识AI（AI到底是什么）
├── 第1课  AI是机器人吗？—— 重新认识人工智能
├── 第2课  AI已经进入我们的生活了吗？—— 无处不在的AI
└── 第3课  什么是深度学习？—— AI如何"学习"

阶段二：AI与工作（AI会取代我们吗）
├── 第4课  AI会取代哪些工作？—— 医生、翻译、司机……
├── 第5课  哪些工作是AI替代不了的？—— 人的不可替代性

阶段三：AI与未来（如何拥抱AI时代）
├── 第6课  AI时代该怎么学习？—— 该学什么、怎么学
├── 第7课  科技的未来 —— 从人工智能到指数增长

阶段四：结课
└── 第8课  结课：你的未来思维 —— 与AI共存、不被淘汰
```

---

## 怎么学？三句真心话

1. **别怕AI，先了解AI。** 恐惧来自"不了解"。搞懂了，你会发现AI是"工具"，不是"敌人"。
2. **重点看"AI和我有什么关系"。** 你不用懂技术细节，但要懂"它如何影响你的工作、学习、生活"。
3. **学完一课的当周，用一次AI工具（如AI助手、AI绘图），亲身体验。**

---

## 结业标准（成为"大佬"的标志）

学完 8 课，你应该能做到：

- [ ] 说清"AI是什么"，区分AI和机器人
- [ ] 举出AI在生活中的应用
- [ ] 理解"深度学习"的大概原理
- [ ] 判断哪些工作会被AI取代、哪些不会
- [ ] 说清"AI时代该怎么学习"
- [ ] 拥有"与AI共存、拥抱变化"的心态

**当你能理性地看待AI（不恐慌、不盲从），并知道如何利用它、如何不被淘汰——你就已经是"看懂未来"的大佬了。**
