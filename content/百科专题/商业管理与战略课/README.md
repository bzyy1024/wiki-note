# 商业管理与战略课：从管好自己，到管好一家公司

> 这是一套帮你从「只懂执行的小白」成长为「懂战略、会管理的大佬」的商业实战课程。
> 课程提炼自卫哲商业实战课（亲授阿里管理心法），案例丰富、层层设问、启发思考。
> 每一课都是一个老商业人，带着一个想创业/想晋升的小白，一步步看懂商业和管理的门道。

---

## 学习路线图

```
阶段一：看清大势（先懂"势"，再谈"术"）
├── 第1课  风口与顺势而为 —— 创业要不要追风口？
└── 第2课  红海与蓝海 —— 为什么别怕红海？

阶段二：经营客户（商业的起点是用户）
├── 第3课  用户体验的"多快好省" —— 用户要的到底是什么？
└── 第4课  新零售的玄机 —— 线上线下的真相

阶段三：带好团队（管理的核心是人）
├── 第5课  一个团队为什么是7-10个人？—— 组织的黄金规模
├── 第6课  招聘与培训 —— 打造你的"铁军"
└── 第7课  激励与考核 —— 顺着人性设计制度

阶段四：看懂模式（生意的本质）
├── 第8课  你盈利，不代表你有盈利模式
├── 第9课  现金流与低成本资金 —— 有时比融资更重要
└── 第10课 合伙人制度 —— 找对人，才能成大事

阶段五：结课
└── 第11课 商业的底层心法 —— 从执行者到操盘手
```

---

## 怎么学？三句真心话

1. **带着"如果是我，我怎么办"来读。** 每一课都是一次商业决策，先自己判断，再看分析。
2. **案例是镜子。** 阿里的做法不一定要照搬，但背后的"人性和商业逻辑"是通用的。
3. **学完一课的当周，用它审视一次你所在的公司或生意。**

## 结业标准（成为"大佬"的标志）

学完 11 课，你应该能做到：

- [ ] 能判断一个"风口"值不值得追
- [ ] 能说清"用户体验"到底拼什么
- [ ] 理解团队规模、招聘、激励背后的管理逻辑
- [ ] 能区分"盈利"和"有盈利模式"
- [ ] 能看懂现金流、融资、合伙人的关键点
- [ ] 拥有"操盘手"的视角，而不再只是"执行者"

**当你能从"老板/操盘手"的视角，看懂一家公司的战略和管理，并能讲清楚——你就已经是商业管理的大佬了。**
