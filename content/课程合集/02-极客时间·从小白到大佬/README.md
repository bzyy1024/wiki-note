# 极客时间 · 从小白到大佬培训课体系

> 把 229 门课，重新编成一条「小白 → 大佬」的成长路线。
> 每门培训课单独一个文件夹，配合案例 + 思考题，边学边问边练。

---

## 这套体系是什么？

你手里有 229 门课，横跨编程语言、算法、网络、数据库、架构、AI、运维、安全、产品、管理……如果按文件名一本本硬啃，很容易「学了很多、用不出来」。

所以我把它们**重新排序、分类、分级**，编成了 **11 门培训课（11 个阶段）**，像爬楼梯一样：

> **先看世界 → 学会一门语言 → 补齐内功 → 会用数据库 → 能写后端/前端 → 敢碰架构 → 懂运维性能 → 会 AI 与数据 → 守得住安全质量 → 最后补齐软技能，实现职业跃迁。**

每一门培训课，都回答三个问题：
1. **为什么学**（不学会怎样，学了能干嘛）
2. **学什么**（核心知识地图）
3. **怎么练**（经典案例 + 引发你思考的问题）

## 怎么用这套体系？

**第一步：读 `00_学习路线总览.md`**
搞清楚「我在哪一层，下一步该爬哪一层」。

**第二步：按阶段走，别跳级**
内功没打好就冲架构，只会「照猫画虎」。每一阶段的「本课导读」都会告诉你**前置条件**。

**第三步：用「案例 + 问题」的方式学，而不是「看视频」的方式学**
每份学习指南里的「引发思考」，是给你自己留的作业。**先自己想 5 分钟，再去看原课**，效果差 10 倍。

**第四步：学完一个阶段，做一个小项目**
比如学完「数据库」，自己建一个表、写几条 SQL、跑一个索引优化；学完「后端」，写一个能跑起来的 CRUD 接口。**做出来，才算真会。**

## 三条学习心法（先记住，后面每课都会反复验证）

1. **知识不等于能力，做题和做项目才是。** 看完不等于会，写出来、跑通才算。
2. **带着问题学，比带着兴趣学更持久。** 一个问题解决不了，你会主动翻遍所有资料。
3. **慢就是快。** 基础阶段多花 1 个月，后面架构阶段能省 1 年。

## 常见问题

**Q：我是纯小白，一点编程都不会，从哪开始？**
A：从「阶段一」和「阶段二」开始，先学一门 Python 或 Java，同时看「阶段一」建立认知。别一上来就啃算法和架构。

**Q：我已经工作 3 年了，还用从头看吗？**
A：不用。看 `00_学习路线总览.md` 的「进阶路线」，直接从「阶段三」或「阶段五」补齐短板即可。

**Q：229 门课都要学完吗？**
A：不用。每门培训课里我会标注「必学 / 选学 / 兴趣」。跟着必学的主干走，选学的按需扩展。

**Q：每天该学多久？**
A：每天 1~2 小时，贵在坚持。这套体系大约对应 1~2 年的持续学习周期，具体看你的基础和时间。
