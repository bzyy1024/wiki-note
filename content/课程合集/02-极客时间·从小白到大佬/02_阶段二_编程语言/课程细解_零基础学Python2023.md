## 三、必须吃透的核心知识点

1. **四大内置类型（单元 2）**：列表（有序可变）、元组（有序不可变）、集合（去重）、字典（键值映射）。这是 Python 的「内功」，后面一切数据操作都基于它们。

2. **函数与装饰器（第 55–56 讲）**：装饰器是「不改变原函数就增强它」——这是 Python 最优雅的语法之一，也是理解 Flask/Django 的基础。

3. **面向对象（单元 6）**：类和实例、继承、`__init__`。Python 的 OOP 是「鸭子类型」，比 Java 宽松。

4. **异常处理（单元 7）**：try-except-finally，自定义业务异常。生产代码必须有异常兜底。

5. **实战思维（贯穿全课）**：从「飞机大战」到「人脸识别」，每个单元都有项目——**Python 的价值在于「快速做出东西」**。

## 四、引发思考

1. 列表和元组的核心区别？（可变 vs 不可变）什么场景用哪个？
2. 字典为什么查找这么快？它底层是什么结构？（哈希表——还记得阶段三吗）
3. 装饰器「不动原函数就增强它」是怎么做到的？和 AOP 思想有什么共通？
4. 文件读写为什么要「打开后关闭」？`with` 语句帮我们做了什么？
5. 学完这门课，你能用 Python 自动化你工作里的哪件重复劳动？
