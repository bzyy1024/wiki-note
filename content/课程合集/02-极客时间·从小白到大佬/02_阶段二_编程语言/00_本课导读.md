# 阶段二 · 编程语言（本课导读）

> **课程定位**：掌握至少一门能用来「做东西」的编程语言。这一阶段，你从「看客」变成「写代码的人」。
> **前置条件**：阶段一（或至少完成「计算机基础实战课」）。
> **时长建议**：6~10 周，专精一门语言，其他语言按需了解。

---

## 一、开场案例：选哪门语言？——「语言战争」背后的真相

小白问老师：**「老师，Python、Java、Go、C++、JavaScript……到底学哪个？网上吵翻了天，我快被劝退了。」**

老师反问：**「你想做网站，还是做后端，还是做 AI，还是做底层系统？」**

小白：**「我想先学会『写程序』，再决定方向。」**

老师：**「那记住这句话：语言是工具，不是信仰。会写代码的人，学第二门语言只需要 2 周。所以你现在要选的不是『最好的语言』，而是『最合适的第一门语言』。」**

老师列了个表：

| 你的目标 | 第一门语言 | 理由 |
|----------|-----------|------|
| 想做 AI / 数据分析 / 自动化 | Python | 生态最全，上手最快 |
| 想进大厂做后端 | Java 或 Go | 岗位多、体系成熟 |
| 想做前端 / 网页 | JavaScript | 浏览器唯一通用语言 |
| 想做底层 / 系统 / 游戏 | C++ 或 Rust | 性能极致、贴近硬件 |

小白：**「明白了，我选 Python，先学会『写程序』的感觉。」**

**案例启示**：老师见过太多人半年换了 4 门语言，最后啥也不会。**专精一门，做出 3 个作品，比浅尝 10 门强一百倍。**

---

## 二、这一阶段学什么？

本阶段按语言分成 5 个「语族」，每个语族内按「入门 → 进阶」排序：

1. **Python 语族**：零基础学 Python（2023版）→ Python 核心技术与实战 → Python 自动化办公 → Python 实战·从0到1搭建直播视频平台（在阶段五，学完语言后做项目）
2. **Java 语族**：零基础学 Java → Java 核心技术 36 讲 →（后续阶段五接 Spring）
3. **Go 语族**：郝林 Go 语言核心 36 讲 → Go 语言从入门到实战 → Go 项目开发实战 → Go 进阶·分布式爬虫实战
4. **JavaScript 语族**：JavaScript 核心原理 → JavaScript 进阶实战 →（后续阶段六接前端框架）
5. **C/C++ 与 Rust 语族**：现代 C++ 实战 30 讲 → 罗剑锋 C++ 实战笔记 → C++20 实战高手课 → Rust 语言从入门到实战 → 张汉东 Rust 实战课 → 陈天 Rust 编程第一课 → Kotlin 编程第一课（JVM 语言，做 Android 或后端可选）

---

## 三、怎么学最有效？

1. **只专精一个语族**，其他语族看懂语法即可，别贪多。
2. **每天写代码，哪怕 30 行**。语言是「手熟」的活儿，像练琴。
3. **每个语法特性，问三个问题**：它解决什么问题？不用它怎么写？它和之前学的什么像？（比如 Python 的 list 和 Java 的 ArrayList 本质都是「动态数组」）
4. **学完一个语族，做一个综合项目**：Python 就写个「通讯录管理程序」或「爬虫」，Java 就写个「图书管理系统」，Go 就写个「HTTP 服务器」。**项目是检验标准。**

---

## 四、学完检验（自测清单）

- [ ] 能用所选语言写出「读文件 → 处理数据 → 写文件」的完整程序
- [ ] 能解释变量、函数、类、异常、模块这几个概念
- [ ] 能看懂别人代码里的报错信息，并独立修好 3 个 bug
- [ ] 能说出所选语言的内存管理方式（GC？手动？所有权？）
- [ ] 能独立完成一个 200 行以上的小项目
