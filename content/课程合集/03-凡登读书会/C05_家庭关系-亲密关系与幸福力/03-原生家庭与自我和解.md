# C05 · 第 3 讲 原生家庭与自我和解

## 📌 学习目标

- 理解原生家庭如何塑造我们的"关系脚本"，但不被其决定
- 学会"看见—命名—重新书写"三步疗愈法
- 区分"和解"与"原谅"，找到与父母关系的舒服距离

---

## 🤔 先想想

1. 你身上有没有"特别像父母"的习惯/情绪模式？是好是坏？
2. 你找的伴侣/朋友，有没有某种"熟悉的感觉"？（哪怕是痛苦的熟悉）
3. 提起父母，你第一反应的情绪是什么？温暖？愧疚？委屈？麻木？

## 📖 知识讲解

### 一、原生家庭不是"锅"，是"初始设定"

**案例：小刘的"遇渣体质"**
小刘接连谈了 3 任对象，都是"忽冷忽热、需要她不断讨好"的类型。她觉得自己"命不好"。咨询师问她："你小时候怎么获得父母的关注？"她愣住了——**她的父亲常年在外，只有她"考得好、乖、懂事"时，父亲才回家抱抱她。**

**原来她从小习得的"爱的公式"是：我必须足够好，才配被爱。** 于是她在亲密关系里不自觉选择"难伺候的人"，重复童年的剧本——因为熟悉的痛苦，比陌生的幸福更"安全"。

**老师**：小白，原生家庭的影响有多大？
**小白**：很大……是不是我这一生都被它决定了？
**老师**：不。心理学家的共识是：**原生家庭是"初始设定"，不是"最终命运"。** 就像手机出厂设置可以改，关键是你**知不知道**自己在运行什么脚本。

### 二、常见的四种"关系脚本"（对照自查）

| 童年经历 | 长大后可能形成的脚本 |
|---|---|
| 父母苛刻 | "我不够好" → 完美主义、怕犯错、讨好 |
| 父母冷漠 | "我不被需要" → 回避亲密、不敢依赖 |
| 父母控制 | "我没有自主权" → 反抗权威或过度顺从 |
| 父母冲突 | "关系 = 战争" → 在亲密关系里习惯性防备 |

**看见，就是改变的开始。** 没意识到脚本的人，一辈子被脚本操控；意识到脚本的人，可以亲手改写它。

### 三、三步疗愈法：看见—命名—重写

**第一步：看见（找脚本）**
问自己："我在亲密关系/职场中最容易反复出现的情绪是什么？它第一次出现是什么时候？当时发生了什么？"

**第二步：命名（给它起个名）**
给这个脚本起名，比如"小刘的'必须优秀才配被爱'脚本"。**命名 = 把它从'我就是这样'变成'我有个模式'**——模式是身外的，可以改。

**第三步：重写（新的剧本）**
- 旧的：我必须完美，才配被爱
- 新的：**我存在，就值得被爱；我犯错，依然值得被爱。**
- 用新剧本指导行动：比如小刘下次恋爱，主动选择"稳定温暖"型，练习表达需求而不是讨好。

**案例：小刘的重写**
她在本子上写下新剧本，每天读一遍；恋爱时第一次主动说"我今天很累，不想做饭，我们点外卖吧"（表达需求，不是讨好）——男友的反应是"好呀，我来点"，没有嫌弃她。**一次次的小实验，一点点覆盖旧脚本。**

## 🧩 案例拆解：《原生母爱》与"和解"的误区

樊登读书 / 2022年 / 0604《原生母爱》讲了一个重要区分：

**"和解" ≠ "原谅" ≠ "父母道歉"**

- 很多"原生家庭和解"课程让人强行原谅父母，这其实是二次伤害
- **和解的对象不是父母，是你自己**——是"我承认这件事发生过，它伤害了我，但我选择不让它继续定义我"
- 有些父母永远等不到一句道歉，但这不妨碍你过好自己的人生

**实操建议：与父母关系的三种"距离"（都是合理的）**
1. **亲近型**：父母愿意改变，可以继续亲密
2. **保持距离型**：父母无法改变，物理/情感上保持距离（"我爱你，但不住一起"）
3. **切割型**：极端伤害的情况下，允许自己切断联系（这是自我保护，不是不孝）

**老师**：小白，你从小刘的故事里学到什么？
**小白**：原来那些"命"，很多都是剧本。
**老师**：对。**你不是在演父母写好的剧本，你正在成为自己人生的编剧。**

## 🗣️ 师生问答

**小白：我知道原生家庭有问题，但一跟父母沟通就崩，怎么办？**
老师：先别指望"改造父母"。**第一步永远是自我疗愈**（上面的三步法），你自己稳了，再谈怎么跟父母相处。很多人的误区是"先让父母变好，我才能好"——顺序反了，**先让自己好，你才有余力处理关系。**

**小白：我该不该把童年的事告诉父母？**
老师：看人。父母有反思能力的，可以温和表达（"小时候有件事我一直很难过"）；没反思能力的，说了只会更受伤。**你的疗愈不依赖他们的回应。** 可以先写"未寄出的信"给自己看。

**小白：我现在也有孩子了，怎么避免重复父母的错误？**
老师：你已经比父母多了一样东西——**觉察**。觉察 ≠ 完美，你依然会犯错，但你可以"犯错后道歉、修复"，这是上一代不会的技能。**给孩子最好的原生家庭，不是完美的父母，是愿意成长、敢于道歉的父母。**

## ✅ 思考作业

1. 用三步法完成一次自我梳理：我的"脚本"是什么？给它起个名字。
2. 写一封"不会寄出的信"给童年的自己（或父母），写下你想说的。
3. 立一个"新剧本"宣言：用一句话写出你的新规则，贴在显眼处。
4. 如果为人父母：写下 1 件"我要传给孩子"的事 + 1 件"我决不再做"的事。
