# 批判性思维实战指南：从入门到精通

## 📖 系列简介

这是一套系统化的批判性思维教程，通过**小白（新手）**和**老鸟（老手）**的轻松对话，帮助你从零基础到精通掌握批判性思维的核心技能。

**学习成果：**
- ✅ 识别生活中的逻辑谬误和思维陷阱
- ✅ 系统分析问题并做出理性决策
- ✅ 批判性地评估信息来源和论证质量
- ✅ 在实际场景中灵活运用批判性思维

## 🎯 如何使用本教程

### 完整学习路径（推荐）

1. **按顺序学习**：从模块0开始，逐步完成每个模块
2. **完成练习**：每篇都有思考题和实战练习，务必动手完成
3. **实践应用**：每个模块学完后，在实际生活中练习一周
4. **定期回顾**：建立批判性思维笔记，定期回顾和总结

### 选择性学习路径

1. **快速入门**：先阅读所有"入门"级别的文档
2. **针对性深入**：选择感兴趣的模块深入学习
3. **综合提升**：最后阅读"综合应用"整合所有技能

### 学习建议

- 📝 **建立思维日记**：记录你的思考过程和进步
- 💬 **与他人讨论**：分享学到的概念，教是最好的学
- 🔄 **刻意练习**：在日常生活中有意识地应用技能
- 📊 **自我评估**：使用每篇的自我评估清单检查进度

## 👥 关于角色

**小白** - 新手学习者
- 充满好奇，不怕提问
- 会犯新手常见的错误
- 代表你在学习过程中的困惑

**老鸟** - 批判性思维实践者
- 耐心、幽默、善于启发
- 用生活化的例子讲解
- 像朋友一样引导你思考
