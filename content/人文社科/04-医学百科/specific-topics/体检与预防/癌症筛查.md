# 癌症筛查：哪些值得做，哪些是白花钱

## 对话1：筛查和体检是一回事吗

**患者**：单位年年组织体检，里面不是有肿瘤项目吗？还需要另外做癌症筛查吗？

**医生**：这是两个概念，很多人混为一谈。

**普通体检**是"看看身体整体状态"，项目多而浅：血压、血常规、肝肾功能、胸片、B超……它的本意是发现高血压、糖尿病、脂肪肝这类常见病，**对早期癌症的发现能力很弱**。比如最常见的胸片，对早期肺癌的漏诊率很高。

**癌症筛查**是"针对某种特定癌症，用专门的方法去找它"，讲究的是针对性。比如低剂量螺旋CT查肺癌、胃肠镜查消化道癌、宫颈涂片查宫颈癌。

简单说：**体检是撒网，筛查是瞄准**。年年做体检却突然查出中晚期癌，往往就是因为只撒了网、没瞄准。

**关键要点**：常规体检≠癌症筛查，筛查需要针对特定癌种的专门检查手段。

## 对话2：什么样的癌症才"值得筛查"

**患者**：那是不是所有癌症都应该筛查？做个全身检查把癌症都找出来不行吗？

**医生**：不是所有癌症都适合筛查。国际上判断一个筛查项目是否有价值，有四条标准：

1. **这个癌症足够常见、足够严重**——罕见病筛查成本效益太低
2. **有早期阶段，且早期发现能改善结局**——能在还没症状时发现
3. **有准确、安全、可接受的筛查方法**——不能太痛苦太危险
4. **早期干预确实能降低死亡率**——这是最终标准

符合这些条件的癌症其实不多。目前**国际公认有效、证据充分**的筛查主要有这几种：

| 癌种 | 推荐筛查方法 | 适用人群 |
|------|------------|----------|
| **肺癌** | 低剂量螺旋CT（LDCT） | 50岁以上、吸烟≥20包年（含已戒烟未满15年者） |
| **乳腺癌** | 乳腺钼靶（X线）+ 超声 | 45-69岁女性（高危人群提前） |
| **宫颈癌** | HPV检测 + 宫颈细胞学（TCT） | 25-64岁有性生活史女性 |
| **结直肠癌** | 肠镜（金标准）、粪便潜血/粪便DNA | 45-75岁一般人群 |
| **胃癌** | 胃镜 | 40岁以上高危人群（含幽门螺杆菌感染者） |
| **肝癌** | 肝脏超声 + 甲胎蛋白（AFP） | 乙肝/丙肝携带者、肝硬化患者 |

**关键要点**：只有少数癌种有公认有效的筛查手段，关键看是否降低了死亡率。

**参考**：详见《癌症是怎么发生的》了解癌症的发生机制。

## 对话3：肺癌筛查——胸片为什么不行

**患者**：我每年体检都拍胸片，为什么医生说要换成CT？

**医生**：因为**胸片查不出早期肺癌**。这是最重要的一个认知更新。

胸片是把立体的胸腔压扁成一张平面照片，心脏、纵隔、肋骨会把肺组织挡住，而早期肺癌往往只有几毫米的小结节，藏在重叠的影像里根本看不见。大型研究证实，**用胸片筛查肺癌，并不能降低肺癌死亡率**。

现在推荐的是**低剂量螺旋CT（LDCT）**：
- 辐射剂量只有常规CT的1/5左右，大约相当于坐几次长途飞机
- 能发现几毫米的微小结节
- 大型研究证实可使**肺癌死亡率降低20%**

**谁应该做**：年龄≥50岁，且吸烟≥20包年（"包年"=每天吸烟包数×吸烟年数，比如每天1包吸了20年=20包年），包括目前仍吸烟或戒烟不足15年的人。此外有职业暴露史（石棉、氡等）、肺癌家族史的人群也应咨询医生。

**关键要点**：胸片不能替代低剂量CT做肺癌筛查，重度吸烟者是筛查重点人群。

**参考**：详见《肺结节》了解查出结节后该怎么办。

## 对话4：胃肠镜——很多人最怕也最有用的一项

**患者**：听说做胃肠镜很痛苦，能不能不做？

**医生**：胃肠镜是**唯一能在检查同时直接切掉癌前病变**的筛查手段，价值极高，强烈建议别躲。

先说个好消息：**现在普遍可以做无痛（麻醉）胃肠镜**，睡一觉就做完了，全程没有痛苦。

为什么它这么重要？因为**大多数结直肠癌不是突然长出来的**，而是从"小息肉→大息肉→不典型增生→癌"一步步演变，这个过程通常要**5-10年**。肠镜的意义就在于：在它还是良性息肉的时候发现并切掉，把癌症扼杀在摇篮里——这是真正意义上的"预防癌症"。

**建议时间**：
- **一般人群**：45岁起做第一次肠镜
- **高危人群**（有家族史、炎症性肠病、既往息肉史）：提前到40岁甚至更早，且间隔更短
- 结果正常者：可5-10年复查一次；发现息肉者按医生要求缩短间隔

**胃镜**则主要针对胃癌高危人群：40岁以上、幽门螺杆菌感染、萎缩性胃炎、有胃癌家族史、高盐腌制饮食者。

**关键要点**：胃肠镜能发现并切除癌前息肉，是真正能"预防癌症"的检查；无痛技术已很成熟。

**参考**：详见《幽门螺杆菌》了解胃癌的重要可控危险因素。

## 对话5：女性两项——乳腺与宫颈

**患者**：女性应该重点做哪些筛查？

**医生**：两项最重要，而且各有各的讲究。

**乳腺癌筛查**（45-69岁女性）：
- **乳腺钼靶（X线摄影）**是国际公认能降低乳腺癌死亡率的方法，尤其能发现摸不到的微小钙化
- 亚洲女性乳腺组织较致密，通常**钼靶+超声联合**效果更好
- 建议45岁起每1-2年一次；有乳腺癌家族史（尤其是一级亲属、BRCA基因突变携带者）应提前到35-40岁开始，并咨询医生是否需要加做磁共振
- **乳腺自检**不能替代筛查，但日常的"熟悉自己的乳房"仍然有意义——发现新出现的肿块、乳头溢液、皮肤凹陷要及时就医

**宫颈癌筛查**（25-64岁有性生活史女性）：
- **HPV检测 + TCT（宫颈细胞学）**联合筛查，比单做一项更准
- 30岁以下可单做TCT；30岁以上推荐联合筛查
- 联合筛查结果正常者可**3-5年**查一次，不必年年做
- 宫颈癌是**唯一病因明确（高危型HPV持续感染）且可通过疫苗预防**的癌症，接种HPV疫苗 + 定期筛查是双重保险

**关键要点**：45岁起筛查乳腺，25岁起筛查宫颈；HPV疫苗+筛查双管齐下。

**参考**：详见《女性健康》了解女性各年龄段的健康管理重点。

## 对话6：肝癌筛查——盯紧高危人群

**患者**：我以前查出来是小三阳，需要专门查肝癌吗？

**医生**：**需要，而且这是最该定期做的一类人**。

肝癌有个特点：**早期几乎没症状，一发现往往就是中晚期**，因为肝脏没有痛觉神经，代偿能力极强。但对高危人群定期筛查，能在肿瘤还很小时就发现它。

**高危人群**包括：
- **乙肝或丙肝病毒携带者**（这是中国肝癌最主要的原因）
- 各种原因导致的**肝硬化**患者
- 有**肝癌家族史**者
- 长期大量饮酒、非酒精性脂肪肝导致的肝损伤者

**筛查方法**：每**6个月**做一次**肝脏超声 + 甲胎蛋白（AFP）**抽血。注意是半年一次，不是一年一次——肝癌长得快，间隔太长会漏掉。

**关键要点**：乙肝/丙肝携带者和肝硬化患者需每6个月做肝脏超声+AFP。

**参考**：详见《病毒性肝炎》《肝脏健康》了解肝癌的源头防控。

## 对话7：肿瘤标志物能筛查癌症吗

**患者**：体检查那个"肿瘤标志物"，升高是不是就有癌？

**医生**：这是**最大的误区之一**。肿瘤标志物**不能用来筛查健康人的癌症**，它的正确用途是**监测已确诊患者的治疗效果和复发**。

为什么不行？两个原因：

**一是假阳性太高**。CEA、CA199、CA125这些指标，在炎症、感染、吸烟、良性肝病、子宫内膜异位、甚至月经期都可能升高。一个健康人查出来轻度升高，绝大多数情况是虚惊一场，但足以让人焦虑好几个月、做一堆不必要的检查。

**二是假阴性也不少**。很多早期癌症，肿瘤标志物完全正常。指标正常就说"没癌"，会给人虚假的安全感。

**正确态度**：
- 健康人**不推荐**常规查肿瘤标志物做筛查
- 已确诊的癌症患者，标志物是用来**动态观察**的——看治疗有没有效、有没有复发，这时看的是"趋势"而不是"单次数值"
- 如果体检发现标志物明显升高，不要恐慌，**找医生复查并寻找原因**，而不是直接等同于"得了癌"

**关键要点**：肿瘤标志物不能用于健康人筛查，只用于已确诊患者的疗效与复发监测。

## 对话8：那些"高大上"的全身体检项目值不值

**患者**：现在有PET-CT全身扫描、基因检测，说能把全身癌症都找出来，有必要做吗？

**医生**：对**没有症状的健康人，不推荐**，这属于过度检查。

**PET-CT**：
- 它的真正用途是给**已确诊的癌症患者**分期、评估疗效、找复发灶
- 用来筛查健康人：一是辐射剂量大（相当几百张胸片），二是**对早期小病灶反而不敏感**，三是假阳性率不低（炎症、结核都可能"亮灯"），反而导致过度检查和焦虑
- 价格昂贵，性价比极低

**基因检测**：
- 检测的是"**遗传易感性**"，比如BRCA突变提示乳腺癌/卵巢癌风险高
- 它**不等于你已经患癌**，也不等于一定会患癌
- 仅推荐**有明确癌症家族史**的人群，在**遗传咨询门诊**指导下进行。普通人跟风做，拿到一个看不懂的风险数字，除了焦虑没有实际指导意义

**关键要点**：PET-CT和基因检测不适用于健康人常规筛查，属过度检查。

## 对话9：筛查结果异常怎么办

**患者**：如果筛查查出问题，是不是就一定是癌？

**医生**：**绝大多数不是癌**。筛查的主要"副作用"就是**假阳性和过度诊断**，这是你需要提前有的心理准备。

举个例子：低剂量CT查肺，初次筛查的人里约20-30%会发现"结节"，但其中**真正是肺癌的不到5%**，大部分是陈旧炎症留下的疤痕、良性结节。

查出异常后的标准流程是：
1. **不要恐慌**，也不要置之不理
2. 找**专科医生**（不是体检机构）解读报告
3. 根据医生建议做**进一步检查**（可能是复查CT、增强扫描、穿刺活检）
4. 或者**定期随访观察**——很多小结节的处理方式就是"先不管，3-6个月后复查对比"

**关键提醒**：一定要**保留好影像资料和报告**，复查时做对比。医生判断结节好恶，最重要的依据就是"它有没有变大、变实"，没有老片子对比会非常被动。

**关键要点**：筛查异常绝大多数不是癌，需专科医生判读并保留资料做随访对比。

## 对话10：什么是"过度诊断"

**患者**：听起来筛查是好事，为什么您刚才提到它还有"副作用"？

**医生**：这是个需要坦诚说明的问题。筛查不是只有好处，它有个概念叫**过度诊断**——**查出一些一辈子都不会引起症状、也不会威胁生命的"癌"**。

最典型的是**甲状腺癌**和**前列腺癌**。研究发现，在一些医疗发达地区，甲状腺癌发病率飙升了好几倍，但**死亡率几乎没变**。为什么？因为高分辨率超声把大量微小的、生长极慢的甲状腺乳头状癌翻了出来，这些"癌"很多人一辈子带着它自然老去，也不会有事。

可一旦被贴上"癌症"标签，患者往往要接受手术切除，承受手术风险、终身服药和心理负担。这就是"查出来反而害了你"。

所以国际上已经开始**主动限制**某些筛查：比如不推荐普通人群常规筛查甲状腺癌、不推荐70岁以上男性常规查前列腺癌PSA。

**关键要点**：筛查存在过度诊断风险，查出"惰性癌"可能导致过度治疗。

## 对话11：怎么判断一个筛查项目靠不靠谱

**患者**：市面上筛查项目那么多，我自己怎么分辨？

**医生**：给你四个判断问题：

1. **"它能降低死亡率吗？"**——这是最核心的问题。如果只是"能查出更多癌症"但死亡率没变，那很可能是过度诊断
2. **"有权威指南推荐吗？"**——看是否有国家卫健委、权威学会的正式指南
3. **"我是它的目标人群吗？"**——年龄、性别、家族史、暴露史是否符合
4. **"机构在推销吗？"**——**警惕"体检套餐""免费筛查""一滴血查百病"**这类营销话术。正规筛查是针对特定人群、有明确间隔的，不会打包成豪华套餐卖给你

特别要警惕的：**"一滴血查出所有癌症"**、**"量子检测"**、**"全身热成像"**——目前没有任何一种单一检查能可靠地筛查所有癌症。

**关键要点**：判断筛查项目看能否降低死亡率、有无指南支持、自己是否属目标人群。

## 对话12：比筛查更重要的——预防

**患者**：那除了筛查，我自己能做什么？

**医生**：**筛查是"早发现"，预防才是"不发生"**。筛查再好也是亡羊补牢，真正能大幅降低癌症风险的是生活方式。

**明确有效的一级预防措施**：

1. **戒烟**——这是头号措施。吸烟与至少15种癌症相关，占所有癌症死亡的约25%
2. **接种疫苗**——乙肝疫苗（防肝癌）、HPV疫苗（防宫颈癌）
3. **根除幽门螺杆菌**——降低胃癌风险
4. **限酒**——酒精是明确的1类致癌物，与口腔癌、食管癌、肝癌、乳腺癌等相关。**没有"安全剂量"**，喝得越少越好
5. **控制体重**——肥胖与至少13种癌症风险升高相关
6. **规律运动**——每周150分钟中等强度运动，可降低多种癌症风险
7. **健康饮食**——多吃全谷物、蔬菜、水果、豆类；**限制红肉（<500g/周）和加工肉（香肠、培根、腊肉）**
8. **防晒**——紫外线是皮肤癌的主要环境因素
9. **避免职业和环境暴露**——石棉、苯、氡气等
10. **心情与睡眠**——长期慢性压力、睡眠紊乱会削弱免疫监视功能

**关键要点**：戒烟、疫苗接种、控体重、限酒、健康饮食是一级预防的核心措施。

**参考**：详见《癌症是怎么发生的》《饮食营养》《运动的科学》。

## 对话13：不同年龄怎么安排

**患者**：能不能给我一个简单的执行清单？

**医生**：给你一份按年龄段的实用清单（一般风险人群，高危人群需由医生个体化调整）：

**20-30岁**
- 女性：25岁起开始宫颈癌筛查（TCT，每3年）
- 接种HPV疫苗（越早越好，9-45岁均可）
- 乙肝表面抗原阴性者接种乙肝疫苗
- 学会乳腺自检，熟悉自己的身体

**30-40岁**
- 女性：继续宫颈筛查（30岁起可TCT+HPV联合，每3-5年）
- 有癌症家族史者：做遗传咨询评估
- 开始关注体重、戒烟限酒

**40-50岁**
- **40岁起**：高危人群做胃镜（幽门螺杆菌、萎缩性胃炎、家族史）
- **45岁起**：女性开始乳腺癌筛查（钼靶±超声，每1-2年）
- **45岁起**：做第一次肠镜（结果正常可5-10年后再查）
- **50岁起**：重度吸烟者开始低剂量肺部CT（每年）

**50岁以上**
- 继续上述项目
- 乙肝/丙肝携带者、肝硬化者：每6个月肝脏超声+AFP
- 有排尿症状的男性：与医生讨论PSA检查的利弊

**关键要点**：40岁起胃肠镜，45岁起乳腺与肠镜，50岁起高危者肺部CT，是几个关键节点。

## 对话14：常见误区汇总

**患者**：关于癌症筛查，最容易犯的错有哪些？

**医生**：我列一张表：

| 误区 | 真相 |
|------|------|
| 年年体检就不会得癌 | 普通体检对早期癌症发现能力弱，需专门筛查 |
| 肿瘤标志物升高＝得癌 | 炎症、吸烟等都会升高，不能用于筛查健康人 |
| 做了PET-CT就万事大吉 | 不适用于健康人筛查，辐射大且早期不敏感 |
| 筛查正常就永不患癌 | 只代表检查当时，仍需按间隔定期复查 |
| 筛查查出结节＝癌 | 肺结节95%以上不是癌，多数需随访观察 |
| 越贵的检查越好 | 适合的才是最好的，贵的常是过度检查 |
| 有症状才需要查 | 筛查的目的恰恰是在没症状时发现 |
| 年轻人不用查 | 有家族史者需提前，且预防应从年轻时开始 |
| 癌症会传染 | 癌症本身不传染，但乙肝、HPV、幽门螺杆菌会传染 |
| 筛查能预防所有癌症 | 筛查只针对少数癌种有效，生活方式预防覆盖面更广 |

**关键要点**：破除"肿瘤标志物筛查""PET-CT万能""年年体检就够了"三大误区。

---

## 对话15：建立正确的筛查观

**患者**：听下来感觉筛查挺复杂的，我该怎么把握？

**医生**：记住三句话就够了：

**第一，筛查是"瞄准"，不是"撒网"。** 选对你这个年龄、性别、风险状况该做的那几项，比做一大堆昂贵套餐有用得多。

**第二，筛查有价值，也有代价。** 它能救命，也可能带来假阳性焦虑和过度诊断。所以要在**医生指导下做**，而不是自己点菜式地买套餐。

**第三，筛查是第二道防线，生活方式才是第一道。** 再完美的筛查，也不如不吸烟、不肥胖、接种疫苗、健康饮食来得根本。

最后一点提醒：**如果你属于高危人群**（家族史、乙肝携带、长期吸烟、幽门螺杆菌感染），请务必主动告诉医生，让他为你制定个体化的筛查方案——这才是筛查真正的价值所在。

**关键要点**：选对人群、选对项目、医生指导、生活方式为先，是正确筛查观的四要素。

**参考**：详见《癌症是怎么发生的》《病毒性肝炎》《幽门螺杆菌》《肺结节》《女性健康》。

## 总结

**癌症筛查核心要点**：

1. 常规体检≠癌症筛查，筛查是针对特定癌种的专门检查
2. 公认有效的筛查：肺（低剂量CT）、乳腺（钼靶）、宫颈（HPV+TCT）、结直肠（肠镜）、胃（胃镜，高危）、肝（超声+AFP，高危）
3. **胸片查不出早期肺癌**，重度吸烟者应做低剂量CT
4. 胃肠镜能切除癌前息肉，是真正"预防癌症"的检查
5. **肿瘤标志物不能用于健康人筛查**
6. PET-CT、基因检测不适用于普通人群筛查，属过度检查
7. 筛查异常绝大多数不是癌，需专科判读并保留资料随访
8. 警惕过度诊断——查出惰性癌可能导致过度治疗
9. 一级预防（戒烟、疫苗、控体重、限酒）比筛查更根本
10. 高危人群应主动告知医生，制定个体化筛查方案

筛查的本质，是在疾病还很"温和"的时候遇见它。而最好的治疗，永远是让它没有机会发生。
