# 医学常识知识库

## 📖 关于本知识库

这是一个**面向普通读者**的医学常识知识库。每个话题都以"患者提问、医生解答"的对话形式展开，从你生活中真实遇到的困惑出发，一步步讲清生理机制、破除常见误区、给出可执行的应对方案。

**定位：让没有医学背景的人看得懂、用得上、记得住。**

**适合谁：**
- 想真正理解身体如何工作、疾病为何发生的普通读者
- 拿到体检报告看不懂、想搞清楚指标含义的人
- 家中有慢性病患者、老人、孩子，需要照护常识的人
- 被网络健康信息搞糊涂，想建立可靠判断框架的人

**核心理念：**
1. **不只告诉你"怎么做"，更要让你理解"为什么这样做"** —— 理解了机制，才算真的掌握。
2. **先讲人话，再讲术语** —— 每个专业名词第一次出现时都会用比喻解释一遍。
3. **明确划清"能自己处理"和"必须就医"的边界** —— 每篇文章都会用 ⚠️ 标出危险信号。
4. **不神化、不恐吓** —— 既不鼓吹"包治百病"的偏方，也不制造无谓的焦虑。

## 🚀 如何使用

### 三种阅读方式

**1. 系统学习（建立框架）**  
从基础概念开始，先理解身体的通用工作原理，再看具体疾病会轻松很多。  
推荐顺序：免疫系统 → 炎症反应 → 发烧的真相 → 其他基础概念 → 具体主题

**2. 问题导向（最常用）**  
遇到具体健康问题，直接查下面的**按症状查找**表或**按人群查找**表。

**3. 随机探索**  
浏览下方完整目录，挑感兴趣的话题阅读。

### 阅读建议

- ⏰ 每篇对话阅读时间：15-25 分钟
- 📝 建议做笔记，特别是每篇末尾的「总结」部分
- 🔗 文中出现的「**参考**：详见《XXX》」可直接跳转，形成知识网络
- ⚠️ 本知识库仅供科普，不能替代医疗建议（见文末重要提醒）

## 🚨 先看这里：哪些情况必须立刻就医

**以下情况不要查资料、不要等、不要自己开车，立即拨打 120（或当地急救电话）：**

| 表现 | 可能的问题 |
|------|-----------|
| 持续 >20 分钟不缓解的胸痛、压迫感，伴冷汗/恶心/濒死感 | 心肌梗死 |
| 一侧肢体无力/麻木、口角歪斜、说话不清、突然视物模糊 | 中风 |
| 突然倒地、无反应、无正常呼吸 | 心跳骤停（立即心肺复苏 + AED） |
| 呼吸困难、不能平卧、咳粉红色泡沫痰 | 急性心衰 / 肺水肿 |
| 大量咯血、呕血、黑便 | 消化道或呼吸道大出血 |
| 严重过敏反应：呼吸困难、喉头紧缩、全身风团、血压下降 | 过敏性休克 |
| 剧烈头痛"这辈子最痛"、伴颈项僵硬或意识改变 | 蛛网膜下腔出血 / 脑膜炎 |
| 高热伴意识模糊、抽搐、皮肤出血点 | 重症感染 / 脑膜炎 |
| 严重外伤、大出血、烧烫伤、中毒、溺水、异物卡喉 | 见《家庭意外处理》 |

**参考**：详见《心肺复苏与AED》《家庭意外处理》《心肌梗死》《中风预防》。

- 儿童、女性、老年人等特殊人群的健康要点
- 体检与癌症筛查的决策依据

**本知识库不覆盖、也不能替代：**
1. **诊断**：同样的症状可能来自完全不同的疾病，需要体格检查、化验和影像学才能判断。
2. **处方**：具体药物、剂量、疗程必须由医生根据个人情况（年龄、肝肾功能、合并用药、过敏史、妊娠状态等）决定。
3. **急诊处理**：急症抢救有严格的时间窗，任何延误都可能致命。
4. **个体化治疗决策**：手术、放化疗、靶向免疫等治疗方案的选择，需要专科医生综合评估。
5. **罕见病、复杂多病共存、重症监护**等高度专业化的领域。

**一句话边界：这里教你"如何更好地理解身体和配合医生"，不教你"给自己当医生"。**
