# 写在前面：这本教程怎么用

---

## 一、这门课，和这本教程，是什么关系

你手上（或电脑里）有一套视频课，叫《思考的原点——如何分析与判断问题》，一共十一讲，五个半小时左右。它讲的是这样一条线：

```
人为什么需要思考 → 平等 → 权利 → 权力 → 立场 → 道德 → 正义 → 逻辑与常识
```

这条线很好。它把一个人分析社会问题时真正用得上的那些"底层概念"，一层一层拆给你看。

但它有一个天然的局限：**视频是单向的。**

你坐在屏幕前，一个声音在讲，字幕在滚，你点头，觉得"说得对"。三天以后，你记得的只有一句"通往地狱的路是善意铺成的"——然后它就变成了一句可以随时挂在嘴边的漂亮话，而不是一种能真的用上的能力。

**本教程要解决的问题就是这个：把"听过"变成"会想"。**

所以这本书不是课程的文字稿，也不是课堂笔记。它把每一讲的核心概念，重新编排成一场**持续的、有来有回的对话**——你会看到有人提出和你一样的困惑，有人替你把那个"好像不太对但说不清哪里不对"的感觉说出口，也有人会反驳你、追问你、把你逼到墙角。

> **你在阅读中会被反复打断。**
>
> 读到某处，会出现一个"**停一下**"。请真的停下来。
>
> 不要急着往下翻，不要想着"反正后面有参考答案"。把你的答案先在脑子里（最好是在纸上）写下来，再去对照。
>
> 这个动作，是这本教程唯一真正重要的东西。跳过它，你就只是又看了一遍别人的想法。

## 二、出场人物

为了让你有代入感，我把这些对话放在一个小教室里。人物不多，但各有各的"思维惯性"——你可以看看自己最像谁。

| 人物 | 身份 | 思维特点 | 他代表的那部分你 |
|------|------|----------|------------------|
| **林知远** | 讲课的老师，五十多岁，教了二十年书 | 不直接给答案，习惯反问。常说的一句话是"你先说说，你说的这个词是什么意思？" | 你心里那个较真的声音 |
| **杨帆** | 大二，理工科，直率，爱抬杠 | 反应快，逻辑不错，但容易把复杂问题简化成"这不就是……吗" | 那个想快速下结论的你 |
| **周雨** | 大三，文科，敏感，爱追问意义 | 感受力强，能察觉到不对劲，但常常"说不清为什么" | 那个隐约觉得哪里不对的你 |
| **老陈** | 教室旁听者，在学校门口开了家小超市 | 没读过多少书，但四十多年的人情世故，常有朴素的洞见 | 常识那部分的你 |

他们四个凑在一起，正好凑齐了思考需要的四种东西：**概念、逻辑、感受、常识**。

少了任何一个，思考都会偏。

## 三、这门课到底在教你什么

先说清楚一件事：**这不是一门知识课。**

你不会从中学到多少"事实"——不会有年份、不会有公式、不会有需要背诵的清单。合上这本书，你的知识储备可能只增加了百分之三。

但它想改的是另一件事：**你处理信息的方式。**

具体来说，是这四件事：

### 1. 把词拆开的能力

我们日常使用的词，大多是一团糨糊。

"这不公平""我有权利""这是为了大家好""这不符合常识"——每句话里的关键词，说话的人自己往往都没想清楚。

这门课做的第一件事，就是把这些词一一拆开：

- "平等"至少有三种意思，它们之间互相打架
- "权利"和"权力"是两回事，虽然读音一样
- "公平"和"平等"不是同义词，甚至经常是反义词
- "善良"和"正义"是两把不同的尺子，量出来的结果经常相反

**拆不开词的人，想不清楚事。**

### 2. 看到硬币背面的能力

任何一个主张，都有它隐含的代价。

"应该给每个人一样的资源"——代价是什么？
"应该惩罚所有坏人"——代价是什么？
"为了安全，可以牺牲一点方便"——代价是什么？

这门课会反复带你做一件事：**当一个人提出一个听起来很对的方案时，去问"然后呢"。**

### 3. 区分"事实"和"判断"的能力

这是全书最硬核、也最实用的部分。

"今天气温38度"是事实。
"今天热死了"是判断。

绝大多数争吵，都源于把判断当成了事实。绝大多数被带节奏，都源于别人把判断包装成了事实。

### 4. 怀疑自己的能力

最后这一点最难。

前三点都是对着外面的，这一点是对着自己的。**你能想到的第一个解释，通常是错的——或者至少是不完整的。**

人是"先下结论，再找证据"的动物。我们以为自己在推理，其实大部分时间在给已经形成的直觉找理由。

这门课的目标，不是让你不再有直觉，而是**让你在直觉出现的时候，能听见一声轻轻的"等等"。**

## 四、每一讲的结构

为了让你的阅读有节奏感，每一讲都按同样的结构展开：

```
┌─────────────────────────────────────┐
│  本讲一句话 —— 这一讲想让你带走什么      │
├─────────────────────────────────────┤
│  开场场景 —— 一个你可能遇到过的生活情境   │
├─────────────────────────────────────┤
│  对话正文 —— 围绕这个概念一层层追问      │
│      ↳ 内含若干「停一下」提问           │
├─────────────────────────────────────┤
│  深一层 —— 更尖锐、更不舒服的追问        │
├─────────────────────────────────────┤
│  生活思考题 —— 5 道题，附参考答案        │
├─────────────────────────────────────┤
│  本讲思维工具 —— 一张可以保存的卡片      │
├─────────────────────────────────────┤
│  一句话带走 —— 明天就能用上的一句话      │
└─────────────────────────────────────┘
```

**关于"参考答案"的说明：**

参考答案不是标准答案。

每题的参考答案，我都会给出**两到三种不同的思路**，并标明每种思路背后的假设。因为这门课的目的不是让你记住某个结论，而是让你看见：**同一个问题，可以有几种站得住脚的看法，而它们之间的分歧，往往源于对某个词的理解不同，或者对某种价值的排序不同。**

看懂了这一点，你就不会再急着问"谁对谁错"，而是会问："**他们的分歧到底在哪一层？**"

## 五、建议的使用方式

### 方式 A：配合视频（推荐，约 6 周）

| 周次 | 内容 |
|------|------|
| 第 1 周 | 先看第 1-2 讲视频，再读第 01、02 章 |
| 第 2 周 | 看第 3-5 讲视频，读第 03、04、05 章 |
| 第 3 周 | 看第 6-7 讲视频，读第 06、07 章 |
| 第 4 周 | 看第 8-9 讲视频，读第 08、09 章 |
| 第 5 周 | 看第 10-11 讲视频，读第 10、11 章 |
| 第 6 周 | 读第 12 章 + 附录，重做你第一次没答上来的题 |

**每周花的时间：** 视频约 30 分钟，阅读与思考约 90 分钟。

**关键动作：** 每读完一章，在生活里找一个例子，用这一章的工具分析它。写在纸上，哪怕只有三行。

### 方式 B：直接读这本教程（约 4 周）

视频是可选的。本教程在内容上是自足的，每一讲的概念都讲透了。

如果你时间紧，优先读：**第 02 讲（平等与公平）、第 04 讲（自由的边界）、第 10、11 讲（事实与判断）**。这四讲是最能立刻用上的。

### 方式 C：当成"抬杠训练手册"

如果你只是想要一个东西来磨脑子，就直接翻到每一讲的"**深一层**"和"**生活思考题**"部分。

先答，再对照。答不上来的地方，就是你思维的盲区。

## 六、几条规矩

在开始之前，我们先约法三章。这几条不是形式主义，它们决定了你能从这本书里拿走多少。

### 规矩一：不要急着同意

读到你觉得"说得太对了"的地方，反而要警惕。

人最容易在认同的时候停止思考。当你猛点头的时候，问自己一句：**"如果我要反驳这句话，我会怎么说？"**

### 规矩二：不要急着反对

读到你觉得"这不对"的地方，先别合上书。

问自己：**"我想反驳的，是他真正说的那句话，还是我心里的一个简化版本？"**

这个动作叫" steelman"（把对方的论点加固后再反驳）。如果你能把一个观点说得比它的提出者还好，你才有资格说它错。

### 规矩三：所有的"对错"，先回到"定义"

吵"该不该做"之前，先吵"这个词是什么意思"。

你会发现，日常生活中九成的争论，其实都是定义之争。一旦把定义说清楚，争论往往就消失了——或者变成了真正的分歧，而真正的分歧是值得尊重的。

### 规矩四：允许自己"现在还没有结论"

这是最难的一条。

我们从小被训练成"每道题都有答案"。但生活里真正重要的问题，大多没有标准答案。

**能够心安理得地说"我现在还不知道"，是一种高级能力。** 它比"我知道"要难得多，也可靠得多。

## 七、一个提醒

最后，说一个这本书里不会明讲、但你需要知道的事。

这门课（以及这本教程）所使用的一套概念——平等、权利、自由、正义、逻辑——主要来自近代以来的思想传统，它是一套**特定的分析工具**，不是唯一的一套。

工具好用，不等于工具是唯一的。

所以在读到某些地方，如果你隐约觉得"好像还缺了点什么"——比如觉得它太强调个人而忽略了群体，太强调规则而忽略了人情，太强调程序而忽略了结果——**请相信这个感觉。**

那不是你没听懂。那是你在用另一套（也许是更贴近我们自身传统的）框架在对照。

**真正会思考的人，脑子里同时装着好几套互相打架的框架，并且能在它们之间来回切换。**

这本书的目的，是让你先拥有一套清晰的。其他的，你自己会长出来。
