## 本讲一句话

**平等是"给的一样多"，公平是"给的该给的那份"。它们经常是反义词。而个体的权利，就是用来回答"凭什么是他该得的"那个东西。**

## 开场：两碗牛肉面

老陈的超市隔壁有家牛肉面馆，老板娘姓孙。这天中午，杨帆、周雨、老陈三个人进去吃面。

杨帆点了一碗，端上来，肉很多。周雨点了一碗，肉明显少。

**杨帆：** （把自己碗里的肉夹了两块给周雨）给你。

**周雨：** 不用不用，我吃不了那么多……

**杨帆：** 拿着吧，这不公平，一样的钱。

**老陈：** （在旁边笑）小杨，你这个动作好，但你这句话说错了。

**杨帆：** 哪儿错了？一样的钱，肉不一样多，这还不叫不公平？

**老陈：** 我问你，要是周雨今天胃口小，她自己跟老板娘说"少给我点肉"，那还是不公平吗？

**杨帆：** ……那当然是她自己要求的。

**老陈：** 那我问你第二个问题。要是周雨是老板娘的闺女呢？

**杨帆：** 那……那更不公平了啊！

**老陈：** 哈，你看。**同一件事——肉多肉少——你一会儿说公平，一会儿说不公平，你的尺子到底是什么？**

杨帆愣住了。

林知远从旁边那桌站起来，端着面碗坐了过来。

"老陈，你这几问，比我要讲的一整节课都狠。"

## 一、平等和公平，不是一回事

**林知远：** 杨帆，刚才老陈问你的其实是：**"公平"这个词的判定标准，到底在"结果"上，还是在"过程"上？**

我们先把两个词摆在一起：

```
┌────────────────────────────────────────────┐
│                                            │
│   平等（Equality）                          │
│   ├─ 关键词：一样                           │
│   ├─ 看的是：结果 / 分配量                   │
│   └─ 判据：是不是每个人都拿到了同样多？       │
│                                            │
│   公平（Fairness / Equity）                 │
│   ├─ 关键词：应得                           │
│   ├─ 看的是：过程 / 依据                     │
│   └─ 判据：每个人拿到的是不是他"该拿的"？     │
│                                            │
└────────────────────────────────────────────┘
```

**周雨：** 所以……如果两个人贡献不一样，公平的做法反而是**不给他们一样多**？

**林知远：** 对。**公平经常要求不平等。**

我们来看一张很经典的图：

```
   平等（给的一样）              公平（给的该给的）

   ┌───┐         ┌───┐        ┌───┐         ┌───┐
   │   │         │   │        │   │         │   │
   │   │  ┌───┐  │   │        │   │  ┌───┐  │   │
   │   │  │   │  │   │        │   │  │   │  │   │
   ├─┬─┤  ├─┬─┤  ├─┬─┤        ├─┬─┤  ├─┬─┤  ├─┬─┤
   │█│ │  │█│ │  │█│ │        │ │ │  │█│ │  │██│
   └─┴─┘  └─┴─┘  └─┴─┘        └─┴─┘  └─┴─┘  └─┴─┘
   矮   中   高                矮    中    高
  （三个人看球赛，都给一样高的箱子）

   → 矮个子还是看不见          → 三个人都能看见
   → 结果是"平等"              → 结果是"公平"
```

**杨帆：** 这不就是"按需分配"吗？

**林知远：** 接近了，但还差一层。我们马上就讲差在哪儿。

先记住一个反直觉的结论：

> **追求平等，往往会制造不公平。**
> **追求公平，往往会制造不平等。**

**这俩不是一回事，而且经常打架。**

## 二、公平的四个面：一张脸还是四张脸？

**周雨：** 林老师，那"该得的"又怎么定？谁来定？

**林知远：** 这就是"公平"最难的地方——它不是一把尺子，它是**四把**。

```
╔══════════════════════════════════════════════════════╗
║                                                      ║
║   公平的四张面孔                                       ║
║                                                      ║
║   ① 分配公平  →  按什么分？                            ║
║       · 按贡献（多劳多得）                             ║
║       · 按需要（谁更需要给谁）                          ║
║       · 按人头（一人一份）                             ║
║                                                      ║
║   ② 程序公平  →  规则怎么定、怎么执行？                 ║
║       · 规则事先说明了吗？                             ║
║       · 对所有人都一样吗？                             ║
║       · 有申诉的渠道吗？                               ║
║                                                      ║
║   ③ 互动公平  →  执行的时候，人被尊重了吗？              ║
║       · 拒绝的时候，解释了吗？                          ║
║       · 语气是不是让人难堪？                           ║
║                                                      ║
║   ④ 补偿公平  →  过去的亏欠，补不补？                   ║
║       · 历史上的伤害要不要还？                          ║
║       · 起点低的要不要补？                             ║
║                                                      ║
╚══════════════════════════════════════════════════════╝
```

**杨帆：** 四种？那到底用哪一种？

**林知远：** **这取决于你在分什么东西。**

这是个关键洞察，请你记下来：

> **不同的东西，适用不同的公平原则。用错了原则，好人也会办坏事。**

我们来做个练习。下面这些东西，你觉得该按什么分？

| 要分的东西 | 按贡献？ | 按需要？ | 按人头？ |
|-----------|:--------:|:--------:|:--------:|
| 公司奖金 | ✅ | | |
| 救灾物资 | | ✅ | |
| 选举投票权 | | | ✅ |
| 小组作业的成绩 | ? | ? | ? |
| 家庭遗产 | ? | ? | ? |
| 急诊床位 | ? | ? | ? |

**周雨：** 小组作业的成绩……我觉得应该按贡献。可是贡献怎么算呢？

**杨帆：** 这就是我们组上次吵架的原因！

## 三、小组作业：一场微型社会实验

**杨帆：** 我们组四个人做一门课的期末项目。我写了八成的代码，做了 PPT，还上去讲。另外三个人，一个找了点资料，一个啥也没干，还有一个快交了才出现，说"我最近太忙了"。

最后老师给分，全组一个分——A。

**我气死了。凭什么？**

**林知远：** 我们先不谈"你该不该气"。我们来拆一下这件事里，**有多少种公平在同时起作用**。

**第一种：分配公平。**
按贡献分，你应该拿 A，那个人应该拿 C 或者 F。
**→ 你是对的。**

**第二种：程序公平。**
问题是：**规则是谁定的？** 老师在开课的时候说"小组一个分"了吗？
- 如果说了 → 你入学时接受了这个规则，现在抱怨，是事后不认账。
- 如果没说 → 规则是模糊的，你有权质疑。

**杨帆：** ……说了。大纲上写着"小组作业统一给分"。

**林知远：** 好。**那你的愤怒其实不是"分配不公平"，而是"规则本身定得不好"。**

这两件事，处理方式完全不同：
- 前者找组员吵。
- 后者找老师改规则（或者下次选课避开这个老师）。

**第三种：互动公平。**
那两个人有没有承认你的付出？有没有说一句"辛苦了，这次主要靠你"？

**杨帆：** （沉默一会儿）……没有。他们连这个都没说。

**林知远：** **你看，让你真正难受的，可能不是那个 A，而是这三个字。**

**这是一个极其重要的发现：**

> **人在遭遇"不公平"时，最强烈的痛苦往往不是来自"分到的少了"，而是来自"我的付出没有被看见"。**

**老陈：** 这个我懂。

我超市去年夏天招了个暑假工，小伙子挺卖力，搬货理货什么都干。月底我给他结账，按说好的给。他数完钱，站在那儿不动。

我问他：怎么，少了？

他说：没少。就是……没事了。

后来我媳妇跟我说：**"你该在给钱的时候说一句'这个暑假多亏你了'。"**

我当时还觉得矫情。后来我想明白了——**钱是按劳分配的，那句话是按人分配的。**

**少了那句话，他就只是个劳动力。**

**林知远：** 老陈，你刚才这句话，值这一讲的一半分数。

## 四、个体的权利：什么叫"这是我的"？

**周雨：** 林老师，我有个问题。刚才我们一直在说"该得的""应得的"——

**凭什么是他该得的？**

比如杨帆说他写了八成代码，所以该拿 A。可是……"你付出了所以你应该得到回报"，这个"应该"，是从哪儿来的？

**林知远：** （放下筷子）

周雨，你问到了这一讲的地基。

这个"应该"，来自一个词：**权利**。

我们先做一个最朴素的区分：

```
┌─────────────────────────────────────────────┐
│                                             │
│   利益（Interest）                            │
│   →  "我想要""对我有好处"                      │
│   →  可以被权衡、可以被牺牲                     │
│   →  例：我想涨工资、我想住大房子               │
│                                             │
│   权利（Right）                               │
│   →  "这是我的，别人不能随便拿走"                │
│   →  不可随意权衡，有边界                       │
│   →  例：我的工资不能被拖欠、我的房子不能被强拆   │
│                                             │
└─────────────────────────────────────────────┘
```

**杨帆：** 那这两者的区别是什么？不都是"我想要"吗？

**林知远：** 区别在这里：

> **利益可以被"更大的好处"压过去。权利不行——或者说，权利需要特别强的理由才能被压过去。**

举个例子：

- "我想在图书馆占个位子"——这是**利益**。如果有人更需要（比如要考试了），让出去无妨。
- "我存在图书馆柜子里的电脑"——这是**权利**（财产权）。别人不能因为"他更需要"就拿走。

**周雨：** 那……权利是从哪儿来的？谁规定的？

**林知远：** 四种说法，我把它们都摆出来，你自己挑：

```
① 天赋说  → 人天生就有，不是谁给的
   问题：那为什么历史上很多人没有？

② 法律说  → 法律规定你有，你才有
   问题：那法律要是可以随便改，权利还稳吗？

③ 契约说  → 大家商量出来的，为了互相约束
   问题：没参与商量的人（比如未来的人）怎么办？

④ 功能说  → 保护它，社会整体更好
   问题：那当它不利于整体时，就可以扔掉？
```

**杨帆：** 这四种……好像都有道理，又都不完整。

**林知远：** 对。**它们不是互斥的，而是从四个不同角度描述同一件事。**

就像描述一头大象：
- 摸到腿的说"像柱子"
- 摸到耳朵的说"像扇子"
- 摸到尾巴的说"像绳子"

**权利就是这样一头大象。** 它有自然法的根基（天赋说），需要实定法的确认（法律说），依赖于社会共识（契约说），并且最终要能自证其价值（功能说）。

## 五、权利的边界：你的权利止于我的鼻尖

**周雨：** 那这样的话，权利是不是越多越好？

**林知远：** 不是。因为——**权利是会撞车的。**

我们来玩一个游戏。我说一些权利，你告诉我，它们什么时候会打架：

**权利 A：言论自由。**
**权利 B：不受诽谤的权利。**

**杨帆：** ……这俩一碰到就打。你说我坏话，是言论自由；但我可以要求你别造谣。

**林知远：** 对。再来：

**权利 C：财产权（我的房子我做主）。**
**权利 D：邻居不受噪音干扰的权利。**

**周雨：** 我在家打游戏到半夜……哦。

**林知远：** 再来一个更狠的：

**权利 E：父母的监护权（决定孩子怎么养）。**
**权利 F：孩子的受教育权。**

**杨帆：** 这个……家长不让孩子上学，"在家自己教"，算谁的？

**林知远：** 这个问题的答案，在不同国家是不一样的。但它说明了一件事：

> **权利不是"我的地盘我做主"，权利是一张网，每个人的权利都在别人的权利那里停下。**

这句话有个经典的说法，叫：

> **"你的自由止于我的鼻尖。"**

**老陈：** 这个我有个事。

我超市有个老主顾，姓吴，七十多了，一个人住。他有个儿子在外地，一年回来一次。

老吴有个习惯：**每次来买东西，都要跟我唠半小时。** 从我孙子学习唠到国际形势，什么都唠。

问题是——**他一来，别的顾客就排在他后头等着。**

有一回一个年轻人急了，说："大爷您能不能快点，我赶时间。"

老吴愣在那儿，脸涨得通红，放下东西就走了。

那天晚上我一宿没睡好。

**林知远：** 后来呢？

**老陈：** 后来我给他儿子打了个电话。我说，你爸不是来买东西的，他是来找人说话的。

他儿子沉默了半天，说：我知道。

现在他每个星期天晚上给他爸打视频，四十分钟。

**老吴现在来我这儿，买完东西就走。** 走得挺快。

**林知远：** （沉默了一下）

老陈，你这个故事里有三种权利：

- 老吴的：**与人交谈、不被羞辱的权利**
- 年轻人的：**不被无谓耽搁的权利**
- 老陈你的：**经营自己的店、决定怎么待客的权利**

你没有用"规则"去解决（比如"每人限购三分钟"），而是**去解决了产生冲突的那个根源**。

**这是最高级的公平：不是在分配端扯皮，而是在源头端消除稀缺。**

## 深一层

### 追问 1：公平感是天生的吗？

有一个著名的实验，叫"最后通牒博弈"：

> 实验者给 A 一百块钱，让 A 分给 B。B 可以接受或拒绝。
> 如果 B 接受，两人按 A 的方案分。
> **如果 B 拒绝，两个人都拿不到钱。**

按"理性人"假设，A 应该给 B 最少的一块钱，B 应该接受（一块钱总比没有强）。

**但真实结果不是这样。**

在几乎所有被测试的文化里：
- A 平均会分给 B **40%-50%**
- 如果 A 分给 B 少于 **20%**，B 有 **一半以上的概率会拒绝**

**也就是说：人们宁愿自己一分钱也拿不到，也要惩罚那个"分得不公平"的人。**

**这说明什么？**

公平感**不是后天教化出来的**，它是写在人脑里的。甚至有研究发现，猴子也会因为同伴拿到了更好的报酬而愤怒地扔掉自己手里的黄瓜。

**但——** 关键的"但"来了：

虽然"公平感"是天生的，但**"什么算公平"却是文化塑造的**。

同样是分一百块：
- 有的文化里，平均分配最公平
- 有的文化里，年长者多拿是公平的
- 有的文化里，今天运气好的人多拿是公平的

**所以：公平的本能是普遍的，公平的标准是局部的。**

**这就是为什么，跨文化交流中的冲突，往往不是"谁不讲理"，而是"我们在用不同的理"。**

### 追问 2：程序公平能救分配不公吗？

假设你们班只有一个保研名额，给了班长。你觉得不公平。

现在告诉你：**这个名额的评定流程是公开的、有明确标准的、有三轮公示的、有异议可以申诉。**

你的感受会变吗？

心理学研究发现：**会变，但没有你以为的那么大。**

- **程序公平会显著降低不满**——即使结果不利，人们也更愿意接受。
- **但它不能消除不满**——如果结果差距太大，再漂亮的程序也压不住。

**这引出一个现实中的常见错误：**

很多管理者以为"只要流程合规，结果再离谱大家也能接受"。

**这是错的。** 程序公平是一个**减压阀**，不是一个**免死金牌**。

> **程序公平的上限，是让人"认了"，不是让人"服了"。**

### 追问 3：补偿公平——欠的债，该由谁还？

这是最棘手的一张面孔。

假设：某家公司四十年前曾经拒绝录用某一群体的人。现在这批人已经六十岁了，他们的子女三十岁。

**问题：今天的公司，应不应该给这些子女优待，作为对历史的补偿？**

- **支持方**：历史伤害有代际传递，当年被排斥的人，他们的孩子起点本来就低。不补偿，不平等就会自我复制。
- **反对方**：今天的年轻人没有伤害过任何人，凭什么让他们承担代价？而且"补偿"会制造新的怨恨。
- **第三方案**：不按身份补偿，按处境补偿——帮助所有低收入家庭的孩子，不管他们属于哪个群体。

**请你在心里给这三种立场排个序，然后问自己：你排序的依据是什么？**

## 生活思考题

### 思考题 1

> 你家有两套房。你妈说："房子都留给你弟弟，你是姐姐，嫁出去了。"
> 你说："这不公平。"
> 你妈说："公平？我生他的时候大出血差点没命，我供你读书花了二十万，怎么不公平？"
>
> **请用本讲的"四种公平"框架，分析你妈这句话里混了哪几种逻辑。**

<details>
<summary><b>参考答案</b></summary>

你妈妈的一句话里，至少混了**三种公平**，外加一个逻辑陷阱。

**① 分配公平中的"按需分配"**
> "房子都留给你弟弟"
她隐含的逻辑是：弟弟更需要（要结婚、要买房）。这是**按需要**分配。

**② 补偿公平**
> "我生他的时候大出血差点没命"
这是**补偿逻辑**：我为他付出过代价，所以他该多得。

**③ 分配公平中的"按贡献/投资"**
> "我供你读书花了二十万"
这是**投资—回报逻辑**：我已经在你身上花过了，所以剩下的给他。

---

**现在来看这套逻辑的问题在哪：**

**问题一：三种标准混用，哪个有利用哪个。**
前面用"需要"，后面用"投资"。如果要一致，就应该：
- 要么都按投资：你花了二十万在我身上，花在他身上多少？你算过吗？
- 要么都按需要：如果按需要，那要看的是**谁更需要**，而不是性别和长幼。

**问题二："嫁出去了"是一个已经失效的前提。**
这个说法来自一个时代：女儿出嫁后，赡养义务归夫家，也不继承娘家财产。
**但在今天，女儿同样承担赡养义务。** 权利义务对等，就不能只让女儿尽义务、不让女儿享权利。

**问题三（最关键）：这件事真正的冲突点，可能不在"公平"。**
妈妈说的三句话，最后都指向一件事：**她怕你不照顾她。**
她在用"财产分配"来处理"情感安全感"的问题——因为这是我们家唯一会认真谈的"大事"。

---

**所以，实操建议（这是一道分析题，也是一道生活题）：**

**第一步：先处理情绪，再处理财产。**
如果直接反驳她的公平逻辑，她会觉得"养你白养了"。
先说：**"妈，你担心我不养你，是吗？"** 把真正的议题放到桌面上。

**第二步：把赡养义务和财产继承分开谈。**
明确表态：无论房子怎么分，我都会尽赡养义务。
**这一步做完，谈判空间就出来了。**

**第三步：用"一致的标准"来谈分配。**
不要吵"给谁多"，而是问："我们的分配标准是什么？"
- 如果按需要 → 谁的经济条件更差？
- 如果按贡献 → 谁照顾你们更多？
- 如果按人头 → 那就一人一套，或者卖了对半分。

**只要标准定了，且对两个孩子一视同仁，结果通常不会太离谱。**

**延伸思考：** 中国家庭里大量的财产纠纷，根源都在于——**父母把"分配"当成了表达偏爱的工具，而不是在解决一个分配问题。**
</details>

### 思考题 2

> 你是老师，要设计小组作业的评分规则，杜绝"搭便车"。
> 要求：可操作，且不能助长互相举报。

<details>
<summary><b>参考答案</b></summary>

**先说什么是坏方案：**

❌ **组内互评打分**——这是最常见的"看起来好"的方案。
问题：它会把学生变成互相监督的敌人，而且催生"报复性打分"。更糟的是，它会把"合作学习"变成"表演学习"——大家忙着留痕、抢功，而不是真的一起做事。

❌ **按字数/行数分配**——鼓励灌水。

---

**好方案应当满足三条：**
1. **贡献可见**（老师能看见谁做了什么）
2. **责任到人**（每个人都有一块无法被别人代劳的工作）
3. **不制造零和博弈**（我加分不需要你减分）

---

**方案 A：角色轮换 + 独立交付物**

把项目切成四块，每人认领一块，**每块都要有自己独立署名的一份交付物**：
- 调研报告（A 署名）
- 数据分析（B 署名）
- 演示文稿（C 署名）
- 代码实现（D 署名）

最后总分 = 小组成绩 × 70% + 个人交付物成绩 × 30%

**优点：** 每个人有一块跑不掉。
**代价：** 老师工作量增加；有些项目不好切分。

---

**方案 B：答辩追问法（最推荐）**

小组统一给基础分，但**每个人单独答辩三分钟**，老师随机追问细节：
- "这个图表为什么用对数坐标？"
- "这段代码第三十七行是干什么的？"
- "这个结论的样本量是多少？"

**搭便车的人，答不上来。**

**优点：**
- 极度可操作，成本极低（一人三分钟）
- 不需要学生互相举报（老师自己判断）
- 倒逼每个人都真的参与

**代价：**
- 对不善表达的学生不友好（可以允许"指认某处代码并解释"）
- 需要老师真的懂内容

---

**方案 C：过程留痕 + 里程碑**

设置三个中期检查点，每个检查点**每个人都要交一段一页纸的"我这周做了什么、卡在哪、下周做什么"**。

**优点：** 过程可见，问题早发现。
**代价：** 增加师生双方的事务负担。

---

**这道题的深层洞察：**

所有"反搭便车"的制度，本质上都在做同一件事——

> **把"看不见的贡献"变成"看得见的"。**

搭便车之所以猖獗，是因为**在"一个小组一个分"的体制下，贡献是不可见的**。

**所以别去惩罚搭便车的人，去让贡献变得可见。** 前者治标，后者治本。
</details>

### 思考题 3

> 图书馆里，对面的人小声打电话。你提醒，他说："我又没大声，图书馆又没写不许打电话。"
>
> 给出至少两条思路，并说明代价。

<details>
<summary><b>参考答案</b></summary>

先分析他的话：

- **"我没大声"** → 这是**事实判断**，可以测量（分贝）。
- **"图书馆没写不许打"** → 这其实**是对的**。很多图书馆的规定只写"保持安静"，没写"禁止通话"。

**所以他在事实上可能站得住。但你要解决的不是"他对不对"，而是"你还要不要看书"。**

---

**思路一：规则路径 —— 找管理员**

请管理员来提醒。

- **优点：** 最干净，不用你自己开口，权力来源正当。
- **代价：** 可能找不到人；管理员可能不管；对方被公开提醒后可能恼羞成怒，反而更大声。
- **适用：** 对方看起来讲道理，只是没意识到。

---

**思路二：事实路径 —— 把判断变成事实**

不说"你吵到我了"，而说：

> **"同学，我戴的降噪耳机开着，还能听见你的声音。你可以到外面打吗？"**

**这句话的妙处：**
- 它描述的是一个**可验证的事实**（我开着降噪还能听见）
- 它没有评价对方（没说"你没素质"）
- 它给出了具体的、低成本的**行动建议**（到外面打）

- **代价：** 对方可能直接拒绝。
- **适用：** 大多数情况。这是**首选**。

---

**思路三：退出路径 —— 换座位**

- **优点：** 零冲突，立刻生效。
- **代价：** 你可能要搬很多东西，而且好位置没了。**而且——如果每次都你退让，公共空间的规则就永远建立不起来。**

---

**思路四：反向路径 —— 让他意识到**

轻轻把你的椅子挪一下，把自己的书翻得响一点，用行动提示。

- **优点：** 不撕破脸。
- **代价：** 幼稚，而且大概率无效。

---

**这道题的核心洞察：**

**所有"公共空间的冲突"，本质都是同一件事——**

> **公共资源（安静）是稀缺的，而"谁有权使用它"的边界是模糊的。**

解决这类冲突，最有效的方式不是争论"谁对"，而是：

1. **把评价换成事实**（"你吵"→"我开着降噪还能听见"）
2. **把对抗换成请求**（"你不能"→"你可以到外面吗"）
3. **把私人冲突转成第三方介入**（找管理员）

**记住一条：在公共空间里，"我是对的"从来不是目的，"我能继续看书"才是。**
</details>

### 思考题 4

> 你们公司要裁员 10%。老板说："为了公平，我们按绩效打分，末位淘汰。"
>
> 你是 HR，你发现：**绩效打分在实际操作中，会系统性地对某些岗位不利**（比如后台支持岗、长期项目岗）。
>
> **你会怎么跟老板说？**

<details>
<summary><b>参考答案</b></summary>

**第一步：先承认老板的出发点是对的。**

"按绩效"确实是比"按关系""按资历"更公平的裁员标准。**不要一上来就否定他的原则。**

---

**第二步：指出"绩效打分"这个词里藏着两个不同的东西。**

> **绩效 = 做了什么（产出） × 有多容易被看见（可见度）**

- 销售岗：每个月有数字，**产出可见**。
- 后台支持岗：价值在于"没出事"，**产出不可见**。你没法给"今年没有数据事故"打分。
- 长期项目岗：今年可能一分钱收入都没有，但三年后会是公司的护城河。

**如果按统一标准打分，会发生什么？**

> **你会系统性地裁掉那些"产出不可见"和"回报在远期"的人。**

**这是一个已知的、反复发生的错误。** 它的名字叫"**用可测量性代替重要性**"。

---

**第三步：给方案，而不是只提问题。**

给老板三个选项，让他选：

**方案 A：分赛道评分**
把岗位分成销售、技术、支持、研发四条赛道，**每条赛道内部排名，按比例分配裁员名额**。
- 代价：跨赛道比较时会扯皮。

**方案 B：增加"不可替代性"维度**
绩效打分只占 70%，另外 30% 由**这个岗位的上下游同事**评价"如果他走了，谁受影响最大"。
- 代价：可能变成人缘投票。

**方案 C：用"未来需要什么"代替"过去谁做得好"**
不问"谁最差"，而是问：**"如果未来两年只做三件事，我们需要哪些能力？"** 然后按能力缺口反推。
- 这是最难但最正确的方案。
- 代价：需要老板真的想清楚了战略，而这往往是他没有的。

---

**这道题的深层点（这是最重要的部分）：**

**"按绩效末位淘汰"听起来是最客观、最公平的规则。但它有一个致命的隐含假设——**

> **它假设所有人的工作，都能被放在同一把尺子上量。**

**这个假设在绝大多数组织里是不成立的。**

**所以，当你听到"我们按客观标准来"的时候，要多问一句：**

> **"这个标准，对谁特别有利，对谁特别不利？"**

**每一个"客观标准"，都是某个人在某个时刻，按某种偏好设计出来的。** 它不中立，只是它的偏向被藏在"客观"两个字后面了。
</details>

### 思考题 5（综合题 · 难）

> 医院急诊科，同时来了两位病人，只剩一张床：
>
> - **病人甲**：28 岁，车祸重伤，抢救后存活率 60%。没有基础病。
> - **病人乙**：65 岁，心梗，抢救后存活率 40%。有糖尿病史。
>
> **如果你是分诊护士，这张床给谁？**
>
> 然后请回答：**你用的原则，能应用到其他场景吗？如果不能，区别在哪里？**

<details>
<summary><b>参考答案</b></summary>

**先说结论：在实际的急诊分诊体系里，这张床大概率给——谁都不给。**

因为在医学上，真正决定资源分配的不是"存活率"，而是**"紧急程度 × 可救治性"**。如果两位都是危重，医院会启动应急预案（调用其他科室床位、转院、加床），而不是二选一。

**这个"跳出二选一"的意识，本身就是一种重要的思维能力。**

**但为了训练，我们假设真的只能二选一。**

---

**四种可能的原则：**

**原则一：救最可能活下来的（甲）**
- 依据：**效用最大化**。同样的资源，救活的概率更高。
- 反对：这会让"本来就弱的"永远排在最后。按这个逻辑，老年人、慢性病患者永远不该被救。

**原则二：救最紧急的（看谁先恶化）**
- 依据：**需要优先**。
- 反对：如果一个人已经救不回来了，把资源投给他是浪费。

**原则三：救年轻的（甲）**
- 依据：**生命年数最大化**。他还有五十年，乙可能只有十五年。
- 反对：这是明确的**年龄歧视**。而且——凭什么老人剩下的十五年就不值钱？

**原则四：先来后到（谁先送进来）**
- 依据：**程序公平**。不判断生命价值，用最简单、最难被操纵的标准。
- 反对：结果上可能救了不该救的，没救该救的。
- **但注意：这是现实中很多体系的兜底原则，因为它避免了"由某个人来评判谁的生命更有价值"这个可怕的权力。**

---

**这道题真正的价值在这里：**

> **你会发现，每一种原则都能被推翻。**
>
> **这不是因为你不够聪明，而是因为这个问题本来就没有"干净"的答案。**

它揭示了一个残酷的事实：

> **当资源真正稀缺的时候，"公平"是不可能的。我们能做的，只是选择"用哪一种不公平"。**

---

**现在回答第二问：这个原则能推广吗？**

**不能。区别在这里：**

急诊这件事有两个特殊性：

1. **不可逆性**——救错了不能重来。
2. **时间压力**——没有时间讨论。

**所以在这种场景下，"程序公平"（先到先得、抽签）的权重会被刻意提高**——不是因为它结果最好，而是因为它**不需要有人承担"决定谁去死"的道德重负**。

**而在可以慢慢讨论、可以补偿、可以调整的场景里（比如评职称、分奖金），我们就应该用更复杂、更精细的原则。**

---

**结论（这一条请记住）：**

> **一个制度的成熟程度，不看它在理想情况下多完美，而看它在资源最紧张、时间最紧迫、压力最大的时候，还能不能站得住。**

**越是极端场景，程序公平越重要。**
</details>
