## 本讲一句话

**逻辑管的是"推理对不对"，常识管的是"结论像不像真的"。逻辑能保你不犯错，常识能保你不荒谬——而很多人只练了其中一样，于是要么严谨地错，要么正确地胡说。**

## 开场：一张"完美"的图表

老陈的侄子在一家公司做运营。去年，他做了一张图发给老陈看。

```
   我们的产品用户增长  vs  竞争对手

   ╭─────────────────────────────────╮
   │                              ╱   │
   │                          ╱       │
   │                      ╱           │
   │                  ╱               │
   │              ╱                   │
   │          ╱                       │
   │      ╱                           │
   │  ╱                               │
   ╰─────────────────────────────────╯
```

**侄子：** 叔，你看，我们涨得比对手快多了。

**老陈：** （看了半天）这图……底下没数字啊。

**侄子：** 数字不重要，看趋势！

**老陈：** 那我问你，你们一个月涨多少，他们一个月涨多少？

**侄子：** 我们涨了一千，他们涨了八百。

**老陈：** 那你们原来有多少用户？

**侄子：** ……我们三千，他们三十万。

**老陈：** 那就是说：**他们涨八百，是三十万零八百；你们涨一千，是四千。**

**侄子：** ……对。

**老陈：** 那这个图，是谁画的？

**侄子：** ……我画的。

**林知远：** （在旁边听着）

老陈，你刚才做的这件事，就是这一讲的核心。

**你用了一样东西：常识。**

**你的侄子用了另一样东西：看起来很像逻辑的东西。**

**我们来把这两件事掰开讲。**

## 一、逻辑谬误图鉴：十种你每天都会遇到的套路

**林知远：** 逻辑谬误的种类有几十种，我挑**十种最常见的**。

**它们分四组：**

```
   第一组：攻击人，而不是攻击论点（3 种）
   第二组：制造假的两难（2 种）
   第三组：证据不够就下结论（3 种）
   第四组：偷换概念与循环（2 种）
```

---

### 第一组：不攻击论点，攻击人

#### 谬误 1：人身攻击（Ad Hominem）

```
   结构：  他这个人是 X  →  所以他的观点不成立

   例子：
   ❌ "他连大学都没毕业，他懂什么？"
   ❌ "你自己都没孩子，凭什么谈教育？"
   ❌ "你上次不也迟到了吗？有什么资格说我？"
```

**为什么它是错的？**

> **一个人的品格、身份、过往，跟"他这句话对不对"，是两件事。**

- 一个坏人可以说一句真话
- 一个外行可以说一个对的观察
- **你自己做不到，不代表你说的不对**

**⚠️ 但要小心一种例外：**

当一个论点**依赖于**说话人的专业能力时，质疑专业能力是合理的。

```
   ❌ "他没当过老师，所以他的教学方法不可行"
      → 这是人身攻击（教学方法可不可行，可以验证）

   ✅ "他声称这个药有效，但他没有任何医学背景，
       而且没有提供任何临床数据"
      → 这不是人身攻击，这是在质疑【证据来源】
```

**区别在哪？**

> **看这个质疑，是针对"人"，还是针对"他的证据"。**

---

#### 谬误 2：稻草人（Straw Man）

```
   结构：  把对方的观点【夸大/扭曲】成一个更容易打倒的版本
           然后打倒它，宣称自己赢了

   例子：
   A: "我觉得应该给学生更多自主安排的时间。"
   B: "你的意思是完全不管学生，放任自流吗？"
      （B 把"更多自主"扭曲成了"完全放任"）

   A: "我觉得这个方案成本有点高。"
   B: "所以你的意思是我们什么都别做了？"
```

**这个谬误为什么这么常见？**

> **因为打倒一个"稻草人"，比打倒真实的论点，容易太多了。**

**怎么识别？**

> **听对方复述你的话的时候，问自己：**
>
> **"他说的是我说的那个意思吗？"**
>
> **如果不是 —— 立刻纠正，不要在他的版本上辩论。**

**标准回应：**

> "那不是我的意思。我说的是 X，不是 Y。
> 如果你要反驳我的观点，请反驳 X。"

---

#### 谬误 3：你也一样（Tu Quoque）

```
   结构：  "你自己也做过，所以你没资格说我"

   例子：
   ❌ 父："你不该抽烟。"
      子："你抽了四十年，凭什么说我？"

   ❌ "你批评公司加班，可你自己上周不也加到十点？"
```

**为什么它是错的？**

> **"谁在说"和"说得对不对"，是两件事。**

- 抽烟的父亲说"抽烟有害"，这句话依然是对的
- 一个偶尔加班的人批评加班文化，这个批评依然可以成立

**⚠️ 但——它有一个"合理内核"：**

```
   如果一个人在批评别人的时候，自己也在做同样的事，
   那么他确实存在"虚伪"的问题。

   但"虚伪"削弱的是【他的说服力】，
   不是【他的论点的正确性】。
```

**所以成熟的回应是：**

> "你说得对，我自己也做过，这是我的问题。
> **但这不影响'这件事本身对不对'这个问题。**
> 我们回到这件事本身吧。"

**——这一句，能从"互相揭短"里，把讨论拉回正轨。**

### 第二组：制造假的两难

#### 谬误 4：虚假两难（False Dilemma）

```
   结构：  把复杂的选项，简化成"只有 A 和 B"
           而实际上还有 C、D、E

   例子：
   ❌ "你要么支持我，要么就是反对我。"
   ❌ "不转不是中国人。"
   ❌ "你要么考研，要么就只能去送外卖。"
   ❌ "公司要么裁员，要么倒闭。"
```

**这是第 06 讲讲的"跳出框架"的反面。**

**识别方法（一个极其实用的问题）：**

> **"除了这两个，还有第三种可能吗？"**
>
> **——如果答案是"有"，那这就是虚假两难。**

**破解话术：**

> "我不认为只有这两个选项。我觉得还有第三种：……"

---

#### 谬误 5：滑坡谬误（Slippery Slope）

```
   结构：  如果允许 A，就会必然导致 B，
           B 必然导致 C，C 必然导致灾难 Z
           →  所以绝不能允许 A

   例子：
   ❌ "今天你允许他迟到十分钟，明天他就敢迟到一小时，
       后天他就敢不来上班。这个团队就完了。"

   ❌ "如果允许未成年人玩游戏，他们就会上瘾，
       上瘾就会荒废学业，荒废学业就会犯罪，
       所以必须全面禁止。"
```

**这个谬误的厉害之处在于：它的每一步，都"有一点道理"。**

**但问题在于：它把"可能"说成了"必然"。**

**破解方法（三问）：**

```
   ① 从 A 到 B，是必然的吗？概率多大？
   ② 每一环之间，有没有"刹车"？
      （比如：他迟到一小时，就会被谈话，所以不会到"不来上班"）
   ③ 如果真到了 Z，中间有多少次可以干预的机会？
```

**一个有用的对照：**

```
   合理的担忧：  "A 可能增加 B 的风险，所以我们需要 X 来防范"
   滑坡谬误：    "A 必然导致 Z，所以绝对不能 A"
```

### 第三组：证据不够就下结论

#### 谬误 6：以偏概全（Hasty Generalization）

```
   结构：  从少量/非典型的样本，推出普遍结论

   例子：
   ❌ "我遇到的三个销售都很油，所以干销售的都这样。"
   ❌ "我朋友吃了这个药好了，所以这个药有效。"
   ❌ "你们 90 后都吃不了苦。"
```

**第 10 讲讲的"幸存者偏差"，其实是以偏概全的一种特殊形式。**

**破解三问：**

```
   ① 样本有多大？（三个够吗？）
   ② 样本有代表性吗？（你遇到的，是随机的吗？）
   ③ 有没有反例？有多少？
```

**⚠️ 特别注意"我朋友/我亲戚"这类证据：**

> **个例（anecdote）在科学上的证据等级，是最低的。**
>
> **但它对人的说服力，却是最高的。**
>
> **——因为个例有面孔、有故事、有情绪。**
>
> **这就是它危险的原因。**

---

#### 谬误 7：相关当因果

```
   结构：  A 和 B 同时发生 / A 之后发生了 B
           →  所以 A 导致了 B

   例子：
   ❌ "冰淇淋销量上升的时候，溺水人数也上升，
       所以吃冰淇淋会导致溺水。"
      （真因：夏天）

   ❌ "成功人士都早起，所以早起能让人成功。"

   ❌ "这个地区的人喝咖啡多，寿命也长，
       所以喝咖啡延年益寿。"
      （可能是：这个地区更富裕）
```

**这是所有谬误里，危害最大的一个。**

**因为它看起来特别像"数据分析"。**

**破解：问出"第三变量"**

```
   A 和 B 相关，有五种可能：

   ① A 导致 B
   ② B 导致 A          （反过来）
   ③ C 导致 A，也导致 B（第三变量）
   ④ A 和 B 互为因果
   ⑤ 纯属巧合
```

**举个具体的：**

| 观察到的相关 | 可能的第三变量 |
|-------------|---------------|
| 喝咖啡多的人寿命长 | 收入水平、医疗条件 |
| 家里书多的孩子成绩好 | 父母的受教育程度 |
| 常去医院的人死亡率高 | 他们本来就有病 |
| 团队加班多的季度业绩好 | 业务旺季导致两者 |

**⚠️ 还有一个变体，叫"事后归因"：**

> **"我吃了这个药，第二天就好了，所以是药的作用。"**

**问题：很多病不吃药也会好。**（医学上叫"自限性疾病"）

**这就是为什么需要"对照组"。**

---

#### 谬误 8：诉诸无知 / 转移举证责任

```
   结构：  "你证明不了它是假的，所以它就是真的"
           或者："你证明不了 A，所以 B 是对的"

   例子：
   ❌ "你说没有鬼，你能证明吗？证明不了吧，那就是有。"
   ❌ "你说我这个方案有问题，那你拿个更好的出来啊！"
```

**这是第 07 讲讲过的"举证责任倒置"的逻辑版本。**

**原则（请记住）：**

> **谁提出主张，谁举证。**
>
> **"我怀疑"不需要举证，"我断定"才需要。**

**破解话术：**

> "我不需要证明它不存在。
> **提出它存在的人是你，所以举证的是你。**"

### 第四组：偷换与循环

#### 谬误 9：偷换概念

```
   结构：  在同一个论证中，一个词的【含义悄悄变了】

   例子：
   ❌ "人都是自私的（描述），所以自私是对的（规范）。"
      → "是"和"应该"之间，有一个巨大的跳跃

   ❌ "他说他很自由，可是他还要上班，哪里自由了？"
      → "自由"从"权利状态"被换成了"随心所欲"

   ❌ "这是为了大家好（good for all），
       所以每个人都应该同意（ought to agree）。"
```

**这种谬误最难识别，因为它不发生在一句话里，而是发生在两句话之间。**

**破解方法：**

> **把论证里的关键词，全部换成同一个定义，再看它还成立吗。**

---

#### 谬误 10：循环论证

```
   结构：  结论已经包含在前提里

   例子：
   ❌ "他是个好人，因为他做的事都是好事。"
      → "好人"和"做好事"是同一个意思

   ❌ "这个药有效，因为它能治病。"
   ❌ "圣经是真理，因为圣经上说它是真理。"
```

**识别方法：**

> **把前提和结论调换位置，看是不是依然"成立"。**
>
> **如果是 —— 那就是循环论证，因为它在原地打转。**

## 二、演绎与归纳：两种"讲道理"的方式

**林知远：** 讲完了"什么错"，我们来讲"什么对"。

**人类的推理，只有两种基本形式。**

```
╔══════════════════════════════════════════════════════════╗
║                                                          ║
║   演绎推理（Deduction）                                    ║
║   —— 从一般到特殊                                          ║
║                                                          ║
║   结构：  大前提 + 小前提 → 结论                           ║
║                                                          ║
║   例子：  所有人都会死。（大前提）                          ║
║           苏格拉底是人。（小前提）                          ║
║           ∴苏格拉底会死。（结论）                          ║
║                                                          ║
║   特点：  如果前提真、形式对，结论【必然】真                ║
║   弱点：  它不产生新知识（结论已包含在前提里）              ║
║   检查点：**前提对吗？**                                   ║
║                                                          ║
╠══════════════════════════════════════════════════════════╣
║                                                          ║
║   归纳推理（Induction）                                    ║
║   —— 从特殊到一般                                          ║
║                                                          ║
║   结构：  观察许多个例 → 推出普遍规律                      ║
║                                                          ║
║   例子：  我见过的天鹅都是白的。                            ║
║           ∴天鹅都是白的。                                  ║
║           （然后有人在澳洲发现了黑天鹅）                    ║
║                                                          ║
║   特点：  结论【可能】真，但不必然                          ║
║   优点：  它产生新知识                                     ║
║   弱点：  永远可以被一个反例推翻                            ║
║   检查点：**样本够吗？有代表性吗？**                        ║
║                                                          ║
╚══════════════════════════════════════════════════════════╝
```

**周雨：** 那……哪个更好？

**林知远：** **都要。** 但检查的地方不一样：

> **听到演绎，去查【前提】。**
> **听到归纳，去查【样本】。**

**这是一个极其实用的检查规则。我给你们演示一下：**

---

**例一：演绎**

> "这个人不靠谱，所以这件事交给他一定会出问题。"

**这是演绎。它的完整形式是：**

> 大前提：**不靠谱的人，做事一定会出问题。**
> 小前提：这个人不靠谱。
> 结论：这件事交给他会出问题。

**检查点在哪？在大前提。**

> **"不靠谱的人，做事一定会出问题"——这是真的吗？**

不靠谱的人，在**他擅长的事、他重视的事**上，未必会出问题。

**——所以这个推理的问题不在逻辑，在大前提夸大了。**

---

**例二：归纳**

> "我们公司去年招的五个应届生，三个干不满一年就走了。所以现在的大学生不稳定。"

**这是归纳。检查点在样本：**

```
   ① 样本多大？  五个。够吗？不够。
   ② 有代表性吗？这五个是随机招的，还是某个渠道来的？
   ③ 有没有反例？公司里那些干了三年以上的应届生，怎么算？
   ④ 有没有别的解释？
      → 是不是公司的入职培训有问题？
      → 是不是这个岗位本身的问题？
```

**——你检查的不是"结论对不对"，而是"样本够不够撑起这个结论"。**

## 三、常识：那个被低估的能力

**林知远：** 现在我们来讲本讲的另一个主角：**常识**。

**周雨：** 常识……不就是"大家都知道的事"吗？

**林知远：** 差不多，但我要给它一个更精确的定义：

> **常识 = 一套关于"世界通常如何运作"的、被反复验证过的、粗略但可靠的预期。**

它有三个特点：

```
   ① 它是"粗略"的      →  不精确，但数量级正确
   ② 它是"背景性"的    →  平时不察觉，违反了才注意到
   ③ 它是"可检验"的    →  违反常识的事，不是不可能，
                          但需要【特别强的证据】
```

**第三点极其重要。请记住这句话：**

> **"违反常识"不等于"是假的"。**
>
> **但它意味着：举证的标准，要大幅提高。**

这就是为什么：
- "我发明了永动机" → 需要极强证据
- "我发现了一种能治百病的草" → 需要极强证据
- **"我有一个稳赚不赔、月收益 20% 的项目"** → 需要极强证据

**——这些说法违反的不是法律，是常识。**

---

### 常识的三个检验法

**林知远：** 常识怎么用？我给你三个具体的检验动作。

```
╔══════════════════════════════════════════════════════════╗
║                                                          ║
║   常识检验 ①：数量级检验                                  ║
║                                                          ║
║   "这个数字，在数量级上说得通吗？"                         ║
║                                                          ║
║   例子：                                                  ║
║   "我们这个项目，一年能赚一个亿。"                         ║
║    →  你们团队 5 人，客单价 100 元                        ║
║    →  一个亿 = 100 万单 = 每人每年 20 万单                ║
║    →  = 每人每天 550 单                                   ║
║    →  **数量级不对劲**                                    ║
║                                                          ║
╠══════════════════════════════════════════════════════════╣
║                                                          ║
║   常识检验 ②：极端检验（归谬法）                           ║
║                                                          ║
║   "把这个逻辑推到极端，还成立吗？"                         ║
║                                                          ║
║   例子：                                                  ║
║   "加班越多，产出越高。"                                   ║
║    →  推到极端：每天工作 20 小时，产出最高？               ║
║    →  显然不成立                                          ║
║    →  **所以原命题是"在一定范围内成立"，不是绝对真理**     ║
║                                                          ║
╠══════════════════════════════════════════════════════════╣
║                                                          ║
║   常识检验 ③：反向检验（换位）                             ║
║                                                          ║
║   "如果这件事是真的，那还应该能观察到什么？                ║
║    那些东西，我看到了吗？"                                 ║
║                                                          ║
║   例子：                                                  ║
║   "这个理财产品，稳赚，月息 5%。"                          ║
║    →  如果它真这么好，为什么轮得到我？                     ║
║    →  为什么银行不抢着买？                                 ║
║    →  为什么创始人要到处拉散户？                           ║
║    →  **这些"应该能看到但看不到"的东西，就是破绽**         ║
║                                                          ║
╚══════════════════════════════════════════════════════════╝
```

**老陈：** 第三个检验，我天天用。

有个人来我这儿推销，说有个"扶贫项目"，投一万，三个月返一万五。

我问他：**"你这么好的事，你为什么不去贷款一百万投进去？"**

他说：名额有限。

我说：**"那你怎么不给你自己家人留着？"**

他就不说话了。

**林知远：** 老陈，你这个问法，是最优雅的常识检验。

> **"如果它这么好，为什么轮得到我？"**
>
> **——这一问，能挡掉 95% 的骗局。**

**因为一个真正的好机会，通常不需要被推销。**

---

### 常识从哪里来？

**周雨：** 林老师，那常识……怎么获得？

**林知远：** 这是一个好问题，而且答案不太舒服。

**常识不能靠"学"获得，它只能靠"积累"获得。**

```
   常识的三个来源：

   ① 经历
      你自己做过、错过、吃过亏的事
      → 这是最扎实的，也是最慢的

   ② 观察
      看别人做过什么、结果如何
      → 这是"间接经验"，成本低很多

   ③ 跨领域的"数量级直觉"
      知道一件事"大概多大""一般多快""通常多少"
      → 这需要你有意识地积累一些"基准数字"
```

**第三点我特别想强调。**

**我建议你们有意识地记一些"基准数字"，它们会成为你的常识骨架：**

| 领域 | 一些有用的基准 |
|------|---------------|
| 人口 | 中国约 14 亿；一线城市 2000 万级 |
| 时间 | 人一生约 3 万天；工作年限约 40 年 |
| 金钱 | 一线城市平均月薪量级；一套房的总价与年租金比 |
| 商业 | 小超市毛利率 15-25%；餐饮净利率 5-10% |
| 生理 | 人一天需要 7-8 小时睡眠；步行速度 5km/h |
| 规模 | 一所大学 2-5 万人；一家小公司 10-50 人 |

**这些数字不需要精确到个位，只需要"数量级正确"。**

> **而一旦你有了这些"锚"，**
> **你就能立刻听出："这个数字不对劲。"**

**这就是老陈能看出那张图表有问题的原因：**

> **他知道"用户基数"这个数字，是判断增长的关键。**
>
> **——不是因为他学过统计学，**
> **而是因为他做过生意。**

## 四、逻辑与常识打架的时候怎么办？

**杨帆：** 林老师，那如果……逻辑上说得通，但常识上觉得不对，怎么办？

**林知远：** 这个问题太好了。

**我的答案是：这时候， usually（通常）是前提出了问题。**

**为什么？因为：**

```
   逻辑：  保证"从前提到结论"的过程没错
   常识：  检验"结论是否符合世界的样子"

   如果过程没错，但结论很荒谬
   →  那么问题几乎一定出在【前提】
```

**我给你们一个经典的例子：**

> 前提一：**一粒沙子不构成一堆。**
> 前提二：**如果 n 粒沙子不构成一堆，那么 n+1 粒也不构成一堆。**
> 结论：**无论多少粒沙子，都不构成一堆。**

**这个推理，逻辑上完全正确。**

**但结论显然荒谬。**

**问题出在哪？**

> **出在"堆"这个词是模糊的。**
>
> **它没有一个明确的界限，所以前提二在边界处失效。**

**这在哲学上叫"连锁悖论"（Sorites Paradox）。**

**它教给我们一件极其重要的事：**

> **当你用逻辑推出一个荒谬的结论时，**
> **不要急着接受这个结论，**
> **也不要急着否定逻辑——**
>
> **去检查你的前提，特别是那些"看起来理所当然"的前提。**

## 深一层

### 追问 1：为什么聪明人也会相信明显荒谬的东西？

这是一个让人不安的问题。

**观察一下：很多高智商的人，会相信非常离谱的说法。**

为什么？

**因为"智商"和"理性"是两件事。**

```
   智商（IQ）：  处理复杂问题的能力
   理性（Rationality）：  避免错误判断的倾向
```

研究显示，这两者的相关性**远低于人们的想象**。

**原因：高智商的人，有一个特殊的"劣势"：**

> **他们更擅长"为自己已经相信的东西，编造合理的解释"。**

- 普通人想不出理由，所以会犹豫
- **聪明人能想出十个理由，所以更确信**

**这叫"智力作为辩护律师"：**

> **智商越高，你的"辩护律师"越强。**
>
> **而一个强的辩护律师，能让你相信任何你已经决定相信的事。**

**破解方法（唯一有效的那个）：**

> **在你开始"找理由"之前，先问一句：**
>
> **"如果我错了，会怎样？"**
>
> **——把辩护律师，换成法官。**

### 追问 2：你能分清"我不理解"和"这是错的"吗？

这是一个极其实用的自我检查。

**当你遇到一个你觉得很荒谬的说法时，请问自己：**

> **"它是真的荒谬，还是我听不懂？"**

**这两者经常被混淆，代价很大：**

- 把"我不懂"当成"它错了" → **你会错过真正重要的东西**
- 把"它错了"当成"我不懂" → **你会被忽悠**

**一个简单的判断原则：**

```
   如果这个说法来自一个【有专业积累、有声誉成本】的人/机构
   →  先假设"我可能没懂"，去弄懂它

   如果它来自一个【没有专业背景、却在讲专业问题】的人
   →  "它错了"的概率大幅上升
```

> **——在判断"对不对"之前，先判断"说话的人，有没有为这句话付过学费"。**

### 追问 3：你自己的"常识"，可能是过时了吗？

这是最狠的一问。

**常识是"被反复验证过的预期"。但世界在变。**

一些曾经是常识的东西：

- "铁饭碗最保险" → 1998 年下岗
- "房价只会涨" → ？
- "上大学就能找到好工作" → ？
- "学一门手艺饿不死" → ？

> **常识最大的风险，是它更新得太慢。**
>
> **因为它是你十几二十年的经验积累，**
> **而它的更新，需要你主动去"打脸"自己。**

**怎么更新？三个动作：**

1. **定期接触跟你不一样的人**（不同行业、不同年龄、不同背景）
2. **专门关注"反例"**（那些违反你常识的成功案例）
3. **每年挑一个自己深信不疑的观点，认真地去试图推翻它**

> **第三条最难，也最值钱。**
>
> **——能推翻自己的常识，是一种高级能力。**

## 生活思考题

### 思考题 1

> 指出下列六句话的谬误类型：
>
> 1. "你要是不支持这个方案，就是跟公司作对。"
> 2. "我爷爷抽了一辈子烟，活到九十五。"
> 3. "你说这个政策不好，那你有什么更好的办法？"
> 4. "现在的小孩玩手机，将来这代人就完了。"
> 5. "你一个学文科的，懂什么数据？"
> 6. "我们成功了，因为我们团队很优秀；我们团队优秀，是因为我们成功了。"

<details>
<summary><b>参考答案</b></summary>

**逐条分析：**

---

**1. "你要是不支持这个方案，就是跟公司作对。"**

→ **虚假两难（False Dilemma）**

它把"支持 / 反对"偷换成了"支持 / 跟公司作对"。

**实际上的选项至少有三种：**
- 支持
- **有保留地支持（原则同意，但认为需要修改 X）**
- 反对这个方案，但提出替代方案
- **弃权（不了解，不表态）**

**破解话术：**

> "我反对这个方案，不等于我反对公司。
> **我反对的是方案里的第三条。**"

**——把"立场"拆成"具体条款"，虚假两难就不成立了。**

---

**2. "我爷爷抽了一辈子烟，活到九十五。"**

→ **以偏概全（Hasty Generalization）+ 幸存者偏差**

**这是两个谬误叠加：**

- **以偏概全**：一个样本推不出普遍结论
- **幸存者偏差**：你爷爷是"返航的飞机"——那些因吸烟早逝的人，不能来跟你说话

**破解：**

> "我奶奶也抽了一辈子烟，六十三岁走的。
> **我们俩的爷爷和奶奶，加起来是两个样本，还是推不出结论。**
> 我们还是得看统计数据。"

**⚠️ 但要注意一个常见的"过度反击"：**

**不要用"你这是幸存者偏差"来嘲笑对方。**

因为说这句话的人，通常不是在讨论统计学，他是在**为一个他爱的人辩护**。

> **——先承认"你爷爷确实长寿，这很幸运"，**
> **——再把话题从"个例"转到"概率"。**

---

**3. "你说这个政策不好，那你有什么更好的办法？"**

→ **转移举证责任（Burden of Proof）**

**这个谬误非常常见，而且很有杀伤力，因为它听起来很"讲理"。**

**问题在哪？**

```
   评价一个方案  ≠  提出一个更好的方案
```

- 一个病人可以指出"这个手术风险太高"，而不需要自己会做手术
- 一个食客可以说"这道菜太咸"，而不需要自己会做菜

**破解话术：**

> "我指出问题，不需要同时提供解决方案。
> **当然，如果我能想到更好的，我也会说。**
> **但'我想不到'这件事，不能证明'它没问题'。**"

**⚠️ 但——我要加一个重要补充：**

**在现实中，光提问题确实不够。**

> **在组织里，一个只提问题不提方案的人，**
> **即使逻辑全对，也会被边缘化。**
>
> **——因为逻辑管的是"对不对"，**
> **——而做事管的是"怎么办"。**

**所以最优解是：**

> "我认为这个方案在 X 上有问题。
> 我暂时没有完整的替代方案，
> **但我建议我们先做一次小规模测试，看看 X 是不是真的会发生。**"

**——这一句，既守住了逻辑，又给出了下一步。**

---

**4. "现在的小孩玩手机，将来这代人就完了。"**

→ **滑坡谬误（Slippery Slope）**

**它的链条是：**

```
   玩手机 → 上瘾 → 荒废学业 → 没有能力 → 这代人完了
```

**每一步都"有可能"，但没有一步是"必然"。**

**破解（三问）：**

```
   ① 从"玩手机"到"上瘾"，概率多大？（不是 100%）
   ② 中间有没有"刹车"？
      → 学校管、家长管、考试压力、同伴竞争……
   ③ 历史上有没有类似的"预言"？
      → 电视出现时，有人说"这代人完了"
      → 小说流行时，有人说"这代人完了"
      → 网络出现时，也有人说"这代人完了"
```

**最后一条最有力，它叫"历史对照法"：**

> **每一代人，都担心下一代被新技术毁掉。**
>
> **而到目前为止，这个预言，一次都没有成真。**

---

**5. "你一个学文科的，懂什么数据？"**

→ **人身攻击（Ad Hominem）**

**攻击的是身份，不是论点。**

**⚠️ 但这里有一个微妙的地方：**

**如果讨论的主题，确实需要统计学的专业训练，那么"你是不是学过"是相关的。**

**怎么区分？**

```
   攻击人：  "你是文科生，所以你说的一定错。"
             → 谬误

   质疑能力： "这个结论需要控制变量，
               你的分析里没有对照组。
               **这个分析方法，是你自己做的吗？**"
             → 合理（针对的是方法，不是身份）
```

**破解话术（优雅版）：**

> "我是文科生，这没错。
> **那我们别谈我的专业，谈这个数据本身——**
> **我的哪一步算错了？请你指出来。**"

**——这一招叫"把讨论拉回到议题本身"。**

---

**6. "我们成功了，因为我们团队很优秀；我们团队优秀，是因为我们成功了。"**

→ **循环论证（Circular Reasoning）**

**这是一个典型案例，因为它的循环非常明显：**

```
   A（优秀）→ B（成功）→ A（优秀）
```

**它什么都没证明。**

**但——我要指出一个更重要的东西：**

**在现实中，这种循环比它看起来要隐蔽得多，也常见得多。**

**看看这些例子：**

- "他有钱，因为他有能力；他有能力，你看，他有钱。"
  → **循环。而且它掩盖了运气、出身、时代等因素。**

- "这个公司是好公司，因为它的产品卖得好；它的产品卖得好，因为它是好公司。"
  → **循环。它掩盖了渠道、时机、竞争等。**

- "我这么想是因为我一直这么想。"
  → **循环。**（这一句，你我都说过）

**破解方法（把循环打断）：**

> **找一个"独立于 A 和 B 的第三个证据"。**

```
   ❌ "他有能力，因为他成功了"

   ✅ "他有能力，因为——
       · 他独立解决过 X 问题
       · 同行对他的评价是 Y
       · 他在没有资源的条件下做过 Z"
```

> **——这三个证据，都不依赖于"他成功"这个事实。**
>
> **所以它们才是真证据。**
</details>

### 思考题 2

> 你朋友给你看一个"投资项目"：
>
> "投入 10 万，每月返 2000，**随时可以退出，本金全额退还**。"
> "公司有实体产业，做新能源的，很稳。"
>
> **请用本讲的"常识三检验"分析它。**

<details>
<summary><b>参考答案</b></summary>

**我们先不谈"这是不是骗局"（虽然它高度疑似）。**

**我们用三个检验，来看看它"说得通吗"。**

---

### 检验一：数量级检验

**月返 2000 / 本金 10 万 = 月息 2%**

**年化是多少？**

```
   单利：  2% × 12 = 24%
   复利：  (1.02)^12 - 1 = 26.8%
```

**现在，请对照一下"常识基准"：**

| 投资品种 | 年化收益（大致） |
|---------|----------------|
| 银行定期 | 1.5% - 2.5% |
| 国债 | 2% - 3% |
| 银行理财（R2） | 2.5% - 4% |
| 股票指数长期 | 7% - 10%（且波动巨大） |
| 顶级对冲基金长期 | 15% - 20%（且门槛极高） |
| **这个项目** | **24% - 27%** |

**结论：它的承诺收益，高于股神巴菲特的长期年化（约 20%），**
**而且——它是"每月返、随时退、本金保"。**

**这三个条件同时成立，在数量级上是不合理的。**

---

### 检验二：极端检验（归谬法）

**把这个模式推到极端：**

**如果这个项目真的能稳定产生 26% 的年化收益，那么：**

```
   第 1 年：  10 万 → 12.6 万
   第 5 年：  10 万 → 32 万
   第 10 年： 10 万 → 100 万
   第 20 年： 10 万 → 1000 万
```

**那么请问：**

> **为什么这家公司需要你的 10 万块？**

**它完全可以：**
- 向银行贷款（年息 4-6%）
- 发债券（年息 5-8%）
- 引入机构投资

**——用 6% 的成本，赚 26% 的收益，它为什么不这么做？**

**唯一的解释是：它借不到钱。**

**为什么借不到？** 因为银行和机构做过尽调，认为风险太高。

> **——银行都不敢借的钱，凭什么你敢投？**

---

### 检验三：反向检验（如果它是真的，还应该看到什么？）

**如果这是一个真实的、可持续的商业模式，那么我们还应该看到：**

```
   ✅ 公开的、可查的工商信息和财务报告
   ✅ 真实的产业（工厂、设备、客户）
   ✅ 金融监管的备案或牌照
   ✅ 银行、审计机构、律师事务所的参与
   ✅ 其他投资者的长期口碑

   ❌ 而不需要：
       · 靠朋友介绍
       · 强调"名额有限"
       · 用"高返利"吸引
       · 说不清楚钱投到哪
```

**现在，请你对照一下，你看到了几项？**

---

### 三个检验之后：关键的"常识三问"

**如果这三检验都指向"不对劲"，那么请再问最后三句：**

**① "如果它这么好，为什么轮得到我？"**
> 好机会不需要被推销。

**② "我看不到我的钱去了哪里，这意味着什么？"**
> 无法追踪的钱，通常就是消失了。

**③ "最坏的情况是什么？我能承受吗？"**
> 不是问"会不会亏"，而是问"如果全没了，我的生活会不会垮"。

**——第三问是唯一真正重要的那一问。**

> **投资的常识第一条，不是"怎么赚"，是"能亏多少"。**

---

### 那你要怎么跟朋友说？

**⚠️ 这是我真正想讲的部分。**

**如果你直接说"这是骗局"，会发生什么？**

- 他会防御（"你不了解"）
- **而且他可能已经投了钱——那么承认是骗局，等于承认自己蠢**
- 他会疏远你

**这就是"反诈"最难的地方：**

> **受害者的最后一道心理防线，不是"骗子太狡猾"，**
> **而是"我不能承认我上当了"。**

**所以，正确的做法（三步）：**

**第一步：不要说"这是骗局"，说"我们一起看看"**

> "这个我不太懂，我们一起查一下？"

**——"一起"这个词，把你们放在了同一边。**

**第二步：不要攻击他的判断力，去查"事实"**

- 一起去查工商信息
- 一起算一算那个年化
- **一起去问一句："钱具体投到哪个项目？能去看看吗？"**

**第三步：如果他已经投了，帮他设计"退出路径"**

> "要不你先退一部分出来试试？就说你有急用，
> **看看他们是不是真的'随时可以退出'。**"

**——这一招极其有效。**

**因为"随时退出"这个承诺，一旦被测试，骗局就会原形毕露。**

> **而他自己发现"退不出来"的时候，**
> **比你说一万句"这是骗局"都管用。**
>
> **——人只能被自己说服。**
</details>

### 思考题 3

> 你的部门今年业绩很好。年底总结会上，领导说：
>
> **"今年业绩好，证明我们'狼性文化'是对的。明年我们要更狼性，目标翻倍。"**
>
> **请用本讲的工具，分析这句话里可能存在的问题。**

<details>
<summary><b>参考答案</b></summary>

**这是一道"相关当因果"的典型题，而且它叠加了另外两个谬误。**

**我们一层一层剥。**

---

### 第一层：相关当因果（核心问题）

**领导的推理是：**

```
   我们推行了"狼性文化"  →  今年业绩好
   ∴  是"狼性文化"导致了业绩好
```

**这个推理，跳过了所有其他可能的解释。**

**请列出"今年业绩好"的【其他可能原因】：**

```
   ① 大环境/行业周期（今年整个行业都在涨？）
   ② 前任/前期铺垫（今年的单子，是去年谈下来的？）
   ③ 运气（一个大客户主动找上门？）
   ④ 竞争格局变化（主要对手出问题了？）
   ⑤ 产品/技术突破（研发那边做了什么？）
   ⑥ 基数效应（去年太差，所以今年的"好"是相对？）
   ⑦ 团队本身的努力（不一定是"狼性"，可能只是更专业了）
   ⑧ **"狼性文化"可能贡献了一部分，但不是全部，甚至不是主要部分**
```

**——至少八种解释，跟"狼性文化导致业绩好"这个结论相容。**

**怎么检验？问三句：**

```
   ① 推行狼性文化【之前】，增长率是多少？
      推行【之后】，增长率是多少？
      → 如果之前也是 20%，之后也是 20%，那"狼性"没起作用

   ② 同行业、同期、没搞狼性文化的公司，增长多少？
      → 如果他们涨得更多，那"狼性"可能是负作用

   ③ 业绩增长，主要来自哪几个客户/哪几个单子？
      → 如果它就来自一个大单，那跟"文化"关系不大
```

---

### 第二层：幸存者偏差（隐藏更深）

**请想一个问题：**

> **"狼性文化"推行之后，那些【受不了而离开的人】，在哪里？**

**他们不会出现在年终总结会上。**

**——你看到的，是"留下来且业绩好的人"。**
**——你看不到的，是"因为受不了而走掉的人"，以及"留下了但身心出问题的人"。**

**这就是幸存者偏差：**

> **"狼性文化有效"这个结论，统计的是"活下来的样本"。**

**而那些"死掉的样本"（离职、 burnout、生病），不会有人统计。**

**一个有用的反问：**

> **"我们今年的人员流失率是多少？跟去年比呢？"**

**如果流失率大幅上升——那么"业绩好"可能是用"换了一批人"换来的。**

---

### 第三层：滑坡谬误（关于明年翻倍）

**"今年有效 → 明年更狼性 → 目标翻倍"**

**这个推理的问题：**

**① 边际递减**

```
   第一次加压，效果明显
   第二次加压，效果递减
   ……
   第 N 次加压，人会崩
```

**任何管理手段，都有一个"有效区间"。超出之后，它会反向。**

**② "目标翻倍"和"更狼性"是两个不同的东西**

- "更狼性"是一个**手段**
- "目标翻倍"是一个**目标**

**从"手段有效"推不出"加强手段就能达到任意目标"。**

> **打个比方：**
> **"跑步让我瘦了五斤，所以明年我跑两倍的量，就能瘦十斤。"**
>
> **——这是错的。因为身体会适应，而且过量会受伤。**

---

### 那么，你应该怎么办？

**⚠️ 关键提醒：这道题不是一个"公开反驳领导"的题目。**

**在年终总结会上当众说这些，你会赢逻辑，输掉很多别的东西。**

**正确的做法：私下 + 用问题 + 带方案。**

**话术示范：**

> "老板，今年这个成绩确实不容易。
>
> 我在想一个事儿：**我们有没有可能拆一下，今年这个增长，到底是哪几个因素带来的？**
>
> 比如：大环境的贡献、几个大单的贡献、团队能力的提升、还有我们推的那些新做法，各占多少？
>
> **如果能拆清楚，明年的目标就能定得更准。**
> 不然我担心的是——如果大部分增长其实来自一个大客户，
> **那我们明年按这个基数定目标，可能会定高了。**"

**这段话的精妙之处：**

```
   ✅ 没有否定领导（"这个成绩确实不容易"）
   ✅ 用的是"我在想"而不是"你错了"
   ✅ 完全没有出现"狼性文化"这个词（避免直接对抗）
   ✅ 落脚点是"目标定得更准"（这是领导也想要的）
   ✅ **而且它暗示了一个风险：定高了完不成**
```

**——最后一条，是领导真正会听进去的东西。**

> **因为对管理者来说，"目标定高"的后果，是要他承担的。**

---

### 这道题的终极洞察

**所有的"成功经验总结"，都有三个天生的缺陷：**

```
   ① 归因简化
      成功是多因素的结果，
      但总结的人，总是会挑出【他希望的那个原因】

   ② 幸存者偏差
      失败者不说话

   ③ 时效性错觉
      今年有效的方法，明年未必有效
      （因为环境变了、人变了、竞争对手也变了）
```

**所以，面对任何"成功经验"，请记住三句话：**

> **① "相关不是因果。"**
> **② "活下来的人才会讲故事。"**
> **③ "上一次的成功，是下一次失败最常见的原因。"**

**——第三句话，是商业史上被验证过最多次的一条。**
</details>

### 思考题 4（综合题 · 难）

> 你看到一条热搜：
>
> **"最新研究：每天喝三杯咖啡的人，平均寿命比不喝咖啡的人长 12%！"**
>
> 下面的评论分成两派：
> - 一派："太好了，我以后多喝点。"
> - 另一派："这些都是骗人的，研究都是收了钱的。"
>
> **请分析：这两派的反应，各有什么问题？以及，正确的"读法"是什么？**

<details>
<summary><b>参考答案</b></summary>

**这是一道"综合应用题"，它用到了第 10 讲和本讲几乎所有的工具。**

**我们来把它拆透。**

---

## 第一部分：两派各有什么问题？

### 第一派："太好了，我以后多喝点。"

**问题一：把"相关"当成了"因果"（第 11 讲谬误 7）**

"喝咖啡的人寿命长" ≠ "喝咖啡让人长寿"

**至少四种其他解释：**

```
   ① 第三变量：
      ● 收入 —— 能每天喝三杯咖啡的人，通常收入更高
        → 收入高 → 医疗条件更好、生活压力更小、饮食更健康

   ② 反向因果：
      ● 也许是"身体好的人，才会喝咖啡"
        （身体不好的人，医生让他别喝）

   ③ 样本偏差：
      ● "每天喝三杯"的人群，可能本来就更健康
        （比如：需要提神的人 vs 需要静养的人）

   ④ 定义问题：
      ● "不喝咖啡的人"这个对照组里，
        可能包含【因为健康原因而戒掉咖啡的人】
        → 这样对照组就被"污染"了
```

**最后一条特别重要，它有一个名字，叫"戒断者效应"（abstainer bias）：**

> **"不喝酒的人"里，有一部分是"因为喝出了问题才戒的"。**
>
> **所以他们本来就更不健康。**
>
> **——这会人为地放大"适度饮酒有益健康"的假象。**

**同样道理适用于咖啡。**

---

**问题二：忽略了"12%"这个数字的含义**

**请做一次"数量级检验"：**

```
   "平均寿命长 12%"
```

**12% 是相对于什么？**

- 如果对照组平均寿命是 70 岁 → 12% = 8.4 年 → **这非常惊人**
- **如果是"死亡风险降低 12%"（相对风险）→ 那换算成寿命，可能只有几个月**

**⚠️ 这是媒体报道最常见的一个"变形"：**

```
   原始论文：  "咖啡摄入与全因死亡率呈负相关（HR=0.88）"
   媒体标题：  "喝咖啡的人寿命长 12%！"
   读者理解：  "多喝咖啡能多活八年"
```

> **——从"HR=0.88"到"多活八年"，中间经历了三次失真。**
>
> **而每一次失真，都让它更"好读"，也更"不准"。**

---

### 第二派："这些都是骗人的，研究都是收了钱的。"

**问题一：动机归因 / 阴谋论思维**

**"研究是收了钱的"——这是一个无法被证伪的说法。**

```
   你说：  "这个研究发表在权威期刊上，经过同行评议。"
   他说：  "期刊也被收买了。"

   你说：  "有多个独立研究得到了类似结果。"
   他说：  "整个行业都被收买了。"
```

> **——一旦进入"无法证伪"的模式，讨论就结束了。**
>
> **这不是在评估证据，这是在拒绝评估。**

**识别方法（第 10 讲）：**

> **问问自己：有没有什么证据，能让我改变这个看法？**
>
> **如果答案是"没有"——那你持有的不是观点，是信仰。**

---

**问题二：把"可能有偏"等同于"一定是假的"**

**这是一个程度错误。**

```
   合理的态度：  "这个研究可能有局限性，我需要看看
                  样本多大、有没有控制变量、是观察性还是实验性"

   第二派的态度：「有局限性」= 「是假的」
```

> **——所有的研究都有局限性。**
> **——如果"有局限性"就等于"是假的"，那所有的科学研究都不能用了。**

---

## 第二部分：正确的"读法"是什么？

**我给你一个五步流程，可以套用到任何"研究称……"的新闻上。**

---

### 第一步：找原始研究（不要只看新闻标题）

**做法：**
- 新闻里通常会提到期刊名或机构名
- 搜索原始论文的摘要（abstract）
- **重点看：研究类型、样本量、结论原文**

**关键区分（这是最重要的一步）：**

```
   【观察性研究】（Observational）
   →  观察一群人，记录他们的习惯和健康状况
   →  只能证明【相关】，不能证明【因果】
   →  ⚠️ 绝大多数的"饮食与健康"研究，都是这一类

   【随机对照实验】（RCT）
   →  随机分组，一组干预，一组对照
   →  可以较强地支持【因果】
   →  ⚠️ 但在营养学领域，很难做（你不能强制一组人喝十年咖啡）
```

> **——看到"研究表明"，第一件事就是问：**
> **「这是观察性的，还是实验性的？」**

---

### 第二步：看效应量，而不是看显著性

**很多新闻会说" statistically significant（统计学显著）"。**

**但"显著"不等于"重要"。**

```
   样本量足够大的时候，
   一个非常微小的效应，也可以是"统计显著"的。
```

**举个例子：**

> 一项研究，样本 50 万人，发现"每天喝咖啡的人，死亡风险降低 3%"。
>
> **这个结果在统计上是显著的（因为样本大）。**
> **但对你个人来说，3% 是什么概念？**
>
> - 如果你 60 岁时的一年死亡风险是 1%
> - 降低 3% = 变成 0.97%
> - **差别微乎其微**

> **——所以，别看"显不显著"，看"效应有多大"。**

---

### 第三步：问"对照组是谁"

**这是一个极其重要但常被忽略的问题。**

**"喝咖啡的人 vs 不喝咖啡的人"——这个"不喝咖啡的人"是怎么定义的？**

```
   ❌ 如果对照组包含"因为生病而戒咖啡的人"
      →  对照组会更不健康
      →  "喝咖啡有益"的结论被人为放大

   ✅ 如果对照组是"从不喝咖啡的健康人"
      →  结论更可信
```

**这个原则适用于所有"饮食研究"：**

> **"不吃红肉的人"里，有多少是"因为三高才不吃的"？**
> **"不运动的人"里，有多少是"因为身体不好不能运动的"？**

---

### 第四步：看有没有"剂量-反应关系"

**这是判断"因果"的一个重要线索。**

```
   如果有因果关系，通常应该看到：

   喝得越多 → 效果越强（在一定范围内）

   比如：
   0 杯  →  基准
   1 杯  →  风险 -3%
   2 杯  →  风险 -7%
   3 杯  →  风险 -12%
```

**如果确实存在这种"梯度"，因果的可能性上升。**

**如果没有梯度（比如"喝 1 杯和喝 5 杯效果一样"），那么更可能是第三变量在起作用。**

---

### 第五步（最重要）：把它放回你已有的知识里

**这一步叫"贝叶斯式"的思考：**

> **一个新的信息，应该【更新】你的看法，**
> **而不是【覆盖】你的看法。**

**具体来说：**

**你已有的知识（先验）：**
- 咖啡含有抗氧化物（可能有益）
- 咖啡因会影响睡眠（睡不好肯定有害）
- 过量咖啡因会心悸、焦虑
- **喝咖啡的方式（加多少糖、多少奶）影响很大**

**新信息：**
- 一项观察性研究说"喝咖啡的人寿命长 12%"

**更新后的看法：**

> "有一些证据提示，适量喝咖啡可能无害甚至略有益。
> 但这个证据强度不高（观察性研究）。
>
> **所以我的行动是：如果本来就在喝，可以继续，但别为了'长寿'去加量。**
> **如果本来不喝，没必要为了这个去开始喝。**"

**——这是一个成熟的处理方式。**

---

## 这道题的终极洞察（三条，请记住）：

**① 关于健康类新闻，一条通用的"安全原则"：**

> **"没有一项单一的研究，能让你改变生活方式。"**
>
> **——能让你改变生活方式的，是大量研究的一致性结论，**
> **——经过多年、多个独立团队、不同方法的验证。**
>
> **比如"吸烟有害"，用了几十年、几千项研究才确立。**

**② 关于"怀疑一切"和"相信一切"：**

> **两者都是偷懒。**
>
> **"全信"把思考的责任交给了别人；**
> **"全不信"把思考的责任交给了自己的偏见。**
>
> **——真正的怀疑，是愿意花五分钟去看原文。**

**③ 最后一句（这一句最有用）：**

> **面对任何"科学新闻"，请问一句：**
>
> **"如果结论反过来，我会改变什么行为吗？"**
>
> **如果答案是'不会'——那这条新闻对你毫无价值，**
> **不管它是真是假。**
>
> **——你的注意力，比这条新闻珍贵得多。**
</details>
