# 第 12 讲　思考与反思——如何摆脱幻觉

> 本课程纲要中的第七模块《思考与反思——摆脱幻觉》，原视频未录制。
> 本篇是本教程的总结篇，由前十一讲的工具汇总而成，也是整本书的"收口"。

---

## 本讲一句话

**前十一讲教你怎么看世界，这一讲教你怎么看"正在看世界的自己"。而最重要的一课是：你无法彻底摆脱幻觉，你只能建立一个机制，让幻觉被更快地发现。**

---

## 开场：老陈的一面镜子

老陈的超市镜子前，贴了一张褪色的便签。

杨帆看了半天，问：**"陈叔，这上面写的什么？"**

**老陈：** "等你下。"——不是，是"等一下。"

**周雨：** 为什么要贴这个？

**老陈：** 我年轻的时候脾气爆。

那时候我在厂里，谁要是当着我的面说我一句，我当场就炸。

后来我师傅给我出了个主意。他说：**"你回家，在镜子前面贴张纸，写'等一下'。"**

我说这有啥用？

他说：**"你每次要发火，先去照镜子。看见自己那张脸，再决定要不要发。"**

**杨帆：** ……有用吗？

**老陈：** 有用。

**不是因为看见了脸，是因为那两秒钟。**

从"我想发火"到"我发火"，中间本来是零秒。

现在多了两秒。

**这两秒里，我就能想起来：我要是骂了他，明天还得跟他一起干活。**

**林知远：** （从门口走进来）

老陈，你师傅是个哲学家。

**他做的事情，是这一讲的核心：**

> **在"刺激"和"反应"之间，插入一段空隙。**

```
   刺激  →  反应          （动物的模式）
   刺激  →  【空隙】→  反应   （人的模式）
```

**而那个"空隙"，就是全部的自由。**

## 一、十一讲，其实只讲了一件事

**林知远：** 我们用了十一讲，讲了十一个主题。

**但如果把它们全部压缩，其实只讲了一件事。**

**周雨：** 是什么？

**林知远：** 我先带你们回头看一遍。

```
╔══════════════════════════════════════════════════════════╗
║                                                          ║
║   前十一讲的"一句话"                                       ║
║                                                          ║
║   01 目的与工具   →  人不是工具，包括你自己                ║
║   02 平等与公平   →  "平等"和"公平"是两把尺子              ║
║   03 权利与权力   →  "我可以"和"我说了算"是两回事          ║
║   04 自由的边界   →  "没人管我"和"我做得成"是两种自由       ║
║   05 权利与责任   →  权利的成本，谁在付？                  ║
║   06 立场与分歧   →  分歧在事实层、价值层，还是关切范围？    ║
║   07 权利与道德   →  "能不能"不等于"该不该"                ║
║   08 好心办坏事   →  善良是动机，正义是结构                ║
║   09 正义的尺度   →  正义不是一把尺，是四把                ║
║   10 事实与判断   →  你以为在说事实，其实在说判断          ║
║   11 逻辑与常识   →  逻辑防"推错"，常识防"荒谬"            ║
║                                                          ║
╚══════════════════════════════════════════════════════════╝
```

**杨帆：** 看起来……都是"这两个东西不一样"？

**林知远：** 对！你说到点子上了。

**它们几乎全都是"区分"。**

```
   平等 / 公平
   权利 / 权力
   消极自由 / 积极自由
   事实 / 判断
   推断 / 结论
   善良 / 正义
   相关 / 因果
   演绎 / 归纳
   观点 / 信仰
```

**而"区分"这个动作，有一个更古老的名字——**

> **它叫"辨析"。**
>
> **而思考，本质上就是不断做辨析。**

**周雨：** 那……为什么要辨析？不辨析会怎样？

**林知远：** 因为——

> **不辨析的人，不是没有想法，**
> **而是被自己的想法【使用】着，而自己不知道。**

**我给你们看一样东西。**

## 二、幻觉清单：我们都在被哪些东西"使用"着？

**林知远：** 我把前面十一讲里出现过的"思维幻觉"，整理成一张清单。

**请你们诚实地给自己打分（1 = 几乎没有，5 = 经常如此）：**

```
╔══════════════════════════════════════════════════════════╗
║                                                   你的分  ║

║   幻觉 ②：把"没被反对"当成"被同意"                        ║

║                                                          ║
║   幻觉 ④：把"合法"当成"对"                               ║
║   →  "规则又没说不行"（第 07 讲）                      ___  ║
║                                                          ║
║   幻觉 ⑤：把"动机好"当成"结果好"                         ║
║   →  "我这是为你好"（第 08 讲）                       ___  ║
║                                                          ║
║   幻觉 ⑥：把"多数"当成"正确"                             ║

║   幻觉 ⑦：把"相关"当成"因果"                             ║

║                                                          ║
║   幻觉 ⑧：把"看不见"当成"不存在"                         ║
║   →  "我从没遇到过这种事"（幸存者偏差）                ___  ║
║                                                          ║
║   幻觉 ⑨：把"我想不到"当成"不可能"                       ║
║   →  "除了 A 和 B，还能怎样？"（虚假两难）             ___  ║
║                                                          ║
║   幻觉 ⑩：把"我记得"当成"发生过"                         ║
║   →  "我记得清清楚楚"（记忆会重写）                    ___  ║
║                                                          ║
╚══════════════════════════════════════════════════════════╝
```

**杨帆：** （填完）……我好像没有低于 3 分的。

**周雨：** 我也是。

**林知远：** 这就对了。

> **这十条幻觉，不是"有些人有、有些人没有"的毛病。**
>
> **它们是【人脑的默认设置】。**
>
> **——你不需要为它们感到羞耻，**
> **——但你最好知道它们的存在。**

**因为——最重要的一句话来了——**

> **你不可能"消灭"幻觉。**
>
> **你只能做到一件事：在它起作用的时候，更快地认出它。**

## 三、元认知：思考你的思考

**林知远：** 现在我们来碰这一讲的核心概念：**元认知**。

**它的定义很简单：**

> **元认知 = 关于思考的思考。**

**周雨：** 听起来有点绕。

**林知远：** 我举个例子。

```
   一级思考：   "这个方案不行。"
                 →  你在思考【方案】

   二级思考：   "我为什么觉得它不行？"
                 →  你在思考【你的思考】

   三级思考：   "我有没有可能，因为这是我的方案，
                 所以我才觉得它行？"
                 →  你在思考【你的思考的偏差】
```

**第三级，就是元认知。**

**而这三级的难度，是递增的：**

```
   一级：  容易。人人都会。
   二级：  需要一点训练。
   三级：  极难。因为它要求你【怀疑自己正在维护的东西】。
```

---

### 为什么第三级这么难？

**林知远：** 我给你们讲一个心理学现象，它叫"**动机性推理**"。

**它的意思是：**

```
   当我们有一个"想要的结论"时，
   我们的推理能力，会被【征用】去服务那个结论。
```

**我跟你们做一个实验。**

**请想象：你刚买了一部 8000 块的手机。**

**第二天，你看到一篇评测，说这款手机续航很差。**

**你的第一反应是什么？**

**杨帆：** 我会想……是不是他测试的方法有问题。

**周雨：** 我会去找别的评测来对比。

**林知远：** 对。**你们俩都在"反驳"那篇评测。**

**但请注意——你们俩都不是手机行业的专家。**

**你们凭什么判断那篇评测是错的？**

> **——你们不是在用"专业"反驳它，**
> **——你们是在用"我不想它是错的"反驳它。**

**这就是动机性推理：**

> **当结论关系到"我的决定""我的面子""我的身份"时，**
> **我的大脑会自动切换成"律师模式"，而不是"法官模式"。**

```
   法官模式：  先有证据，后有结论
   律师模式：  先有结论，后找证据
```

**而人，天生是律师。**

---

### 怎么切换回"法官模式"？

**林知远：** 我给你们四个动作，按有效性排序。

```
╔══════════════════════════════════════════════════════════╗
║                                                          ║
║   切换到「法官模式」的四个动作                              ║
║                                                          ║
║   动作 ①：换人称（最有效，也最简单）                        ║
║                                                          ║
║   不要问："我该不该买这个？"                               ║
║   要问：  "如果我的朋友来问我，我会怎么说？"                ║
║                                                          ║
║   为什么有效：                                            ║
║   →  它把"我"从利害关系里拽出来了                          ║
║   →  （这叫"所罗门悖论"：                                 ║
║       人给别人的建议，总比给自己的明智）                    ║
║                                                          ║
╠══════════════════════════════════════════════════════════╣
║                                                          ║
║   动作 ②：换时间                                          ║
║                                                          ║
║   "十年后回看这件事，我会怎么看？"                          ║
║   "如果明天就截止，我还会这么做吗？"                        ║
║                                                          ║
║   为什么有效：                                            ║
║   →  情绪是"现在"的，理性可以"穿越时间"                    ║
║   →  把时间拉长，情绪的权重会自动下降                      ║
║                                                          ║
╠══════════════════════════════════════════════════════════╣
║                                                          ║
║   动作 ③：预先承诺（Pre-mortem）                          ║
║                                                          ║
║   在做决定【之前】，先假设它失败了：                        ║
║                                                          ║
║   "现在是三年后。这个项目彻底失败了。                      ║
║    请写下：它是怎么失败的？"                               ║
║                                                          ║
║   为什么有效：                                            ║
║   →  它绕过了"我必须证明自己对"的心理压力                  ║
║   →  **人在"解释失败"的时候，比在"预测失败"的时候诚实**     ║
║                                                          ║
╠══════════════════════════════════════════════════════════╣
║                                                          ║
║   动作 ④：找一个"会告诉你真话"的人                         ║
║                                                          ║
║   注意三个条件：                                          ║
║   ① 他会说真话（不是会讨好你的）                           ║
║   ② 他了解这件事（不是外行）                               ║
║   ③ **他跟你没有利益关系**（这一条最难）                   ║
║                                                          ║
║   为什么有效：                                            ║
║   →  因为你自己永远在自己的盲区里                          ║
║                                                          ║
╚══════════════════════════════════════════════════════════╝
```

**老陈：** 第四条我有个说法。

**我这辈子做对的最重要的决定，是听了我媳妇一句话。**

那年我想盘下隔壁那个铺面，扩大。转让费十八万，我觉得值。

我媳妇说了一句话：**"你现在的店，一天忙得过来吗？"**

我说：忙不过来。

她说：**"那你扩了，谁看？"**

**我当时愣住了。**

**我一直算的是"多一个铺面能多赚多少"，从来没算过"我一个人看不了两个店"。**

**林知远：** 后来呢？

**老陈：** 后来我改成雇了个人，守着这一个店。

**那个隔壁的铺面，半年后换了个老板，又半年，关门了。**

**那条街后来修路，封了一年。**

## 四、建立你自己的思维系统

**林知远：** 现在，我们来做最后一件，也是最重要的一件事。

**前面讲了四十多个工具。但我今天要告诉你们一个不太舒服的真相：**

> **工具如果不被"系统化"，很快就会忘掉。**
>
> **你不会记得第几讲的第几号工具。**
>
> **你需要的是——把它们变成【几个习惯】。**

**我把整本书，压缩成五个可以每天执行的习惯。**

```
╔══════════════════════════════════════════════════════════╗
║                                                          ║
║   五个思维习惯（这本书的全部）                             ║
║                                                          ║
║   习惯 ①：听到一个词，先问"它是什么意思"                   ║
║                                                          ║
║   触发：  听到"公平""权利""自由""不专业""不靠谱"           ║
║   动作：  在心里补一句"你说的这个词，指的是……？"           ║
║   频率：  每天至少三次                                    ║
║                                                          ║
╠══════════════════════════════════════════════════════════╣
║                                                          ║
║   习惯 ②：下一句结论前，先补一句"我看到了什么"             ║
║                                                          ║
║   触发：  想说"他就是……""肯定……""都是……"                ║
║   动作：  把它翻译成"我看到的三次事实"                    ║
║   频率：  每次想下判断时                                  ║
║                                                          ║
╠══════════════════════════════════════════════════════════╣
║                                                          ║
║   习惯 ③：听到一个"两难"，先问"有没有 C"                   ║
║                                                          ║
║   触发：  "要么 A，要么 B"                                ║
║   动作：  强迫自己想出第三个选项，哪怕很烂                 ║
║   频率：  每次遇到二选一                                  ║
║                                                          ║
╠══════════════════════════════════════════════════════════╣
║                                                          ║
║   习惯 ④：做一个决定前，先假设它失败了                     ║
║                                                          ║
║   触发：  任何重要的决定                                  ║
║   动作：  "三年后它失败了，是怎么失败的？"写下三条         ║
║   频率：  重要的决定，每次                                ║
║                                                          ║
╠══════════════════════════════════════════════════════════╣
║                                                          ║
║   习惯 ⑤：每年挑一个"深信不疑"，认真去推翻它              ║
║                                                          ║
║   触发：  每年一次                                        ║
║   动作：  找出一个你最确信的观点，                         ║
║           写下"最强的反对论证"                            ║
║   频率：  一年一次，够了                                  ║
║                                                          ║
║   ⚠ 这一条最难，也最值钱                                  ║
║                                                          ║
╚══════════════════════════════════════════════════════════╝
```

**周雨：** 林老师，这五个习惯……要练多久才能成习惯？

**林知远：** 说实话吗？

**很久。而且你会经常失败。**

**我教了二十年书，我自己到现在，也常常在说"他就是那种人"。**

**杨帆：** ……啊？

**林知远：** 真的。

**但区别在哪里？**

```
   以前：  我说完"他就是那种人"，会继续相信下去，
           然后根据这个判断去行动。

   现在：  我说完这句话，会【停一下】，
           然后想："我看到了什么？"
           然后我往往会发现，我的证据其实不足。
```

> **这就是全部的区别。**
>
> **不是不再犯错，是犯错之后的"觉察时间"变短了。**
>
> **——从三天，到三小时，到三秒钟。**

**老陈的师傅让他照镜子，给他的也不是"不发火"，**
**是那两秒钟。**

## 五、最后一个诚实的问题：思考有用吗？

**周雨：** 林老师，我问一个……可能不太合适的问题。

**林知远：** 问。

**周雨：** 就是……**想这么多，有用吗？**

我是说，我知道的很多人，他们不想这些，也过得挺好。

而且，有时候我觉得，**想得越多，越不快乐。**

**你看到了不公平，但你可能改变不了。**
**你知道了逻辑谬误，但网上的那些话还是有很多人信。**
**你明白了"好心会办坏事"，但你还是会办坏事。**

**那……为什么要学这些？**

（教室里安静了很久）

**林知远：** 周雨，这个问题，是我这二十年里，被问过最多次的一个。

**也是最重要的一次。**

**我给你三个回答。你可以挑一个，也可以都不要。**

---

### 回答一：它不能让你快乐，但能让你"不被骗"

**林知远：** 你说得对，**思考不保证快乐。**

**很多时候，恰恰相反。**

但是——

> **不思考的人，不是没有痛苦，**
> **而是他的痛苦，常常是【别人替他安排好的】。**

- 别人告诉他"该买房了"，他买了，然后痛苦三十年
- 别人告诉他"这个专业好"，他报了，然后痛苦四年
- 别人告诉他"你该结婚了"，他结了，然后……

**思考不能让你不痛苦，但它能让你的痛苦，是"你自己的"。**

> **——这是我唯一能给你的保证：**
> **——你受的苦，至少是你自己选的。**

---

### 回答二：它让你能做"别人做不到的事"

**林知远：** 我给你讲一件很小的事。

去年，我们学校有个学生，家里条件不好，找了一份兼职。

合同上写着：**"工作不满三个月，扣除全部培训费 3000 元。"**

他签了。

干了两个月，他发现这个公司有问题——**主要是让学生去贷款买他们的课。**

他想走。但想到那 3000 块，又犹豫了。

**后来他做了一件事：他去查了《劳动合同法》。**

他发现：**用人单位不得以任何名义向劳动者收取财物，也不得约定由劳动者承担违约金（除两种法定情形外）。**

**那 3000 块的"培训费"条款，是无效的。**

他去跟公司谈。他说：**"这一条，法律上无效。你们要么让我走，要么我去劳动监察。"**

公司让他走了。

**周雨：** ……然后呢？

**林知远：** 没有然后。这就是全部。

**他没有改变世界，他也没有"维权成功"的轰动故事。**

**他只是——少损失了三千块，和一段可能更糟的经历。**

> **——思考的价值，百分之九十九，是这种"很小很小的事"。**
>
> **它不会让你出名，不会让你发财，**
>
> **它只是让你在关键时刻，不那么容易被人拿走东西。**

---

### 回答三（最重要的一个）：它让你"能和自己相处"

**林知远：** 最后这个回答，是我真正想说的。

**你有没有注意到一个现象：**

> **有些人，独处的时候很安宁。**
> **有些人，独处的时候很难受。**

**差别在哪里？**

**我的观察是：**

> **能不能独处，取决于你脑子里有没有一个"可以对话的对象"。**

- 如果你脑子里只有"别人怎么说""网上怎么说"——**那你一个人的时候，就是在听噪音。**
- **如果你脑子里有一套自己的框架，能跟自己讨论——那你一个人的时候，是在聊天。**

> **思考给你最大的礼物，不是"更聪明"，**
>
> **而是一个"你愿意和他待在一起"的自己。**

**我知道这听起来有点玄。我换个说法：**

> **当你老了，退休了，孩子走了，**
> **你会花很多很多时间，跟你自己的脑子待在一起。**
>
> **——那间屋子里，是空的，还是有意思的，**
> **——取决于你这辈子往里面放了什么。**

---

## 深一层

### 追问 1：如果思考让你跟周围的人格格不入呢？

这是一个真实的代价，我不回避。

**你会遇到：**

- 你想讨论"这个词是什么意思"，对方说"你想太多了"
- 你指出一个逻辑问题，对方说"你就是杠精"
- 你想要一个理由，对方说"大家都这样"

**这不是你的错，也不是他们的错。**

**这是一种"速度差"：**

> **你在用"慢速思考"处理一个需要快速给出反应的场景。**

**怎么处理？我给你三条：**

**① 分清场合**

- 工作会议、正式讨论 → 慢思考是资产
- **朋友吐槽、家人闲聊 → 慢思考是负担**

> **别人跟你吐槽老板，他要的是"太过分了"，不是"我们来分析一下他的动机"。**

**② 分清对象**

- 有些人愿意被追问 → 跟他深入
- **有些人不愿意 → 收起来，不丢人**

**③ 保留一个"出口"**

> **找一个能跟你聊这些的人，哪怕只有一个。**
>
> **——人长期不能说真话，是会生病的。**

### 追问 2：你会不会变成"想太多而做不成事"的人？

**会。这是一个真实的风险，它有一个名字叫"分析瘫痪"。**

**识别和破解：**

```
   识别信号：
   ·  你一直在收集信息，但迟迟不开始
   ·  你能列出十个方案的缺点，但选不出一个
   ·  你总觉得"还不够了解"

   破解：设一个「信息截止时间」

   →  给自己定一个期限：
      "我再查两天，两天后必须做决定。"
   →  到点就停，不管还差多少
```

**一个更根本的解法：**

> **把"做对"的目标，换成"做得了调整"。**

- 追求"一次做对" → 你会一直犹豫
- **追求"做完之后能改" → 你会很快行动**

**这就是为什么第 06 讲的"可逆性优先原则"那么重要：**

> **选那个"错了还能改"的选项，然后立刻开始。**

### 追问 3：这本书里，哪一条你可能会忘掉？

**我的预测是：你会先忘掉"逻辑谬误"那十条。**

因为它们是"知识"，而知识不用就会忘。

**你会最后忘掉的，是这三句：**

```
   ① "你说的这个词，是什么意思？"
   ② "我们是不是在争'什么更重要'？"
   ③ "除了 A 和 B，有没有 C？"
```

**为什么是这三句？**

**因为它们是"动作"，不是"知识"。**

> **动作会在你嘴里形成肌肉记忆。**
>
> **——用一百次之后，你不需要想起它，你会说出口。**

**所以，如果这本书你只带走三句话，请带走这三句。**

## 生活思考题

### 思考题 1

> 请诚实地完成一件事：
>
> **列出三个你"深信不疑"的观点。**
>
> 然后，为每一个，写下**一个最强的反对论证**。
>
> 要求：这个论证要强到，持相反观点的人看了会说"对，我就是这么想的"。

<details>
<summary><b>参考答案</b></summary>

**这道题没有"标准答案"，因为我不知道你写下的是哪三个观点。**

**但我给你一个"评判自己做得好不好"的标准，以及三个常见的失败模式。**

---

## 三个失败模式（请对照检查）

### ❌ 失败模式一：写了"稻草人版的反对意见"

**错误示范：**

> 我的观点：应该给外卖骑手上社保。
>
> 反对论证：**反对的人会说"这样会增加企业负担"。**
> （然后你写两个理由反驳它）

**问题在哪？**

> 你写的"反对论证"太弱了，弱到你自己都能轻松打倒。
>
> **这不是在为难自己，这是在给自己的观点找成就感。**

**正确做法：把反对论证写到你"不知道怎么反驳"的程度。**

---

### ❌ 失败模式二：反驳的是"动机"而不是"论证"

**错误示范：**

> 我的观点：应该取消大学期末考试。
>
> 反对论证：反对的人是想维持现状，怕麻烦。

**问题在哪？**

> **你在猜测对方的【动机】，而这不是论证。**
>
> 而且——**一旦你开始归因为"他怕麻烦"，你就永远赢不了，**
> **因为你永远可以这么归因。**

**正确做法：只写"如果他是对的，理由是什么"。**

```
   ✅ 反对论证：
   "期末考试提供了一种【统一的、可比较的】评价标准。
    取消之后，评价会变得更加依赖主观判断，
    而这会让【没有资源、没有关系】的学生更难被看见。
    它保护的，恰恰是弱势学生。"
```

**——这一条足够强。而且你可能真的反驳不了。**

---

### ❌ 失败模式三：写完之后，假装没写过

**这是最常见的失败。**

你写了一个很棒的反对论证，然后说：

> "虽然它有道理，但我还是坚持我的观点。"

**然后就结束了。**

**——这不叫思考，这叫"参观了一下对方的阵地，然后回家了"。**

---

## 那"做对了"是什么样子？

**做对了，你会有三种感受之一。而且这三种，都是好事。**

### 感受一："我没想到这个角度"

> **恭喜。你的观点升级了。**
>
> **它不再是"我认为 X"，而是"我认为 X，但我知道 Y 也是真的"。**
>
> **——这两者，是不同级别的认知。**

### 感受二："我有点动摇了"

> **这更恭喜。**
>
> **能被动摇，说明你的观点不是"信仰"。**
>
> **第 10 讲讲过：如果你无论看到什么都能解释成"我没错"，**
> **那你持有的不是观点，是信仰。**

### 感受三："我完全说不出话来"

> **这是最好的结果。**
>
> **因为这是唯一一个，你的认知【真的】发生了改变的时刻。**
>
> **——人一辈子，这种时刻不会太多。**
> **——每一次，都值得记住。**

---

## 我给你一个示范（我自己的）

**我的一个深信不疑的观点：**

> **"教育应该培养独立思考的能力。"**

**现在，我写一个最强的反对论证：**

> "独立思考"这个说法，预设了一个"不依赖别人的思考者"。
>
> **但所有真正的思考，都是站在别人的肩膀上的。**
>
> 一个不学习前人成果、凡事都要"自己想"的人，
> 不是独立，是**无知**。
>
> **而且，"独立思考"这个口号，在实践中经常变成：**
> **"我觉得权威都是错的"——**
> **这不是独立思考，这只是另一种服从（服从于'反权威'这个姿态）。**
>
> **教育真正该给的，不是'独立思考的能力'，**
> **而是'知道该相信谁、以及为什么'的能力。**
>
> **——前者让人狂妄，后者让人可靠。"

**……怎么样？**

**我写完之后，我自己沉默了很久。**

**我没有放弃我的观点，但它已经不是我写之前那一个了。**

> **——这就是"思考"的样子。**
>
> **它不是让你站得更稳，**
> **它是让你站的地方，稍微移动了一点点。**
</details>

### 思考题 2

> 你工作三年了，有一份稳定但不喜欢的工作。
> 你有一个机会，去一家很想去但风险很高的公司。
>
> **请用"预先验尸法"（Pre-mortem）分析这个决定。**

<details>
<summary><b>参考答案</b></summary>

**先把方法说清楚：**

```
   预先验尸（Pre-mortem）
   ───────────────────────
   在做决定【之前】，做一个思想实验：

   "现在是三年后。这个决定彻底失败了。
    请写出：它是怎么失败的？"
```

**为什么这个方法这么有效？**

> **因为"预测失败"会触发防御（"你凭什么说我会失败"），**
> **而"解释已经发生的失败"，不会。**
>
> **——这是一个绕过心理防线的巧妙设计。**

---

## 第一步：写下"它是怎么失败的"

**请你现在，认真地写下三条。不要跳过。**

（写完再看下面）

---

**我给你一些常见的、值得考虑的失败路径：**

**失败路径 A：公司本身的问题**
- 融资没到位，B 轮死
- 创始人分歧，团队分裂
- 业务方向调整，你的岗位被裁撤

**失败路径 B：你自己的问题**
- 能力跟不上新公司的节奏
- **你以为你喜欢的是"这个行业"，其实你喜欢的是"不用做现在这份工作"**
- 你的抗压能力，没有你以为的强

**失败路径 C（最容易被忽略）："成功"的失败**
- 公司做成了，但你做的不是你想做的事
- 你升职了，但你更不开心了
- **你得到了你想要的机会，然后发现它不是你想要的**

**第三条最重要。因为它是唯一一个，你没法靠"努力"避免的。**

---

## 第二步：给每条路径，评估"概率"和"可控性"

**请画一个表：**

| 失败路径 | 概率（1-5） | 可控吗？ | 我能做什么降低它？ |
|---------|:---------:|:------:|------------------|
| A 公司倒闭 | | 部分 | ? |
| B 能力跟不上 | | **高** | ? |
| C 成功后不开心 | | 中 | ? |

**为什么"可控性"这一栏重要？**

> **因为概率高但可控的风险，不是风险，是"待办事项"。**
>
> **而概率低但完全不可控的风险，才是真正需要权衡的。**

---

## 第三步：针对每条，设计"早期预警信号"

**这是预先验尸法最实用的一步。**

**不要只写"可能会失败"，要写"我在什么时候，能知道它正在失败"。**

**示范：**

| 失败路径 | 预警信号 | 触发后我做什么 |
|---------|---------|--------------|
| 公司要出问题 | ① 工资延迟发放 ② 核心人员开始离职 ③ 创始人开始谈"转型" | ① 出现即更新简历 ② 出现两个即启动找下家 |
| 我能力跟不上 | ① 连续两个月绩效垫底 ② 我的方案反复被否定且说不清原因 | ① 主动约谈，问清楚差距 ② 给自己三个月补 |
| 我不开心 | ① 周日晚上开始焦虑 ② 我不再跟人聊工作 | ① 认真问自己：这还是我想要吗 ② 允许自己再换 |

**——有了这个表，"做决定"这件事，就不那么可怕了。**

> **因为你不再是在赌一个"结果"，**
> **你是在启动一个"有监控的过程"。**

---

## 第四步：做"可逆性"检查（第 06 讲的工具）

**最后，问一句：**

> **"如果三年后我发现错了，我还能回来吗？"**

**请具体评估：**

```
   ① 原来的公司，还会要我吗？（关系维护了吗？）
   ② 这个行业的经验，能迁移回去吗？
   ③ 我的积蓄，能支撑多久的"空窗"？
   ④ 我的年龄、家庭状况，允许多少次试错？
```

**如果"回得来"的可能性不低 → 这个决定的风险，被大幅降低了。**

> **——还记得第 06 讲那句吗：**
> **——"在两个选项都不确定的时候，选'错了还能改'的那个。"**

---

## 这道题的终极洞察（三条）：

**① 好决定 ≠ 好结果**

这一点我们已经讲过（第 09 讲），但在这里格外重要。

> **你可以做一个非常好的决定，然后因为运气不好而失败。**
>
> **你也可以做一个糟糕的决定，然后因为运气好而成功。**
>
> **——所以，不要用"结果"来评判你当初的决定。**
> **——用"当时的信息和流程"来评判。**

**② 最大的风险，通常不是"失败"，而是"没想过失败"**

> **没想过失败的人，不会设预警信号。**
> **没有预警信号，就会在问题已经很严重的时候才发现。**
> **发现得太晚，就回不来了。**

**③ 最后一句（这一句最重要）：**

> **做这个决定的时候，请问自己：**
>
> **"如果三年后我失败了，我会后悔做过这个决定吗？"**
>
> **如果答案是"不会，我会后悔没试过"——**
>
> **——那就去。**
>
> **——因为这一类"后悔"，是唯一一种，**
> **——时间越长，越会折磨你的。**
</details>

### 思考题 3

> 你的一个朋友，最近很"沉迷"于刷短视频，一天六个小时。
> 他很痛苦，觉得自己浪费时间，但停不下来。
>
> 他问你："我是不是意志力太差了？"
>
> **你怎么回答？**

<details>
<summary><b>参考答案</b></summary>

**先给答案：不是。**

**而且这个回答，比你想的更重要。**

---

## 为什么"意志力差"这个解释是错的？

**因为它会导致一个【无效且有害】的解法：**

```
   错误归因：  我意志力差
       ↓
   错误解法：  我要"更努力地控制自己"
       ↓
   结果：      失败 → 更自责 → 更焦虑 → 更需要刷 → 更失败
```

**这是一个自我强化的死循环。**

**而"自责"是这个循环里最危险的燃料。**

---

## 那么，真正的原因是什么？

**我给你三个层面，从浅到深。**

### 层面一：这不是意志力问题，是设计问题

**请理解一件事：**

> **你朋友的对手，不是他自己。**
>
> **他的对手，是几千个工程师，**
> **拿着几百万美元的年薪，**
> **日夜工作，目标只有一个：让他多刷五分钟。**

**他们用的工具包括：**

- **变量奖励**（variable reward）：不是每次都给你好的内容，所以你会一直刷
  → 这是老虎机的原理
- **无限下滑**（infinite scroll）：没有"终点"，所以没有天然的停止信号
- **自动播放**：消除所有"要不要继续"的决策点
- **个性化推荐**：越来越准，所以越来越难停下

**这不是一场"意志力"的较量。**

> **这是一场"一个人"对"一整个行业"的较量。**
>
> **——输，是正常的。**

**所以第一步：告诉你的朋友——"这不是你的错"。**

**这句话不是安慰，它是事实，而且它是所有后续改变的起点。**

> **因为羞耻感不会带来自控，羞耻感只会带来逃避。**

---

### 层面二：要问的不是"怎么戒掉"，而是"它在替你解决什么问题"

**这是最关键的一问。**

**刷短视频，通常不是"享受"，而是"逃避"。**

**请你的朋友诚实回答：**

```
   他通常在【什么时候】开始刷？
      · 睡前？        → 逃避失眠或焦虑
      · 工作间隙？    → 逃避压力
      · 一回到家？    → 逃避孤独
      · 跟人吵完架？  → 逃避情绪

   刷完之后，他感觉如何？
      · 放松了？      → 那是真休息
      · **更空虚？**  → 那不是休息，是麻醉
```

> **一个行为如果是"麻醉"，那"戒掉它"是无效的。**
>
> **——你必须先处理那个"痛"。**

**实操问法（这一句可以直接用）：**

> **"你刷的时候，是在逃避什么？"**

**很多人听到这个问题，会沉默很久。**

**——那个沉默，就是答案开始的地方。**

---

### 层面三：不要"戒"，要"换"和"堵"

**这是唯一可行的操作层。**

**核心原则：**

> **意志力是有限资源，不要依赖它。**
>
> **要依靠"环境设计"。**

**三个具体动作：**

**① 增加"启动成本"（把那两秒钟找回来）**

```
   ·  把 App 从主屏幕移到第三页的文件夹里
   ·  退出登录（每次要重新输密码）
   ·  卸载 App，只用网页版（体验差很多）
   ·  **设置"屏幕使用时间"限额，让家人设密码**
```

**原理：不是让你"不能刷"，而是让"开始刷"这个动作，多花十秒钟。**

> **而这十秒钟，就是老陈镜子上的"等一下"。**

**② 提供替代品（关键！）**

**这一条最容易被忽略，但它可能是最重要的。**

> **如果你只是"拿走"刷视频，那个空出来的时间，**
> **会被更糟的东西填满。**

所以要提前准备好替代：

```
   刷视频通常在：  睡前  →  换成：有声书 / 播客 / 纸质书
   刷视频通常在：  通勤  →  换成：下载好的音乐 / 课程
   刷视频通常在：  饭后  →  换成：散步十分钟
```

**注意：替代品必须是"同样容易"的。**

- 不要说"用读书代替刷视频"——读书难多了
- **要说"用听书代替刷视频"——躺下就能听**

**③ 改变"触发点"**

```
   观察：  你是什么时候，手伸向手机的？
   →  通常是：躺下、坐下、等电梯、排队

   对策：  改变这些"触发时刻"的物理环境
   →  手机充电器放在客厅，不放卧室
   →  排队的时候，手插兜里
   →  吃饭时手机放另一个房间
```

---

### 最后：给他一个"尺度"

**这一点很重要，因为它决定了他会不会陷入新的焦虑。**

**请告诉他三件事：**

**① 一天六小时是"多"，但不是"病"**

- 判断是否成瘾的标准，不是"时长"
- **而是：「它有没有损害你的生活功能」**
  - 影响睡眠了吗？
  - 影响工作/学习了吗？
  - 影响人际关系了吗？
  - **你想要停，停得下来吗？**

**② 目标不是"零"，是"减少"**

> **把"我要戒掉"改成"我要从六小时减到三小时"。**
>
> **——前者会失败，后者会成功。**
>
> **——而一次成功的"减少"，会带来第二次。**

**③ 允许反复**

**他一定会有一天，又刷了六个小时。**

**那一天不是"失败"，那一天只是"数据"。**

> **——自责才是真正的失败。**
> **——重新来过，从来都不算晚。**

---

## 这道题的终极洞察（这是最重要的一段）：

**我们这个时代，有一个巨大的、系统性的误解：**

> **我们把"结构性问题"，当成了"个人品质问题"。**

- 刷短视频停不下来 → "你意志力差"
- 工作中拖延 → "你不够自律"
- 攒不下钱 → "你不会理财"
- 焦虑失眠 → "你想太多"

**这些归因有一个共同的功能：**

> **它把责任，从"设计者"身上，转移到了"使用者"身上。**

- 平台的责任，变成了你的意志力问题
- 工作制度的问题，变成了你的效率问题
- 消费环境的问题，变成了你的理财能力问题

> **——而一旦你接受了这套归因，**
> **——你会开始攻击自己，**
> **——而真正的那个问题，则安然无恙地留在原地。**

**所以，这道题真正的答案是：**

> **下次你想说"我是不是太差了"的时候，**
>
> **先问一句：**
>
> **"是什么样的设计，让一个正常人，做出了这个选择？"**
>
> **——这一问，是这本教程留给你最有用的东西。**

**它不是让你不再努力。**
**它是让你把力气，用在真正能改变的地方。**
</details>

### 思考题 4（结业题 · 最难）

> 假设你可以回到三年前，给当时的自己带去一句话。
>
> **你会带哪一句？**
>
> 然后，请回答更难的一问：
>
> **如果你带去的这句话，真的改变了三年前的你——**
> **那么今天的你，还想要这个改变吗？**

<details>
<summary><b>参考答案</b></summary>

**这是一道"结业题"。它没有标准答案，但我希望你能真的停下来，写下你的那句话。**

**然后，我们来做第二问。因为第二问才是这道题的全部。**

---

## 第一问：你会带哪一句？

**我先给你一些别人写过的（真实收集）：**

> "不要为了'显得合群'做那些决定。"
>
> "你爸妈说的话，有一半是对的。但你当时不知道是哪一半。"
>
> "那个让你难受的决定，是对的。"
>
> "不要那么在意别人的评价，他们真的没那么在意你。"
>
> "把那笔钱花在学英语上，别买那个东西。"
>
> "你现在最不在乎的那件事，三年后会是最重要的。"
>
> **"你以为的'来不及'，其实还早得很。"**

**最后一句，是出现频率最高的。**

> **——这本身就是一个洞察：**
> **——我们绝大多数的焦虑，来自一个错误的"时间感"。**

---

## 第二问（真正的问题）：你真的想要这个改变吗？

**现在，认真想：**

**如果你三年前真的听到了这句话，你做出了不同的选择——**

**那么，今天的你，会变成什么样？**

---

**我们来具体推演一下：**

假设你带去的那句话是：**"别怕，去表白。"**

于是三年前的你表白了，然后：

```
   情况 A：  在一起了
   →  今天的你，有了三年的恋爱
   →  **但你不会遇到后来的那些人，不会有后来的那些事**
   →  你不会是现在的你

   情况 B：  被拒绝了
   →  今天的你，多了一次"被拒绝"的经历
   →  可能更勇敢，也可能更胆怯
   →  **你也不会是现在的你**
```

**两种情况下，"现在的你"都消失了。**

**——而现在这个你，是你唯一确定拥有的东西。**

---

**这就是这道题真正想让你看见的东西，它有两部分：**

### 第一部分：你今天的样子，是你所有选择的总和

**包括那些"错误"的选择。**

```
   你后悔的那次分手      →  它教会了你什么？
   你后悔的那个专业      →  它让你遇到了谁？
   你浪费的那两年        →  它在什么时候救过你？
   你犯过的那个错        →  你今天还在靠它提醒自己
```

> **人有一种奇怪的倾向：**
> **我们会把自己的成就，归功于"正确的选择"；**
> **却忘了，那些"错误的"选择，同样塑造了我们。**

**这不是在为错误辩护。**

**这是说：如果真的能回去改掉它，你要知道——**

> **你改掉的不只是那件事，**
> **你改掉的是"从那件事里长出来的那个你"。**

---

### 第二部分：更深的一层——"想要改变过去"这个念头本身

**请诚实地问自己：**

> **"我想改变过去"这件事，**
> **有多少是因为"过去真的错了"，**
> **有多少是因为"我现在不快乐"？**

**这是一个非常尖锐的问题。**

**因为很多时候，"如果当初……"这个句式，真正的功能是：**

> **它给"我现在的不如意"，提供了一个【不用负责的解释】。**

```
   "如果当初我去了那家公司……"
   →  潜台词：我现在过得不好，是因为那次选择，不是因为我现在的任何事。
```

**——这是一种自我保护，它很正常。**

**但它有一个代价：**

> **它把"改变现在"的责任，**
> **转移给了"改变不了的过去"。**

---

## 那么，这道题的答案是什么？

**我的答案（你可以不同意）：**

> **如果真的能回去，我什么都不会带。**

**为什么？**

**三个理由：**

**① 三年前的我，听不懂**

> **一句话之所以有用，是因为你【已经准备好】听懂它。**
>
> **而三年前的我，没有准备好。**
>
> **——同一句话，在不同的时候说，是完全不同的东西。**

**② 就算他听懂了，他也做不到**

> **知道"不要在意别人的评价"，不能让你不在意别人的评价。**
>
> **——那是一种需要被生活磨出来的东西，不是一句话能给的。**

**③ 最重要的一条：我今天能问出这个问题，恰恰是因为我没有被改变**

> **——如果三年前的我被改变了，**
> **——那么此刻正在问"要不要改变他"的这个我，就不存在了。**

**这是一个悖论：**

> **你无法改变过去，**
> **因为"想要改变过去的你"，正是过去的结果。**

---

## 所以，这道题真正想让你带走的是：

> **"如果当初……"这个句式，**
>
> **在有的时候，是一种安慰；**
> **在有的时候，是一种逃避。**
>
> **——而区分它们的方法只有一个：**
>
> **——说完这句话之后，你是更想做点什么，**
> **——还是更不想做点什么了？**

---

## 最后：给你一个可以真的用上的版本

**既然不能回到过去，那就把这个问题【换个方向】：**

> **不要问："如果回到三年前，我会带什么话？"**
>
> **改问："如果三年后的我，回到今天，他会带什么话？"**

**然后，你大概率会知道那句话是什么。**

**因为——**

> **你现在最该做、但一直没做的那件事，**
>
> **就是三年后的你，最想提醒你的那件事。**

**——你早就知道了。**

**——你只是需要一个理由，去开始。**

**——那么，这就是那个理由。**

---

> **祝你，想得清楚，也做得成。**
