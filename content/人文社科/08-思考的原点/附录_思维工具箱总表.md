## 一、语言与概念类（1—5）

### 工具 01：拆词三问
**用在哪：** 听到"这不公平/这不平等/这不专业/他不靠谱"

```
① 你说的是哪一种？（人格平等 / 规则平等 / 结果平等）
② 这句话是"描述事实"还是"规定主张"？
③ 这个方案牺牲了什么？
```
> 说不出代价的方案，都是没想完的方案。

### 工具 02：工具检测法
**用在哪：** 判断一件事有没有把人当工具

```
当指标和人冲突时，改的是指标，还是人？
   改指标 → 人是目的
   改人   → 人是工具
```
> 别忘了对自己也用一次。

### 工具 03：公平四问
**用在哪：** 任何"分配"问题

```
① 分配公平？  按贡献 / 按需要 / 按人头
② 程序公平？  规则事先说了吗？能申诉吗？
③ 互动公平？  有没有让人"没被看见"
④ 补偿公平？  按身份补，还是按处境补？
```
> 程序只能让人"认"，不能让人"服"。

### 工具 04：权利 vs 利益
```
为了更大的好处，可以牺牲它吗？
   可以 → 利益（可权衡）
   不行 → 权利（有边界）
```

### 工具 05：客观标准的照妖镜
```
听到"我们按客观标准来"时，多问一句：
   ➜ 这个标准，对谁特别有利，对谁特别不利？
```
> 每一个客观标准，都是某人按某种偏好设计的。它不中立，只是偏向被藏起来了。

## 二、权利与权力类（6—9）

### 工具 06：权利 / 权力 分辨法
```
「我可以……」「你不能对我……」 → 权利 (Right)
「你必须……」「不然我就……」   → 权力 (Power)
```
> 有权力 ≠ 有权利。"我能做到" ≠ "我有权这么做"。

### 工具 07：支配关系探测器
```
不要看"他给了你什么"
要看：他有没有抬高你的「退出成本」？
```
> 竞业协议 / 十年健身卡 / 平台数据绑定 / 让你断掉朋友——都是同一件事的马甲。

### 工具 08：制约权力四件套
```
① 退出权  → 我能走吗？（成本多高？）
② 发声权  → 我说了有人听吗？
③ 分权    → 互相能制衡吗？
④ 规则    → 掌权者能自己改规则吗？
```
> ⚠ 退出权是地基。没有它，其余三个都是空中楼阁。

### 工具 09：过时规则考古四问
```
① 它当年为了解决什么问题？（先假设它有理）
② 那个问题还在吗？
③ 如果不在了，为什么它还在？（谁会受损？）
④ 有没有成本更低的替代方案？
```

## 三、自由类（10—13）

### 工具 10：两种自由分辨法
```
消极自由 (freedom FROM)：没人管我｜有多少扇门关着
积极自由 (freedom TO)：  我做得成｜我有力气推开门吗
```
> 它们会打架：积极自由要权力"多帮我"，消极自由要权力"少管我"。

### 工具 11：自由的边界——「影响」检验法
```
❌ 通俗版：你的自由止于我的鼻尖
✅ 精确版：当影响越过你自己的范围，就不再只是你的自由
```
> ⚠ 影响 ≠ 身体接触：噪音、气味、视觉、心理压力，都是影响。
> ⚠ 反过来也成立：**"没被反对" ≠ "被同意"。沉默不是授权。**

### 工具 12：安全措施好坏检测仪
```
这个措施让人变得更弱了，还是变得更强了？
   拿走能力（护栏、禁令）→ 短期有效，长期退化
   增加能力（教学、演练）→ 见效慢，但治本
```

### 工具 13：自由的三个代价
```
① 责任的代价 —— 自己选，自己扛
② 选择的代价 —— 选项越多，焦虑越多
③ 孤独的代价 —— 你可能不被所属群体接纳
```
> 自由的最高形式不是"想做就做"，而是"不想做就能不做"。

## 四、责任与道德类（14—17、22—25）

### 工具 14：权利真伪三问
```
① 它有对应的义务人吗？（没有义务人的"权利"，只是愿望）
② 这个义务，是对方自愿承担的吗？
③ 行使它需要对方付出什么？比例合理吗？
```

### 工具 15：责任三层
```
第一层 事后责任 「做错了，我认」       被动 · 可逃避
第二层 事前责任 「我答应的，我做」     主动 · 可检验
第三层 无承诺责任「没人要求，我看见了」 自发 · 无法被要求
```
> 判断标准：**"我扫那个地，不是给他扫的。"**

### 工具 16：责任过载三形态（识别被甩锅）
```
① 无限责任  → "出了事都是你的"
② 转移责任  → "为你好，所以听我的"（我担责，但决定权在你）
③ 责任绑架  → "你不这样，就是不负责任"
```
> 区分"表达委屈"（我累了）和"要求权力"（所以你得听我的）。

### 工具 17：无效帮助检测器
```
帮了六次，问题还在吗？
   在 → 你帮的是"症状"，而且你的"帮"在消灭对方的动力
```
> 解药：给钱 → 给能力 → 给边界（第三层才是真帮）

### 工具 22：合法 / 道德 四象限
```
A 合法 + 道德    → 日常大多数行为
B 违法 + 不道德  → 偷、骗、伤人
C 违法 + 可辩护  → 为救人闯红灯
D 合法 + 不道德  → 钻空子 ⚠
```
> 钻空子 = 在规则的**文字**内，做违背规则**精神**的事。

### 工具 23：道德四层（能要求谁）
```
第一层 不伤害 → 可以【要求别人】
第二层 互惠   → 可以【要求自己】
第三层 助人   → 只能【期待】，不能要求
第四层 牺牲   → 做不到完全正常
```
> 识别道德绑架句式：「你有 X 能力/身份 → 所以你应该做 Y」
> **缺的那一环是：「我愿意」。**

### 工具 24：道德直觉处理流程
```
① 直觉报警 → "我觉得不对，但说不出为什么"
② 不要停在这里（停在这里就是偏见）
③ 追问 → "到底哪个词让我不舒服？"（往往能发现一个分类错误）
④ 找到被冒犯的原则
⑤ 一致性检验 → "这个原则，别的情况我还坚持吗？"
```
> 直觉是警报器，不是判决书。直觉给你方向，理性给你坐标。

### 工具 25：基本归因错误自检
```
别人做错 → 我默认归因于【他的品格】
我做错   → 我默认归因于【我的处境】
```
> ⚠ **理解 ≠ 免责**。"我理解你为什么这么做" ≠ "你这么做是对的"。

## 五、分歧与沟通类（18—21）

### 工具 18：分歧三大来源诊断法
```
① 我们是不是在争"什么更重要"？（价值排序 → 无法用事实解决）
② 我们算的账，是同一个时间长度吗？
③ 我们把同样的人算进去了吗？（关切范围，常是隐形的）
```

### 工具 19：争论升级六台阶 + 四个刹车
```
① 你的观点不对  ② 你的论据有问题  ③ 你的逻辑有问题
④ 你的动机有问题 ← 从这里开始就回不去了
⑤ 你是个坏人    ⑥ 支持你的人都是坏人
```
**刹车：**
- 🛑 ① 复述对方论点，直到他说"对，我就是这个意思"（Steelman）
- 🛑 ② 主动说出"我在什么情况下是错的"
- 🛑 ③ 把"你错了"换成"我们的分歧在哪一层"
- 🛑 ④（老陈版）吵到第二句时，问一句："你饿不饿？"

### 工具 20：跳出框架三问
```
当你在 A 和 B 之间左右为难时：➜ 有没有 C？
```
> 秋游之争 → 分歧点是【钱】→ 补贴钱，或换个不花钱的方案
> 宿舍之争 → 分歧点是【作息】→ 分作息宿舍，而不是"谁迁就谁"

### 工具 21：可逆性优先原则
```
两个选项都不确定时，选"错了还能改"的那个
```
> 不是因为它更可能对，而是因为——万一错了，你还回得来。

## 六、善良与正义类（26—34）

### 工具 26：好心办坏事——四个机制
```
① 信息不完全  你不知道对方真正需要什么
② 激励扭曲    你的善意改变了对方的行为
③ 系统效应    局部的善，整体的恶
④ 责任错位    你替他决定，他承担后果
```

### 工具 27：善良 vs 正义
```
善良 = 动机 · 由近及远 · 现在 · 被"可见性"绑架
正义 = 结构 · 由普遍到具体 · 长期 · 忽视"这一个"
```
> 正义，是对"可见性偏见"的制度性纠正。**它保护那些不会哭的人。**

### 工具 28：可识别受害者效应
```
一个有名有姓的受害者 → 强烈情感 → 行动
一群抽象的统计受害者 → 同情     → 不行动
```

### 工具 29：善意的三个刹车
```
① 先问"想要什么结果"，再选手段
② 先小实验，再大规模推开（善意的规模 ∝ 你掌握的信息量）
③ 让受益人成为"参与者"，而非"接收者"
```

### 工具 30：分配正义四原则
```
分投票权 / 基本保障 → 平等原则
分工资 / 奖金       → 贡献原则
分医疗 / 救灾       → 需要原则
分市场收益          → 自由原则
```
> ⚠ 两个价值塞进一个奖励 → 两边都不满意。解法：**拆开，每个奖只用一把尺子。**

### 工具 31：决策质量 ≠ 结果质量
```
重来一次，在【同样】的信息下，我会不会做同样的决定？
   会   → 决策没问题，是运气问题
   不会 → 决策有问题（哪怕这次赚了）
```

### 工具 32：无知之幕（日常版）
```
定规则前问："如果我不知道自己会站在哪个位置上，我还会定这个规则吗？"
```
> 民间版：**"分的人最后拿。"** ——不要求人善良，只要求人自私。这才稳固。

### 工具 33：好制度的通用结构
```
上层：有限的、透明的例外通道 ← 善良
底层：统一的规则             ← 正义
```
> ⚠ 例外要**有限**（否则规则形同虚设）、要**透明**（否则变成"看关系"）。

### 工具 34：信息不足时的转向
```
不要问："谁对谁错？"（需要确知真相）
改问：  "接下来怎样对所有人最好？"（不需要）
```

## 七、事实与逻辑类（35—44）

### 工具 35：语言的四层
```
① 事实  可验证（能拍下来/量出来吗？）
② 推断  从已知推未知（有其他解释吗？）
③ 判断  依赖标准（标准谁定的？）
④ 感受  不需要验证，只需要被承认
```
> 日常语言里 90% 是 ②③，而我们以为自己在说 ①。

### 工具 36：推论阶梯
```
7 行动 ← 6 信念 ← 5 结论 ← 4 假设 ← 3 意义 ← 2 选择 ← 1 数据
```
> 关键在第 2 层：数据无限，注意力有限。
> 用法：**下结论前，往下爬两级，问"我跳过了哪几级"。**

### 工具 37：认知偏差四巨头
```
① 确认偏误   破解：主动找"如果我错了，我会看到什么"
② 幸存者偏差 破解：问"同样这么做的人，多少失败了？"
③ 可得性偏差 破解："我的印象来自亲身经历，还是媒体？"
④ 锚定效应   破解：看到对方的价格前，先自己估一个
```

### 工具 38：信息可信度三问
```
① 谁说的？      一手还是转述？有动机吗？
② 怎么知道的？  亲眼所见？有记录吗？
③ 有别的说法吗？**如果它是假的，谁会受益？**
```
> ⚠ 别转发"未核实的警告"，改发"核实的方法"。

### 工具 39：判断 → 证据 翻译练习
```
每说一个判断，补一句："我是因为看到了什么，才这么说的？"
```

### 工具 40：十大逻辑谬误速查
```
【攻击人】① 人身攻击  ② 稻草人  ③ 你也一样
【假两难】④ 虚假两难  ⑤ 滑坡谬误
【证据不足】⑥ 以偏概全  ⑦ 相关当因果  ⑧ 转移举证
【偷换循环】⑨ 偷换概念  ⑩ 循环论证
```

### 工具 41：演绎 / 归纳 检查点
```
演绎（一般→特殊）→ 检查【前提】
归纳（特殊→一般）→ 检查【样本】
```

### 工具 42：常识三检验
```
① 数量级检验  这个数字，量级说得通吗？
② 极端检验    推到极端，还成立吗？
③ 反向检验    如果它是真的，还应该看到什么？
```
> ★ 最强一问：**"如果它这么好，为什么轮得到我？"**

### 工具 43：违反常识 ≠ 是假的
```
但它意味着：举证标准要大幅提高
```
> ⚠ 常识最大的风险是**更新太慢**。每年挑一个深信不疑的，认真试图推翻它。

### 工具 44：研究新闻五步读法
```
① 找原始研究：观察性 or 实验性？
② 看效应量，别看"显著性"
③ 问"对照组是谁"（戒断者效应会污染对照组）
④ 看有没有"剂量-反应"梯度
⑤ 放回已有知识：新信息【更新】看法，不【覆盖】看法
```

## 八、元认知类（45—49）

### 工具 45：十条思维幻觉自检
```
① 把"我的想法"当"事实"      ⑥ 把"多数"当"正确"
② 把"没被反对"当"被同意"    ⑦ 把"相关"当"因果"
③ 把"我想要"当"我有权利"    ⑧ 把"看不见"当"不存在"
④ 把"合法"当"对"           ⑨ 把"我想不到"当"不可能"
⑤ 把"动机好"当"结果好"      ⑩ 把"我记得"当"发生过"
```
> ⚠ 它们不是"有些人的毛病"，是**人脑的默认设置**。
> ⚠ 你消灭不了它们，只能做到：**更快地认出它们。**

### 工具 46：切换到「法官模式」四动作
```
① 换人称   → "如果是我朋友来问我，我会怎么说？"
② 换时间   → "十年后回看，我会怎么看？"
③ 预先验尸 → "假设三年后失败了，它是怎么失败的？"
④ 找真人   → 说真话 + 懂 + 跟你无利益关系
```

### 工具 47：五个思维习惯（全书压缩版）
```
① 听到一个词，先问"它是什么意思"
② 下结论前，先补一句"我看到了什么"
③ 听到"两难"，先问"有没有 C"
④ 做决定前，先假设它失败了
⑤ 每年挑一个"深信不疑"，认真去推翻它
```

### 工具 48：如果只带走三句话
```
① "你说的这个词，是什么意思？"
② "我们是不是在争'什么更重要'？"
③ "除了 A 和 B，有没有 C？"
```
> 它们是**动作**不是**知识**。用一百次之后，你不需要想起它们，你会说出口。

### 工具 49：终极一问
```
下次你想说"我是不是太差了"的时候，先问：
   ➜ "是什么样的设计，让一个正常人，做出了这个选择？"
```
> 把"结构性问题"当成"个人品质问题"，是这个时代最大的、系统性的误解。

## 九、一张图：全书的结构

## 十、最后：三条使用建议

### 建议 1：不要一次用全部工具

**一次用一个。** 挑一个你最需要的（我推荐下面这三个之一），用一个月：

- **如果你经常跟人吵架** → 用工具 19 的"刹车①"（复述对方论点）
- **如果你经常后悔做过决定** → 用工具 46③（预先验尸）
- **如果你经常被人说服去买不需要的东西** → 用工具 42（常识三检验）

**一个工具用一个月的价值，大于知道四十九个工具。**

### 建议 2：找一个"陪练"

工具是需要反馈的。

**找一个人，跟你约定：**
- 当你说了"他就是那种人"，他指出你
- 当你陷入二选一，他问你"有没有 C"

**——这比读十遍书有用。**

### 建议 3：允许自己用不出来

**最开始的一段时间，你会在"吵架已经结束之后"才想起来该用哪个工具。**

**这很正常。这是所有学习的必经阶段。**

```
   阶段一：事后才想起来     （"刚才我应该问那句话的……"）
   阶段二：事中就意识到     （"等等，这是稻草人"）
   阶段三：事前就自动触发   （成为习惯）
```

> **第一阶段会持续挺久。别急，也别自责。**
>
> **——老陈照了三十年镜子，才把那两秒钟变成本能。**
