# 阶段五 · 后端开发工程（本课导读）

> **课程定位**：把前面学的语言 + 数据库 + 中间件，组装成「能上线的后端系统」。这一阶段结束，你能独立完成一个真实的 Web 后端项目。
> **前置条件**：阶段二（精通一门语言）+ 阶段三 + 阶段四。
> **时长建议**：2~3 个月，以项目为纲。

---

## 一、开场案例：从「会写接口」到「能上线」

小白问老师：**「老师，我能在本地跑通 Spring Boot 的 Hello World 了，也能查数据库了。但我还是不敢说自己『会后端』——人家说的『生产环境』『依赖注入』『网关』我都没概念。」**

老师：**「很正常。你现在是『零件都认识，但不会组装』。这一阶段就是练组装：**从零搭一个完整的后端项目——登录鉴权、增删改查、缓存、消息队列、日志、异常处理、单元测试、打包部署。**做完这一个项目，你才算『会用后端』。」**

小白：**「那我直接学 Spring Boot 就行了吧？」**

老师：**「框架是皮，原理是骨。Spring 全家桶课教你『怎么用』，Spring 核心编程思想、手写 MiniSpring 教你『它凭什么这么设计』。只会用框架的人，换一个框架就废；懂原理的人，任何框架都是『又一个 Spring』。」**

**案例启示**：某公司两个新员工，都会 Spring Boot。一个只会照模板写 CRUD，遇到「循环依赖」「事务失效」「配置不生效」就抓瞎；另一个学过原理，看一眼报错就知道是 Bean 生命周期还是 AOP 代理问题。**半年后，第一个还在写 CRUD，第二个已经在设计系统了。**

## 三、怎么学最有效？

1. **主线项目制**：选定一个项目（如「电商订单系统」），边学边做，学完一门课，往项目里加一块能力。
2. **先「会用」，再「懂原理」**：先用 Spring Boot 把项目跑起来，再回头啃「Spring 核心编程思想」和「手写 MiniSpring」。
3. **每个组件问三个问题**：它解决什么问题？不用它怎么实现？它的核心原理是什么？（例如：AOP 解决横切逻辑，不用它就得到处写重复代码，原理是动态代理）
4. **必须会看报错**：后端 90% 的时间在跟报错搏斗。看到异常先读栈，别急着上网搜。

## 四、学完检验（自测清单）

- [ ] 能用 Spring Boot 独立搭一个含登录、CRUD、异常处理、日志的 Web 服务
- [ ] 能解释 IOC（依赖注入）和 AOP 的原理，说出 Bean 的生命周期
- [ ] 能配置数据库连接池 + MyBatis/JPA，并处理事务（含事务失效场景）
- [ ] 能接入 Redis 缓存 + 消息队列，并说出各自解决的问题
- [ ] 能说出「单体 → 微服务」的演进理由，画出微服务架构图
- [ ] 能把项目打包并用 Docker 部署到服务器
