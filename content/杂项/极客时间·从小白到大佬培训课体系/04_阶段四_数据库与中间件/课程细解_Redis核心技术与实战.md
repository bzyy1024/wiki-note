## 一、这门课到底讲什么

Redis 不只是「缓存」，它是缓存、分布式锁、排行榜、计数器、消息队列、布隆过滤器的综合底座。这门课按「基础架构 → 数据结构 → 高性能 → 持久化 → 主从哨兵 → 集群 → 缓存实践 → 并发与锁」层层递进，学完你能答出「为什么 Redis 快」「缓存怎么不崩」「分布式锁怎么不掉坑」。

## 三、必须吃透的核心知识点

1. **单线程为什么快（第 3 讲）**：纯内存 + 单线程（避免锁和上下文切换）+ IO 多路复用（一个线程管多个连接）。快不是因为「单线程」，而是因为「内存 + 高效模型」。

2. **AOF vs RDB（第 4–5 讲）**：AOF 记录每条写命令（更安全、文件大），RDB 是内存快照（恢复快、可能丢数据）。生产常「AOF + RDB 混合」。

3. **缓存三兄弟（第 26 讲，面试必考）**：穿透（查不存在→布隆过滤器/缓存空值）、击穿（热点 key 过期→互斥锁/不过期）、雪崩（大量 key 同时过期→过期时间加随机）。

4. **分布式锁（第 30 讲）**：SETNX + 过期时间 + 唯一值 + Lua 原子释放。坑：锁过期续期（看门狗）、主从切换丢锁（Redlock）。

5. **切片集群（第 9、35 讲）**：数据分到多个实例（Redis Cluster 哈希槽 16384 个），解决单机内存上限。

6. **秒杀实践（第 36 讲，精华）**：Redis 原子扣减库存 + 预扣 + Lua 脚本，把流量挡在数据库外。
