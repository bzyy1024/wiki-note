# 03 前缀篇：方向 · 位置 · 否定

> 本课目标：**掌握 43 个核心前缀**，让你一眼看出一个单词"往哪走、加不加否定、程度多深"。前缀是单词的"路牌"，数量少、规律强，是建立信心的第一站。

---

## 一、前缀是什么？一句话讲透

前缀（prefix）是**加在词根前面的"方向牌"**。它本身不决定单词的核心意思，但决定这个动作/状态**怎么发生**。

```
trans + port = transport    trans（跨越）+ port（搬）= 跨过去搬 = 运输
im  + port = import         im（向里）+ port（搬）= 往里搬 = 进口
ex  + port = export         ex（向外）+ port（搬）= 往外搬 = 出口
```

同一个词根 `port`（搬），换了三个前缀，意思就"搬"出了三个方向。**这就是前缀的威力。**

## 二、第一类：方向前缀（往哪走？）

### 1. 向里 / 向外

| 前缀 | 意思 | 案例 | 拆解 |
|------|------|------|------|
| in- / im- / il- / ir- | 向里（在……里） | import | im + port（搬）→ 往里搬 → 进口 |
| in- / im- | 向里 | invade | in + vade（走）→ 往里走 → 入侵 |
| e- / ex- / exo- | 向外 | exit | ex + it（走）→ 往外走 → 出口 |
| e- / ex- | 向外 | export | ex + port → 往外搬 → 出口 |
| extra- | 向外、超出 | extraordinary | extra + ordinary（寻常）→ 超出寻常 → 非凡的 |

> 🤔 **想一想**：为什么 `import` 的 `in` 会变成 `im`？答案是"同化"——因为后面 `port` 的首字母是唇音 `p`，`n` 为了好发音就变成了 `m`。同理，`illegal`（非法的）为什么是 `il` 不是 `in`？因为后面是 `l`。你能猜出 `irregular`（不规则的）里的 `ir` 是怎么来的吗？

### 2. 向上 / 向下 / 穿过 / 回来

| 前缀 | 意思 | 案例 | 拆解 |
|------|------|------|------|
| super- / sur- / supra- | 在上、超越 | superman | super + man → 超人 |
| sur- | 在上、超越 | surpass | sur + pass（过）→ 超过 |
| sub- / suc- / suf- / sus- / sup- | 在下、向下 | subway | sub + way（路）→ 地下的路 → 地铁 |
| sub- | 在下 | submarine | sub + marine（海的）→ 海下的 → 潜水艇 |
| trans- | 穿过、跨越 | transport | trans + port → 运输 |
| re- | 回、再 | return | re + turn（转）→ 转回来 → 返回 |
| retro- | 向后 | retrospect | retro + spect（看）→ 回头看 → 回顾 |

> 🤔 **想一想**：`sub` 这个前缀有五个分身（sub/suc/suf/sus/sup），它们都表示"在下"。你能不能用"同化"的道理，解释为什么 `succeed`（suc+ceed）、`support`（sup+port）、`suspect`（sus+spect）里的 `sub` 都变样了？

### 3. 之间 / 向内 / 周围

| 前缀 | 意思 | 案例 | 拆解 |
|------|------|------|------|
| inter- | 在……之间 | international | inter + national（国家的）→ 国家之间的 → 国际的 |
| inter- | 在……之间 | interact | inter + act（行动）→ 相互行动 → 互动 |
| intro- / intra- | 向内、内部 | introduce | intro + duce（引导）→ 往内引导 → 介绍 |
| circum- | 周围、环绕 | circumstance | circum + stance（站）→ 站在周围 → 环境、情况 |
| peri- | 周围 | perimeter | peri + meter（测量）→ 四周的测量 → 周长 |

> 🤔 **想一想**：`inter-` 和 `intra-` 就差一个字母，意思却一个"之间"一个"内部"。`interstate`（州际的）和 `intrastate`（州内的）意思完全不同，你能分别说出它们吗？

## 三、第二类：否定前缀（加不加"不"？）

这是考试里最常考、也最好拿分的一类。掌握它们，阅读里的"反义词"就全看穿了。

| 前缀 | 意思 | 案例 | 拆解 |
|------|------|------|------|
| un- | 不 | unhappy | un + happy → 不开心 |
| in- / im- / il- / ir- | 不、无 | invisible | in + visible（看得见的）→ 看不见的 |
| im- | 不 | impossible | im + possible（可能的）→ 不可能的 |
| non- | 非、不 | nonsense | non + sense（意义）→ 无意义、胡说 |
| dis- / dif- | 不、分离、相反 | disagree | dis + agree（同意）→ 不同意 |
| dis- | 分离 | disappear | dis + appear（出现）→ 消失 |
| mis- | 错误 | misunderstand | mis + understand → 误解 |
| anti- | 反对、抗 | antibiotic | anti + bio（生命）+ tic → 抗生命的 → 抗生素 |
| contra- / counter- | 反对、相反 | contradict | contra + dict（说）→ 反对着说 → 反驳 |
| dys- | 不良、异常 | dysfunction | dys + function（功能）→ 功能失常 |
| mal- | 坏、恶 | malfunction | mal + function → 失灵 |
| de- | 去除、向下、相反 | decode | de + code（密码）→ 去掉密码 → 解码 |
| apo- | 离开、脱离 | apology | apo + log（说）→ 说开、说脱 → 道歉 |

> 🤔 **想一想**：`un-` 和 `in-` 都表示"不"，那 `unable` 和 `inability` 有什么区别？提示：`able` 是形容词，`ability` 是名词——**不同的否定前缀，往往搭配不同的词根/词性**。这就是前缀和后缀的"联动"。

## 四、第三类：程度与数量前缀（多强？多少？）

### 1. 程度（高低、大小、强弱）

| 前缀 | 意思 | 案例 | 拆解 |
|------|------|------|------|
| hyper- | 过度、超出 | hypertension | hyper + tension（压力）→ 高血压 |
| hypo- | 低于、不足 | hypodermic | hypo + derm（皮肤）+ ic → 皮下（注射）的 |
| ultra- | 极端、超越 | ultraviolet | ultra + violet（紫色）→ 超出紫色的 → 紫外线 |
| over- | 过度、在上 | overestimate | over + estimate（估计）→ 高估 |
| under- | 不足、在下 | underestimate | under + estimate → 低估 |
| super- / sur- / supra- | 超级、在上 | supermarket | super + market（市场）→ 超级市场 |
| micro- | 微小 | microscope | micro + scope（看）→ 看微小之物 → 显微镜 |
| macro- | 宏大 | macroeconomics | macro + economics → 宏观经济学 |
| mini- | 小 | miniskirt | mini + skirt → 迷你裙 |
| mega- | 巨大 | megacity | mega + city → 巨型城市 |

> 🤔 **想一想**：`hyper-` 和 `hypo-` 只差一个字母，意思却完全相反（过度 vs 不足）。医生说的"甲亢"是 `hyperthyroidism`，"甲减"是 `hypothyroidism`。你能用前缀把它们区分开吗？

### 2. 数量（多少、单双、全）

| 前缀 | 意思 | 案例 | 拆解 |
|------|------|------|------|
| mono- / uni- | 单一 | monopoly | mono + poly（卖）→ 一个人卖 → 垄断 |
| uni- | 单一 | uniform | uni + form（形式）→ 统一形式 → 制服 |
| bi- / di- / twi- | 二 | bicycle | bi + cycle（轮）→ 两个轮 → 自行车 |
| di- | 二 | dioxide | di + oxide（氧化物）→ 二氧化物 |
| tri- | 三 | triangle | tri + angle（角）→ 三角形 |
| multi- / poly- | 多 | multimedia | multi + media → 多媒体 |
| poly- | 多 | polygon | poly + gon（角）→ 多角形 |
| semi- / hemi- / demi- | 半 | semicircle | semi + circle → 半圆 |
| pan- / omni- / holo- | 全、遍 | panorama | pan + orama（视野）→ 全景 |
| omni- | 全 | omnipotent | omni + potent（有力）→ 全能的 |

> 🤔 **想一想**：`monopoly`（垄断）里的 `poly` 是"卖"的意思（和"多"无关哦）。那 `monopoly` 为什么是"垄断"？因为"**一个人**卖"= 独家经营。而 `polygon` 里的 `poly` 才是"多"。**同一个字母组合，在不同单词里可能是完全不同的零件**——这提醒我们，拆词要看"位置和语境"。

## 五、第四类：时间与关系前缀

### 1. 时间（先后、新旧）

| 前缀 | 意思 | 案例 | 拆解 |
|------|------|------|------|
| pre- | 在……之前 | preview | pre + view（看）→ 提前看 → 预览 |
| post- | 在……之后 | postwar | post + war（战争）→ 战后的 |
| fore- | 在前、预先 | forecast | fore + cast（投）→ 提前投出 → 预报 |
| ante- | 在……之前 | antecedent | ante + cedent（走）→ 走在前面的 → 前例 |
| pro- | 向前、赞成 | progress | pro + gress（走）→ 向前走 → 进步 |
| proto- | 原始、最初 | prototype | proto + type（型）→ 原型 |
| neo- | 新 | neologism | neo + log（词）+ ism → 新造的词 |
| paleo- | 古老 | paleontology | paleo + ontology → 古生物学 |

> 🤔 **想一想**：`pre-` 和 `pro-` 都带"前"的意思，但一个偏"时间在前"（before），一个偏"向前推进/赞成"（forward）。`prescribe`（提前写下来→开药方、规定）和 `propose`（向前放→提议），你能体会这细微差别吗？

### 2. 关系（共同、自己、分离、透过）

| 前缀 | 意思 | 案例 | 拆解 |
|------|------|------|------|
| com- / con- / co- | 一起、共同 | cooperate | co + operate（运作）→ 一起运作 → 合作 |
| con- | 一起、加强 | connect | con + nect（绑）→ 绑在一起 → 连接 |
| syn- / sym- | 共同、相同 | symphony | sym + phony（声音）→ 一起发声 → 交响乐 |
| sym- | 共同 | sympathy | sym + pathy（感情）→ 相同的感情 → 同情 |
| auto- | 自己 | automatic | auto + matic（动的）→ 自己动 → 自动的 |
| hetero- | 异、不同 | heterogeneous | hetero + geneous（种类）→ 异质的 |
| homo- | 同 | homogeneous | homo + geneous → 同质的 |
| per- | 穿过、彻底 | perfect | per + fect（做）→ 彻底做完 → 完美的 |
| se- | 分离 | separate | se + par（分开）+ ate → 分开 → 分离 |
| eu- | 好、优 | eulogy | eu + logy（说）→ 说好话 → 颂词 |

> 🤔 **想一想**：`sympathy`（同情）和 `symphony`（交响乐）都带 `sym`（共同），为什么一个成了"情感"，一个成了"声音"？答案在**词根**：`pathy` 是"感情"，`phony` 是"声音"。这再次证明——**前缀定方向，词根定核心**。
