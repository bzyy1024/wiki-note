# 08 词根篇四：度量 · 时空 · 数量

> 本课目标：**攻克"时间、空间、数量、度量"词族**——时、年、月、日、地、水、光、星、二、三、十百千、多、少、大、小、变、新…… 学完这门课，88 个词族全部到齐，你也就掌握了整套词根体系。

---

## 一、开场：时间都去哪了？

> 👩‍🏫 **老师**：`time` 是"时间"，但英语里表示"时间"的**词根**，却是 `chron`。你猜猜 `chronic`（慢性的）、`synchronize`（同步）、`chronicle`（编年史）有什么共同点？
>
> 👨‍🎓 **小白**：都和时间有关？`chron` 是"时间"。
>
> 👩‍🏫 **老师**：对。记住 `chron`，这一族词就都通了。

## 二、重点词族精讲

### 词族 1：「时间、年、日」—— chron / ann / temp / di

**核心词根**：`chron`（时间）、`ann/enn`（年）、`temp`（时间）、`di/die`（日）

| 单词 | 拆解 | 意思 |
|------|------|------|
| chronic | chron + ic | 长时间的 → 慢性的 |
| synchronize | syn（相同）+ chron + ize | 使时间相同 → 同步 |
| chronicle | chron + icle | 按时间记录 → 编年史 |
| annual | ann + ual | 每年的 |
| anniversary | ann + i + vers（转）+ ary | 每年转回来 → 周年纪念 |
| temporary | temp + orary | 一时的 → 临时的 |
| diary | di + ary | 按日记录 → 日记 |

> 🤔 **想一想**：`anniversary`（周年纪念）拆开是"**年 + 转 + 回来**"——时间转了一圈，又回到这一天。这个画面感，是不是比"周年纪念"四个字好记得多？

### 词族 2：「地、球、人」—— terr / geo / hum

**核心词根**：`terr`（土地）、`geo`（地球）、`hum`（土、人）

| 单词 | 拆解 | 意思 |
|------|------|------|
| territory | terr + itory | 领土 |
| terrain | terr + ain | 地形 |
| geography | geo + graphy（写） | 描写地球 → 地理学 |
| geology | geo + logy（学） | 地质学 |
| human | hum + an | 尘土造的人 → 人类 |
| humble | hum + ble | 低到尘土 → 谦卑的 |

> 🤔 **想一想**：`human`（人）和 `humble`（谦卑）同根，都源于 `hum`（土）。为什么"人"和"土"有关？——因为在很多古老传说里，**人是神用泥土捏成的**。所以"谦卑"就是"低到尘埃里"。而 `territory`（领土）就是"**属于你的土地**"。

### 词族 3：「水」—— aqu / mar / hydr / flu

**核心词根**：`aqu`（水）、`mar`（海）、`hydr`（水）、`flu/flux`（流）

| 单词 | 拆解 | 意思 |
|------|------|------|
| aquarium | aqu + arium（场所） | 水族馆 |
| aquatic | aqu + atic | 水生的 |
| marine | mar + ine | 海洋的 |
| submarine | sub（下）+ marine | 海下的 → 潜水艇 |
| hydrogen | hydr + gen（产生） | 产生水（的气体）→ 氢 |
| dehydrate | de（去除）+ hydr + ate | 脱水 |
| fluent | flu + ent | 流动的 → 流利的 |
| influence | in + flu + ence | 流入 → 影响 |

> 🤔 **想一想**：`influence`（影响）字面是"**流入**"。为什么"流入"会变成"影响"？——因为影响就像水流，悄无声息地"流进"你的思想。还有 `fluent`（流利的）——说话像流水一样顺畅，就是"流利"。

### 词族 4：「光、神、星」—— luc / phot / astr / sider

**核心词根**：`luc/lum`（光）、`phot`（光）、`astr/stell`（星）、`sider`（星）

| 单词 | 拆解 | 意思 |
|------|------|------|
| lucid | luc + id | 发光的 → 清晰的 |
| illuminate | il（向）+ lumin + ate | 照进光 → 照亮、阐明 |
| photo | phot + o | 光 → 照片 |
| photograph | phot + o + graph（写） | 光写下的 → 照片 |
| astronomy | astro + nomy（法则） | 研究星球的法则 → 天文学 |
| astronaut | astro + naut（航行） | 星际航行者 → 宇航员 |

> 🤔 **想一想**：`lucid`（清晰的）为什么是"光"？——因为"清晰"就是"**看得透亮**"，像光一样明白。所以 `illuminate` 既是"照亮"又是"阐明"——把道理讲明白，就是给别人的脑子"照进一道光"。

### 词族 5：「数量」—— bi / tri / dec / cent / mill / mult

**核心词根**：`bi/di/du`（二）、`tri`（三）、`dec`（十）、`cent`（百）、`mill/kilo`（千）、`mult`（多）

| 单词 | 拆解 | 意思 |
|------|------|------|
| bicycle | bi + cycle（轮） | 两个轮 → 自行车 |
| dioxide | di + oxide（氧化物） | 二氧化物 |
| triangle | tri + angle（角） | 三角形 |
| decade | dec + ade | 十年 |
| century | cent + ury | 一百年 → 世纪 |
| percent | per（每）+ cent | 每一百 → 百分比 |
| million | mill + ion | 百万 |
| kilogram | kilo + gram | 千克、公斤 |
| multiple | mult + iple | 多倍的 |

> 🤔 **想一想**：`percent`（百分比）字面是"**每一百**"。所以 50% 就是"每一百里有五十"。这个逻辑，比死记"百分比"清楚多了。你能用 `dec`（十）猜出 `decimal`（小数）为什么和"十"有关吗？——因为小数是"**逢十进位**"的。

### 词族 6：「大、小、多、满」—— magn / min / plen / sat

**核心词根**：`magn/maj`（大）、`min/mini`（小）、`plen/plet/ply`（满）、`sat`（足、饱）

| 单词 | 拆解 | 意思 |
|------|------|------|
| magnify | magn + ify（使） | 使变大 → 放大 |
| major | maj + or | 较大的 → 主要的、专业 |
| minute | min + ute | 极小的 → 分钟（很小的单位） |
| minimum | min + imum | 最小量 |
| complete | com + plete | 完全填满 → 完成 |
| supply | sup + ply | 补满 → 供应 |
| satisfy | sat + isfy | 使满足 |

> 🤔 **想一想**：`minute` 既是"分钟"又是"极小的"，这俩意思怎么统一？——因为"一分钟"是"**极小的一段时间**"。而 `complete`（完成）字面是"**填满**"——做完了，就是"填满了空缺"。

### 词族 7：「变、新、多」—— mut / vari / nov / neo

**核心词根**：`mut`（改变）、`vari`（变化）、`nov`（新）、`neo`（新）

| 单词 | 拆解 | 意思 |
|------|------|------|
| mutate | mut + ate | 变异、突变 |
| mutual | mut + ual | 互相（你来我往）的 |
| commute | com + mute | 来回交换 → 通勤 |
| vary | vari | 变化 |
| various | vari + ous | 各种各样的 |
| novel | nov + el | 新的 → 小说、新奇的 |
| innovate | in + nov + ate | 引入新东西 → 创新 |

> 🤔 **想一想**：`commute`（通勤）字面是"**互相交换**"——你每天在"家"和"公司"之间来回换，这就是通勤。而 `novel`（小说）本义是"**新的**"——因为小说讲的是"新奇的、虚构的故事"。

### 词族 8：「关、界、结」—— clud / fin / term

**核心词根**：`clud/clus`（关闭）、`fin`（边界、结束）、`term`（边界、终点）

| 单词 | 拆解 | 意思 |
|------|------|------|
| include | in（里）+ clude | 关在里面 → 包含 |
| exclude | ex（外）+ clude | 关在外面 → 排除 |
| conclude | con + clude | 关闭（话题）→ 下结论 |
| finish | fin + ish | 结束 |
| define | de（加强）+ fine | 划出边界 → 定义 |
| infinite | in（无）+ finite | 没有边界 → 无限的 |
| terminate | term + inate | 到终点 → 终止 |

> 🤔 **想一想**：`define`（定义）字面是"**划出边界**"。定义一件事，就是给它"划清边界"——什么算、什么不算。而 `infinite`（无限的）就是"**没有边界**"。这俩词，一个是"划界"，一个是"无界"，完美呼应。

### 词族 9：「转、弯」—— vers / vert / volv / clin / flect

**核心词根**：`vers/vert`（转）、`volv/volut`（卷、转）、`clin`（倾斜）、`flect/flex`（弯）

| 单词 | 拆解 | 意思 |
|------|------|------|
| version | vers + ion | 转出来的版本 → 版本 |
| convert | con + vert | 完全转过来 → 转变、皈依 |
| reverse | re（回）+ verse | 转回去 → 颠倒、逆转 |
| evolve | e（向外）+ volve | 向外展开 → 进化 |
| involve | in + volve | 卷入 → 涉及 |
| reflect | re（回）+ flect | 弯回来 → 反射、反思 |
| flexible | flex + ible | 可弯的 → 灵活的 |

> 🤔 **想一想**：`evolve`（进化）字面是"**向外展开**"——生命一点点"展开"成更复杂的形态，就是进化。而 `reflect`（反思）是"**弯回来**"——把目光"折回"到自己身上，就是反思。

### 词族 10：「升、强、用」—— lev / val / us

**核心词根**：`lev`（升起）、`val/vail`（力量、价值）、`us/ut`（用）

| 单词 | 拆解 | 意思 |
|------|------|------|
| elevate | e（向外）+ lev + ate | 升起 → 提升、抬高 |
| lever | lev + er | 升起用的 → 杠杆 |
| value | val + ue | 价值 |
| valid | val + id | 有力的 → 有效的 |
| prevail | pre + vail | 力量占上风 → 盛行、获胜 |
| use | us | 使用 |
| utility | ut + ility | 有用性 → 实用、公用事业 |

> 🤔 **想一想**：`valid`（有效的）本义是"**有力的**"。为什么"有力"会变成"有效"？——因为一份"有力"的合同、证件，才是"有效"的。所以"有效期"本质是"**仍有法律效力**"的期限。

## 三、其余度量时空词族速查表

| 词族 | 核心词根 | 代表词 | 字面逻辑 |
|------|---------|--------|---------|
| 满、饱、多 | plen/plet/ply, sat | plenty（充足）、satisfy（使满足） | 满 |
| 部分、分配 | part, tribut | participate（参与）、contribute（贡献） | 分 |
| 钱、买卖 | merc, vend | commerce（商业）、vendor（小贩） | 交易 |
| 形状 | form, morph | conform（一致）、transform（变形） | 形 |
| 接触、摸 | tact/tang | contact（接触）、tangible（可触摸的） | 摸 |
| 单、聚 | mon/mono, greg | monopoly（垄断）、aggregate（聚集） | 单、聚 |
| 岛、隔绝 | insul, isol | island（岛）、isolate（隔离） | 岛 |
| 产生、带来 | gen, nat, duc/duct | produce（生产）、introduce（引进） | 生出、引导 |
| 根、辐射 | rad/radic, radi | radical（根本的）、radiate（辐射） | 根 |
| 二分之一 | semi/hemi/demi | semicircle（半圆）、hemisphere（半球） | 半 |

> 🤔 **想一想**：`contribute`（贡献）字面是"**分给**"（con 一起 + tribut 分）。所以"贡献"就是"把自己的一份分出去"。而 `tangible`（可触摸的）源于 `tang`（摸）——摸得到的，才是"实实在在的"。那 `intangible`（无形的）呢？
