# 06 词根篇二：看听说与心智

> 本课目标：**攻克"用眼、用脑、用心"的词族**——看、听、显示、知道、问、选、相信、想、爱、怕、愿…… 这些词根覆盖了阅读、写作、考试中最核心的心智类词汇。

---

## 一、开场：你每天都在"看"，但你真的会"看"吗？

> 👩‍🏫 **老师**：`look`、`see`、`watch`、`stare`、`glance` 都是"看"，但英语里表示"看"的**词根**却另有其人。
>
> 👨‍🎓 **小白**：谁？
>
> 👩‍🏫 **老师**：`vis/vid` 和 `spec/spect`。这两个词根，一个"看见"，一个"仔细看"，撑起了上百个高级词汇。

---

## 二、重点词族精讲

### 词族 1：「看」—— vis / vid / spec / spect

**核心词根**：`vis/vid`（看见）、`spec/spect`（看、观察）

| 单词 | 拆解 | 意思 |
|------|------|------|
| visible | vis + ible（可） | 看得见的 |
| vision | vis + ion | 视力、愿景 |
| visit | vis + it | 去看 → 拜访 |
| video | vid + eo | 看的 → 视频 |
| evidence | e（向外）+ vid + ence | 摆出来看 → 证据 |
| inspect | in（向里）+ spect | 往里看 → 检查 |
| respect | re（回）+ spect | 回头看 → 尊重 |
| spectator | spect + ator（人） | 看的人 → 观众 |
| prospect | pro（向前）+ spect | 向前看 → 前景、展望 |

> 🤔 **想一想**：`respect`（尊重）的字面意思是"**回头看**"。为什么"回头看"会变成"尊重"？——因为你会回头看的人，是你在意、敬重的人。而 `inspect`（检查）是"往里看"。**同一个"看"，配上不同前缀，就成了完全不同的词。**

### 词族 2：「听」—— audi / son

**核心词根**：`audi`（听）、`son`（声音）

| 单词 | 拆解 | 意思 |
|------|------|------|
| audio | audi + o | 音频 |
| audience | audi + ence | 听的人 → 听众、观众 |
| audible | audi + ble（可） | 听得见的 |
| auditorium | audi + torium（场所） | 听的地方 → 礼堂 |
| sound | son | 声音 |
| unison | uni（同一）+ son | 同一个声音 → 齐声、一致 |

> 🤔 **想一想**：`audience` 是"听众"，为什么很多场合也翻译成"观众"？——因为在现代，人们去"听"一场演出时，同时也在"看"。但它的词根 `audi` 清楚地告诉我们，**它的本义是"听"**。

### 词族 3：「显示」—— monstr / monst

**核心词根**：`monstr`（显示、指出）

| 单词 | 拆解 | 意思 |
|------|------|------|
| demonstrate | de（加强）+ monstr + ate | 清楚地指出来 → 演示、证明 |
| monster | monstr + er | 显眼的庞然大物 → 怪物 |

> 🤔 **想一想**：`demonstrate`（演示）和 `monster`（怪物）居然同源！"演示"是"把东西指给你看"，"怪物"是"显眼到让人害怕的东西"。**词根的世界，就是这么神奇。**

### 词族 4：「知道」—— sci / cogn / gnos

**核心词根**：`sci`（知道）、`cogn/gnos`（知道）

| 单词 | 拆解 | 意思 |
|------|------|------|
| science | sci + ence | 知识 → 科学 |
| conscious | con + sci + ous | 共同知道的 → 有意识的、自觉的 |
| conscience | con + sci + ence | 内心知道的 → 良心 |
| recognize | re（再）+ cogn + ize | 再次知道 → 认出、识别 |
| diagnose | dia（透过）+ gnose | 透过（症状）知道 → 诊断 |
| ignore | i（不）+ gnore | 不去知道 → 忽视 |

> 🤔 **想一想**：`conscience`（良心）和 `conscious`（有意识的）只差一个后缀，意思却一个是"名词"一个是"形容词"。你能说出 `-ence` 和 `-ous` 分别是什么后缀吗？（答案就在后缀篇里！）

### 词族 5：「问、要求」—— quir / quis / quest / pet

**核心词根**：`quir/quis/quest`（问、寻求）、`pet`（寻求、追求）

| 单词 | 拆解 | 意思 |
|------|------|------|
| question | quest + ion | 问题 |
| require | re + quire | 反复问 → 要求 |
| request | re + quest | 请求 |
| inquire | in + quire | 往里面问 → 询问、打听 |
| compete | com（一起）+ pete | 一起追求 → 竞争 |
| petition | pet + ition | 请求、请愿 |

> 🤔 **想一想**：`require`（要求）和 `request`（请求）都带"问"，但语气一个硬一个软。你能体会吗？——`require` 是"必须"，`request` 是"恳请"。这种细微差别，正是词根词缀法帮你在阅读中精准把握的。

### 词族 6：「选、收、读」—— lect / leg / lig

**核心词根**：`lect/leg/lig`（选择、收集、读）

| 单词 | 拆解 | 意思 |
|------|------|------|
| select | se（分开）+ lect | 挑出来 → 选择 |
| collect | col（一起）+ lect | 收在一起 → 收集 |
| elect | e（向外）+ lect | 选出来 → 选举 |
| lecture | lect + ure | 读（讲）的东西 → 讲座 |
| legend | leg + end | 被传读的故事 → 传说 |

> 🤔 **想一想**：`select`、`collect`、`elect` 三个词，词根都是 `lect`（选/收）。你能否用前缀把它们区分清楚？`se-` 是"分开"，`col-` 是"一起"，`e-` 是"向外"。

### 词族 7：「相信」—— cred / fid

**核心词根**：`cred`（相信）、`fid`（信任、信仰）

| 单词 | 拆解 | 意思 |
|------|------|------|
| credit | cred + it | 相信 → 信用、学分 |
| credible | cred + ible（可） | 可信的 |
| incredible | in（不）+ credible | 难以置信的 |
| confident | con + fid + ent | 完全相信（自己）→ 自信的 |
| fidelity | fid + elity | 忠诚 |

> 🤔 **想一想**：`credit` 既是"信用"又是"学分"还是"存款"。这三层意思怎么统一？——都源于"**别人相信你**"。你信用好，银行才敢借钱给你（存款/信用）；你表现好，老师才给你学分。**一个"信"字，串起三个意思。**

### 词族 8：「想」—— put / sider

**核心词根**：`put`（想、计算）、`sider`（星、考虑）

| 单词 | 拆解 | 意思 |
|------|------|------|
| compute | com（一起）+ pute | 一起算 → 计算 |
| dispute | dis（分开）+ pute | 想法不合 → 争论 |
| consider | con + sider | 一起看星 → 考虑 |
| desire | de + sire | 从星象中期待 → 渴望 |

> 🤔 **想一想**：`consider`（考虑）的词根是 `sider`（星）。为什么"考虑"和"星星"有关？——因为古人靠**观星**来做重大决定。所以"考虑"的本义就是"一起观星、思量"。

### 词族 9：「爱」—— am / phil

**核心词根**：`am`（爱）、`phil`（爱）

| 单词 | 拆解 | 意思 |
|------|------|------|
| amateur | am + ateur | 出于热爱做事的人 → 业余爱好者 |
| amiable | am + iable | 可爱的、亲切的 |
| philosophy | phil + o + sophy（智慧） | 爱智慧 → 哲学 |
| philanthropist | phil + anthrop（人）+ ist | 爱人类的人 → 慈善家 |

> 🤔 **想一想**：`amateur`（业余爱好者）和"职业选手"的区别，其实藏在词根里——`amateur` 是"**出于热爱**"做事的人，不为钱。你能从 `philosophy`（爱智慧）反推出 `soph` 是什么意思吗？

### 词族 10：「怕」—— terr / tim / phob

**核心词根**：`terr`（怕）、`tim`（怕）、`phob`（恐惧）

| 单词 | 拆解 | 意思 |
|------|------|------|
| terror | terr + or | 恐怖 |
| terrible | terr + ible | 可怕的 |
| timid | tim + id | 胆小的 |
| intimidate | in（使）+ timid + ate | 使害怕 → 恐吓 |
| phobia | phob + ia | 恐惧症 |

> 🤔 **想一想**：`terr` 既是"土地"（territory 领土）又是"害怕"（terror 恐怖），这俩有什么关系？其实它们是**两个不同的拉丁词源**，恰好拼写相同。这提醒我们——**拆词要看上下文，别硬套。**

## 三、其余心智类词族速查表

| 词族 | 核心词根 | 代表词 | 字面逻辑 |
|------|---------|--------|---------|
| 理由 | log, ratio | logic（逻辑）、rational（理性的） | 道理 |
| 名字、名望 | nomin/nom, onym, not | nominate（提名）、synonym（同义词）、notable（著名的） | 名字、标记 |
| 法、誓 | jur/jus, leg | justice（正义）、legal（合法的） | 法律、誓言 |
| 直、正、管 | rect/reg/rig, norm | correct（纠正）、regulate（管理）、normal（正常） | 直、规则 |
| 神圣、宗教 | sacr/sanct | sacred（神圣的）、sacrifice（献祭） | 神圣 |
| 否定 | neg, null | negative（否定的）、null（无效的） | 否认 |
| 测量 | meter/metr, mens | geometry（geo 地+metry 测→几何）、dimension（尺寸） | 测量 |
| 平等、复制 | equ, simil/simul | equal（平等）、similar（相似）、simulate（模拟） | 相同 |
| 另外、超 | ali/alter | alien（异域的）、alter（改变）、alternative（替代的） | 别的 |
| 中间 | medi/mid | medium（媒介）、medieval（中世纪的） | 中间 |
| 意愿 | vol, volunt | volunteer（志愿者）、voluntary（自愿的） | 意愿 |
| 尝试、冒险 | per/peri | experience（经验）、experiment（实验）、peril（危险） | 尝试 |
| 鄙视 | spis/spect | despise（鄙视）、despite（尽管） | 看不起 |
| 玩、不认真 | lud/lus | illusion（幻想）、ludicrous（荒唐的） | 玩耍 |

> 🤔 **想一想**：`alien`（外星人、异域的）和 `alter`（改变）、`alternative`（替代方案）都源于"别的/另一个"。你能看出"改变"和"另一个"的逻辑联系吗？——改变，就是变成"**另一个**"样子。
