# 01 认知篇：词根词缀的魔法

> 本课目标：**彻底转变你对"背单词"这件事的看法**。学完这一课，你会明白为什么过去背了十年单词还是记不住，以及为什么"拆词法"才是通往一万词的正道。

---

## 一、开场：一个小白和老师的故事

> 👨‍🎓 **小白**：老师，我背单词背了十年，还是只会 `good、bad、happy、sad`，我是不是没救了？
>
> 👩‍🏫 **老师**：先别急着给自己判死刑。我问你，`predict` 和 `dictionary` 这两个词，你认识吗？
>
> 👨‍🎓 **小白**：认识啊，`predict` 是"预测"，`dictionary` 是"字典"。
>
> 👩‍🏫 **老师**：好。那我现在告诉你一个秘密——**这两个词里，藏着一个一模一样的零件：`dict`，意思是"说"**。
>
> - `pre-dict`：pre（提前）+ dict（说）→ **提前把话说出来** → 预测
> - `dict-ionary`：dict（说）+ ionary（名词后缀）→ **收集各种"说法"的书** → 字典
>
> 👩‍🏫 **老师**：现在我再给你一个新词，你猜猜 `contradict` 什么意思？
>
> 👨‍🎓 **小白**：contra 是"反对"……那 `contradict` 是不是"**反对着说**"？就是"反驳、顶嘴"？
>
> 👩‍🏫 **老师**：完全正确！你看，**你从来没背过 `contradict`，但你把它猜出来了**。这就是词根词缀的魔法。

## 二、为什么你过去背单词是"白费力气"？

先做个实验。下面这个词，请你用你过去的方法背下来：

```
conscientious   [ˌkɒnʃiˈenʃəs]   形容词：认真负责的、勤勤恳恳的
```

是不是觉得：字母又多、读音又怪、意思还抽象？死记硬背的话，明天就忘。

现在，我们用"拆词法"再来一次：

| 拆解 | 部分 | 意思 |
|------|------|------|
| con | 前缀 | 一起、共同 |
| sci | 词根 | 知道（know） |
| ent | 后缀 | ……的人/……的 |
| ious | 后缀 | 形容词后缀（充满……的） |

`conscientious` = "内心**共同知道**（什么是对的）" → **凭着良知办事的** → 认真负责的。

**"凭良知办事"和"认真负责"之间，有一条逻辑线**。一旦你把这条线搭起来，这个单词就再也不容易忘了——因为你不是在背一串字母，而是在记一个**有道理的故事**。

## 三、单词是怎么被"造"出来的？

英语有个秘密：**大部分单词，尤其是难词、长词，都不是凭空冒出来的，而是古代人用"零件"拼出来的。**

这些"零件"主要来自拉丁语和希腊语。古代人拼词的逻辑，跟我们现在拼乐高一模一样：

```
核心零件（词根）：决定这个"乐高小人"是干什么的
修饰零件（前缀）：决定它往哪走、加不加否定、程度多深
身份零件（后缀）：决定它最后是个名词、动词还是形容词
```

所以，与其说英语有 100 万个单词，不如说英语只有 **几百个常用零件**，而这一百万个单词，就是这几百个零件**排列组合**出来的。

**你只要认识零件，就能"看穿"绝大多数生词。**

---

## 四、两大原则（这门课的魂）

### 原则一：意思靠词根，不靠"联想编故事"

网上有些"谐音记忆法"教你把 `pest`（害虫）记成"拍死它"，把 `ambulance`（救护车）记成"俺不能死"。这种记忆法**偶尔管用，但不能帮你打通一万词**，因为它是"一个词一条线"，而词根词缀是"一个零件一片天"。

词根词缀法的厉害之处在于：**学一个 `dict`（说），你同时解锁了 dictionary、predict、contradict、verdict、dictate、diction 一整个家族**。这才是"乘法"，不是"加法"。

### 原则二：先认"一级词根"，再认"二级词根"

有些词根超级高产，比如：

- `dict`（说）→ 造出上百个词
- `mit/miss`（送）→ 造出上百个词
- `spect`（看）→ 造出上百个词

这些叫**一级词根**，是这门课的绝对重点，必须滚瓜烂熟。

还有一些词根比较冷门，见一面混个眼熟即可。**别平均用力**——把 80% 的精力花在 20% 最高产的词根上，你的词汇量会以肉眼可见的速度膨胀。

<details>

## 六、思考题（别跳过，动脑才有记忆）

1. 为什么 `predict`（预测）和 `preview`（预览）都带 `pre-`？这个 `pre-` 是什么意思？
2. 如果你认识 `visible`（看得见的），你能猜出 `invisible` 的意思吗？这里的 `in-` 起什么作用？
3. 为什么说"背一个词根 = 背一百个单词"？试着用你自己的话说说这个道理。
4. 你觉得 `ambulance`（救护车）里面可能藏着一个和"走"有关的词根，你能猜出是哪个吗？（提示：`ambul`）

## 七、本课小结

| 要点 | 一句话 |
|------|--------|
| 单词 = 积木 | 单词是"前缀 + 词根 + 后缀"拼出来的 |
| 词根是心脏 | 词根决定核心意思，永远优先学 |
| 前缀是路牌 | 前缀决定方向、否定、程度 |
| 后缀是身份证 | 后缀决定词性（名/动/形/副） |
| 两大原则 | 意思靠词根；先攻一级词根 |
