# 《超越智商》——基思·斯坦诺维奇

一句话说破：**聪明人干蠢事，不是因为笨，是因为"智商"和"理性"是两回事。** 这本书最值钱的一个洞见是：智商测的是你脑子转得快不快，而理性测的是你**有没有用对方式去想**——这两件事几乎不相关。

斯坦诺维奇是加拿大认知科学家，他写这本书就是想纠正一个大众幻觉：以为高 IQ = 不会犯错。真相是，很多智商很高的人在投资、健康、人际关系上反复翻车，因为他们缺的是"理性"，不是"智力"。

## 它真正在讲什么

**1. 三重心智模型**
- **自主心智**：本能、直觉、快思考（系统 1）。省算力，但容易错。
- **算法心智**：工作记忆、处理速度——基本就是你 IQ 测的那部分。
- **反省心智**：能跳出直觉、按目标审视自己思路的那一层——这才是"理性"的所在地。

关键结论：**高 IQ 只保证算法心智强，不保证反省心智在线。** 一个物理学家可能因为"锚定效应"在谈判里吃亏，这和他的智商毫无关系。

**2. 两个"理性"**
- **工具理性（instrumental）**：你的行为有没有有效达成目标。
- **认识理性（epistemic）**：你的信念有没有尽量靠近真相。

很多人不是不够聪明，是既没想清楚自己要什么（工具理性弱），也没认真校验自己的判断是否靠谱（认识理性弱）。

**3. 为什么聪明人会不理性**
- **认知吝啬鬼（cognitive miser）**：大脑默认走最省力的捷径，哪怕捷径会错。理性需要主动"踩刹车"，而踩刹车消耗能量。
- **心智程序（mindware）污染**：你脑子里装了错误的心智模型（阴谋论、伪科学、赌徒谬误），再高的 IQ 也只是更快地推导出错误的结论。垃圾进，垃圾出。

**4. 好消息：理性可以练**
理性不像 IQ 那样基本是天生的，它更像"思维卫生"——通过学逻辑偏误、学概率直觉、建立反思习惯，可以明显提升。

## 它的边界（别盲信的地方）

- **书本身偏学术，有些章节在反复论证同一个观点**，读起来略枯燥，核心其实就上面几点。
- **它把"理性"描述得可训练，但训练方法给得偏原则性**——你知道"要踩刹车"和真的能在情绪上头时踩住，中间差着大量练习。
- **理性不是万能。** 很多重要决策（择偶、职业方向）涉及价值观和不可量化因素，理性只能帮你少犯低级错，不能替你回答"什么对我重要"。

## 对你（写代码、做技术决策的人）怎么用

这本书简直是工程师的"防蠢指南"：

- **警惕"认知吝啬鬼"在 code review / 选型时的偷懒。** 看到"大家都用 X"就跟着上，是典型走捷径。逼自己走一步反省：X 在我这个场景真的合适吗？有没有更朴素的方案？
- **检查你的"心智程序"有没有污染。** 比如"重写比修别人的代码快"（常常错）、"加机器能解决一切性能问题"（常常错）、"测试通过了就稳了"（常常错）。这些是错误的 mindware，要靠经验 + 复盘替换掉。
- **把"概率直觉"当基本功练。** 工程师天天和不确定性打交道：这个方案失败概率多大？这个告警是误报还是真故障？补一点贝叶斯和基率思维，比多背算法题更防翻车。
- **建立"踩刹车"的硬机制。** 别指望临场冷静。用 checklist、用"先写 RFC 再动手"、用"上线前必须有人复核"——把理性外化成流程，比依赖个人觉悟可靠。

一句话带走：**智商决定你跑多快，理性决定你跑不跑偏。大多数工程事故，不是算不过来，是压根没想对方向。**
