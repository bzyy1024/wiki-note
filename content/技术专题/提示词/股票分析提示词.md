# A股股票基本面分析提示词模板

你是一位专注基本面研究的A股投资分析师。请只分析中国A股上市公司，不分析美股、港股或其他市场。

请围绕以下股票进行系统性分析：

- 股票名称：{在这里替换股票名称}
- 股票代码：{在这里替换股票代码}

## 分析目标

从行业、商业模式、财务报表、多年业绩、竞争优势、风险、估值方法等维度，对这家公司做一份偏基本面的深度分析，帮助判断这家公司是否值得长期跟踪，以及当前价格区间是否具备研究价值。

## 输出结构

### 1. 公司基础信息

- 公司名称、股票代码、所属行业、主营业务
- 公司主要收入来源与利润来源是什么
- 用通俗语言说明：这家公司到底靠什么赚钱

### 2. 行业分析

- 所属行业当前处于什么阶段：成长、成熟、周期下行、周期上行、出清期，还是景气回升期
- 行业的市场空间有多大，未来3到5年增长逻辑是什么
- 请明确判断行业成长空间：当前渗透率、天花板、政策或技术驱动下的增量空间分别有多大
- 行业竞争格局如何：是否分散，是否龙头集中，是否存在价格战
- 请明确判断竞争程度：CR3/CR5集中度变化、进入壁垒高低、行业内价格战强度、替代品威胁
- 请单独给出行业周期位置判断：当前处于上行/下行/筑底/过热哪个阶段，并说明依据（价格、库存、开工率、产能利用率、订单、利差等）
- 请说明行业周期通常持续多久、历史上行与下行幅度如何、当前是否接近历史极值区间
- 行业的关键驱动因素是什么：政策、技术、消费升级、产能周期、原材料价格、利率、地产、出口等
- 这个行业适合用哪些核心指标观察，为什么
- 这个行业最大的风险是什么

### 3. 商业模式与核心竞争力

- 公司的商业模式是什么
- 它是靠品牌、渠道、规模、成本、技术、资源、牌照，还是管理效率赚钱
- 公司的核心护城河是什么
- 这种护城河是短期优势还是长期优势
- 公司相较同行的优势与劣势分别是什么
- 公司是否具备定价权、客户粘性、复购能力、规模效应或转换成本
- 请判断公司属于轻资产、重资产或中间型模式，并说明依据（固定资产与资本开支强度、折旧摊销占比、营运资本占用、现金转换周期等）

### 4. 财务报表深度分析

请结合最近5年至10年的数据，尽量从趋势而不是单一年份做判断。

- 营业收入：是否持续增长，增速是否稳定
- 归母净利润：是否持续增长，利润弹性如何
- 毛利率：是否稳定，是否说明公司有定价权
- 净利率：盈利质量如何，是否有改善趋势
- ROE：是否长期处于较好水平，是否依赖高杠杆
- 资产负债率：杠杆是否合理，偿债压力大不大
- 经营现金流：是否与净利润匹配，利润是否有“含金量”
- 自由现金流：公司是否真正能持续创造现金
- 存货、应收账款、预收款、合同负债等项目是否有异常变化
- 资本开支是否过高，是否影响未来回报
- 分红情况：分红率、股息率、分红稳定性如何
- 资产结构：固定资产/在建工程/无形资产占比变化，判断资产模式是否在演变（轻转重或重转轻）
- 请用杜邦分析拆解ROE：净利率、总资产周转率、权益乘数（杠杆）三项分别贡献了多少
- 请明确公司盈利更依赖哪一项：高杠杆、高利润率还是高周转；并判断这种驱动是否可持续

请特别说明：

- 哪些财务指标最值得重点关注
- 哪些财务数据可能存在表面好看但实际质量一般的问题
- 公司财务上最强的点和最弱的点分别是什么
- 若ROE较高，请说明是经营质量改善驱动，还是杠杆放大驱动，避免只看单一ROE结论
- 结合资产模式说明其优缺点：轻资产是否更易扩张、重资产是否受制于资本开支与周期波动

### 5. 多年经营质量分析

- 结合5年至10年的历史表现，分析公司业绩增长是稳定增长、周期波动、还是阶段性爆发
- 公司过去的增长主要来自提价、放量、扩产、并购、行业红利，还是一次性因素
- 如果历史业绩很好，请判断其可持续性
- 如果历史业绩波动较大，请说明核心原因
- 公司未来业绩增长最关键的变量是什么
- 请拆分公司业绩中“周期贡献”和“公司能力贡献”：顺周期受益、逆周期韧性、穿越周期能力分别如何

### 6. 管理层与资本配置

- 管理层是否稳定，战略是否清晰
- 管理层过去的决策质量如何
- 公司是更偏激进扩张，还是稳健经营
- 资本配置能力如何：分红、回购、并购、扩产、研发投入是否合理
- 是否存在大股东减持、频繁融资、商誉过高、关联交易较多等需要警惕的问题

### 7. 风险分析

- 行业风险
- 政策风险
- 周期风险
- 技术替代风险
- 原材料成本波动风险
- 竞争加剧风险
- 财务风险
- 公司治理风险

请明确说明：

- 哪些风险是短期风险
- 哪些风险会影响长期逻辑
- 哪些风险一旦发生，会直接改变投资判断
- 请加入周期下行情景压力测试：在价格下跌/需求下滑/成本上升情境下，对收入、利润、现金流和估值的影响区间

### 8. 估值分析

请根据公司所属行业和商业模式，选择最合适的估值方法，不要机械地只用一种方法。

可选估值方法包括但不限于：

- PE估值
- PB估值
- PEG估值
- DCF估值
- EV/EBITDA估值
- 股息率估值
- 周期股的历史中枢估值法

请按以下要求展开：

- 为什么这个行业和这家公司适合用该估值方法
- 给出估值公式
- 明确各变量含义
- 给出保守、中性、乐观三种估值情景
- 给出对应的合理估值区间
- 如果当前价格高于合理区间、接近合理区间或低于合理区间，请明确说明

如果采用多个估值方法，请做交叉验证，并说明不同估值结果为什么会有差异。

### 9. 投资价值总结

请最终总结以下问题：

- 这家公司值不值得长期跟踪
- 这家公司最核心的投资逻辑是什么
- 这家公司最大的护城河是什么
- 这家公司最容易被市场高估或低估的点是什么
- 这家公司当前最大的风险点是什么
- 什么情况下可以考虑买入
- 什么情况下应该放弃关注

### 10. 最终结论

请以表格形式输出以下内容：

- 公司名称
- 行业分类
- 核心看点
- 主要风险
- 关键财务特征
- 资产模式分类（轻资产 / 重资产 / 中间型）
- 盈利驱动类型（高杠杆 / 高利润 / 高周转）
- 周期属性与位置（强周期 / 弱周期 / 逆周期；上行 / 下行 / 筑底 / 过热）
- 适合的估值方法
- 合理估值区间
- 当前所处判断：低估 / 合理 / 偏高估 / 无法判断
- 投资者应重点跟踪的3个后续指标

- 如果涉及估值公式，请使用Markdown格式清晰展示，必要时可用代码块单独展示公式

- 不要只罗列概念，要给出判断逻辑

- 如果某些数据无法确认，请明确写“数据待核实”，不要编造

## 可选增强（建议优先使用）

如需更聚焦“成长空间 + 竞争强度 + 盈利驱动”，请在分析中增加一个单独小节：

### 11. 三个关键判断（必须回答）

- 成长空间判断：
	- 公司未来3到5年的主要增长来自哪里（渗透率提升、提价、份额提升、品类扩张、出海等）
	- 增长天花板在哪，最可能先触及的瓶颈是什么
- 竞争程度判断：
	- 公司所处赛道是“强竞争/中竞争/弱竞争”哪一类，依据是什么
	- 公司相对同行是“抢份额”还是“守利润”，是否有持续价格战风险
- 盈利驱动判断：
	- 结论必须三选一或组合：主要靠高杠杆、主要靠高利润、主要靠高周转
	- 给出证据（近5到10年趋势）并判断可持续性
	- 明确触发结论反转的关键指标
