# no-magic 交互式中文教程

这是基于 [no-magic](https://github.com/no-magic-ai/no-magic) 仓库创建的对话式中文学习教程。

## 🎯 教程特色

- **对话式教学**：通过苏格拉底式问答构建直觉，而非单向讲解
- **概念优先**：重点解释"为什么"和"权衡取舍"，而非代码细节
- **完整覆盖**：涵盖47个AI/ML核心算法
- **多路径学习**：支持线性阅读、模块化跳转、按轨道学习
- **独立自足**：无需查看原代码仓库，教程内含所有必要内容

## 🎓 学习建议

1. **不要死记硬背**：重点是建立直觉，而非记公式
2. **主动思考**：看"导师"回答前，先自己想
3. **动手实践**：运行代码片段，修改参数观察变化
4. **连接应用**：思考算法解决什么实际问题
5. **关注演化**：理解算法间的继承关系
