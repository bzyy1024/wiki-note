## 内核架构总览

```
┌─────────────────────────────────────────────────────────┐
│                    用户程序 (Ring 3)                       │
│                  通过INT 0x80系统调用                      │
├─────────────────────────────────────────────────────────┤
│                     系统调用接口                          │
│              exit | write | read | yield                │
├────────────┬────────────┬────────────┬──────────────────┤
│  进程管理   │  内存管理   │  设备驱动   │  调度器           │
│  PCB       │  PMM(位图)  │  VGA屏幕   │  Round-Robin     │
│  创建/销毁  │  VMM(分页)  │  PS/2键盘  │  上下文切换       │
├────────────┴────────────┴────────────┴──────────────────┤
│              中断/异常处理 (IDT + PIC + PIT)               │
├─────────────────────────────────────────────────────────┤
│     GDT | TSS | 保护模式                                  │
├─────────────────────────────────────────────────────────┤
│         Bootloader (实模式 → 保护模式 → 内核)              │
└─────────────────────────────────────────────────────────┘
```

## 扩展方向

### 短期扩展（难度：中等）

1. **简单Shell**: 基于键盘输入实现命令行界面
2. **内存堆管理器**: 替换bump allocator为真正的malloc/free
3. **定时器优化**: 实现sleep()和精确计时
4. **串口输出**: 用于调试和日志

### 中期扩展（难度：较高）

5. **文件系统**: 实现FAT12/FAT16文件系统
6. **磁盘驱动**: ATA/IDE硬盘读写
7. **高半内核**: 将内核映射到3GB处
8. **ELF加载器**: 从"磁盘"加载用户程序
9. **信号机制**: 进程间信号通信

### 长期目标（难度：高）

10. **网络栈**: 实现TCP/IP协议栈
11. **图形界面**: VGA图形模式、窗口管理器
12. **SMP支持**: 多核CPU支持
13. **64位模式**: 切换到Long Mode
14. **UEFI启动**: 替换BIOS引导
