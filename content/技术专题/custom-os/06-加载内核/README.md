# 第6章：加载C内核

> 从汇编跳转到C语言编写的内核

## 学习目标

1. 理解C运行时环境的建立
2. 编写最小的C语言内核
3. 掌握链接脚本的使用
4. 创建完整的构建流程（汇编+C+链接）

## 预计时间

⏱️ 3-4小时

## 前置要求

- 完成 [05-进入保护模式](../05-进入保护模式/README.md)

## 本章成果预览

```
Started in 16-bit Real Mode
Kernel loaded into memory
Hello from C kernel!
```

第一行和第二行由16位Bootloader打印，第三行由C语言内核输出！
