# 第3章：BIOS与启动过程

> 理解计算机如何启动，编写并运行第一个引导扇区代码

## 学习目标

1. 理解按下电源后计算机的启动过程
2. 了解BIOS的职责和工作方式
3. 理解MBR（主引导记录）的结构
4. 编写并运行第一个引导扇区程序

## 预计时间

⏱️ 2-3小时

## 前置要求

- 完成 [01-环境准备](../01-环境准备/README.md)
- 阅读 [02-基础知识](../02-基础知识/README.md)

## 本章成果预览

完成本章后，你将在QEMU中看到自己编写的代码被执行——屏幕上显示字符 'A'：

```
SeaBIOS (version ...)
Booting from Hard Disk...
A
```

这是你的第一个操作系统代码！
